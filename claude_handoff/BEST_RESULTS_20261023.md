## 4. 已确立的机制结论
1. **码容量密度**：精度取决于 64 个块里有多少落在房子上。更多 bit / 坐标没用：16 bit 时表示上限不变。矩形图幅的额外增益不显著。
2. **数据**：600 → 7,200 套户型带来 +5 到 +10 pp；到 14,400 套基本饱和。
3. **训练长度**：第二个周期 +2.4 pp，第三个周期 +1.0 / +1.3 pp，收益在减半。
5. **解码器容量**：×2 通道在 Q 预算 +2.2 / +1.6 pp，三周期后 +1.2 / +0.8 pp（ambiguous，但 8 组配对全正）；码级嵌入（符号读法）有害（−1.0 / −5.7 pp）；分析-综合编码 K0 +3 但 R8 −1（编码器侧排除）。
6. **公共帧条件化**（解码器知道像素尺度与块相位）：Q 预算 +1.8 / +1.0 pp（ambiguous），增益随图幅单调上升，8+ 室 +2–4 pp；零成本。
4. **融合无损**：最大精度选择与"直接编码并集观测"相差 ≤ 0.4 pp。

## 5. 如实说明的限制
- 贴合图幅取户型外接框，相当于假设建筑轮廓已知；可部署版本（对观测外接框做共识）尚未实现。
- 像素尺度随户型变化：每个户型在自己的原生栅格上评估。
- 单次运行噪声约 ±1–2 pp。
- 8 室以上大户型（R8 .82–.87）接近 64 维的容量边界。
- 与 README 第 8 节的强无损增量 raw 对照相比，压缩优势仍有限，且质量未匹配；没有全过程 100× 的证据。
