## 0. 执行摘要（5 行）

1. **码装的不是"位置"而是"足迹密度"**：3S-W 编码器输出的 μ 与块内已知空闲体素比例的 Spearman 相关 .95（四个竖直带 .93–.97），与块内有无墙的相关 −.08；q 与覆盖率相关 .77。墙在块内的位置（偏移在 16 格内几乎均匀分布，3.98 bit）基本不在码里，这就是内墙召回 .1–.29 的直接原因。
2. **容量不是瓶颈，语义才是**：K0 每条消息有效载荷 ≈ 78 个带证据的块 × 16 bit ≈ 1,250 bit；一个 agent 的墙平面图只需 ≈ 73 bit（11 个含墙块 × 6.45 bit），并集 ≈ 180–250 bit；但观测**足迹**（known 轮廓 11.7 bit/块 + 竖直剖面 5.8 bit/列 × 2,900 列 ≈ 17 kbit）远超载荷，known-BCE 把码逼成了足迹的 8-bit 密度摘要。
3. **融合损失（R8 − K0 = −6 到 −9 pp）主要是 q 排序问题，不是 join 本身**：max-q 选中的源只覆盖并集已知体素的 .83（覆盖最优源 .93），58 %（3S-W）/ 37 %（3S-C）的争议块选到覆盖最大的源。只在评估时把选源键换成块覆盖率（码、线路、解码器全不动），R8 表面 +3.4 / +4.0 pp、可变结构 +4.7 / +5.7 pp（3S-W / 3S-C，24 个 TRAIN 场景），达到 D4-10 式"理想同态"上界的 76 % / 90 %。
4. **2.5-D 分配是杠杆**（3S-C 种子 1 已出）：16×16×1 对 3S-A 的 Δ R8 可变 +10.9 pp、Δ 表面 +1.7 pp，K0 可变 .588 为全线最高；它的码确实更像"内容码"（μ 与墙的相关 −.64）；但 12k→16k 才发生 +13 pp 的晚期跃迁，且融合差扩大到 −8.8 pp。
5. **建议首发**：在 3S-C 配方上把精度改成确定性的覆盖率（q = 4 × 块覆盖比例，去掉 q 头；2D 已有 `coverage` 模式），单变量、零算力、W1 每种子约 30 min；预注册预期 R8 表面 +3–5 pp、可变 +4–6 pp，融合差缩小 ≥ 3 pp。其次是解码器的块相位平面（2D 批次 V 的教训，3D 版漏掉了）。**D = 256 不必动**：budget 不缺 bit。

## 2. Q1：一个块的 8+8 bit 能装什么，块里有什么

读法：
- **墙平面图很便宜**。即使 2D 的保守估算（fp_day5：直墙 3–5 bit，拐角/门洞 9–14 bit）也只占载荷的 6–12 %。在 2D 同一个 8×8 网格、每块 16×16 px 上，训练好的系统 K0 墙 F1 .92–.94（BEST_RESULTS §1），门槛测试量出每块 37 个可分辨图案 ≈ 5.2 bit（D5-3）——恰好覆盖 70 % 的单线块（偏移 4 bit + 向 1 bit），输在 22 % 的双线块上。所以"8×8 网格装不下墙"不成立；3S-C 把 16×16 的 4.70 bit / 82 % 单线块交给一个标量，更宽裕。
- **足迹（哪些体素被看见）才是信息大户**。known-BCE 是对全部 524k 体素取平均的损失（`train_3d_v420.py:241-242`，权重和占据项相当），它要求码告诉解码器块内 known / unknown 的形状。横向 11.7 bit/块 × 16 个部分块 ≈ 190 bit 还能装；竖直剖面在 4 带掩码之外仍有 5.84 bit/列，一个 agent 约 2,900 列 ≈ 17 kbit，是载荷的 13 倍——装不下，只能靠解码器的先验，而码里最便宜的足迹摘要就是"块内空闲体素比例"这一个 8-bit 数。这正是第 3 节测到的码语义。
- **2D 上限（D4-6）的校准**：16×16×1 .918 vs 8×8×1 .694 vs 4×4×4 .623 说的是"码覆盖多少个独立空间单元"。3D 的 8×8×4 在水平方向只有 64 个单元（4 个竖带重复同一张平面图：墙是竖直拉伸的，`mapping_3d_storey_data_v420.py:313`），16×16×1 有 256 个。3S-C 种子 1 的 Δ 可变 +10.9 pp 与 2D 的 +22 pp 方向一致、幅度减半（3D 还要带竖直信息）。注意 D4-6 的协议被 code_review_v424 M1 指出低估（2D 训练模型 .92 > "上限" .694），所以这些数只能定方向，不能定幅度。

## 3. Q2：码的语义——测到的、需要的、学得会的

### 3.1 测到的（3S-W 种子 1，95 个 TRAIN 场景，60,723 个带证据块）

| Spearman | μ | q |
|---|---|---|
| 与块内已知**空闲**比例 | **.952**（分带 0–3：.97 / .97 / .95 / .93） | .78 |
| 与块覆盖率（已知比例） | .929 | **.77**（分带 .90 / .68 / .53 / .88） |
| 与块内占据比例 | .09 | .26 |
| 与块内**有墙**的比例 | **−.08**（限定覆盖 > .9 的块：−.36 / −.55 / −.66 / −.67） | .07 |

- 两条通道编的都是足迹：μ ≈ 空闲比例，q ≈ 覆盖率。墙的信息只在"覆盖完整的块里墙多则 μ 低"这种密度余量里，而不是位置。
- 两个 agent 同时看到同一块里的墙时，码几乎一致（|Δμ| 中位 .031；其他对 .14）——码是块几何的确定函数，但这个函数是密度。
- 对比 3S-C 种子 1（16×16×1）：μ 与有墙比例的相关变成 **−.64**，有墙竖柱 μ 均值 −.25、无墙 +.56；μ 与空闲比例仍 .88。它的 q 则几乎放弃了覆盖语义：中位 .031，**70 % 的带证据坐标 q < 0.1**，q 与覆盖率相关只有 .22。即分配到平面的分辩率越高，μ 越像内容码；而 q 退化成近似二值的门。
- 3S-C 的训练曲线（R8 表面 .426 → .516 → .521 → **.653**，最后 4k 次更新时 lr 已在峰值的 6 %→5 %）是一次语义跃迁：解码器学会读位置之后编码器才得到写位置的梯度。2D 用了 57,600 × 3 次更新才把 8×8 码推到 .92，3D 只有 16,000 次。

### 3.2 一个标量怎样带一堵墙（连续位置码）

- 解码器在码网格上做 3×3×3 卷积（`train_3d_v420.py:129,138`）：pre 两层给 ±2 块的感受野，之后每级再加 ±1 个计算格，水平总感受野约 ±3.3 块（8×8×4 下 ≈ 0.4 L，16×16×1 下 ≈ 0.2 L）。一堵横穿若干块的墙，只要相邻块的码取相近的"偏移值"，卷积就能读出一条线；拐角 / 门洞落在双线块（22 % / 18 %），需要第二个自由度，这是 2D 残差的来源（D5-3 门槛测试：残差 53 % 是 1 px 抖动）。
- **tanh + hard-8 + max join 允许连续位置码**：127 级/侧对 16 个偏移留 ~8 级余量；join 只选不插值（`train_3d_v420.py:179-183`），码在线路上逐位转发，μ 不再被二次量化（见 2.1）。2D 门槛测试的"37 个可分辨图案 ≈ 16 偏移 × 2 向"就是这种码自发出现的证据。D5-7 的码级嵌入失败是因为 profile-4 线路的 ±3 级舍入，3D 的 8+8 k-bit 线路没有这个问题。
- **现在的编码器能产生它**：输入含公共坐标平面 x,y,z（`train_3d_v420.py:100-101`），每个体素在块内的绝对位置可知；三层 stride-2 卷积 + mean/max 池化（`:89-92,:106`）把 8×8×4 计算格压到 1×1×1 × 128 通道，位置信息要经通道携带，容量够（128 维 → 2 个标量）。瓶颈不在表达力，在学习：解码器先得学会按位置读，编码器才有梯度按位置写（3.1 的跃迁）。
- **解码器读位置缺的一样东西：块相位**。公共平面只有 x,y,z 与 L/25.6（`train_3d_v420.py:73-80`）。要把"块 k 的码 = 偏移 t"译成体素，解码器需要知道每个计算格在块内的位置 u,v（锯齿函数 frac(8x)），这对几层 SiLU 卷积不是容易的函数。2D 批次 V 正是补上 u,v + L/20 平面：+1.82 / +0.99 pp，8+ 室 +2–4 pp，机制核对两种子成立（D5-10）；v420 只继承了尺度通道，没有相位（D8-0 自称"2D 公共帧条件化的 3D 版"，只做了一半）。墙偏移在块内均匀分布（3.98 bit）说明块边界与墙无关，相位信息不能从码本身推断。

## 4. Q3：2.5-D 分配——3S-C 种子 1 怎么读，3S-C / 3S-L 能和不能回答什么

**3S-C 种子 342101 final VAL**（`runs/v423-layout/a-s342101`）：K0 表面 .741 / 可变 .588 / FPR .020；R8 表面 **.653** / 可变 **.491** / 容差 1 .814 / 家具区 .173 / FPR .041；fresh R8 .663。对 3S-A 同种子：Δ R8 可变 **+10.9 pp**，Δ R8 表面 **+1.7 pp**，Δ K0 表面 +5.6，Δ K0 可变 +15.2 → 种子 1 满足 D8-5 的"杠杆"档。对 3S-W 种子 1（W = 2，解码器参数 3.9×）：R8 表面 −1.2、可变 +2.9；K0 表面 +0.8、可变 +5.4。逐跳：R1 .705 → R2 .682 → R4 .659 → R8 .653，融合差 **−8.8 pp**（3S-A −4.9，3S-W −6.8）。

**3S-C 种子 342202（运行中，06:50 UTC 读到 4k 验证）**：K0 表面 .696 / 可变 .465，R8 表面 **.658** / 可变 **.447**，FPR .048——在 4k 次更新时就已超过 3S-A 两个种子的 16k 终值（R8 .636 / .382、.631 / .398），种子 1 的跃迁在这个种子上提前发生。按 D8-5 判据，种子 2 大概率也落在"杠杆"档；FPR .048 需在终值上核对（判据保护 ≤ .03 两条线都没过）。

读法：
- 2.5-D 的核心事实：墙是平面图的竖直拉伸，天花高度是每栋一个数（U(2.4, 3.0)，`:198`），楼板位置固定。8×8×4 用 4 个竖带各编一次同样的平面图，并用 64 个顶带坐标重复编码一个 3 bit 的天花高度；16×16×1 把这些冗余换成 4 倍的平面单元。可变结构 +11 pp 是这笔交换的收益。
- 代价在竖直足迹：16×16×1 的掩码只说"这根竖柱有没有已知体素"，7.06 bit/列的竖直剖面全部要靠码和先验（8×8×4 的 4 带掩码白给 1.22 bit，并把余量压到 5.84）。3S-C 在 4k–12k 的表面 F1 比 3S-A 低 10–14 pp 而可变结构反而高 2–3.5 pp，就是楼板（表面的 .41）一度丢失、16k 才补回来的痕迹；FPR .041 对 3S-A .042 持平。
- **混合布局在 D = 256 下没有干净的方案**：16×16×1 = 256 已用满；8×8×4 的竖带非均匀化（例如 0–0.5 / 0.5–1.5 / 1.5–2.3 / 2.3–3.2 m）意义不大，因为现在的顶带 2.4–3.2 m 已经只含墙 + 天花。若要"平面 16×16 + 竖直剖面"，只能 (a) 把天花高度做成公共帧参数（像 L 一样，1 B，需要用户同意改公共协议；3S-C 到 16k 已自己学回楼板，所以收益估计 ≤ +1 pp，不优先），或 (b) D → 512（16×16×2，1 KB/消息），这要先看 3S-L 的 C4 − C3。
- **3S-C 能回答**：在 W = 1、16k 次更新、同一编码器族下，平面分辨率是不是杠杆（种子 1：是）。**不能回答**：它与 W = 2 是否叠加（两者各自 +3 到 +11 pp 的可变结构增益作用在不同环节：码语义 vs 渲染）、晚期跃迁是否在种子 2 上也在 16k 之前发生（若没有，种子 2 可能停在 .52 而判 ambiguous——这是本批最大的风险）、以及融合差为何扩大（第 5 节回答）。
- **3S-L 能回答**：C3 − C1 = 理想编码器下布局的差（预期 ≥ +10 pp 可变）、C4 − C3 = 维度的差、C2 − C1 = 理想码下解码器宽度是否仍受限。**不能回答**：块局部编码器能否实现自由码（3S-C 已给了部分答案），以及 **R8 上限**——自拟合码的 q 没有任何排序动机，3S-L 的 R8 数字会被第 5 节的 q 排序问题压低，读 R8 列时应当附上"按覆盖率选源"的变体（评估项，不改协议）。另外 code_review_v424 M1/M3 已指出协议只给下界：C1 若低于 3S-A 的 K0 .685 / .436 超过 2 pp 即为无效臂。

## 5. Q4：融合损失的分解（只评估，CPU，24 个 TRAIN 场景，部署的解码器与线路）

变体：K0 = 自身 belief；R8_actual = 部署的 `rollout_max`；R8_covsel = 集中式 join，选源键换成"该源对该块的覆盖率"，但转发的仍是赢家自己的 (μ, q)（线路量化照旧；对解码器而言仍是训练分布内的真实码）；R8_oracle = D4-10 的"理想同态"：编码器直接编码该节点可达源的并集观测，不做 join。

| 3S-C s1 | 内墙 / 边界墙召回 | .604 / .799 | .533 / .834 | .574 / .842 | .540 / .853 | 16×16×1 的内墙召回已是 3S-A（.212）的 3 倍 |

三个权重上 R8_oracle 对 R8_actual 的增益都是 +3.4 到 +4.5 pp 表面、+4.2 到 +5.8 pp 可变，而 **R8_covsel 拿到其中 53–90 %**。因此：
- **融合损失是表示问题，但不在 join 的代数里**（join 对环路、重发精确，D4-10 的"同态无损"在 3D 依然近似成立：oracle 只比最佳选源高 0.4–1.6 pp），而在 **精度头没有学会按完整性排序**：
  - 3S-W：争议块（85 % 的并集块有 ≥ 2 个观测者）里只有 58 % 选到覆盖最大的源；赢家的已知体素占并集已知的 .83（p10 .48），覆盖最优源能到 .93；赢家看到的墙格只占并集墙格的 .71；7.8 % 的含墙争议块由一个根本没看见墙的源赢得。
  - 3S-C：更糟，37 % 选对，赢家 / 并集 .77（p10 .33）——因为它的 q 已退化为门（70 % < 0.1，与覆盖率相关 .22），排序信息几乎为零。
  - 为什么学不会排序：q 只在 belief 的 log(1/P) 通道里被解码器读到（`train_3d_v420.py:203`），训练时它同时要当"解码器的第二内容通道"和"join 的选源键"，而选源的效果要经过 8 轮非光滑的 argmax（`:181-183`）才进入损失，梯度只流向被选中的那个源；2D 的编码器报告已指出 q 实际是第二内容通道（D5-3）。3D 的争议块比例（85 %）和块内互补性（69 % 的并集内墙格在任何单个 agent 的图里都不是内墙；最佳单源也只覆盖并集已知体素的 .93）都比 2D 大，所以 2D 的 −2 pp 在 3D 成了 −6 到 −9 pp。
- **"union-composable"码**：D4-10 在 3D 的近似成立（oracle ≈ covsel）说明不需要再加一致性 / 同态训练项；需要的是让赢家是看得最全的那个。
- 技术提醒：我的集中式 join 与 `rollout_max` 在同一键下逐坐标不完全相同（max |Δbelief| 0.5–1.8），来源是 255 级线路量化造成的并列精度在洪泛中按边序、在集中式里按 agent 序打破；只影响极少数坐标，不影响上表的量级，但部署前应用训练器自身的 `select` 复核。

**单变量检验**（训练批次）：精度改为确定性覆盖率 q = PRECISION_MAX × 块内已知体素比例（无 q 头；mask 不变）。它同时做三件事：选源严格按完整性（赢家 / 并集 .83 → .93）、解码器在 K0 与 R8 都拿到精确的块覆盖率（known-BCE 的大头）、μ 不必再复制足迹。2D 已有同名模式（`train_v378.py:143`，`PRECISION_MODE = 'coverage'`）。

## 6. 候选单变量修改的排序（按每个租约的预期 F1 增益）

### 6.1 首发：确定性覆盖率精度（`--precision coverage`）

- **机制**：第 5 节。q 不再是学习量，join 的赢家 = 看该块最全的源；解码器的第二通道变成精确覆盖率；μ 的 8 bit 从足迹密度中释放。
- **预测**：在 3S-C 配方（16×16×1，W1，16k）上，R8 表面 **+3–5 pp**（种子 1 → .68–.70），R8 可变 **+4–6 pp**，融合差从 −8.8 缩到 ≤ −5；K0 在 ±1.5 pp 内（q 在 3S-C 里几乎没有内容：与覆盖、占据、墙的相关 .22 / .28 / .09）；FPR 不升（covsel 评估里 FPR 持平 .050）。若 3S-C 种子 2 未过而回到 3S-W 配方，预测 R8 表面 +2–4、可变 +3–5。依据：只评估的 covsel 增益 +4.0 / +5.7（3S-C）、+3.4 / +4.7（3S-W）、+1.8 / +3.1（3S-A），训练时解码器还能适应新通道。
- **代价**：一个租约放两个种子都够（W1 16k ≈ 30 min/种子，含加载与验证；或按规则每种子一个租约）。代码：`OwnedHead` 改输出 1 维、q = 4 × `coverage`（`train_3d_v420.py:116-121` 处 10 行）+ 一个 flag；`rollout_max`、解码器、损失、数据、线路不变；参数 −129。
- **对照**：3S-C 同种子（若其种子 2 过）；否则 3S-W 同种子。身份守卫：编码器 trunk 与解码器初始张量逐位相同。
- **两种子预注册判据**（final VAL，配对 Δ）：两种子 Δ R8 表面 ≥ +2 pp 且 Δ R8 可变 ≥ +3 pp 且 FPR ≤ 对照 + 0.3 pp 且 K0 可变 ≥ 对照 − 2 pp → **精度语义是杠杆**；两种子 Δ R8 表面 < +0.5 → 不是；其余 ambiguous。机制核对（附报）：两种子 R8 − K0 缩小 ≥ 3 pp；争议块"赢家 = 覆盖最优"达 100 %（构造保证）。
- **风险与混杂**：(i) 学习的 q 在 W2 / 8×8×4 上确有一点内容（与覆盖率外的残差），K0 可能 −1；(ii) 解码器失去了"低 q = 不确定"的软信号，边界抖动可能略增（容差 1 指标附报）；(iii) 覆盖率在 3D 里是体素计数，一个只看见天花板一角的源与看见半个房间的源都可能"覆盖 .3"——若需要，可用"已知空闲体素比例"为键，但那是第二个变量，不进本批。
- **什么能证明我错**：训练后 R8 增益 < 1 pp（评估期增益只是解码器"看到更完整的码"的幻象，训练时它本来就会对马赛克适应）；或 K0 可变 −3 pp 以上（q 原来是内容通道）。

### 6.2 解码器块相位平面（u, v[, w] ∈ [−.5, .5)，每级卷积旁）

- **机制**：3.2。墙偏移在块内均匀分布（3.98 bit），解码器读连续位置码需要知道块边界；2D 批次 V 的 3D 版，v420 漏掉。
- **预测**：R8 表面 +1–2 pp，可变 +2–3 pp，增益在 L 大（格粗）的户型更大（D5-10 的分层模式）；内墙召回 +3–5 pp。
- **代价**：零算力，+约 20k 参数，恒等初始化（新列零权重，D5-9 做法）；一个租约两种子（W1）。
- **对照 / 判据**：对照 = 当时的工作基线同种子；两种子 Δ R8 表面 ≥ +1 pp → 杠杆；都 < +0.5 → 不是。附报 1 体素容差 F1（预期 exact 与 tol1 的差缩小）。
- **风险**：2D 上判定 ambiguous（+1.8 / +1.0）；3D 的尺度通道已在，增益可能只剩相位那一半。

### 6.3 让码不再为足迹买单（与训练角度共享；表示上的理由在 2.2）

- **机制**：known-BCE 对全部体素取平均、楼板表面与墙表面同权（1 + 4×surface，`train_3d_v420.py:244`）。楼板占目标表面 .41 而几乎完全可由 z 与天花高度预测；足迹的竖直剖面不可传输。两者一起把梯度推向"密度码"。
- **候选单变量**：表面权重只给非楼板表面（z 索引 1–24 的 surface 体素权 5，楼板表面权 1；用 z 代理，不需要缓存里没有的 slab 掩码）。**预测**：可变 +3–5 pp，表面 ±1（楼板召回从 .92 掉到约 .90 被墙的增益抵消）。
- **风险**：主判据是表面 F1，楼板权重下降可能净负；这是训练分析者的领域，我只给出"码语义跟着损失走"的证据，不把它排在 6.1 之前。

### 6.4 公共天花高度平面（需用户同意扩展公共帧，1 B/场景）

- **机制**：4 节。把每栋一个的 H_w 当作与 L 同类的公共量，8×8×4 的 64 个顶带坐标与 16×16×1 的竖柱码都不再需要编码它。
- **预测**：+0.5–1.5 pp 表面（楼板召回 .92 → .96 的直接贡献约 +1.6 × .41），3S-C 已自学回楼板，所以释放容量的二阶收益不确定。排在 6.1–6.3 之后；它与 6.1 叠加时可考虑作为同一"公共帧扩展"批次（但那是两个变量）。

### 6.5 不建议 / 暂缓

- **一致性 / 同态训练项、分析-综合编码**：oracle − covsel ≤ 1.5 pp，没有空间；2D 已否定（D4-10、D5-4）。
- **码级嵌入 / 符号读法**：D5-7 有害；3D 线路虽然对 μ 无损，但 3S-C 的晚期跃迁说明平滑读法本身能到位置码，不必冒险。
- **8×8×4 竖带非均匀化**：顶带已是纯结构带，被 3S-C 取代。
- **增加每坐标 bit 数**：D4-11 在 2D 否定；本文 2.1 显示 μ 已用 254 级 / 7.69 bit，但语义是密度——多给 bit 只会给更精细的密度。

### 6.6 关于 D（独立建议，不改变上面的排序）

**现在不建议动 D = 256。** 理由是数字：K0 载荷 1,250 bit 对墙平面图 73 bit、R8 载荷 2,190–2,620 bit 对并集平面图 181–254 bit，预算是需求的 10–17 倍；卡住的是码语义（密度 vs 位置）和 q 的排序，两者都不是 bit 数能解的。2D 的 D4-6 显示 16×16×1（256 维）对 8×8×1（64 维）+22 pp，但那是"空间单元数"而非"维数"的效应——3S-C 用同样的 256 维换布局拿到了 +11 pp 可变结构，正是这个效应。应当动 D 的条件：3S-L 的 **C4 − C3 ≥ +10 pp 可变**（16×16×4 对 16×16×1，同一 16×16 平面网格只加竖带）且 3S-C 配方叠加 6.1、6.2 后仍 < .80。若到那一步，优先 16×16×2（D = 512，1 KB/消息：平面 + 1 bit 竖直掩码，H_profile 给定 2 带后约 5.0 bit），而不是 16×16×4。

## 7. 首发顺序与理由（一段）

先发 **6.1**（覆盖率精度，在 3S-C 配方上；若 3S-C 种子 2 判 ambiguous，则在 3S-W 配方上，判据不变）。理由：它攻击的是三条线里最大、且已被只评估实验定量到 76–90 % 可回收的一块损失（−6 到 −9 pp 中的 +3 到 +6）；零算力、W1 一个租约两个种子；与宽解码器、更多周期、布局都正交，之后可直接叠加。6.2 第二发（零成本，2D 有先例，能和 6.1 共用对照）。两者都过之后再做"确认杠杆叠加 + 多周期"的训练批次——3S-C 在 lr 只剩 5 % 时还跃迁 +13 pp，说明这条线的训练远未收敛，但那是训练分析者的章。
