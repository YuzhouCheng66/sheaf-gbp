## 0. 一句话

两个冻结的异构大模型，各自只看到证据的一半，各发一次 K 个带精度的 256 维隐槽，经二次 sheaf 能量共识后解码作答：在同样一轮、同样预算下，能否比交换文字更准，比单向投影更稳，而且一方缺席时平滑退化。

## 1. 要回答的问题

评估（D8-81）核对过的先例：Ramesh & Li（ICML 2025，激活求和/替换，单向，免训练）、ThoughtComm（NeurIPS 2025，稀疏自编码器抽潜在想法）、C2C（ICLR 2026，KV cache 经投影器 + 门控进对方，异构）、LatentMAS（ICML 2026，末层隐态 + 共享 KV 接力）。"隐态通信"本身不是空白；空白是：没有对称的概率共识、没有逐坐标的精度、异构只有黑箱投影器、没人处理缺席、没人给"互相理解"一个可测定义。本实验只回答与此对应的四件事：

> **在一个刻意构造、使"通信必不可少"的证据分片问答里，两个冻结大模型各自一个 K × 256 的带精度隐槽、经 sheaf 共识后作答，能否：**
> 1. 在同样一轮、同样预算下比交换文字更准（P1）；
> 2. 不输给单向投影（C2C 式）（P2）；
> 3. 精度有用（P3）；
> 4. 一方缺席时退化到自身而不是崩掉（只报告）。

诚实的边界：两个节点上 GBP 与直接解线性方程等价，所以本实验证明的是"层能量 + 精度"，不是 GBP。GBP 的不可替代性（≥ 8 个智能体、异步、按精度稀疏发送）是第二阶段的主张。

## 2. 任务与数据

| 条件 | 实现（写死） | 为什么需要 |
|---|---|---|
| 互补部分可观测 | HotpotQA distractor 设置：每题 10 段（2 段金标 + 8 段干扰）。随机分成两份、每份 5 段，保证每份恰含 1 段金标；金标在哪一份随机，不固定"第一跳"。两个智能体都看到问题 | bridge 题的答案段和桥接段分在两边，不通信答不出；comparison 题需要两边的事实 |

## 3. 模型与接口（所有臂共享骨架，一次只改通信方式）

- **异构对**：Qwen3-1.7B（28 层，d = 2048）+ Llama-3.2-1B-Instruct（16 层，d = 2048）。分词器、层数、训练数据都不同；d 相同只是巧合。备选 Gemma-3-1B-it（d = 1152，强迫 d 不同）。
- **同模型对**：Qwen3-1.7B 两份，共享底座、共享 LoRA 与适配器（两个智能体就是同一网络看不同分片）。它把"异构"和"隐态 vs 文字"两个因素分开。
- **底座冻结**。可训练：LoRA（r = 16，全部线性层，每个模型各自）、发送适配器、读头、精度头、w。可训练参数 < 2 %。
- **发送适配器 P_i（限制映射的角色）**：K = 32 个学习查询交叉注意到第 L 层隐态（L = ⌊2/3 · 层数⌋；实现前只在同模型臂上扫 L ∈ {1/2, 2/3, 5/6}，不计入判决），输出 z_i ∈ R^{K×256}；精度头输出 log λ_i ∈ R^{K×256}，λ 夹在 [1e-3, 1e3]。
- **读头 R_i**：R^{256} → R^{d_i}（线性 + LayerNorm），把融合后的 x_i* 变成 K 个软 token，插在"段落之后、问题之前"，第二次前向作答。每轮两次前向（第一次取 z，第二次读融合态）。
- **能量与融合（S1）**：
  - E = Σ_i ½(x_i − z_i)ᵀΛ_i(x_i − z_i) + ½ w‖x_1 − x_2‖²，x_i ∈ R^{K×256}，F = I，w 可学（初值 1）。
  - 训练时直接解 (Λ + wL)x = Λz：两节点上与精确 GBP 等价，梯度精确。
  - 评估时真的发 GBP 消息（每条 K × 256 均值 + K × 256 精度，fp16 共 32 KB），这样才能测缺席。
  - 茎 = 共享边空间。本实验 F = I，限制映射由 P_i 承担（从模型自己的空间到共享空间）。私有信息不需要经过茎——模型的上下文还在自己手里。学习 F ≠ I 的版本（茎 = 模型自己的 d_i，融合态带私有坐标）留到第二阶段。
- **时间维规则**（与 v1 相同）：多轮时每轮融合一次，融合态只作软 token，不回灌 KV。
- **训练**：答案 token 的交叉熵，两个智能体取平均，梯度穿过线性求解进两边的 LoRA 与适配器。AdamW，LoRA 2e-4、适配器 1e-3，1 个 epoch（20k 题，batch 8，2,500 步），bf16，种子 342101 / 342202。
- **平凡解防护**：P_i 输出做 LayerNorm（防 z → 0，等价于 F → 0）；λ 有下界；任务本身不通信答不出。

## 4. 对照臂

| 臂 | 做法（唯一的变化） | 检验什么 |
|---|---|---|
| B0 无通信 | 各自 5 段 + 问题，LoRA | 下界 |
| B4 全上下文上界 | 单模型 10 段 + 问题，LoRA（异构对里每个模型各一个） | 上界 |
| T 文字交换（主文字对照） | 发送方 LoRA 训练成从自己的 5 段里抽出支撑句（HotpotQA 有标注），截到 T = 64 token；接收方 LoRA 先用金标消息训练，再用训练好的发送方的预测消息微调一遍（两阶段，避免训练–评估不匹配） | 文字在同样一轮、64 token 下的最强做法 |
| T0 零样本文字 | 冻结模型按提示写 ≤ 64 token 的"对方可能需要的信息"，接收方同 T | 不训练的文字（只报告） |
| U 单向投影 | 接收方得到 R_i(z_j) 作软 token，无共识、无精度；参数量 = S1 − 精度头；训练时随机丢 30 % 消息 | 与 C2C 式投影的公平对照 |
| **S1 Sheaf 共识** | 如上，Λ 学，w 学；不做消息丢弃 | 本方法 |
| S1-Λ≡1 | 去掉精度头，Λ ≡ 1 | 精度有没有用 |
| C 同能量直接解 | 用 S1 的 z, Λ 直接解，不训练 | 代码核对：评估时 GBP 消息定点必须与 C 逐数一致（断言） |

- 异构对训练 B0 × 2、B4 × 2、T、U、S1、S1-Λ≡1；同模型对训练 B0、B4、T、S1。每臂两个种子，共 (8 + 4) × 2 = 24 次训练。
- **"同预算"的定义**：这里字节不是货币（隐态 32 KB，文字约 200 B），时延和准确率才是。主判据定在文字 64 token / 隐态 32 槽、同样 R = 1。只报告文字预算扫描 T ∈ {16, 64, 256} 和 R = 2；如果 T(256, R = 2) ≥ S1(R = 2)，照实写"隐态只在紧预算、单轮下赢"。

## 5. 指标与读数

- **主指标**：VAL 两个智能体平均 EM（F1 并列）。
- **只报告**：
  - 答案段在对方手里时的 EM（"互相理解"的操作化）；
  - 缺席曲线：评估时以 p ∈ {0, .3, .6, 1} 丢掉对方消息；S1 用先验（即自身 z），U 用零向量，T 用空消息；p = 1 时 S1 应逐数等于 B0 的同一网络（断言）；
  - 融合前分歧 ‖z_1 − z_2‖ 与对错的相关；精度 λ 与答案熵的相关；
  - 每题字节与发送端时延（64 次顺序解码 vs 一次前向）；
  - 文字预算扫描；R = 2。
- 两节点无环，H¹ 为零；"无法调和的分歧"要 ≥ 3 个智能体，留到第二阶段。

## 6. 判据（草案；VAL，两个种子都要过）

**第 0 阶段：只训 B0 与 B4。**
- **P0（门槛）**：每个模型 B4 − B0 ≥ 15 pt EM，且 ≥ 5 倍两种子间 |ΔB0|。不过就停，改分片规则（例如加大干扰段数），其余臂一个都不训。

**第 1 阶段：其余臂。**

| 编号 | 主张 | 门槛 |
|---|---|---|
| P1 | 隐态共识优于文字 | 异构对 S1 − T ≥ +2.0 pt EM |
| P2 | 对称共识不输单向投影 | S1 − U ≥ +1.0 pt |
| P3 | 精度有用 | S1 − S1(Λ≡1) ≥ +1.0 pt |

- **判决**：P1–P3 全过 → **LEVER**，进入第二阶段。P1 不过 → **NO**。其余 → AMBIGUOUS。C 断言失败、sha 不符、缺臂 → INCOMPLETE。
- **降级**：fresh 上 S1 − T 比 VAL 低 1.0 pt 以上 → 最多判 AMBIGUOUS。
- **同模型对只作诊断**：若同模型 S1 过 P1 而异构对不过，结论是"对齐（P_i）是瓶颈"，不是"隐态无用"。

## 8. 算力与流程

- 两个 1–2B 模型 bf16 冻结 + LoRA，上下文约 600 token + 32 软 token，batch 8，每步两次前向 × 两模型：估 0.8–1.2 s/步，每次训练 35–50 分钟（实现后按实测重估，不引用预热前的速率）。24 次训练约 16–20 小时，约 8–10 个 5090 租约，分多天。不阻塞推进的臂（T0、文字预算扫描、L 扫描）放 bigboy。第 0 阶段先跑，P0 不过就提前结束租约。
- 数据在 CPU 上预处理成分片 + 提示模板，缓存到 `/mnt/datasets/.../cache_hotpot/`。
- 顺序：已定稿为预注册（D8-82）→ 实现与单测（断言 C；GBP 消息与直接解一致；缺席 p = 1 等于 B0）→ 独立审查 → 请用户确认 GPU → 发射。

## 9. 第二阶段（本次不做，仅列出）

1. **≥ 3 个智能体**（MuSiQue 2–4 跳，分片成 3–4 份）：通信图有环，H¹ 残差可测，GBP 不再退化，重复计数（迭代 PoE 对照）重新出现。
2. **按精度稀疏发送**：只发 λ 高的槽，通信量随确定度变化；异步多轮。
3. **可审计读头**：训练一个小解码器把边空间共识翻成文字，供监控；这是对"CoT 可监控性"一派的回答。
4. **对齐训练**：不带任务，只用 sheaf 能量在成对输入上训练两模型的 LoRA + P_i，再测跨模型迁移（A 的槽注入 B，B 在 A 擅长的领域是否变好）——"互相理解"的版本。
5. **学习 F ≠ I**：茎 = 模型自己的空间，融合态带私有坐标，用于多轮记忆。
6. **异构专长对**：代码模型 + 数学模型，任务需要两者。

## 10. 已决定的点（用户于 2026-10-29 选择"按默认定稿"）

1. 文字对照的预算：**T = 64 token**（更紧的 32 对隐态有利，更松的 128 对文字有利；预算扫描 {16, 64, 256} 只报告）。
2. 主判据：**异构对**；同模型对只作诊断。
3. 模型对：**Qwen3-1.7B + Llama-3.2-1B-Instruct**；Gemma-3-1B-it 不用。
4. 作答：**两个智能体都作答、取平均**；"答案段在对方手里"只报告。
5. 接口：**K = 32、D_e = 256** 沿用。
