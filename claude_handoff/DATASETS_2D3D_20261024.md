# 真实场景的 2D / 3D 栅格地图数据集选择（2026-10-24）

**问题**：为多机 Sheaf-GBP 建图找一个重要的 2D 栅格地图数据集和一个重要的 3D 栅格地图数据集。要求是真实场景（优先室内）、与 SLAM 有关，不要求本身是多机数据；我们自己把场景拆给多个 agent，每个 agent 局部随机游走、用标准占据建图方法从自己的传感器建图，位姿用真值。

**结论**：2D 和 3D 都用同一个来源，**HM3D（Habitat-Matterport 3D）**。3D 直接用它的真实扫描网格；2D 用同一批建筑按楼层切片得到的占据栅格，这正是 Active Neural SLAM、Occupancy Anticipation 等探索工作在 Gibson / MP3D 上生成真值俯视图的做法。另配两个小而经典的真实传感器数据作为零样本演示：2D 用 Cartographer 德意志博物馆激光包，3D 用 uk-linux 上已有的 Replica。

## 1. 为什么是 HM3D

| | Replica | MP3D | Gibson | ScanNet | **HM3D** |
|---|---|---|---|---|---|
| 场景数 | 18 | 90 | 571 | 1,613 | **1,000**（800 训练 / 100 验证 / 100 测试，测试不公开） |
| 楼面面积（m²） | 2.19k | 101.82k | 217.99k | 39.98k | **365.42k** |
| 可通行面积（m²） | 0.56k | 30.22k | 81.84k | 10.52k | **112.50k** |

数字取自 HM3D 论文表 1（NeurIPS 2021 数据集赛道）。

- **真实**：1,000 栋真实建筑，Matterport Pro2 三脚架深度相机扫描，来自 38 个国家，包括多层住宅、商店和其他室内空间；单个场景楼面面积 49 m² 到 2,172 m²。
- **质量**：论文报告其网格的不完整重建伪影比 Replica / MP3D / Gibson / ScanNet 少 34–91 %。
- **规模够训练**：800 栋训练建筑、多楼层，切成 2D 楼层后有上千张真实楼层图；我们在 HouseExpo 上用 14,400 套户型，HM3D 的数量级低一些，但每张图大得多、结构真实得多。
- **2D 与 3D 同源**：同一栋楼可以同时做 2D 和 3D 实验，结果可以配对比较。
- **已有标准做法**：Habitat 生态里 2D 俯视真值图、深度投影建图、随机游走 / 探索都是成熟流程。

## 2. 多机建图流程（奥卡姆版本，不需要 Habitat-Sim）

uk-linux 上已经有 `open3d`、`trimesh`、`embreex`，没有 `habitat_sim`。最简单的流程只换掉 v400 的世界生成，其余照旧：

1. **几何**：载入 HM3D 的 GLB 网格，用 Open3D 的射线求交场景（Embree）。
2. **轨迹**：在可通行空间（网格体素化后"地面占据、上方 1.5 m 自由"的格）上做每个 agent 的局部随机游走；位姿用真值。
3. **传感**：每个位姿对网格做首击射线投射（2D：水平激光一圈；3D：深度相机或球面射线），把命中点和射线经过的空间写入各自的三值占据栅格。这正是 OctoMap / voxblox 一类方法在真值位姿、无噪深度下的更新规则，也就是我们 v400 的 `observe()`，只是从体素世界换成真实网格。以后可以加深度噪声或换 nvblox。
4. **真值**：训练目标仍是可达 agent 自身图的并集（与现在相同），所以**不需要水密网格**；墙体内部未知不影响，因为指标本来就只在目标已知范围内、并以表面 F1 为主。
5. **2D**：每层取楼板以上 0.1–1.5 m 的高度带投影成障碍，得到楼层占据图；每个 agent 用 2D 激光在同一切片上射线投射建图。

需要新做的设计只有一处：HM3D 楼栋比我们的 12.8 m 立方体大得多，需要 3D 版的"贴合房屋的图幅"（对应 2D 的 v371），或按楼层 / 固定尺寸分块。这个要单独预注册。

## 3. 补充数据（不作为主训练集）

- **2D 真实激光**：Cartographer 公开的德意志博物馆 2D 背包数据（ROS bag，水平激光 + IMU，Apache 2.0）。可以把一次长采集按时间切成多段当作多个 agent，位姿用 Cartographer 优化后的轨迹，作为"真实激光、零样本"的演示。更老的 Radish（Freiburg 079、Intel Lab 等）也可用，但只有原始日志和 SLAM 地图。
- **2D 文献可比基准**：KTH 楼层图（149 张真实校园楼层蓝图，墙和门，0.1 m/像素），是 MapEx（ICRA 2025）等"地图预测 + 探索"工作的标准集。只有墙和门、没有家具，风格接近 HouseExpo。
- **2D 真实户型**：ZInD（1,524 套真实空置住宅，71,474 张全景，2D / 3D 平面图含门窗）。只限学术使用，需在 Bridge 平台注册同意条款。没有家具，作为 HouseExpo 的真实版可选。
- **3D 立即可用**：Replica，18 个高质量真实扫描场景，已在 uk-linux 的 `/mnt/datasets/replica_v1`。太少不能训练，但可以今天就把第 2 节的网格射线流程搭起来做演示，或拿 v401 的合成训练模型做零样本测试。
- **3D 真实传感器**：ScanNet++（1,000 多个用 Faro 激光扫描仪扫描的室内场景，需申请令牌）。EmbodiedScan / Occ-ScanNet 提供室内占据标注，但是房间级单目占据预测基准（如 60×60×36 体素、4.8 m 盒子），不适合楼栋级多机建图。
- **真实多机数据**：Kimera-Multi（MIT 校园，最多 8 台机器人，带参考真值点云地图）、SubT-MRS（CMU，地下多机多光谱，亚厘米级稠密真值模型）。适合作为最终的真实多机演示，规模不够训练。

## 4. 访问与许可（需要用户本人操作）

- **HM3D**：免费，仅限学术非商业研究。流程：在 Matterport 的 HM3D 研究数据页面申请并同意条款，然后在 my.matterport.com 的开发者设置里生成 API token，用 `habitat_sim.utils.datasets_download` 下载（可指定 `hm3d_minival_v0.2`、train、val；加 `_full` 下载原始 GLB）。同意条款和处理 token 都需要用户本人完成；不装 habitat-sim 也可以从 Matterport 页面直接下载。
- **Replica**：已下载。
- **ZInD**：学术使用，Bridge 平台注册并同意 Zillow 数据条款。
- **KTH**：公开。
- **Cartographer 德意志博物馆**：Apache 2.0。
