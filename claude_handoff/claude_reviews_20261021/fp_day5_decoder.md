# Day-5 第一性原理：解码器 / 先验 / 学习视角（Claude 独立分析，2026-10-23）

角色问题：解码器把 64 个均值 + 64 个 log 方差（8×8）经双线性上采样 CNN 变成 128×128 三值地图，它在哪里丢掉门楣短墙、薄内墙、窄开口；什么**解码器侧**结构能带来 ≥ +3 pp。只读分析；除本文件外未改任何文件。行号均指 `scripts/claude_v342/train_v378.py`，"D 节"指 `OVERNIGHT_REPORT_20261021.md`，"第 N 行"指该报告行号。"证据"与"推测"分开标注。

## 1. 第一性原理：R8 .89–.90 的残差由什么决定

**解码器实际做的事（证据）**：输入 2 个 8×8 平面 [hard-8 后验均值, log 后验方差/8]（:196）→ 两层 3×3 卷积（:189）→ **双线性**上采到 16×16（:200）→ lift 两层卷积，拼入公共平面 (x, y, 1/size, 1/size)（:53-58, :64-65, :77）→ 四级，每级先双线性上采再两层 3×3 卷积、再拼公共平面（:79-82）→ 1×1 卷积出 known logit 与 DT 通道（:73, :83）。wall := softplus(DT) < 0.5 px（:402）；损失 = known BCE + 截断 DT（T = 4 px，:420）的加权 L1，近墙 1.5 px 内权重 ×5（:389-396）。融合是逐坐标最大精度选择（:317-322），后验均值恒为某一来源的码本值并再次 hard-8 量化（:341-347）。

**推理链**
1. 瓶颈语义 = 每个 L/8 m 块一个 8-bit 标量，编码器严格块局部（:86-107，unfold :103）。已确立（证据）：卡住的是"一块一标量"而不是 bit——16 bit 上限不变（D4-11）；4×4×4（每 5 m 块 4 个标量）反而比 8×8×1 低 7 pp（D4-6）；HouseExpo 上 R8 < K0 归因于"每块要承载更多内容"（D4-10）。
2. 从解码器看，这个上限的**机制**（推测，但与上三条同源）：CNN 把码值平滑地映射成图案（D4-11 原话"解码器把标量映射为图案的方式是平滑的"），所以每块 255 级只能走出一条**一维图案族**（如"竖墙在偏移 p"）；"墙 + 开口在 y"、"墙在块内终止（门楣）"、"同块两道薄墙"是多参数结构，不在族上。D4-6 的 4×4×4 < 8×8×1 正是"平滑场读法"的指纹：若标量被当作任意符号，每 5 m 块 4×8 bit 与每 2.5 m 块 4×(1×8) bit 等价，不应更差。
3. 于是编码器只能选"最近的族成员"：开口被补成连续墙、门楣被截到块边界、薄墙按 L1 中位数被抹平。v293 解剖（证据）：R8 幻觉墙 90 % 在门洞、95 % 在多源块，门端像素预测 DT ≈ 0 是"自信的墙"，阈值扫描无效（D3-3；D3-4 第 189 行；`error_anatomy_v347max_s342202.json`:25-28, 31-32）。HouseExpo 固定面板（`figures/houseexpo_best_v383_panels.png`）第 1、3、6 行的红/蓝误差同样集中在门楣、窄开口和 8+ 室户型的薄内墙；自由空间与外墙几乎无误差。
4. 必须诚实区分（证据）：v293 上后来证明门洞残差主因是**训练预算**而非"码里没信息"（第 311 行：72 ep 后 door recall .50 → .81）。HouseExpo 三个周期的收益已减半（+2.4 → +1.0/+1.3，D5-1），再一周期预期 +0.5 pp（第 618 行）。所以剩余 ~10 pp 中"预算可解释"的部分正在耗尽，剩下的才是结构性残差。
5. 第二个结构缺陷——**尺度盲**（证据）：L = max(8, ⌈bbox + 1⌉) ∈ [8, 20] m（v371:36），cell = L/128 = 0.06–0.16 m（v371:45；D4-8 第 440 行），但解码器的"尺度"平面恒为 1/128（:57），DT 阈值 0.5 px、近墙带 1.5 px、截断 4 px 全按像素定义（:394-402, :420），物理含义漂移 2.5×（0.03–0.08 / 0.09–0.23 / 0.25–0.63 m）；开口代理宽 0.4–1.5 m（D4-2 第 373 行）= 2.6–24 px。8+ 室层（L 最大）R8 .82–.87 vs 2–4 室 .92–.94（`BEST_RESULTS_20261023.md` 第 29-31 行）。D4-13（第 500 行）已登记"解码器不知道图幅尺寸"。
6. 第三（推测）：解码器没有**块对齐**的位置编码——只有全局 x, y 斜坡（:54-56），而码语义按块定义；码平面一进解码器就被双线性插值与邻块混合（:200, :80），块相位只能从插值折点推断。这是渲染"块内结构"的额外障碍，未量化。

**结论**：残差 = (a) 平滑解码器把 8-bit 符号当一维连续量读（主因）；(b) 尺度盲 + 像素制常数（8+ 室层最受害）；(c) 块相位缺失（次要）。注意 HouseExpo 的量化误差解剖（容差 F1、门洞填充占比、按 L 分层）**尚未做**，现有解剖 JSON 都是 v293。

## 2. 候选结构（≤ 3）

### 候选 1（top-1）：码值傅里叶特征——让解码器在码值轴上不再平滑
- **机制**：把输入均值平面 μ̂ 扩成 [μ̂, sin(2^j π μ̂), cos(2^j π μ̂)]，j = 0..6（+14 个 8×8 平面；最高频周期 1/32，hard-8 步长 1/127（:242-244）可分辨）。即 Tancik 等 2020 的傅里叶特征克服谱偏置，用在**码值轴**而非坐标轴。效果：同一块的 255 级可索引"图案类 × 偏移"，"墙 + 开口"进入码本。log 方差平面不动（精度不得载几何，README §3 第 1、2 条）。离散升级 **1b**：`nn.Embedding(255, d)` 直接查表（max 选择保证后验均值恒为码本值，:341-347），soft-to-hard STE 训练；它把 μ 当名义符号，语义上需用户拍板。
- **≥ +3 pp 的依据**（推测 + 数量级）：K0 目标无损信息 333–577 bit（D4-7 表 v365/v371 行），落在房子上的块 45 个（D4-5 第 402 行）× 8 bit = 360 bit——只有每级都是有效符号时才够；一维平滑族远达不到。R8 对每块可分辨图案数极敏感：4 bit −12 pp、5 bit −3.7 pp（D3-6）。把"可分辨图案"从一维族扩到类 × 偏移，预期 R8 +2–4 pp，8+ 室层 +4–8 pp（该层两 strata 各 +9 pp 即总体 +3 pp）。
- **硬约束逐条**：(1) 64+64、线路、量化器不变，只是解码器对后验均值的固定特征映射；(2) 融合不变；(3) 解码器只读 (q, h)；(4) 划分不变；(5) 首层卷积 2→16 通道，8×8 上 FLOPs 可忽略，Q 协议 57,600 次更新 ≈ 5,400 s 双任务可完成（brief 第 15 行）；(6) 可预注册。
- **代价**：`OwnedDecoder.__init__/forward`（:189, :196）约 15 行；BARF 式频率掩码（第 1 轮 14,400 次更新内线性开启，抑制 2^j 的梯度放大；梯度裁剪 5.0 仍在 :681）。
- **训练**：从头 Q 协议，一个租约两种子；或自 v384 热启动——新通道零初始化使起点函数与 v384 逐位相同（需在 :556-569 的加载器上加 10 行；`--allow-partial-init` 已有 :440），对照为同起点第四周期（需两租约）。
- **对照**：批次 Q（同种子 ⇒ 编码器/head 初始权重与数据顺序相同，用 T 的身份守卫 D5-2 第 625 行）。
- **判据**：两种子 final VAL R8 ≥ Q +1 pp 且 FPR ≤ +0.3 pp（项目标准）；"大幅" = 两种子 ≥ +3 pp；附报 8+ 室层增益 ≥ 总体增益。机制检验（评估期零成本）：把后验均值零样本重量化到 6/5 bit，新模型掉幅应大于 Q（证明它用到了更细的码值）。
- **否定**：两种子 < +1 pp；或 8+ 室层不比 2–4 室层多得；或第 1 轮训练损失高于 Q（高频不稳定）。

### 候选 2：公共帧条件化——块对齐坐标 + 块常数码注入 + 图幅尺度 L
- **机制**：在 `public()`（:53-58）加 3 个平面：块内坐标 u = frac(8x)、v = frac(8y)，以及 L/20；并把 8×8 码平面按最近邻（块常数）在每级与公共平面一起拼入（不再只走双线性）。三者都是公共帧几何（与 agent 无关、已披露：L 即图幅规则 v371:36-38, :114），不含样本相关内容。
- **依据**：§1.5–1.6；8+ 室层 .82–.87（BEST_RESULTS 第 31 行）；D4-13 已登记的尺度盲。估计（推测）总体 +1–2 pp、8+ 室层 +2–3 pp；**不能独立承诺 +3 pp**，但零风险、零成本。可与候选 1 合并为一个"解码器条件化层"（代价：归因要靠后续消融）。
- **约束**：全部满足（公共帧信息，README §3 第 3 条）；部署前提同 D4-8（外接框为公共元数据）。
- **代价**：`public()` 与 `OwnedDecoder.forward` 约 20 行；训练时间不变；热启动可零初始化新通道。
- **对照 / 判据 / 否定**：同候选 1；机制检验：增益随 L 单调（按 L 三分位报告），否则机制不成立。

### 候选 3：8×8 码格自注意力（4 层，d = 128，64 token + 块位置编码），置于 `pre` 之前
- **机制**：内容寻址的长程对齐（同一道墙跨 8 块保持同偏移）。但 `pre` 两层 3×3（:189）+ 各级卷积的感受野按我的计算已 ≈ ±5 块，近乎全局；D4-10 显示跨块拼接只丢 ≤ 0.4 pp。估计 +0–2 pp，**没有 ≥ +3 的依据**。
- **约束**满足；参数 +0.5 M，FLOPs 可忽略；Q 协议可完成；对照、判据同上。
- **建议**：仅当批次 T（宽度 ×2）两种子 ≥ +1 pp（同族容量仍有余量）时再考虑；否则不做。

## 3. 反证（针对 top-1）
1. **瓶颈在编码器**：若 v387（冻结 v384 解码器上 50 步码精修）≥ +3 pp，说明平滑族内还有更好的码、前馈编码器找不到；此时让解码器更"尖"只会让编码器更难（高频梯度）。v265 的 8 步精修曾 +9.6 pp（`encoder_information.md` §2.6 第 110 行）。→ 预注册门：**v387 ≤ +1 pp 才发射候选 1**。
2. **8 bit 已被用满**：k-bit 6 bit 在种子 2 上 −3.8 pp（第 318 行，"6 bit 免费"未复现），模型可能已用到 7–8 bit 分辨率；若如此，高频特征只是把分辨率换成类数，净收益可能为 0。
3. **门洞是训练预算问题**（第 311 行，v293）：若 HouseExpo 同理，第四周期就能拿到同样增益，候选 1 的增益会被对照吃掉——这正是用 Q 协议从头对照并报告周期内曲线的理由。
4. **负面先例**：v335/v340 周期/隐式解码器族 K0 仅 .55（`encoder_information.md`:38）；SDF 头、free 头在 v293 无效（5b 第 53-58 行、5c 第 60-65 行）。它们改的是坐标轴/决策规则而非码值轴，但说明"换解码头"在本项目多次失败。
5. **可训练性**：sin(2^6 π μ̂) 对编码器的梯度放大 ~200×；无频率退火时第 1 轮可能发散。
6. **未量化项**：HouseExpo 的 1-px 错位占比未知；若残差主要是错位（v293 容差 F1 .98，第 272 行），候选 1 无效而候选 2 的尺度项才对症。建议先用 `error_anatomy_v347.py` 在 v384 面板上跑解剖（CPU，零成本），按 L 分层。

## 4. 排序
- **top-1：候选 1（码值傅里叶特征）**——唯一在不动 64 维的前提下、从解码器侧直接攻击"一块一标量"这一已确立上限的结构。发射前置条件：v387 ≤ +1 pp；HouseExpo 解剖显示门楣/开口/薄墙（非错位）占残差 ≥ 一半；T 两种子 < +1 pp（同族饱和）更支持它。
- **top-2：候选 2（公共帧条件化）**——零风险、零成本、修复已登记的尺度盲；若 T 与 v387 都指向"同族已饱和"，可与候选 1 合并为一个干预。
- **明确不推荐**：
  - 隐式坐标解码（query (x,y) → 占据）：残差不是空间锐度（v293 容差 F1 .97–.98，D3-3、第 272 行），且本项目隐式/周期族先例失败（`encoder_information.md`:38）。
  - 轴对齐线段头 / 光栅化：门洞填充在 v293 被证明是训练预算而非决策规则（第 311 行）；几何渲染器族可达性仅 .85–.88（`encoder_information.md`:112）；槽位分配问题难训练。
  - 输出侧测试时优化 / 循环一致性：解码器处没有观测，只能对码做一致性，码里没有的信息补不回（D3-4）；且 122 ms/agent（brief 第 39 行）。
  - 多假设头：门端预测 DT ≈ 0 是自信错误而非模糊（D3-4 阈值扫描）。
  - 开口感知 / 结构化损失：free 头门洞 +3.1、墙 −2.2 pp（5c）；重加权不增加信息。
  - 数据增强 / 阶段权重 / 更长训练：7,200 → 14,400 已饱和（D4-18），周期收益减半（D5-1），属"更多同类"。
  - 注意力：等 T 的结果。
