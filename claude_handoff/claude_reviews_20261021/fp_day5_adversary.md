## 1. 第一性原理：残差由什么决定，64 标量/块的天花板在哪

### 1.1 证据链
1. **残差一半以上在 8+ 室**。宏观 R8 .893/.901 是 6 层等权均值（T L635-642）；分层 R8（BEST L25-31）：2–4 室 .92–.94、5–7 室 .91–.92、8+ 室 .82–.87。把种子 342101 六层残差相加（.060+.076+.075+.090+.159+.182 = .642），8+ 室占 **53 %**，5–7 室 26 %，2–4 室 21 %【推断】。等权分层不是人为放大：TRAIN 每层 5,383 / 8,533 / 6,450 套（CR375 L155），按人口加权得 .893，与等权 .893 相同【推断】。
2. **8+ 室是 bit 短缺**。v371 图幅下整栋轴对齐多边形描述 282 / 516 / 794 bit，27 / 48 / 79 个顶点（OR D4-7 表）；户型平均落在 45 个块上（OR D4-5）⇒ **6.3 / 11.5 / 17.6 bit/块**。每块只有 8 bit 均值；精度经验熵 ≈4.6 bit（OR D3-6）且按 BR 约束 2 必须是置信度。2–4 室够用、5–7 室勉强、8+ 室短约 2×——与三层 F1 的台阶逐一对应。
3. **决定性的是独立空间单元数，不是每单元位数**：16 bit 上限 .814 vs 8 bit .819（OR D4-11）；4×4×4 .623 < 8×8×1 .694 < 16×16×1 .918（OR D4-6）；贴合图幅 24→45 块 +10–13 pp（OR D4-8）。但 D4-11 的协议是"冻结光滑解码器 + 梯度拟合自由码"，只证明光滑解码器用不上更多级数，不证明 8 bit 对 8+ 室足够（BR L29-31 承认训练模型已超该上限 10 pp）。
4. **不在融合、不在决策规则、不在损失**：理想同态 vs 实际 ≤0.4 pp（OR D4-10）；anchored 读出 −2.8/−2.9（OR D3-8）、一致性损失 +0.6/+0.9（N2-3）、SDF 头持平（5b）、free 头 −2.2（5c）、τ 扫描无增益（D3-4）、owner-priority 更差（D3-4）。门洞是靠更长训练修好的（D3-11），即先验问题。
5. **残差形态**：v293 解剖（EA L22-37）：精确 F1 .917 → 1-px 容差 .969；幻觉墙 2.5 %，其中 90 % 在门洞（L26）、95 % 在多源块（L29）；1-px 抖动 FN 5.3 % / FP 5.1 %（L36-37）。HouseExpo 没有同类 JSON，只有面板（figures/houseexpo_best_v383_panels.png）：误差 = 沿墙细红/蓝平行线（抖动）+ 门洞旁短墙段、大户型薄内墙整段缺失（BR L36-37）。

## 2. 候选结构（≤3）与通用规则

### 2.0 通用预注册规则（统计）与预算
噪声事实：同配置复跑 sd ≈ 2.3 pp（OR N2-1）；种子 342202 系统性高 1–2 pp（D4-18）；安慰剂子集 −5.85 / +1.58 pp（D4-17：13 户 fixture 逐比特相同）⇒ 逐户噪声重尾；位姿抽样 0.76 pp、配对后 0.48（CR378 L63-66、L88）；有效样本 24 户（N8/N16 共享户型，V365 L208）。历史同种子配对差（+2.2/+4.5、+0.25/+2.57、−0.8/+1.6、+1.04/+1.28）给出**配对差 sd ≈ 1.2–1.7 pp**，下面取 1.6。

"+3 pp 结构性"才可宣称的规则：
1. 配对：同种子 ⇒ 编码器/head 初始权重逐位相同、数据顺序相同（T L227-229、L650；CR386 §2 已证）；位姿按 CR378 M1 平移配对，fixture 不变的户型作安慰剂；对照与候选同期跑，或复用批次 Q 并过 `initial.pt`/RECIPE 身份守卫；读最终权重不读 best.pt（T L697-720）。
2. 判据（两种子筛选）：VAL **和** fresh 上**两种子都 ≥ +2 pp 且均值 ≥ +3 pp**；8+ 室两种子 ≥ 0；FPR ≤ +0.3 pp；逐户配对 cluster bootstrap（24 户为簇，B = 3000，D3-1b 做法）95 % CI 下界 > 0。sd 1.6 下的正态近似【推断】：零效应误报 ≈ 0.4 %，真 +3 的功效 ≈ 45 %，真 +4 ≈ 70 %。功效偏低是刻意的——结构性主张必须大到不含糊。通过后再跑第三种子 342303（HouseExpo 没有它的对照，须新跑）确认。
3. 附报：1-px 容差 F1 与 DT 场的 AUPRC（分离"定位"与"内容"，DHA A3）；无近副本子集（CR375 M3）；多源块上的 R8。

租约预算：当前模型 57,600 × 0.09 s = 5,184 s + 加载 + 4 次验证 ≈ 5,600 s < 6,600 s（R 实测 5,331 / 5,378 s，D5-0）。**可并行阈值 ≈ 0.104 s/更新（≈1.1× 当前 0.094，HANDOFF L38）；单跑阈值 ≈ 1.6–1.9× 当前算力**（解码器 ×2 单跑 0.083 s = 4,781 s 装得下，并行 0.14 s = 8,064 s 装不下，BR L54）。筛选 = 1 租约（可并行）或 2（单跑）；第三种子 + 对照 = 再 1–2；若要在三周期前沿（.90）而非批次 Q 预算（.86）上证明（CR386 §7 保留 7：迁移未经检验），每种子再 2 周期 ⇒ 合计 **4–8 个 7,200 s 租约**。

### 2.1 候选 A（若被迫出资）：公共自适应分块，只用公开量（外接框 + 全体位姿 + 5 m 感知半径）
- 机制：均匀 8×8 块中，外接框外（图幅 43 %，D4-11）与任何 agent 5 m 圆盘之外的块必然无人观测，q = 0（T L155-161、L327-328）却占坐标。把 64 个单元按公共密度（圆盘并 ∩ 外接框）做 k-d 划分；编码器把每单元重采样为 16×16 补丁进 PatchTrunk（T L103-104 的 unfold 换 grid_sample）；解码器按同一划分把 64 码散回 16×16 画布（T L196-200）再进 CnnTrunk。位姿已是公共帧（T L489 森林用它，V371 L117），无新信息进入读出。
- 量级：块密度是唯一测过剂量响应的杠杆（D4-6、D4-8），残差 ≈ 密度^(−0.8)【拟合：1.9× → ×0.59，4× → ×0.27】。A 的密度 ≈ 64/(45–50) = 1.3–1.4× ⇒ 残差 ×0.77 ⇒ **+2–2.5 pp**（大户型 N8 受益多，小户型 ≈ rect 增益）。诚实地说**达不到 +3**，预注册 +2。
- 约束逐条：64+64 不变；无侧信道（划分只依赖公开量）；融合不变（join 按坐标，坐标 = 公共单元）；解码器只读 (q,h) + 公共划分平面；TRAIN/VAL/TEST 不变。
- 代价：数据模块 / 编码器 / 解码器各一处，0.5 天 + 数学测试（划分退化为均匀时须与 v378 逐位相同，照 CR378 `square=True` 做法）；算力 +5–10 % ⇒ 可并行，1 租约 2 种子。
- 对照：均匀 8×8（批次 Q）；安慰剂 = 划分退化为均匀的户型。判据：§2.0 但阈值 +2 / 均值 +2.5。
- 否定证据：rect（同类、更弱）+0.25 / +2.57 模棱两可（D4-17）；几何边茎选择零样本掉 1.6–4 pp、ROI 任务无信息损失仍掉 7–10 pp（D3-5）⇒ 解码器依赖邻块上下文，不规则划分会打乱它。

### 2.2 候选 B（需用户裁定）：A 的强版——按观测块掩码的 OR 共识分块
- 机制：第 0 阶段洪泛 64 bit 观测块掩码（OR 是格 join，与 max 同一语义，直径轮收敛），划分 = f(并集掩码)，之后按该划分编码、洪泛码。密度 ≈ 64/(并集观测块 ≈40–45) ≈ 1.5× ⇒ 残差 ×0.72 ⇒ **≈ +3 pp**。
- 问题：掩码是样本相关量进入读出，按 BR 约束 1 原文是侧信道；但同样 64 bit 已由精度平面精确披露（q = 0 ⇔ 未观测，T L155-161；LRE §1 A1）。多一个阶段、每消息 +8 B。**不裁定不启动。**
- 对照：同样洪泛掩码并把掩码平面给解码器、划分保持均匀——使"已知头拿到并集支持图"这一混淆两臂相同。

### 2.3 候选 C（需用户裁定）：块码改为 8 bit 索引 + 学习码本（VQ）
- 机制：现在 8 bit 标量经 tanh/round（T L241-244）进光滑解码器，是**一维流形上的 255 个图案**；经验熵只用 5.4–7.6 bit（D3-6、D4-14）。改为 256 项学习嵌入（STE），线路、位数、max-join（索引整体胜出）全部不变，只有解码器第一层读嵌入。
- 为什么可能 ≥ +3：8+ 室需 ~18 bit/块，8 bit 不够，但 256 个任意图案 + 卷积先验比 1-D 流形更接近"每块一个结构原语"；D4-11 的 16 bit 零结果是光滑解码器协议的结论，不覆盖此设计。期望不确定（0 到 +3）。
- 约束风险：均值不再是高斯均值（sum 下无意义；max 下无影响）；README §3.1 "不要 token" 可能被认定违反。**不裁定不启动。** 代价最小（一个 Embedding），算力不变，1 租约。
- 对照：同架构、嵌入冻结为 1-D 线性（等价现状）。

## 3. 反证：候选 A 最可能怎样失败
1. 增益 ≈ rect 的外接框部分，而 rect 在同噪声下不可判（D4-17）；圆盘排除只在大户型 / N8 起作用，等权宏观摊薄到 < 1 pp。
2. 不规则单元重采样让补丁不再像素精确（大单元被下采样），K0 先掉；解码器要学"划分→画布"的可变映射，冷启动在等更新下吃亏（CR386 §7 保留 1、3）。
3. 解码器依赖邻块上下文（D3-5 零样本 ROI 掉 7–10 pp）；划分改变邻接后上下文先验失效。
4. 即使 +2 pp，也在"所有 64 标量设计合计 +2.5–3.5 pp"的预算内，与批次 T、第四周期不可叠加——必须在 T 的赢家上做，否则增益会被后续周期吞掉而无法归因。
已有相悖结果：D4-17、D3-5 (a)(b)。

## 4. 排序
- **top-1（被迫出资）：候选 A**，预注册 +2 pp（不是 +3）；若用户裁定 §2.2 的 64 bit 共识轮属"公共帧"，改做 B，预注册 +3。
- **top-2：候选 C（VQ 码本）**，前提是用户认可"硬 8 bit 整数已是码，嵌入读出不违反 64+64"；它是唯一直接攻 8+ 室 bit 短缺且代价最小的改动。
- **明确否决：隐式/坐标解码器**——负证据最强（−42 pp、五次 K0 = 0、10–19× 慢）、最贵、最易被"换分辨率评估"误读。同时否决训练期分析-合成（装不进租约）与连续性因子（定理级反证，CPU 测试即可杀掉，不值一个租约）。
- 对在飞实验的预测（事先写下）：批次 T 两种子 +0.5–2 pp（模棱两可区）；v387 精修 K0 +1.5–2.5、R8 ≤ +0.5 ⇒ 按 BR L56 读作"表示 / 解码器受限"。若 T 通过，(b) 项缩小、(a)+(c) 的 6–7 pp 成为硬底；若 T 不通过，解码器不是杠杆，结论不变。
