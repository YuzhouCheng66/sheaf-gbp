# 准确率达标之后的三件事——按同一原则（奥卡姆 + 第一性）写的设计提纲（只设计，不启动）

## 1. 极限编码：每维少于 8 bit，且在训练中处理
- 原则：码率由"训练时的量化器"决定，不做后压缩。现在的 hard-8（255 级均匀量化 + STE）就是最简单的 8 bit 版本，直接推广为 **k-bit 均匀量化 + STE**（k = 6/5/4/3），其他一切不变——这是奥卡姆的第一步，先测 k–精度曲线，知道哪里开始掉。
- 第二步（只在均匀量化先掉时做）：**熵编码而不是减级数**。块码的分布高度不均（多数块"空/未观测"），对 μ 的 255 级做 TRAIN 拟合的熵模型（每块一个简单的分类分布，或以邻块为条件），训练时加 λ·E[−log p(code)] 的码率项（经典 Ballé 式端到端率失真），wire 用算术编码。精度 q 本就偏向两端（弃权 vs 满覆盖），1–2 bit 足够。
- 评价口径不变：墙 F1 / acc / FPR 对 **实际发送字节**（含 header、来源/版本、重传）画曲线，与 2-bit raw 和强无损 raw 对照同图。
- 预期：owned 码的"未观测块"几乎免费（q=0 ⇒ 不发 μ），这正是 owned 语义在码率上的红利——现在 172 B 包里有大约 85% 的块是空的。

## 2. 让 restriction map 不再是恒等
- 现状：常值层 R^64 + 恒等限制映射；所有权只体现在顶点势的支撑上。能保持消息精确对角的限制映射只有：正对角缩放、带符号置换、部分选择（已证明）。
- 最小而有意义的非恒等版本：**边茎 = 两端"都可能相关"的块选择**（partial selection），由公共几何决定（如离边中点 ≤ 通信半径 + 感知半径的块），其余块不进入该边——这保持精确对角，减少无关坐标的传输（码率↓），且是严格意义上的 restriction map。
- 更进一步（会改变能量，需要单独审计）：把 restriction 的对角缩放 a_e 用来表达"信任/时效"，例如对旧版本来源降权（见第 3 点），而不是用来重定址。
- 不做：稠密 restriction 后丢掉非对角项（破坏目标），或在环路图上做等式洪泛（×875 精度膨胀已测）。

## 3. 动态 / 增量更新：64 维向量作为 multi-agent memory
- 第一性：owned 码天然支持增量——agent 探索扩大后，只有**新覆盖或覆盖变化的块**的 (μ_k, q_k) 变化；GBP 已有 source-once + 版本号机制（`replace_sources`：新版本**替换**旧源因子，不是累加），所以"重新沟通"= 发送变化的块 + 版本号，接收端替换该来源的因子后重新做 cavity 消息。数学上与一次性沟通一致，不会重复计数。
- 需要新增的只有：(a) 发送端的"块级 diff"打包（变化块的索引 + 新值）；(b) 接收端对**同一来源旧版本**的替换（已有）；(c) 评价：按时间步报告墙 F1/acc 与累计字节，和"每次全量重发"对照。
- 训练：把每个 agent 的三个位姿当作时间步（观测随时间扩大），训练时随机截断观测历史，使 encoder 学到"码随探索单调细化"；一致性损失自然推广为 enc(A_t) 与 enc(A_{t+1}) 在未变化块上的稳定性。
- 不做：把旧后验当作新观测重新注入（会被 v295 的断言拒绝，也是双重计数）。
