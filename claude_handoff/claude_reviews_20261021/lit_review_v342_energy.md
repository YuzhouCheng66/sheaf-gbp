## 1. Is the forest posterior exactly the per-block precision-weighted union? Where is the residual inexactness?

### 1.1 What the sealed code computes (exact statement)

Trainer `diag/train_v342_owned.py:213-234` (`make_rollout`): `evidence_q = mask*q_learned` (L218), `precision = evidence_q + prior` with `prior = 1e-4/(64N)` (L217,219), `h = evidence_q*mu` (L221), `forest.initialize(q,h,edges)` (L222), one `forest.advance(state,1,quantized=True)` per round (L230), features = `[hard8(mean), log var]` from `forest.scalar_belief` (L224-226). In `mapping_multiroom_forest_v295.py` the cavity is the original source factor plus the other incoming messages (L204-205), messages replace caches (L220), belief = source + incoming (L161-166). On a forest each directed cavity contains each source at most once, so after R rounds, for recipient i and block k, with S_i(R) the sources within forest distance R and O_ik = {j in S_i(R): mask_jk = 1}:

P_ik = sum_{j in O_ik} q_jk + |S_i(R)|*alpha,   eta_ik = sum_{j in O_ik} q_jk*mu_jk,   mean = eta/P, var = 1/P.

Witness W2: on 16 real VALIDATION forests the unquantised sealed rollout equals this reached-set sum to < 1e-10 (ER T6: 4e-16). Three cases:

- O_ik empty (nobody in S observed block k): mean = 0 exactly, var = 1/(|S| alpha). Abstention survives the quantised wire exactly, because h = 0 gives a standardised information value of exactly 0 before block-float rounding (`forest_v295.py:183-192`); W2 asserts unobserved-block posterior means are 0.0 in both float and profile-4 rollouts.
- |O_ik| = 1: mean = mu_jk * q_jk/(q_jk + |S| alpha): the single observer's code, shrunk by the prior (quantified in 1.2).
- |O_ik| >= 2: a precision-weighted average of several agents' codes *for the same 2.5 m x 2.5 m block*. This is a union only if the codes agree (redundant views), or the code is an additive sufficient statistic with q proportional to coverage (ER condition O3; the occupancy-grid log-odds sum is the classical instance, Elfes 1989), or training has co-adapted encoder and decoder so that the average decodes to the union.

So: arithmetically the posterior is exactly the per-block precision-weighted sum over the reached set; semantically it is a per-block *average over observers*, and "union" is exact only across blocks (disjoint ownership) and, within a block, only under O3.

Whether it is mean blending, variance-channel readout or decoder load is not separable from the endpoint numbers; section 5 is designed to separate it.

**(b) Profile-4 wire quantisation (small, irreducible, calibrated by training).** `forest_v295.py:174-194`: precision on 255 log levels over [1e-8,128] (step ratio (128/1e-8)^(1/254) = 1.0960, i.e. +-4.7 %), information as h/sqrt(p) with a 7-bit mantissa and one shared exponent per 64 coordinates; FP32 cast. W3/W3b on real 8-16 node forests, random owned factors with q in [0.3,3.8]: posterior-mean error at R8 on observed blocks mean 0.76 hard8 steps, p95 2.1, max 4.1-5.4 steps (= 0.6 % / 4 % of the [-1,1] code range); log-variance error <= 0.092 nats (exactly one precision step, log 1.096), i.e. 0.011 decoder-input units after the /8 scaling (`train_v342_owned.py:155-156`). Dependence on posterior precision is weak (corr(log P, error) = -0.15; blocks with P < 1 average 1.0 steps, P in [10,30) 0.55 steps), so the shared block-float exponent is not a significant penalty for heteroscedastic owned precisions. Scale: if a block scalar encodes a position linearly across a 2.5 m block, one hard8 step is 1 cm and the worst observed 5 steps are 5 cm, against 15.6 cm pixels at H128: sub-pixel. The test `test_v342_math.py:41-42` asserts <= 2/127 for a 2-source line; W3 shows that bound is scene-specific, not general (real forests reach ~5 steps); not a bug, but the stated tolerance should be reported as "about 1 step typical, 5 max".

**(c) Prior double counting (negligible on means; a disclosed |S|,N cue on variances).** Each source carries alpha = 1e-4/(64N) (`train_v342_owned.py:217`, same as v277 `factors`), so a reached set contributes |S| alpha instead of one prior. Product-of-posteriors with prior division (Tresp 2000 Bayesian committee machine; DDF fusion rule p(x|Z_a U Z_b) proportional to p(x|Z_a)p(x|Z_b)/p_c with the common information p_c, Dagan & Ahmed 2021 Eq. 2) would use alpha once. The excess is Delta = (|S|-1) alpha <= (N-1)*1e-4/(64N) < 1.5625e-6 per coordinate.
- Mean shift of an observed block: |mu| Delta/(sum q + Delta). At the precision floor q = 1e-4 and |S| = N: 1.54 % of |mu| = 1.95 hard8 steps at |mu| = 1 (W2 measured max 1.77); at q >= 1e-3 it is < 0.2 step and rounds away; with typical q (W2): 5e-4 steps. Irrelevant.
- Log-variance shift of an observed block: log(1 + Delta/sum q) <= 1.5e-2 nats at the floor, 4.8e-6 nats typical (W2). Irrelevant.
- Unobserved blocks (the only place where the prior *is* the precision): log var = log(64N/(|S| 1e-4)) = 13.37 + log(N/|S|) nats, i.e. 15.45 (N8) / 16.14 (N16) at R0 and 13.37 at full reach; in decoder-input units 1.93-2.02 at R0 down to 1.67 at |S| = N, versus at most 1.15 for any observed block (single observer at the floor) and -0.52 for 16 observers at q = 4. The abstention signal therefore stays readable (ER condition O4) with a margin >= 4.2 nats (0.52 input units) for every |S| <= 16, and as a by-product the decoder can read |S| (2.77-nat swing) and N from any unobserved block. This is the "prior double counting term" in the owned arm: it does not touch means, it is the mechanism by which the variance channel carries reach count. Note also that at |S| = N the total prior is exactly 1e-4/64 independent of N, i.e. v277's alpha is a *split prior* that coincides with exact PoE-with-prior-division for a global prior of 1e-4/64 at full reach; for partial reach it undercounts that prior by (N-|S|)alpha. Either reading: <= 1.6e-6, immaterial. Recommendation: keep it, state it in the write-up (the code review already asked for this disclosure), do not "fix" it: replacing |S| alpha by alpha would remove the |S| cue the decoder was trained with.

**(d) Correlated evidence (not a prior effect).** Two observers of the same block are deterministic functions of the same world, so adding their precisions overstates certainty (the data-incest problem that covariance intersection addresses, Julier & Uhlmann 1997). On a forest with source-once cavities this does not bias the mean when codes agree; it only inflates the variance channel, which here is a learned feature rather than a calibrated posterior, so it is harmless for this decoder. It would matter if the log-variance were ever used as a calibrated confidence downstream.

Ranking of the residual: (a) >> (b) > (c), (d). A fusion-side improvement at H128 can only come from (a).

## 2. Is the owned construction a cellular sheaf? What restriction maps would be natural, and do they keep messages diagonal?

**Definitions (Hansen & Ghrist 2019, Def. 2.4-2.5, Sec. 3.2).** A cellular sheaf on a graph assigns a stalk F(v) to each vertex, F(e) to each edge and linear restriction maps F_{v <| e}: F(v) -> F(e); the coboundary is (delta x)_e = F_{u <| e} x_u - F_{v <| e} x_v, the degree-0 sheaf Laplacian is L_F = delta^T delta (diagonal block sum_e F^T F, off-diagonal -F_u^T F_v), global sections H^0 = ker delta are the assignments consistent across every edge. The constant sheaf has every stalk equal to V and every restriction map the identity; its Laplacian is the graph Laplacian tensor I_V and its global sections are the constant assignments (consensus). Weighted sheaves (Sec. 3.1, 3.5) put inner products on the stalks; a weighted constant sheaf is isomorphic, though not unitarily, to the constant sheaf.

**Verdict on v342.** The owned arm is the constant sheaf R^64 on the BFS forest: stalk R^64 (8x8 block scalars) at every vertex and edge, identity restriction maps, hard equality (infinite edge weight) in v295. The energy ½ sum_i (x_i - mu_i)^T Q_i (x_i - mu_i) subject to delta x = 0 is a Dirichlet problem for the constant sheaf with vertex potentials; the finite-precision family B (ER 2a) is the weighted sheaf-Laplacian quadratic form x^T L_F x plus vertex potentials. Ownership changes *none* of the sheaf data: it changes the support of the vertex potentials Q_i = diag(mask_i q_i). In Hansen-Ghrist's weighted language, q_ik = 0 is a degenerate inner product on coordinate k of the vertex potential, not a restriction map. So "owned sheaf" is correct only in the degenerate sense "constant sheaf + support-restricted observation potentials"; the sheaf-theoretic content is the choice of one public chart (the 8x8 grid) in which all vertex stalks are identified. Hansen & Ghrist's discourse-sheaf picture (2021) - private opinion space at the vertex, shared discourse space on the edge, restriction map = how the private state is expressed publicly, "selective opinion modulation" - is the natural vocabulary: here every agent expresses itself in the public chart with the identity map and modulates by weight (q = 0), not by map.

**Natural non-trivial restriction maps for owned blocks, and diagonal closure.**
1. Cover-nerve / sensor-integration sheaf (Robinson 2017): F(i) = R^{B_i} (blocks i observed), F(ij) = R^{B_i ∩ B_j}, restriction = coordinate selection; global sections = assignments that agree on overlaps = glued maps, and Robinson's consistency radius is exactly the disagreement between observers of the same block (W1's "differing views"). Selection maps are scaled partial permutations, so by the diagonal-closure argument (ER 2b, T8: the delivered precision B^T (A Q^{-1} A^T + I)^{-1} B is diagonal for all diagonal Q iff no column of A and no row of B has two nonzeros) they keep every message exactly diagonal; with hard-equality edges the message is simply the cavity restricted to B(e) and zero-padded, and an abstained zero stays zero. But on a tree used for *relaying*, an edge stalk B_i ∩ B_j (or even B_i U B_j) blocks transit: j's content about blocks i never saw cannot pass through i to a third agent, so the R8 arrived-union target would be unreachable. The constant sheaf with abstention is precisely the zero-padded lift of the cover-nerve sheaf that restores transit: identical posteriors on B_i, plus relay for free. That is the strongest argument that the current (trivial) sheaf is the right one for the union task.
2. Geometric selection, F(e) = blocks within distance d of the edge midpoint: diagonal-closed for the same reason, saves wire bytes (only |B(e)| of 64 coordinates), and encodes a locality prior. At this world scale it is nearly vacuous: communication radius 8 m, sensor range 5 m, so each endpoint's own content lies within 9 m of the midpoint, i.e. covers most of a 20 m x 20 m map; and for sources r hops away the block must be inside B(e) on every edge of the path, which is again a filter against the union target. It becomes natural only for worlds much larger than the communication radius, together with a locally-defined (not arrived-union) target.
3. Any mixing map (e.g. a coarse edge stalk that sums 2x2 blocks for distant content) is *not* diagonal-closed (ER T8: generic dense 0.51 off-diagonal mass) and would destroy the per-block abstention structure once diagonalised; multi-resolution owned codes therefore cannot be expressed with 64 diagonal precisions and equality/incidence edges.

Conclusion: with owned blocks the only natural restriction maps are selections; they are diagonal-closed; they are either redundant with q = 0 abstention (constant chart) or harmful to relaying under arrived-union targets. The sheaf name should be kept honest in the write-up: constant sheaf, identity maps, ownership in the data terms.

## 3. General cyclic graphs: are owned codes with equality edges safe under loopy GBP?

**Literature.** Weiss & Freeman (1999/2001): if loopy BP converges in a Gaussian model it yields the correct posterior means for any topology, while the covariance estimates are generally incorrect. Malioutov, Johnson & Willsky (2006): convergence is guaranteed for walk-summable models (a strict subset of positive-definite models; implied by diagonal dominance / pairwise normalisability), and LBP variances are walk-sums over a restricted class of walks, hence wrong in general. Ortiz, Evans & Davison (2021, Sec. 1.3) restate tree exactness and the empirical robustness of GBP on loops. None of this covers the v295 model: hard equality edges make the joint precision singular (every cycle has an infinite-precision constraint), the model is not pairwise normalisable, and the equality sum has no fixed point on a loop - the belief precision grows with the number of rounds (ER T7b: 3,5,9,17 on a triangle). This is why `validate_forest` (v295 L44-58) refuses cycles.

**Witness W5 on a real N8 physical graph (14 radius edges, 7 independent cycles; W4: N16 scenes have 37-40 physical edges beyond the 15 forest edges).** Synchronous equality-sum flooding with the standard "exclude the sender" cavity, 8 rounds, owned factors:
- precision overcount on observed blocks: median x875, max x1582 relative to the reached-set sum; the log-variance channel is destroyed (log 875 = 6.8 nats, 0.85 input units, far outside the trained range);
- abstention: unobserved-block means remain exactly 0 (all copies have h = 0);
- agreeing observers (block code a public function of the block content): means exact to 3e-7 (any convex combination of equal values is that value);
- disagreeing observers (complementary partial views): means move by 3.6 hard8 steps on average, 33.7 max, relative to the forest-sum average - sources on short cycles near the receiver are over-weighted. The mean stays inside the convex hull of the observers' codes (positive weights), so the result is still "some blend of views of this block"; the union semantics degrades to a re-weighting rather than breaking as the dense code does (ER T4(ii), wrong already at R1).
So: owned codes under loopy equality GBP are exactly safe for abstention and for redundant content, approximately safe (re-weighted) for complementary blocks, and unsafe for the variance channel. A decoder trained on forest statistics would misread the variance channel; the claim "no general-cycle inference" in the endpoint is correct and should stay.

**Known fixes compatible with 64 diagonal precisions.**
1. Spanning forest (current). Equivalent to the channel filter of decentralised data fusion, which removes common information exactly only on tree topologies (Grime & Durrant-Whyte 1994; Dagan & Ahmed 2021 Sec. III, V.C). Cost: W4 shows the BFS forest reaches 2.7-2.9 sources at R1 and 5.1-5.2 (N8) / 7.4-8.1 (N16) at R2, against 4.1-4.3 / 7.5-7.9 at R1 and 6.3-6.8 / 13.9-14.0 at R2 on the physical graph - the forest costs roughly one round of reach for N16 and about half a round for N8.
2. Source-once journaling at source granularity: each packet carries a 16-bit source bitmask (2 bytes) and the receiver stores per-source factors and sums each source ID once. Exact on any topology (order- and duplicate-insensitive in the sense of Nath et al. 2004: the fusion "union of (id, factor) records" is commutative, associative and idempotent, their properties P2-P4). Cost: up to N records per edge per round, but owned records are sparse (8 observed blocks x (1 B mu + 1 B q) + 8 B bitmap ~ 24-32 B per source), so 16 sources ~ 0.5 kB per edge per round, about 3x one 172-B summed packet; memory N x 128 numbers per node.
3. Idempotent per-block selection: per block keep the (q, h) of the highest-precision observer (deterministic tie-break by source ID makes (q, -id) a total order, so the rule is a join-semilattice: commutative, associative, idempotent). W5: bitwise equal to the centralised max over the reached set on the cyclic graph; no extra bytes; same 64 diagonal (p, eta) wire; it can run on the physical graph and so gains the reach of W4 (R1 reach 4.1-4.3 / 7.5-7.9 sources instead of 2.7-2.9). Semantics: abstention and agreeing content exact; on complementary blocks it *selects* instead of blending, i.e. it gives up the additive-statistic route (O3) in exchange for loop safety. Whether selection or blending composes partial-block unions better is an empirical question (section 5). The learned q becomes a coverage/confidence score, which the encoder can learn from its own view.
4. Covariance intersection / inverse covariance intersection (Julier & Uhlmann 1997; Noack et al. 2017): coordinate-wise on diagonal precisions, p = w p_a + (1-w) p_b, eta = w eta_a + (1-w) eta_b (CI) or p = p_a + p_b - (w/p_a + (1-w)/p_b)^{-1} (ICI, never more conservative than CI at matched parameters, consistent and tight under unknown common information, iterable). Both stay diagonal and idempotent; both are consistent on loops without bookkeeping; both are conservative (a single observer's precision is scaled by w under CI) and both still blend means on complementary blocks. With w in {0,1} CI reduces to rule 3.
5. Average consensus / push-sum on (sum q, sum h) (Xiao, Boyd & Lall 2005; Kempe, Dobra & Gehrke 2003): the owned mean eta/P is invariant to the common scale, so at convergence every node holds the exact precision-weighted average on any connected graph, and push-sum's mass conservation ("the sum of all weights is always n") rules out double counting even under asynchronous gossip; the precision comes out scaled by 1/N. Cost: convergence takes mixing time, not diameter; incompatible with the R <= 8 paid-round regime.

Recommendation: keep the forest for the sum rule; if cycles are ever claimed, the only zero-byte, decoder-compatible route is rule 3 (and it changes what the decoder is trained on, so it needs its own matched pair).

## 4. Trainer verification: no posterior re-injection; R-stage targets = forest reached sets

- Source factors are built once per scene from the encoder (`train_v342_owned.py:428`, `:372`) and enter the forest only through `forest.initialize` (L222), which stores them as `state['q']`, `state['h']` (v213 L22-24) and validates FP64/diagonal/positivity/envelope (v295 L131-142). `advance` builds every cavity from `result['q']`, `result['h']` and the previous round's messages (v295 L204-205) and replaces message caches (L220); `scalar_belief` (L161-166) is read-only. The trainer never calls `replace_sources` (grep: no match) and never writes back `feats`, decoder outputs or predictions into `mu`, `q`, `mask` or the state. Decoder inputs are `cat(feats[0], feats[k])` (L432, L392): the R0 belief (own factor, prior-shrunk) and the round-k belief. Verdict: nothing re-injects a posterior as evidence. The local-refinement variant (L373-387) optimises the *source* mean z against `tgt[0]`/`dt[0]` (own observation; `forest_targets(inp,0)` returns the own map because `reached = eye` at rounds = 0, bank L118-122) with the owned mask applied (L380, L387, patch A), then reruns the rollout from scratch (L388): local computation on the agent's own data, not re-injection; it is reported separately and never used for training or selection.
- Targets: `load` (L317-324) calls `bank.forest_targets(inp,k)` for k in (0,1,2,4,8) and `bank.select_forest(positions, adjacency, radius)` for the rollout edges; `forest_targets` (bank L110-122) calls the *same* `select_forest` with the same arguments (L117) and propagates `reached` over the undirected forest edges for exactly k synchronous steps (L118-121), then takes the per-cell max over reached sources (L122), legal as a union because L116 rejects conflicting observations. The sealed `reachability` (v295 L100-111) is the same k-step adjacency power on the same forest, `central_reference` (L282-293) sums exactly that set, and W2 shows the unquantised rollout equals it to 1e-10 on 16 scenes (ER T6: 4e-16). Since `advance` moves information exactly one forest hop per round, the stage-k features and the stage-k targets refer to the same reached set S_i(k). The code review's independent check (`code_review_v342.md` section 2) agrees.
- Disclosures that follow from section 1.2(c): the own-channel log variance of an unobserved block equals -log alpha = 15.45 (N8) / 16.14 (N16), so the decoder can read N at K0 and |S| at R>0 from unobserved blocks; both pass through the declared 64+64 bottleneck and are the intended abstention semantics, but they should be stated next to the "never a decoder input" sentence of the protocol.

## 5. The single most informative next fusion-side experiment (with gates)

G1 is the only failed gate and the only fusion-side defect left at H128; sections 1-3 reduce its candidate causes to three: (i) mean blending on complementary blocks (section 1.2(a)), (ii) decoder misreading of the fused variance channel (|S|-dependent, sum-of-precisions), (iii) decoder load from rendering a larger union (not a fusion effect). No training is needed to separate them.

**Experiment F1 - counterfactual fusion-rule swap on the trained v342 owned weights (best.pt and final.pt), inference only, VALIDATION H128 (48 scenes) + FRESH panel, sealed `node_metrics`, R1 and R8.** For each recipient i build the decoder input `[own, posterior']` with posterior' one of:
- A actual GBP posterior (must reproduce .837 own / .848 union at R8);
- B owner-priority mean: on blocks i observed, posterior mean := i's own hard8 mu; variance channel unchanged (isolates mean blending);
- C actual mean, but on i's observed blocks variance := K0 variance 1/(q_i + alpha) (isolates variance readout);
- D = B + C on own blocks (own blocks exactly K0, peer blocks actual);
- E max-precision selection over S_i(8) per block (the loop-safe rule of section 3, computed centrally; report with variance := 1/q_max and, separately, variance := actual sum to isolate the decoder's variance expectation).
Stratify own-wall F1 by block class (exclusive / redundant / complementary, computed from the private maps and the reached sets exactly as in W1). Cost: 48 scenes x 5 variants x 2 stages, minutes on the remote CPU; only sealed APIs plus the trainer's `OwnedDecoder`.

Gates (equal-weight 6 strata, R8 unless stated):
- Reproduction: A within 0.3 pp of the endpoint numbers, else stop.
- Mechanism (i): B own-wall F1 >= .890 (K0 - 2 pp) and A - B >= 5 pp, and the complementary-block own-F1 drop in A is >= 2x the exclusive-block drop. Then mean blending on shared blocks is the G1 mechanism and O3 is only partly learned. Record B's union F1: if B loses > 2 pp union vs A, blending is also what composes the union and G1 cannot be met without a representation change (multi-bit block statistics), not by a protocol change.

## 6. Verdicts

- Q1: arithmetic exact (1e-10); the residual is almost entirely within-block averaging of complementary partial views (64-87 % of own blocks, 57-84 % of own wall cells at R8); wire ~1 hard8 step typical / 5 max, 0.09 nats; prior double counting <= 1.56e-6 (<= 2 hard8 steps only at the q floor), immaterial for means, a disclosed |S|/N cue on unobserved-block variances. Confidence high (measured).
- Q2: constant sheaf with identity maps; ownership lives in the vertex potentials; natural owned restriction maps are selections (diagonal-closed) but either redundant with abstention or harmful to relaying under arrived-union targets at this world scale. Confidence high (definitions + T8).
- Q3: loopy equality GBP with owned codes keeps abstention and redundant content exact, re-weights complementary blocks (3.6 steps mean / 34 max on a real graph) and destroys the variance channel (x875 median); fixes compatible with 64 diagonal precisions: forest (current), per-source journaling (~3x bytes), idempotent max-selection (zero bytes, exact on any graph, different semantics on complementary blocks), CI/ICI (consistent, conservative). Confidence high for the mechanism, medium for the practical merit of selection (untested on this decoder).
- Q4: verified line by line; no re-injection; targets equal forest reached sets. Confidence high.
- Q5: run F1 before any further fusion-side training; it costs minutes and decides between protocol change, decoder fix, or closing G1 as a decoder-load artefact.
