### 7. 科学 / 预注册

- **主指标被世界不变的 "骨架" 严重膨胀（M2）**。楼板 + 外墙在每个世界里占据完全相同的体素：整世界占据体素的 73 %，VALIDATION 目标已知占据体素的 58 %（K0）/ 60 %（R8）。本文在 8 个 VALIDATION 场景上算了 "给定目标已知掩码、只在骨架上画占据、其余画自由" 的参考：**occupied F1 = surface F1 = 0.698（K0）/ 0.731（R8）**，accuracy 0.91 / 0.92。也就是说，一个只学会 "已知范围" 并记住固定骨架的解码器就能越过预注册里 "R8 < .70 ⇒ 不迁移" 的下限，"partial" 区间 (.70, .80) 可能完全由骨架贡献，".80 ⇒ 迁移" 也只要求骨架之外有有限的信息。2D 合成墙（.94 / .95）没有这么大的固定份额，阈值类比不成立。
- "surface F1" 对厚实体的动机（只计信息性的表面）在 64³ 上落空（第 4 项：等于 occupied F1）；它在 128³ / 256³ 才有意义。
- 阈值与无对照设计：作为可行性批次，单臂双种子可以接受，K0 是自带的 "自有地图" 参照、R8 ≥ K0 − 3 pp 是有效的融合检查（骨架在两者中相同，不影响该比较）。但 "是否迁移" 的读数必须以非骨架结构（隔墙、走廊墙、门窗边、家具）为准，否则结论不可解释。
- 射线密度（任务书中 "5 m 处约 0.1 m" 有误）：4096 个 Fibonacci 方向在 r 处的线间距 = r·√(4π/4096) = **0.277 m @ 5 m**（0.2 m 体素在 3.6 m 之外开始漏格）；三个位姿方向相同、只平移 ≤ 0.1 m，合计 12,288 束名义上把全覆盖半径推到 ≈ 6 m，但平移量只有间距的一半、覆盖不均匀 ⇒ 远墙在私有地图里呈 "麻点未知"。指标在目标已知范围内不罚它，但已知掩码在体素级不可预测，会推高未知→已知 FPR 与已知 BCE 的保守性。应记为数据层面的保留（128³ 不足已在头部注明）。
- 其他应记录的保留：世界极规则（楼层高度、外墙、走廊方向固定，cw ∈ [1.6, 2.0]）⇒ 解码器可学到很强的先验；每 agent 已知体素仅 3–6 %，8 agent 并集 35–40 %；M1 修正后 VALIDATION 几何会变、上面的参考数字需在 32 场景面板上重算。

## 结论

**LAUNCH OK WITH CHANGES（M1、M2、M3）。**

训练器主体是对 v378 的忠实移植：块序在 `unfold` / `avg_pool3d` / `reshape` 三处一致（数值核对），`select` / `rollout_max` 与 v378 逐行等价（先验按 n·D 缩放、原点一次量化、未量化自有因子参与信念、首项平局规则），`kbit_wire_quantize` 以 8+8 位导入（实测），泛洪 == 中心化联接 / 幂等 / 置换等变测试通过；损失、预测、三分类准确率、FPR、`agg` / `summary` / `final.json` 的键与链脚本分析一一对应；预检路径（100 步、第 100 步验证、`--deadline-total 0` 跳过最终评估、`history.json` 的 `seconds`）与 `rate()` 的正则在实际日志格式下解析正确；租约 JSON 合法、pgrep 锚定、SOLO 分支每种子独立租约。

三处必改都在发射前可低成本完成：(M1) `_fill` 的下界把恰在体素中心上的边界层排除，64³ 下第 0–2 层所有内墙悬空 0.2 m、第 3 层楼板 2 层厚 —— 修正两行公式 + 楼梯洞顶边距、加测试、6 分钟重生成缓存；(M2) 固定骨架占目标占据体素的 58–60 %，"只画骨架" 即得 R8 .73，高于预注册的 ".70 ⇒ 不迁移" 下限，且 64³ 下 surface F1 恒等于 occupied F1 —— 必须补非骨架 F1、记录参考值并重述三分读数，使 "迁移到 3D" 的结论可解释；(M3) 单进程 11–13 GiB、双进程 24–27 GiB / 32 GiB，并行预检一旦 OOM 链脚本就直接退出而不是回退到顺序方案 —— `rate()` 容错 + ABORT→SOLO + 发射前显存检查。改完后可发射；第 7 项的射线密度（5 m 处 0.28 m，不是 0.1 m）与世界规则性保留请在发射前写入 D5 报告。
