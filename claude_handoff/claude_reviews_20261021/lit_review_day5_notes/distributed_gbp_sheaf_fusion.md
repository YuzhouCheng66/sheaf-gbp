## Key Question 1: Has anyone built a multi-robot mapping system whose shared state is a small fixed-dimension learned Gaussian code with declared per-coordinate information/precision message semantics, and what accuracy/bandwidth did they report?

### Takeaway
No prior work found that matches the full combination (fixed-dimension learned Gaussian map code + per-coordinate precision semantics + lattice/max join + byte-level message budget). The nearest neighbours are (a) GBP systems that exchange Gaussian messages in natural parameters (η, Λ) but over pose/landmark/inducing-point variables rather than a learned code (Robot Web; DistGP, ICRA 2026), and (b) neural-implicit multi-agent mapping that exchanges network parameters with heuristic per-parameter "uncertainty" weights (RAMEN 2025, UDON 2025). None of these reports bytes-per-message; the GBP papers explicitly do not report bandwidth.

### Cited Findings

Closest match in the GBP family (learned function, Gaussian natural-parameter messages):
- DistGP (Nabarro, van der Wilk, Davison), "A Distributed Gaussian Process Model for Multi-Robot Mapping", arXiv 2603.07351, submitted 7 March 2026, accepted to ICRA 2026: a sparse GP whose factorisation mirrors the multi-robot structure, trained distributedly via Gaussian belief propagation; reported to outperform Tree-Structured GPs, train online with dynamic connectivity, and to match a centralised batch model (more slowly) — [arXiv abstract](https://arxiv.org/abs/2603.07351)
- DistGP details: SST experiment uses 25 robots on a 5x5 grid; each robot keeps only its 200 most recent inducing points; robots exchange GBP messages in natural parameters (precision Λ and information vector η) on factors linking their inducing points; communication is asynchronous and range-limited (0.15 in the toy grid, 1500 km in SST); message sizes are not stated — [arXiv HTML](https://arxiv.org/html/2603.07351v1)
- DistGP vs DiNNO (SST MSE, Table I): 0.134 vs 0.175 (Central Atlantic), 0.160 vs 0.222 (North Indian), 0.230 vs 0.316 (South Indian), 0.108 vs 0.166 (West Pacific), 0.240 vs 0.303 (East Pacific); under reduced communication DistGP stays ~0.14–0.17 while DiNNO degrades to 0.249–0.420 and diverges at 700 km range; DistGP converges "in a single pass" on occupancy whereas DiNNO needs many passes (Fig. 5 shows 200); loops "boost accuracy" but "require more iterations"; the paper does not discuss double counting — [arXiv HTML](https://arxiv.org/html/2603.07351v1)

Robot Web (Gaussian messages over poses, not a learned code; no byte figures):
- Murai, Ortiz, Saeedi, Kelly, Davison, "A Robot Web for Distributed Many-Device Localisation", IEEE T-RO vol. 40, pp. 121–138, 2024 (arXiv 2202.03314, Feb 2022): each message is a marginal in the variable's tangent space — information vector η, full precision matrix Λ, plus a linearisation point; the paper uses full precision matrices, does not discuss diagonal approximations, and gives no byte-level message sizes or bandwidth figures — [ar5iv full text](https://ar5iv.labs.arxiv.org/html/2202.03314); [arXiv](https://arxiv.org/abs/2202.03314v2); [Imperial Spiral record](https://spiral.imperial.ac.uk/entities/publication/ac087e1d-6aff-4dc0-b17d-908540e034c1)
- Robot Web real experiment: nine TurtleBot3 Burgers (Raspberry Pi 3B+), ROS2 Foxy best-effort pub/sub, publisher at 10 Hz, messages may arrive late/out of order; RMSE ATE vs Vicon: 0.162 ± 0.085 m (no landmarks, no comm) -> 0.043 ± 0.020 m (no landmarks, with comm); 0.071 ± 0.020 m -> 0.028 ± 0.007 m (with landmarks); message size and bandwidth not reported; authors expect inter-robot communication to be the main long-term bottleneck as the graph grows — [ar5iv full text, Sec. VII](https://ar5iv.labs.arxiv.org/html/2202.03314)

Neural-implicit multi-agent mapping (learned parameters exchanged, heuristic per-parameter weights, not Gaussian precisions):
- RAMEN (Real-time Asynchronous Multi-agent Neural Implicit Mapping), arXiv 2502.19592 (Feb 2025): each agent sends its hash-feature-grid parameters Θ_i and per-parameter uncertainty values u_i to neighbours; u_i accumulates the sign of the absolute gradient per iteration (i.e., an update count); the consensus target is z_ij = (W_ij + W_ji)^-1 (W_ij Θ_i + W_ji Θ_j), so more-updated parameters pull harder; 3 agents in simulation (4–6 in a scalability test), 2 TurtleBots in hardware exchanging maps every 30 s (3.33% message success); parameter count and message size not stated — [arXiv HTML](https://arxiv.org/html/2502.19592v1)
- RAMEN accuracy (Table I, 3 agents, 50% message success, avg over 4 scenes; Artifacts cm / Holes cm / Completion %): DSGD 34.34 / 4.20 / 79.03; DiNNO 19.35 / 3.74 / 80.46; RAMEN 12.98 / 2.57 / 91.44. Hardware (Table II): Robot 1 DiNNO 26.43/4.70/63.07 vs RAMEN 6.50/4.43/78.47; Robot 2 DiNNO 10.76/12.77/39.83 vs RAMEN 5.87/5.15/69.66; no centralised baseline — [arXiv HTML](https://arxiv.org/html/2502.19592v1)
- RAMEN authors state C-ADMM as used by DiNNO and Di-NeRF "is not robust to asynchronous communication or message loss" and that neural implicit maps "lack a direct merging mechanism unlike explicit representations" — [arXiv PDF](https://arxiv.org/pdf/2502.19592v1)
- UDON (arXiv 2509.12702, 2025): uncertainty-weighted distributed optimisation for neural implicit mapping under severe packet loss, penalising disagreement between communicating pairs — [arXiv](https://arxiv.org/abs/2509.12702v1)
- DiNNO (Yu et al., RA-L 2022, arXiv 2109.08665): ADMM-based; robots alternate local optimisation and communication of intermediate network weights; globally optimal for convex objectives; experiments include multi-robot implicit mapping; validation loss "equivalent to centrally trained models" — [ar5iv](https://ar5iv.labs.arxiv.org/html/2109.08665)
- Di-NeRF (arXiv 2402.01485, 2024): C-ADMM distributed NeRF with relative pose refinement; no rendezvous needed; global NeRF quality "comparable to a fully centralized method" — [arXiv HTML](https://arxiv.org/html/2402.01485v2)
- MNE-SLAM (CVPR 2025): distributed multi-agent neural SLAM, peer-to-peer, exchanges network parameters and keyframe poses, merges networks by comparing rendered images / SDF values in overlaps — [CVPR 2025 PDF](https://openaccess.thecvf.com/content/CVPR2025/papers/Deng_MNE-SLAM_Multi-Agent_Neural_SLAM_for_Mobile_Robots_CVPR_2025_paper.pdf); MCN-SLAM (arXiv 2506.18678, 2025): hybrid implicit representation with multi-agent distillation into a global map — [arXiv PDF](https://arxiv.org/pdf/2506.18678)

Learned map compression for multi-robot communication (compression only, no probabilistic latent fusion):
- Sensors (May 2024), "Deep Compressed Communication ... Multi-Robot 2D-Lidar SLAM: An Intelligent Huffman Algorithm": CNN feature extractor + Huffman/run-length coding + recovery CNN; ~99% reduction in communication overhead while maintaining map quality; two-robot 2D lidar setup — [PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11124910/)
- "Communication-Aware Map Compression for Online Path-Planning" (arXiv 2309.13451, 2023) — [arXiv PDF](https://arxiv.org/pdf/2309.13451); rate–distortion map compression with multi-resolution hierarchical encoder (arXiv 2504.10751, 2025) — [arXiv](https://arxiv.org/abs/2504.10751v1); redundant-Gaussian removal for multi-agent Gaussian-splatting SLAM (arXiv 2604.00804, 2026) — [arXiv](https://arxiv.org/abs/2604.00804)

### Inferences
- The combination "fixed 64+64-dim learned Gaussian code + declared precision semantics + max join + 14–27 B messages" appears novel relative to everything found. The closest conceptual sibling is DistGP (ICRA 2026): a learned function held as Gaussian natural parameters on a bounded local state (200 inducing points) with GBP messages; but DistGP is sum-type (GBP), variable-dimension, and reports no bytes.
- RAMEN's per-parameter "uncertainty" (update count) plays the role of a per-coordinate precision in a weighted average — the same object as a diagonal precision in a product-of-Gaussians — but it is a heuristic weight inside ADMM, not a declared information semantics, and it is sum/average-type (not idempotent): resending the same map changes the consensus target.
- Message-size estimate for Robot Web (derived from the stated message structure, not stated by the paper): an SE(2) variable's message is η (3) + unique Λ entries (6) + linearisation point (3) = 12 floats ≈ 48 B at fp32 per variable per message; SE(3) would be 6 + 21 + 6 = 33 floats ≈ 132 B. With 20 GBP iterations per step and one neighbour per iteration (Robot Web simulation setting), that is ~20 messages per robot per motion step. Treat as a back-of-envelope comparison to the 14–27 B / 8-round budget in the assignment.
- Learned-compression papers (99% reduction, Sensors 2024) show interest in bandwidth but merge decoded explicit maps, not latents; none fuses codes with a probabilistic rule.

### Gaps
- No bandwidth or byte-level numbers exist in Robot Web (T-RO 2024), the RA-L 2024 auto-calibration paper, DistGP, RAMEN, DiNNO, or Di-NeRF abstracts/HTML read here. Murai's 2025 PhD thesis ([PDF](https://www.doc.ic.ac.uk/~ajd/Publications/Riku-M-2025-PhD-Thesis.pdf)) might contain them but exceeded the fetch size limit.
- No paper found that fuses learned map latents by a product-of-experts or precision-weighted Gaussian rule across robots ("product of experts over map latents" returned nothing relevant).
- Kimera-Multi (T-RO 2022, arXiv 2106.14386) claims to be "parsimonious in terms of communication bandwidth" ([arXiv abstract](https://arxiv.org/abs/2106.14386v2)) but the per-robot MB figures are in the full text, which was not retrieved. Swarm-SLAM (Lajoie & Beltrame, RA-L 2024) bandwidth figures were not retrieved (wrong arXiv ID tried).

## Key Question 2: What is known about exactness/convergence of max-type (lattice) fusion vs sum-type (GBP) fusion on graphs with cycles and duplicate evidence, and does any prior work use max-precision selection as a principled alternative to covariance intersection?

### Takeaway
The theory splits cleanly: sum-type GBP on loopy graphs has no general convergence guarantee, gives exact means but overconfident variances at convergence (Weiss & Freeman 1999; walk-summability of Malioutov et al. 2006 is the standard sufficient condition), whereas lattice/max-type operators are topology-independent — max-consensus converges exactly in at most diameter(G) rounds, state-based CRDT merges are idempotent/commutative/associative by construction, and Ghrist–Riess's Tarski Laplacian on lattice-valued sheaves has fixed points exactly equal to global sections with finite-time convergence under a descending-chain condition. No prior work was found that proposes per-coordinate max-precision selection as a principled alternative to covariance intersection; CI, ICI and channel filters are the standard tools and all are sum/convex-combination type.

### Cited Findings

Sum-type (GBP) on cycles:
- Weiss & Freeman, "Correctness of Belief Propagation in Gaussian Graphical Models of Arbitrary Topology", NeurIPS 1999: analyses BP for jointly Gaussian nodes on arbitrary topologies; when GaBP converges, the marginal means are exact — [NeurIPS 1999](https://proceedings.neurips.cc/paper/1999/hash/10c272d06794d3e5785d5e7c5356e9ff-Abstract.html)
- Malioutov, Johnson, Willsky, "Walk-Sums and Belief Propagation in Gaussian Graphical Models", JMLR 7 (2006) 2031–2064: correlations decompose as sums over walks; walk-summability is a sufficient convergence condition tighter than diagonal dominance; provides walk-sum interpretation of loopy GBP — [JMLR PDF](https://jmlr2020.csail.mit.edu/papers/volume7/malioutov06a/malioutov06a.pdf); NeurIPS 2005 precursor — [NeurIPS 2005 PDF](https://papers.neurips.cc/paper_files/paper/2005/file/ade55409d1224074754035a5a937d2e0-Paper.pdf)
- Robot Web (T-RO 2024) states: at convergence marginal means match the centralised MAP solution; variances are overconfident on loopy graphs; no general convergence guarantee, though damping helps (factor damping 0.2 used); relative precisions are argued to be correct at convergence — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Murai et al. RA-L 2024 (auto-calibration): "GBP has no convergence guarantees on graphs with cycles"; the method diverged in many cases without their adaptive regulariser — [arXiv HTML](https://arxiv.org/html/2401.15036v1)
- DistGP (ICRA 2026): loopy GBP convergence not guaranteed; if it converges the marginal means are correct (citing Weiss & Freeman); cycles improve accuracy but cost iterations — [arXiv HTML](https://arxiv.org/html/2603.07351v1)
- Robot Web pose-graph benchmark (Table IV, termination 1e-2): Sphere GBP 1240 iterations (cost 858.9 vs Gauss–Newton 843.5); Parking Garage 1472 iterations (0.695 vs 0.631); Cubicle 244 iterations (397.2 vs 318.3); block Jacobi (same communication pattern as GBP) needs far more iterations and reaches higher cost — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)

Max/lattice-type:
- Ghrist & Riess, "Cellular Sheaves of Lattices and the Tarski Laplacian", arXiv 2007.04099 (July 2020, revised April 2021): the Tarski Laplacian is a meet-based lattice map on 0-cochains (meet over incident edges of upper adjoints of restriction maps applied to neighbours' values); Theorem 3.1: Fix(id ∧ L) = Γ(X; F̄), the global sections (Cor. 3.1: global sections = Post(L)); Theorem 3.2: with finitely many cells and stalks satisfying the descending chain condition, the harmonic flow Φ_t = (id ∧ L)^t reaches its fixed set in finite t (orbits are strictly descending or eventually fixed; no explicit bound given); results hold on arbitrary cell complexes (cycles not treated separately); complete stalks give unique maximum and minimum global sections (Cor. 3.2); motivations stated: consensus and distributed optimisation over networks; no experiments; no explicitly defined join-based dual, though lattice duality (Prop. 2.2) would give one — [ar5iv full text](https://ar5iv.labs.arxiv.org/html/2007.04099); [arXiv](https://arxiv.org/abs/2007.04099v1)
- Ghrist, Lopez, North, Riess, "Categorical Diffusion of Weighted Lattices", arXiv 2501.03890 (Jan 2025): generalises the Tarski Laplacian to weighted lattices / enriched categories ("Lawvere Laplacian") — [arXiv HTML](https://arxiv.org/html/2501.03890v2)
- Ghrist & Riess gossip on networked lattices: an asynchronous Laplacian for a gossip algorithm shown to converge asymptotically to stable "harmonic" distributions of lattice data (from a 2026 citing paper's reference list) — [arXiv 2606.19529 PDF](https://arxiv.org/pdf/2606.19529)
- Max-consensus on a connected static graph converges in a number of iterations equal to the graph diameter (<= n for n agents), for undirected or strongly connected directed graphs; since nodes rarely know the diameter, a cap t_max > n is used in practice — [Distributed k-means, arXiv 1312.4176](https://arxiv.org/pdf/1312.4176); a two-stage max-consensus scheme reaches finite-time convergence in d(2m+1) rounds (d diameter, m agents) — [Falsone et al., arXiv 1608.08358](https://arxiv.org/pdf/1608.08358); FAIM achieves finite-time average consensus by repeated max-consensus, with a companion algorithm bounding the diameter within 2x — [Oliva et al.](https://gnosis.library.ucy.ac.cy/handle/7/44434?show=full)
- State-based CRDTs (Shapiro, Preguiça, Baquero, Zawirski 2011): a data type whose state forms a join-semilattice with a merge that is commutative, associative and idempotent is a Conflict-free Replicated Data Type; replicas converge without coordination — [HASLab publication page](https://webarchive.di.uminho.pt/haslab.uminho.pt/cbm/publications/conflict-free-replicated-data-types.html); surveys: Preguiça 2018 — [arXiv 1806.10254](https://arxiv.org/abs/1806.10254v1); Almeida 2023 — [arXiv 2310.18220](https://arxiv.org/abs/2310.18220v2)

Conservative fusion under unknown correlation (the CI family):
- Covariance Intersection replaces the Kalman-style addition of information with a convex combination of inverse covariances, which avoids double counting (the "well-known effect" of overconfidence when common information is re-used); the fused estimate is consistent for any unknown correlation; the weight ω is usually chosen to minimise determinant or trace — [UCL Discovery, CI paper](https://discovery-pp.ucl.ac.uk/id/eprint/15814/1/15814.pdf)
- CI "is the optimal bounding technique for two estimates under completely unknown correlations" — [Harmonic Mean Density Fusion, arXiv 2412.06725](https://arxiv.org/pdf/2412.06725)
- CI limitation: uses only the first two moments, so cannot exploit multimodal/discrete information — [UCL Discovery](https://discovery-pp.ucl.ac.uk/15814/1/15814.pdf)
- Inverse Covariance Intersection (Noack, Sijs, Reinhardt, Hanebeck, Automatica 2017): an outer ellipsoidal bound on the intersection of inverse-covariance ellipsoids; consistent under unknown common information and more accurate than CI; Ellipsoidal Intersection is tighter on average but can underestimate the true error for some cross-covariances (inconsistent) — [Automatica 2017 PDF](https://ams.iks.cs.ovgu.de/content/bib/pdf/Automatica17_Noack.pdf); [Fusion 2017 PDF](https://isas.iar.kit.edu/pdf/Fusion17_Noack.pdf)
- Overlapping Covariance Intersection (arXiv 2603.16768, March 2026) generalises CI to structural correlation knowledge and characterises family-optimal solutions for CI and split-CI — [arXiv PDF](https://arxiv.org/pdf/2603.16768)
- Consensus-based multi-target filters are "susceptible to the double counting of common information"; a Generalized-CI variant is proposed to avoid it — [Consensus multi-Bernoulli filter](https://signal.ejournal.org.cn/en/article/doi/10.16798/j.issn.1003-0530.2018.01.001)

Exact removal of common information on trees (channel filter):
- The channel filter is a distribution conditioned on the common information shared by a node pair; the fused estimate is the product of the two distributions divided by the common information; with Gaussians it reduces to an information filter; it applies to tree-connected networks — [Dagan & Ahmed, arXiv 2106.13285](https://arxiv.org/pdf/2106.13285); heterogeneous extension reports >99.5% potential communication reduction in numerical examples — [Dagan & Ahmed, arXiv 2101.11116](https://arxiv.org/pdf/2101.11116); conservative filtering variant for dynamic systems — [arXiv 2203.07142](https://ar5iv.labs.arxiv.org/html/2203.07142)
- Origin citation: S. Grime and H. F. Durrant-Whyte, "Data fusion in decentralized sensor networks", Control Engineering Practice 3(5), 849–863, 1994 (cited in the Dagan–Ahmed bibliography; the paper itself was not opened) — [arXiv 2106.13285](https://arxiv.org/pdf/2106.13285)

### Inferences
- Per-coordinate max-precision selection is mathematically the diagonal CI family evaluated at the endpoints ω ∈ {0,1} for each coordinate independently (ω=1 returns estimate A, ω=0 returns B; a convex combination of two inverse variances with ω at an endpoint is exactly selection). It is therefore consistent (never over-confident) by the same argument as CI, but it is strictly a lower bound on what trace/determinant-optimal CI achieves for the fused covariance. Its distinguishing property versus CI is algebraic, not statistical: selection is idempotent and associative (a join-semilattice), whereas optimal-ω CI of A with (A fused with B) is not idempotent and yields order-dependent results on cycles. I found no paper making this argument explicitly — this is the gap the assignment's system sits in.
- The Tarski-Laplacian result (fixed points = global sections, finite-time convergence under DCC) is the closest published theorem to "lattice fusion is exact on any graph": a per-coordinate max over a finite 8-bit precision alphabet satisfies the descending/ascending chain condition trivially, so Theorem 3.2 applies to such a sheaf with identity restriction maps (join version via duality). But Ghrist–Riess define the meet-based operator, give no iteration bound, and treat no sensor-fusion example, so the application is an inference.
- Max-consensus's diameter-round convergence bound implies that 8 synchronous rounds on a radio forest are exact for any forest of diameter <= 8; for larger diameters the join is still monotone and idempotent but incomplete after 8 rounds. (Diameter bound from the max-consensus citations; the "8 rounds" figure is from the assignment.)
- Sum-type GBP's duplicate-evidence problem shows up in the literature as "double counting"/overconfident variances on loops and as the need for channel filters (exact only on trees) or CI (conservative, non-idempotent). Idempotent fusion sidesteps the common-information bookkeeping that channel filters require, at the cost of discarding the information gain that two genuinely independent observations would provide (the assignment's "<= 0.4 pp loss vs union encoding" would be the empirical measure of that cost; not verified here).

### Gaps
- No source found that evaluates "selection fusion" / per-coordinate max-precision against CI or ICI quantitatively. The UDRC CI slide deck that might state the endpoint property ([URL](https://udrc.eng.ed.ac.uk/sites/udrc.eng.ed.ac.uk/files/publications/julier_udrc_SS20151.pdf)) refused the connection.
- The original Julier & Uhlmann CI paper (ACC 1997) and the Grime & Durrant-Whyte 1994 channel-filter paper were not opened; facts above come from secondary citing papers.
- Ghrist & Riess's "gossip on networked lattices" paper (asynchronous lattice Laplacian) was seen only in a 2026 reference list; its own venue/URL was not retrieved.
- No published analysis of information loss of max-type vs sum-type fusion for Gaussians with duplicate evidence was found (only the CI consistency argument).

## Key Question 3: What do sheaf-based approaches contribute beyond "consensus with restriction maps" in practice, and are there any experimental multi-robot results?

### Takeaway
In practice sheaf-based methods contribute three things beyond plain graph consensus: (i) heterogeneous stalks (agents with different state dimensions/types, handled via restriction maps), (ii) an algebraic obstruction/diagnostic (sheaf cohomology, consistency radius) that tells you whether a global section exists before fusing, and (iii) lattice-valued (non-vector) diffusion with finite-time exactness. Experimental evidence is thin: all multi-agent sheaf papers found up to mid-2026 report simulations only (Hanks et al. 2025 coordination and target tracking; SIGMA on grid MAPF); no hardware multi-robot sheaf-fusion result was found, and the 2026 "Sheaf Laplacian for data fusion in sensing networks" preprint shows no experiments on its abstract page.

### Cited Findings

Foundations:
- Hansen & Ghrist, "Opinion Dynamics on Discourse Sheaves", arXiv 2005.12798 (2020): H^0(G;F) (global sections) are "harmonic" — in the kernel of the sheaf Laplacian (Theorem 4.1); the sheaf Laplacian at vertex v is the difference between x_v and the value that would bring v into harmony with all neighbours; relative cohomology gives harmonic distributions vanishing on a subgraph — [arXiv PDF](https://arxiv.org/pdf/2005.12798); [ar5iv](https://ar5iv.arxiv.org/html/2005.12798). Ghrist (AMS abstract): the Hodge Laplacian induces a heat equation whose harmonic distributions are consensus, with sheaf cohomology as the obstruction to harmonic extension — [AMS abstract](https://www.ams.org/amsmtgs/2247_abstracts/1163-91-1219.pdf). Follow-up Bosca & Ghrist 2026 (arXiv 2601.22431) converts the equilibrium problem into a forced sheaf Poisson equation under clamped opinions — [arXiv HTML](https://arxiv.org/html/2601.22431v2)
- Ghrist & Riess Tarski Laplacian (lattice-valued sheaves; see KQ2) — [arXiv 2007.04099](https://arxiv.org/abs/2007.04099v1)
- Robinson, "Sheaves are the canonical data structure for sensor integration", arXiv 1603.01446 (2016): the consistency radius quantifies self-consistency of sensor data against the sheaf model; a principled fusion algorithm is "computing the nearest global section" to the observations; the original data's consistency radius lower-bounds the distortion incurred by fusion; cohomology (data-independent) flags where fusion can fail — [arXiv PDF](https://arxiv.org/pdf/1603.01446); [ar5iv](https://ar5iv.arxiv.org/html/1603.01446)
- Robinson, "Assignments to sheaves of pseudometric spaces", arXiv 1805.08927: consistency radius is continuous and robust to noise — [arXiv PDF](https://arxiv.org/pdf/1805.08927v5); Robinson IAS 2018 talk: signal-separation example by minimising consistency radius, "8x improvement over state-of-the-art in heavy noise" (slide claim) — [IAS slides](https://ias.edu/sites/default/files/video/20180407_IAS.pdf)
- Sheaf UQ of heterogeneous geolocation information (arXiv 1912.05487, 2019/2020) — [arXiv PDF](https://arxiv.org/pdf/1912.05487); sheaf self-filtering network of low-cost air-quality sensors (arXiv 2212.14353, 2022) — [arXiv PDF](https://arxiv.org/pdf/2212.14353)

Sheaf neural networks:

Multi-agent / robotics sheaf work (2025–2026):
- Hanks, Riess, Cohen, Gross, Hale, Fairbanks, "Distributed Multi-agent Coordination over Cellular Sheaves", arXiv 2504.02049 (April 2025): nonlinear sheaf Laplacians generalise graph Laplacians for heterogeneous coordination; ADMM-based distributed solver for "nonlinear homological programs"; consensus, formation and flocking cast as such programs; numerical simulations only — [arXiv HTML](https://arxiv.org/html/2504.02049v2); [arXiv PDF](https://arxiv.org/pdf/2504.02049)

- "Game sheaves" (arXiv 2606.01663, 2026): restriction maps encode best-response dynamics; theory plus case study — [emergentmind summary](https://www.emergentmind.com/papers/2606.01663) (aggregator; primary not opened)

### Inferences
- The practical contribution of a sheaf over plain consensus for the assignment's setting is modest but real: with identical 64-dim stalks and identity restriction maps the sheaf reduces to a graph, and the "Sheaf-GBP" label is then justified mainly by (a) the lattice-valued (Tarski) semantics for the max join, and (b) the ability to declare non-identity restriction maps later (e.g., a robot with a different code size or a projection onto shared coordinates) without changing the fusion rule. The 2025 Hanks et al. papers are the published precedent for exactly that heterogeneous-stalk use.
- Robinson's consistency radius is the sheaf-native diagnostic the assignment's system could report for free: with per-coordinate Gaussian stalks, the disagreement between overlapping codes before the join is a consistency-radius-type quantity; no robotics paper was found doing this.
- Everything sheaf-related in multi-agent robotics through mid-2026 is simulation-only; a hardware multi-robot sheaf fusion result would be new.

### Gaps
- Hansen & Ghrist, "Toward a spectral theory of cellular sheaves" (J. Appl. Comput. Topol., 2019) is the standard sheaf-Laplacian reference but was not retrieved in this session (no URL verified).
- Full texts of arXiv 2504.02049 / 2512.24886 / 2606.19529 were not read; agent counts, simulation scale and any comparison to graph consensus are unknown.
- No source found for "cellular sheaves for sensor networks" with a quantitative comparison to Kalman consensus or CI.

## Key Question 4: What bandwidths and accuracies do Robot Web / distributed GBP systems report, and at what scale?

### Takeaway
Scale is the strong point of the Robot Web line (simulations to 1024 robots, 9 real robots; 16–128 robots in the 2024 RA-L extension; 25 robots in DistGP 2026) and accuracy is consistently within ~1.2–2x of a centralised solver (often equal at large N), with robustness to 50–80% message loss and 40–80% outliers. Bandwidth is the weak point: none of the Robot Web / GBP papers read here report bytes per message or kB/s; messages are full dense precision matrices in float, exchanged 20–30 iterations per motion step.

### Cited Findings

Robot Web (T-RO 2024, arXiv 2202.03314):
- Simulations: 32–1024 robots (Fig. 4), 100 m square arena, 10 known beacons, 100 pose steps per robot, 20 GBP iterations per step with one neighbour per iteration, factor damping 0.2, neighbour chosen with inverse-squared-distance weighting; range-bearing noise σr = 0.01 m, σb = 0.05 rad, 30 m range (harder: 0.05 m, 0.1 rad, 10 m); odometry σ = 0.1 m / 0.01 m / 0.01 rad per step; 10% of range-bearing measurements replaced by uniform outliers, DCS kernel Φ = 10 — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Accuracy vs GTSAM (Table I, ATE): N=16, 10 m range: GTSAM 0.660 ± 0.217 m vs GBP 0.770 ± 0.183 m (windowed GBP 0.934 m); N=64, 10 m: 0.154 vs 0.290 m; N=128, 10 m, noisier: 0.082 vs 0.102 m; N=128, 30 m: both 0.006 m. Gap largest at few robots / short range (slow propagation of low-frequency drift); relative pose errors similar at all N — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Robustness: ATE stays low with 70–80% corrupted range-bearing measurements (50 robots); accuracy holds with >= 50% random message drop; gains from communication range saturate at ~25–30 m; initialisation robust to ~0.2 m / 0.2 rad perturbation, breaks at 0.5 (upper whisker 3.51 m) — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Scaling: average ATE keeps decreasing from 32 to 1024 robots with each robot limited to one peer per iteration — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Communication model: each robot publishes outgoing messages as a read-only web page (HTTP one option; pub/sub also allowed); no synchronous or bidirectional exchange required; no shared global information — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Real robots: 9 TurtleBot3, RPi 3B+ (1.4 GHz Cortex-A53, 1 GB), RealSense D435i + AprilTag cubes, ROS2 Foxy best-effort, 10 Hz publishing; ATE 0.028 ± 0.007 m with landmarks + communication (vs 0.071 without communication); bandwidth not reported — [ar5iv](https://ar5iv.labs.arxiv.org/html/2202.03314)
- Venue: IEEE T-RO vol. 40, pp. 121–138, 2024 — [Spiral record](https://spiral.imperial.ac.uk/entities/publication/ac087e1d-6aff-4dc0-b17d-908540e034c1)

Murai, Alzugaray, Kelly, Davison, "Distributed Simultaneous Localisation and Auto-Calibration using GBP", RA-L vol. 9 no. 3, pp. 2136–2143, March 2024, DOI 10.1109/LRA.2024.3352361 (arXiv 2401.15036):
- 64 robots default (16/32/128 also), 20 m cube, 50 random motions, 30 GBP iterations per motion, 10 runs; range-bearing to 3 closest robots within ±60°, noise 0.05 m / 5°; exchanged on inter-robot edges: factor-to-variable messages (mean + information matrix) and variable-to-factor messages (linearisation point + Gaussian); only sensor and marker pose estimates are shared, not calibration variables; bandwidth and message size not reported — [arXiv HTML](https://arxiv.org/html/2401.15036v1)
- Accuracy N=64 (RMSE ATE/ARE): centralised LM 0.043 m / 1.684° vs proposed 0.054 m / 1.761° (0.066 m / 2.082° without calibration); extrinsics 0.020 m / 0.969° vs 0.025 m / 1.214°; base-pose ATE falls from 0.084 m (16 robots) to 0.049 m (128); 30% of messages dropped by default, "largely unaffected" up to ~80% failure, 100% prevents co-localisation; stable up to 40% outliers; at 10 m comm range ~24% of robots in range, at 20 m ~85%; MR.CLAM real data (2D, window 30): ATE 0.0984 m with auto-calibration vs 0.107 m without under added calibration noise — [arXiv HTML](https://arxiv.org/html/2401.15036v1); [DBLP](https://dblp.org/pid/263/7362)

Other GBP-for-robotics items:
- Davison & Ortiz, "FutureMapping 2: Gaussian Belief Propagation for Spatial AI", arXiv 1910.14139 (Oct 2019): position paper/tutorial arguing GBP suits distributed, incremental probabilistic estimation on heterogeneous hardware; simulation examples and code — [arXiv](https://arxiv.org/abs/1910.14139)
- Ortiz, Evans, Davison, "A visual introduction to Gaussian Belief Propagation", arXiv 2107.02308 (July 2021), interactive at gaussianbp.github.io: GBP as a special case of loopy BP with purely local updates; argued as a scalable distributed inference framework given hardware trends — [arXiv](https://arxiv.org/abs/2107.02308v1)

Bounded-communication estimation baselines (for bit budgets):
- Quantised-innovation Kalman filtering (Msechu, Roumeliotis, Ribeiro, Giannakis): performance close to the unquantised KF with ~2–3 bits per observation; MSE penalty ≈1.57x (1 bit), 1.15x (2 bits), ≈1.0x (3 bits) — [IEEE TSP 2008 PDF](https://www-users.cse.umn.edu/~stergios/papers/TSP08-QKF.pdf); [IEEE CSM 2010 overview](https://www-users.cse.umn.edu/~stergios/papers/CSM-Special-issue-for-Kalman-2010.pdf); [ICASSP 2008 record](https://experts.umn.edu/en/publications/distributed-kalman-filtering-based-on-quantized-innovations/)
- Sign-of-innovation (1-bit) filters round small innovations to ±1, causing large errors; multi-level quantised-innovation KF addresses this — [IFAC 2008 PDF](https://skoge.folk.ntnu.no/prost/proceedings/ifac2008/data/papers/0788.pdf)
- Quantising both estimate and covariance so the receiver's bound stays consistent (two-bitrate periodic coding) — [Brunel PDF](https://bura.brunel.ac.uk/bitstream/2438/29342/1/FullText.pdf)
- Information-weighted consensus filter with partial information exchange (entry-selection matrix) still converges to the centralised KF — [arXiv 2112.08121](https://ar5iv.labs.arxiv.org/html/2112.08121)
- Quantised average consensus with bounded bits: finite-time exact averaging of initially quantised values (bits not always bounded) and dynamic-compression variants targeting bounded bit usage — [arXiv 2508.06893](https://arxiv.org/html/2508.06893v1); [arXiv 2512.24700](https://arxiv.org/html/2512.24700v1)

### Inferences
- Scale/accuracy comparison: the assignment's 8–16 agents is at the low end of Robot Web's range (16–1024) and is the regime where Robot Web's GBP is weakest relative to centralised (0.770 vs 0.660 m at N=16, ~17% worse). The assignment's F1 metric (0.89–0.90 HouseExpo) is not comparable to ATE numbers; no GBP paper reports a map-quality F1.
- Bandwidth comparison (derived, not reported by the papers): Robot Web SE(2) messages are ~12 fp32 values (~48 B) per variable per message with 20 messages per step; Murai 2024 uses 30 iterations per motion with SE(3) messages (~33 floats ≈ 132 B per variable). The assignment's 14–27 B per message over 8 rounds is roughly 1–2 orders of magnitude less traffic per agent per step than a float-precision GBP round schedule, but this is an estimate because no GBP paper publishes bytes.
- Quantised-KF literature (2–3 bits per scalar innovation ≈ lossless) suggests 8+8 bits per coordinate is comfortably above the regime where quantisation dominates estimation error; the sign-of-innovation failure mode (1 bit) is the cautionary bound.
- Robot Web's robustness to 50–80% message loss is a sum-type property obtained via damping and robust factors; an idempotent join gets loss-tolerance for free (re-sends are harmless), which is a qualitatively different mechanism — no paper found compares the two.

- Kimera-Multi (T-RO 2022) and Swarm-SLAM (RA-L 2024) per-robot MB figures were not retrieved (abstract-only / wrong ID), so the standard decentralised-SLAM bandwidth baselines are missing from these notes.
