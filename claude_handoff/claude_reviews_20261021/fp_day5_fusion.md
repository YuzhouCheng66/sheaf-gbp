## 1. 第一性原理：残差由"每个固定坐标要承载的自由度"决定，不由融合决定

1. **融合已精确且无损。** `select`（L317-322）与 `rollout_max`（L324-362）是逐坐标 max-precision 选择，源头量化一次、中继逐位转发（L335-337）；幂等、环路精确（D3-0）；字典序平手 + 自身量化后处处等于集中式 join（D4-1，R8 变化 ≤0.04 pp）；理想同态与实际 R8 相差 ≤0.4 pp（D4-10）。**融合算子无可改进；增益只能来自坐标语义。**
2. **残差与每块墙要素数同向。** [本文计算] VAL 三层 L 中位 11/14/16 m → 块边 1.4/1.75/2.0 m、像元 8.6/10.9/12.5 cm；多边形顶点 27/48/79（D4-7）落在约 45 个在房块上（D4-5）→ 每块 0.6/1.1/1.8 个墙顶点。8+ 室层每块近两个独立要素，正是 R8 .82-.87 的层（BRIEF L20）；残差图样（门洞旁短墙段、窄开口、薄内墙，BRIEF L36-37）都是"一块里的第二个要素"。
3. **一个标量 = 一个自由度，不是 8 bit。** 解码器把标量平面经平滑 3×3 卷积映成图案（L189-200）：16 bit 不涨（D4-11），6 bit 代价 0-4 pp、5 bit −3.7 pp（D3-6、D3-12 Phase D）→ 解码器沿标量只分辨约 2^5-2^6 个图案；N2-3 已明示"1 个标量/块无法同时表达两种互补半块视图的并集"。平滑解码器把 255 级映成一条**曲线**，两要素块需要一张**曲面**；加 bit 只是把同一条曲线采样得更密。
4. **max join 对码的唯一要求是"在选择下封闭"，不是"在平均下封闭"。** 胜者整块替换（L317-322），胜者几乎总是看全该块者（q 与覆盖率 Spearman .91，N2-0）。所以**码可以是不可插值的（类别/码本）**——sum 融合（L295-315）做不到，这是本角色能给出的唯一新自由度。推论：让坐标变粗（多分辨率、向量茎）会提高"胜者未观测该像素"的比例（8×8 时已占真墙像素 32%，D3-4(b)），把 ≤0.4 pp 的融合损失变大。

## 2. 候选结构

### 候选 1（top-1）：码本化块码——非插值块码，max join 保证精确
- **机制**：编码器、精度头、线路、join 全不变。只把解码器输入的均值平面（L196 `post[:, :64]`）换成学习的 1-D 核嵌入 E(μ)=Σ_j softmax_j(−(μ−c_j)²/2τ²)·E_j，c_j=j/127（hard-8 字母表 L241-244），E∈R^{255×C}，C=8（约 2k 参数）；log 方差平面照旧。初始化 E_j=(c_j,0,…,0)，初始模型与 v378 逐张量相同（身份守卫同 D5-2）。前向在小 τ 下是查表；反向经 softmax 权重给编码器连续梯度（STE 不变）。效果：每块可实现 255 个**任意**图案，而不是一条曲线上的 ~50 个，一块能表达"墙 + 门端"。
- **增益估计**：均值 512 bit ≥ 2-4 / 5-7 室目标（347 / 560 bit），为 8+ 室（799 bit）的 64%（BRIEF L33）；目前有效约 5-6 bit/块（§1.3）。估计 R8 **+2 到 +4 pp**，8+ 室 +3-5 pp，2-4 室 ≈0。数量级推理，非测量。
- **约束逐条**：64+64 不变（嵌入是解码器参数，不随样本）；仍是声明的逐坐标 CI 能量 + max join（lit_review_day2 §2.1），精确性不变，**恰因 join 从不插值**；精度通道未触碰，仍只是置信度；解码器只读 (q,h)。
- **线路**：封存 profile-4 把均值舍入 ≤3 码步（D3-0），会打乱码本邻接 → τ 固定 2 码步；或 `--wire kbit` 8/8（L127-140，并集 0 误差）取 τ=1。第一轮用封存线路 + τ=2，对照即批次 Q。
- **代价 / 租约**：输入通道 2→C+1；时延不变（BRIEF L39）。批次 Q 协议（57,600 更新、两种子并行 ~5,400 s）**一个租约**；与批次 T 正交，可叠加。
- **匹配对照**：批次 Q 同种子，身份守卫：`pre` 以外张量逐位相等。
- **发射前零成本门（CPU）**：冻结 v384 解码器，固定真实上下文，扫一块的 255 级，数不同墙图案数（Hamming >2 px）。≥200 → 曲线已折叠够密，**不发射**；<64 → 发射。并按块核对：缺口是否集中在"≥2 墙分量或含墙端点"的块（机制预言：是）。
- **预注册判据**：两种子 R8 ≥ 对照 +1 pp 且 FPR ≤ +0.3 pp；次判据 8+ 室 ≥ +2 pp。两种子 |Δ| <1 pp → "曲线极限"被否定，残差是 64 单元的硬自由度极限。

### 候选 2（top-2）：两阶段共识划分——公共图幅本身成为格上的共识对象
- **机制**：阶段 1 只 join 64 个精度（观测块指示）得公共并集掩码 M（格元素，max-consensus ≤直径轮收敛，D3-8 末段）；确定性公共规则把 64 坐标重新分配到 M 上（观测块四叉细分到 64 格，未观测区 0 格）；阶段 2 各 agent 在该划分上重编码（PatchTrunk 改按格 ROI 重采样到 16×16）再 join；解码器把 64 个 (μ, log var) 散布到栅格 + 格尺寸平面。各阶段划分由该阶段实际到达并集决定，与现有目标（L368-372）一致。
- **增益估计**：贴合图幅 45/64 块在房、单 agent 观测 19.4 块（D4-5）；R8 并集约 30-40 块 → 密度 ×1.6-2。已测密度律：×1.9 → +10 pp（D4-8），×1.18 → +1.4 pp 且模棱两可（D4-17），次线性 → **+2 到 +6 pp**。
- **约束逐条**：仍 64+64；两阶段都是精确 join；精度语义不变；划分是融合精度（瓶颈内数据）的公共确定函数，但需用户确认其"公开框架信息"地位（README L91 公共图幅假设的推广）。
- **代价**：ROI 编码器、划分算法与测试、散布解码器 ≥1 天工程，本轮不可发射；字节 ×2；**与增量 CRDT 记忆不兼容**（并集增大 → 划分漂移 → 全量重编码重发，抵消 D3-7/D3-9 的 diff 优势）。
- **对照 / 判据**：批次 Q；两种子 R8 ≥ +2 pp；K0 不作主指标。**否定证据**：重现 D4-17 的"一种子 <1 pp"；或候选 1 + 批次 T 证明极限是每块自由度而非单元数。

## 3. 反证（top-1）
- **最可能的失败**：SiLU 卷积已把曲线折叠得够密（D3-12：6 bit 代价可达 −3.8 pp，说明分辨 >63 级），嵌入无余量 → Δ 落在 ±1-2 pp 噪声内（BRIEF L38）。零成本门专为此设。
- **编码器优化**：折叠码本使损失对 μ 非凸，摊销编码器可能找不到索引（`encoder_information.md` 摊销缺口史；v387 在测）。缓解：身份初始化 + 第一轮 τ 从 8 步退火到 2 步（预先声明）。
- **线路**：封存舍入 ≤3 步要求 τ≥2；kbit 线路在 HouseExpo 未与封存配对（v293 −0.7/+0.7，D3-6）。
- **相悖结果**：D4-11 同时与"曲线极限"和"单元极限"一致；自由码上限协议低估联合训练（BRIEF L30-31），不能用来证伪；v293 上 H_μ 4.4 bit 只损 <1 pp（D4-14/19），但 v293 本征维度低，不可迁移。若批次 T ≥ +3 pp，"曲线"只是容量症状，嵌入与加宽部分冗余。

## 4. 排序
- **top-1**：码本化块码——唯一不改 64+64、不碰 join、一个租约、机制直指残差（两要素块）的结构改动；合法性恰来自 max join 不插值。
- **top-2**：两阶段共识划分——上限更高但工程 ≥1 天、需确认"公共划分"地位、与 CRDT 记忆冲突。
- **明确不推荐**：多分辨率、向量值茎（减少细单元，D4-6 已否定方向）；任何非恒等限制映射（定理限定为选择/置换，只换字节）；平滑因子（伤薄墙、破坏 unknown 语义）；回到 sum 或 Split-CI 精度求和（D3-1b sum 更差，D4-10 无损可收回）。
- **最重要的警示**：本文全部结论建立在 D4-10 之上——融合无损意味着融合侧没有 ≥+3 pp 的杠杆；候选 1、2 改的是坐标语义与公共框架，不是算子。若 v387 显示摊销编码器才是瓶颈（精修 K0 ≥ +3 pp，BRIEF L56），两者都应让位于编码器侧改动。
