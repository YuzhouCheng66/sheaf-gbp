## 4. 翻转精确率与幻影块

**定义与实现**（`flip_counts`，161–171）：
- 计数对象是计分范围（T.known ∩ H.region）内、满足 NET = 1、配对 B6 = 0、S × 0.05 ≤ −thr 的体素；分子是其中真值（T.tr）为占据的。
- S 的符号与单位：
  - S 是 NET 读的那张表上的分量和（0.05 nat 单位，不含先验 l0q）；
  - 表在 L 的负端为负（L = −40 处是 −120），正端为正（L = 68–70 处是 +113 到 +138），符号正确；
  - 这与 R-A 的 `ra_kinds.py` 定义相同（`Sn = S * 0.05`，`pn & ~pb & scope & (Sn <= -thr)`）。
- **B6 那一项是冗余条件**：θ_A = 51、θ_B = 49 都大于 0，所以 S ≤ 0 已经推出配对的 B6 判空闲。冒烟里两种 B6 配对给出的计数完全相同。
- **池化**：每格（变体 × 种子 × 检查点）把 24 房的计数相加后再求比例，而不是对每房的精确率求平均。所以分母小的房不会带来噪声。
- **分母为 0**：记为通过并报出计数（P3）。判决变体不会遇到：冒烟里每房就有约 100–290 个体素。
- **与 R-A 的差别**：
  - 实现的计数按分量大小加权（246）；R-A 不加权，而且只测了 342101。
  - 4 个冒烟房都是单一 8 智能体分量，两种口径相同（加权数 = 8 × 体素数）。见 S2。

## 5. 判决逻辑

- **`_cell`（431–435）与 `verdict`（439–498）对照 D8-53**：
  - 安全 = 下面 5 条同时满足：
    - 新物体区 ΔF1 ≥ −1 pp；

    - 翻转精确率 ≥ .70（分母为 0 记为通过）；

  - 有害 = 任一格满足下面任一条：
    - 新物体区 < −1 pp；
    - 翻转精确率 < .50；
    - 幻影块 > B6 + 2。
