## 1. 全场最强的 3 个设计（不含我的）

**① A03 设计 A：RAY-SHEAF。**
- **为什么强**：
  - 证据最硬：24 房、无标签分割；
  - 自己地图 198 B（p90 331），收敛消息 317 B，每房 4.9 KB；
  - 190/192 张逐位精确，其余 ≥ .9995；
  - 而且只有它量了自己的脆弱处：转 45° 时盒子 62 → 109；σ = 2 cm 时无损外壳 ×4.9。
- **最弱的假设**：无噪声、轴对齐；学习只剩熵模型，空间约 1.5–1.8 倍（DL 107 B）。
- **我能怎样加强**：
  - (a) 有损定律"只删不糊"：丢掉 < 8 体素的盒，211 B 时家具 .973 / .979；粗化 2×2×1 只有 .55。这给它一条有原则的 RD 曲线。
  - (b) 位姿：协议规定在 1 mm 格点上感知，约 8 B/智能体即可逐位精确，不必用 26–27 B 浮点。
  - (c) 盒语言升级成物体 token（我的 D2），约 110–140 B。
  - (d) 有噪声时，把一致集换成最大似然拟合，融合改为对数几率求和。

**② A01 LL/Hyper-Sheaf。**
- **为什么强**：
  - 光线序事件码在信息论上最干净：码长 ≈ H(表面 | 可见性)，留一先验 250 B；
  - "停止且未知"的有损替换在构造上不会漏光，是投射解码唯一有原则的有损语义（它自己实测：直接重放现模型输出，R8 FPR +4 pp）；

- **最弱的假设**：一个 ≤ 60 B 的学习潜码能付清自己的账；逐射线步解码约 480 批/智能体。
- **我能怎样加强**：超先验不用 32×32 稠密潜码，改用物体 token。"桌面与四条腿的关系"正是局部上下文看不到、而 token 一句话说清的东西。

**③ A07 D2 + D3：真值评分的噪声世界 + 配准感知 sheaf。**
- **为什么强**：
  - 它是唯一让"学习 + sheaf-GBP"有意义的方向。

## 2. 我要攻击的 3 个论断

**(A) 在无噪声世界里给学习式有损码花 GPU：它们被经典码严格支配。**

| 设计（自己的预测） | 字节 | 家具 |
|---|---|---|
| A09 W-Sheaf | 420 B/条 | .72–.82 |
| A04 ΔV | 505 B | .73 |
| A05 RAYFIELD 有损 | 145–175 B/自己地图 | .85–.93 |
| A06 RayField | 450–700 B | .80–.88 |
| A03 RK-Δ | 245 B | .62–.68 |

经典凸包已经实测：
- A03 无损 198 / 317 B，家具 .994；
- A03 有损 m = 16 时 126 B，.941；
- 我的 box ≥ 8 是 211 B，.973。

每个学习有损点都落在凸包内部：字节更多，F1 更低。A09 的第一步 A1（2 个租约，在 3S-Z2 上加率项）量的是一个已被支配的点。

**结论**：这类设计的第一个实验必须放在加固面板上，并与经典凸包比。

**(B) "处处 max-join，sum-GBP 危险"（A01 #6、A04 R2 / §7.6、A05 #5、A10 #6、A03 #3）。**
- 电台图是 Kruskal **森林**。`rollout_max` 已带排除回传，在树上求和时每个智能体只计一次，是精确的；875–1,582 倍的放大只发生在有环图上。
- 无噪声时，sum 与 max 的判决逐体素相同（不会冲突）；有噪声时，sum 一致更好：
  - 我的探针：R8 家具 +0.8 / +3.3 / +6.2 / +3.1 pp（lidar / cam / 配准 / cam + 配准）；
  - A07 用更重的噪声测得 +8–18 pp。
- **所以**：融合算子应当是森林上的整数对数几率求和（向零取整），max 只是无噪声的退化情形。能量用 Φ(t) = Σ_v |comp(v) ∖ S_v(t)|，单调不增。

**(C) A04 用"盒子级槽位：家具 .53"（§0.4、§7.3、P5）否定盒子 / 物体槽。**
- P5 把每个实例观测部分的包围盒整块填进目标，桌下观测到的空也被填了，也就是违反了 D ⊆ ¬F。
- 原语级盒子是精确的：
  - 我的贪心盒：280 B，48/48 逐位精确；
  - A03 P3：201 B，192/192；
  - A05 p4：预言世界盒，自己地图 59.5 个，精确。
- .53 是"糊"的代价（我的粗化 2×2×1 → .55；A05 外扩一格 → .13–.17；A06 水平加厚 → .63），不是盒子的代价。所以 ΔV-Sheaf 的立论（"家具要的是竖柱区间"）不能当作放弃物体 token 的理由。

## 3. 合成提案：TRS-Sheaf（词元–残差–射线层叠 sheaf）

### 3.1 来源

| 组成 | 取自 |
|---|---|
| 骨架、线路 | A03 |
| 残差 | A01 光线序事件 + A01 的"停止且未知" |
| 遮挡区补全 | A02 |
| 物体 token + 学习先验 | A05-2、A01-Ⅲ、我的 D2 |
| 森林求和融合 | 我的 (B)、A07 D2 |
| 位姿配准 | A07 D3 |

### 3.2 stalk 索引集与内容（两种工况同一结构）

| 索引 | 无噪声 | 有噪声 |
|---|---|---|
| I_pose（8 个智能体） | 1 mm 格点位姿，平格 | SE(2) 高斯（均值、协方差），限制映射 = 位姿变换 |
| I_plan（128² 竖柱） | {⊥, 墙, 过梁} | 整数对数几率 |
| I_vox（128²×32，信念层） | {⊥ < 空, ⊥ < 占}，max-join | 整数对数几率，森林求和 |
| 线路：I_tok（16² 锚格，稀疏）、I_res | 物体 token（类别、6 面或偏航 + 尺寸、高度、面精度）；残差事件 | token 是最大似然拟合（去噪）；残差有损 |

结构只活在线路语言里，融合状态停在体素：关联问题按构造消失（A03 的论证）。

### 3.3 能量

$$E=\underbrace{\sum_v\sum_i[\rho(s^*_i)-\rho(x_{v,i})]}_{\text{无噪声：格秩亏量}}\ \ \text{或}\ \ \underbrace{\sum_v|\mathrm{comp}(v)\setminus S_v(t)|}_{\text{有噪声：未吸收证据}}\;+\;E_{\text{pose}}$$

- E_pose 是 SE(2) 高斯 sheaf Laplacian，二色块坐标下降，只接受让能量下降的步。
- 各项都单调不增。
- 量化：精度向下取整，坐标在格点上；熵编码和新息不改变轨迹。

### 3.4 线路、解码器、损失与训练

**线路**：新位姿 + 平面新息（2D ctx）+ token（自回归先验，条件为平面图和房间）+ 残差事件（以渲染结果和接收方状态为上下文）。只发新息，采用两趟调度。

**解码器**：渲染 → 首次命中投射。有噪声时改为软投射，再按 F1*/2 判决（A02 / A06）。

**损失**：
- 分词器：CE + L1，标签来自生成器 spec；
- 先验：NLL；
- 有噪声时：对干净几何的 BCE + λ·比特。

**训练**：

| S0 | 经典 RAY-SHEAF | CPU |
| S1 | token 先验 | 1 个租约 |

### 3.6 预计 F1

- **无噪声**：R8 表面 .999、K0 .998、家具 .994–.996（1 cm 位姿）；格点位姿下为 1.000。
- **加固面板**（cam + 配准，按真值评分）：现在的底是 R8 sum .916 / .831。配准 GBP 目标是逼近无配准误差的 .986 / .977，即 R8 表面 ≥ .95、家具 ≥ .90（估计）。K0 在本机坐标系约 .96 / .95。
- token 不随噪声变长，相对无损传噪声图（ctx 2,263–2,412 B）约 16–22 倍。这是"相对无损十几到几十倍"唯一诚实的成立处。

### 3.7 三个特别问题

**在这个合成世界里学习还剩什么价值？**
- 只剩码率，而且上限小：198 B → DL 107 B，至多约 1.85 倍。另有分词器的速度。
- F1 由物理给出，学习对 F1 的贡献为 0。在干净基准上写"学习 + sheaf-GBP"，论文实质是"经典码 + 熵模型"。

**评估必须改吗？** 必须改，最少六条：
1. 测距噪声、漏测、离群；
2. 机间配准误差（它才是主矛盾：K0 家具 .76）；
3. 按真值评分；K0 在本机坐标系，R8 在公共坐标系；
4. 家具偏航旋转和留出类别（防生成器泄漏；A03：45° 时盒子 ×1.8）；
5. 空闲召回保护（A04 p8 / A09：只发 S 就能让四个 F1 都 = 1、空闲召回 0）；
6. 按网络总账计字节。

干净面板保留，作精确性自检。

### 第一步实验：4S-0，纯 CPU，0 个租约

- **单变量**：编解码器。臂 = 经典 RAY-SHEAF：无标签平面 + 盒子 + 1 mm 格点位姿 + 投射解码，用真正的算术编码往返。对照 = 3S-X + 校准规则，同房同智能体配对。
- **面板**：VAL-24 与 fresh-24。
- **两种子**：盒子先验在两个不相交的 TRAIN 半集上各拟合一次，代替两种子。
- **预注册**（两面板 × 两先验，全部都要过）：
  1. K0 与 R8 逐体素 100 % 精确；
  2. 自己地图中位 ≤ 250 B、收敛消息 ≤ 400 B、每房网络 ≤ 6 KB；
  3. 空闲召回 ≥ .999 且 FPR = 0；
  4. 报告相对原始、gzip、ctx、ELS 的倍数。
