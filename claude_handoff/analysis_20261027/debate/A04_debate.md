# A04 辩论稿：底线守门人的裁定、攻击与合成

A04，2026-10-27。已读完 A01–A03、A05–A10 九份。新探针 P8–P10 只用本机 CPU、单进程、内存 < 1 GB，脚本和 JSON 在 `probes/A04/`。

## 0. 立场

九份都独立发现了同一件事：自己的地图 = RayCast(命中集, 位姿)。其中八份做了逐体素核验，结果 0 失配。所以在这个无噪声世界里，不学习的结构化精确码支配了一切有损学习码，包括我自己的 ΔV-Sheaf。

我的裁定：
- 这些精确设计**形式上都守住了底线**；
- 但它们把"学习的 sheaf 向量"挤出了融合路径；
- 要让"学习 + sheaf-GBP"重新有意义，必须把评估搬到有噪声和配准误差的世界。在那里，求和型 GBP 重新胜过 max（P9：表面 +9–14 pp，家具 +17–24 pp）。

## 2. 攻击与底线审查

**攻击 1：有损学习体素码在本基准上被支配。** 对象：A09-A W-Sheaf、我的一和二，以及 A03-B、A06-3 同类。

| 设计 | 收敛消息 | 家具区 F1 | 状态 |
|---|---|---|---|
| W-Sheaf | 约 420 B | .72–.82 | 预测 |
| 我的 ΔV-Sheaf | 505 / 333 B | .73 | 预测 |
| A03-A | 317 B | .994 | 实测 |
| A08-D1（新息消息） | 405 B | .994 | 实测 |

按 A07 的判据（率失真平面上不被支配，R_net 低于精确基线），这一族在无噪声基准上没有贡献。W-Sheaf 还有一个风险：精度键若被补全抬高，就等于先验进了融合，违反 R5。A09 自己提的修法（π 只由本机首击数决定）必须写成硬约束。

**攻击 2：在学习潜码上做信息相加的高斯 GBP。** 对象：A09-B、A08-D3。

求和精确的前提，是各源证据在给定变量下条件独立。本世界里，重叠视角给出的是同一批体素的同一个观测：
- P3d：发送方已知的体素中，只有 45 % 对接收方是新的；
- A10：平均观测重数 μ = 2.87。

两个学生编码器对同一面墙各出一份似然，相加就是重复计数，重叠区精度最多被高估约 2.9 倍。校准一坏，F\*/2 阈值和熵模型的概率都跟着坏。"后验减 N(0, I)"也只在学生的隐含先验恰好是 N(0, I) 时才成立。

修法：独立证据按源记账求和，重复转发和共享先验走 CI / max，也就是 split-CI。

**攻击 3：F1 有空闲漏洞，所有"F1 = X"的有损主张都要重估。**

P8：只发占据集 S（不发位姿，其余全报未知）时，K0 和 R8 的表面、可变、家具 F1 都是 1.000，FPR = 0，代价只有 569 / 1,538 B。但三态准确率只有 .13 / .15，空闲召回是 0；3S-X 是 .97 / .98。所以用户的三条 F1 目标加 FPR 保护，可以被"只传 S"平凡满足。

以下估计都没把空闲区算进去，必须加报空闲召回，建议保护线为不低于对照 −1 pp：
- A01-Ⅱ 的有损模式（"停下并标未知"，估计 100–120 B、家具 .93–.96）；
- A05 RAYFIELD 的保守变体；
- A09 W-Sheaf。

**附：中继有损再拟合会破坏全局截面（P10）。** π_m 把占据连通块中小于 m 个体素的碎片删掉，它不是 join 同态。

| 删除门槛 m | 中继每跳重编码：节点间成对分歧 | 源端只做一次：分歧 | F1 差 |
|---|---|---|---|
| 8 | 2.4 体素 | 0 | ≤ 0.1 pp |
| 32 | 13 体素 | 0 | ≤ 0.25 pp |

F1 差的方向是中继重编码反而略好。所以这项违规只是形式上的、代价可以忽略，但规则要写死：有损只在源端做一次，或者用同态 π。

**精度只取 0 / ∞ 的格值 join 还算 GBP 吗？算，可以写成命题。**

命题：若每个坐标上的证据要么缺席（q = 0），要么精确且彼此一致（q = ∞，μ 相同），则对任意 β ∈ [1, ∞]：

$$Q_\beta=\infty,\qquad \mu_\beta=\mu .$$

所以 sum-GBP（β = 1）、CI（β = ∞）和格 join 的不动点逐点相同；环路上 ∞ + ∞ = ∞，判决也不变。875–1,582 倍的过计数只在有限精度下才有意义。这是 GBP 的"精确证据角点"，Tarski 秩亏是整个 β 族共同的 Lyapunov 函数。

**用户会不会认为这已经离开了 sheaf-GBP？** 形式上没有：R1–R5 全部满足，消息式和 `rollout_max` 逐字相同。但实质上变了三件事：
- "中间 sheaf vector"从学习的潜码退化成了观测原子；
- GBP 退化成了集合并；
- 学习只剩下熵模型。

我建议：
- 对外叙事改成"精确格层管融合和 F1，学习管码长"；
- 保留一个学习潜码 stalk（A01-Ⅱ）；
- 把主战场搬到有噪声和配准误差的世界。在那里精度是有限的，GBP 才重新是真正的推断。

## 3. 合成提案：EX-Sheaf（精确核 + 学习先验 + 噪声就绪的融合族）

| 部件 | 无噪声（本基准） | 噪声与配准（新基准） |
|---|---|---|
| 索引集 | 位姿 ⊔ 高度 ⊔ 128² 平面列 ⊔ 体素原子（按 32² 竖柱稀疏记账）⊔ 32² 潜码 | 同左 |
| stalk | 平面 OR；原子 {⊥ < 空, ⊥ < 占}，q ∈ {0, ∞}；潜码 (κ, z ∈ Z⁴≥0) 逐分量 max；位姿为拥有型 | 原子 = 有界 log-odds ℓ ∈ [−15, 15] + 8 bit 源位图；位姿 = SE(2) × 高度的高斯 stalk，加相对位姿因子（连接 sheaf，非恒等限制映射） |
| 能量 | 秩亏 ℱ = Σ_v Σ_k [r(x\*_k) − r(x_vk)]；join 是膨胀的，≤ diam 轮收敛 | 原子：b = Σ_{s ∈ S_v} ℓ_s，Φ = Σ_v \|S\* ∖ S_v\|，源位图让求和在任意图上幂等。位姿：E = Σ_e ‖T_j ⊖ T_i − Δ_ij‖²_Λ + Σ_i ‖T_i − T_i⁰‖²，树上做 GBP，用带接受判据的阻尼 GN；环上改用 CI |
| 线路 | 收集—分发调度。每条消息 = 新位姿 + 新平面位 + 新原子；原子用 p_θ(· \| 接收方下界, 潜码, 平面, 位姿) 做 rANS 编码；编码端做无模态补全（A02），盒渲染作上下文（A03） | 同左；有损只在源端做 |
| 解码 | 渲染 + 精确光线投射 | 去噪解码器读融合后的 log-odds，按 F\*/2 判决 |
| 损失 | −log₂ p_θ + 潜码比特 | 再加 λ·D（按真值）和空闲召回保护 |
| 训练阶段 | S0：CPU 精确核；S1：条件先验，1 个租约；S2：潜码门槛，1–2 个租约 | S3：噪声缓存 + 求和融合 + 去噪，2–3 个租约；S4：位姿连接 sheaf |

**三问。**

1. **这个世界里学习还剩什么价值？** 只剩码长，即先验和无模态补全，而且被 DL 封顶：自己的地图 ≤ 1.9–2.3 倍，并集 ≤ 2.9 倍。F1 已经是 1，学习无从提升。
2. **评估要不要改？** 必须改：
   - 加测距噪声和漏测；
   - 加机间坐标误差；
   - 加旋转家具和训练时留出的家具类别；
   - 按真值评分，即干净传感器在真位姿下看到的图；
   - 加空闲召回保护（P8）；
   - 以 R_net 为主码率指标，精确核作为最强无损基线。
3. **噪声下用 sum 还是 max？** 对独立噪声用 sum。P9 的设置：体素独立翻转概率 p，10 % 漏测，按干净并集评分；表中是 R8 表面 / 家具 F1。

   | p | max（现规则） | 森林上求和 | 环图上洪泛求和（圈秩 17.5） |
   |---|---|---|---|
   | .05 | .815 / .495 | **.907 / .737** | .888 / .664 |
   | .15 | .580 / .231 | **.721 / .401** | .683 / .333 |

   - 与 A07 用真实感噪声测得的结论一致：家具 +8–18 pp。
   - 环上直接求和会过计数：比树上少 2–4 pp 表面、7 pp 家具，但仍比 max 好。按源去重就能恢复精确。
   - max 对重复转发和共享先验仍然是对的规则，所以需要 split 融合。
   - 机间坐标误差两者都救不了：A07 测得 −16 到 −29 pp。只有位姿 stalk + SE(2) 限制映射能救，这也是 sheaf 第一次真正需要非恒等限制映射的地方。

**我的前 3 名**（也就是合成提案的三层）：
1. A03-A + A10-α 的精确核（结构化线路 + 新息中继），现在就做。

**第一步实验（纯 CPU，0 个租约）：E0 精确核门槛。**
- **单变量**：编解码器。
- **臂**：A03 式平面 + 盒 + 残差 + 浮点位姿，配 A10 的收集—分发新息线路。
- **对照**：3S-X + 校准规则 + A10-β 新息线路（不重训）。
- **"两种子"**：VAL-24 和 fresh-24 两个面板，各配两个不相交 TRAIN 半集拟合的静态先验，共 4 种组合。
- **预注册判据**，4 种组合都要过：
  1. K0、R1–R8 逐体素精确 100 %，空闲召回 = 1，FPR = 0；
  2. 自己地图中位 ≤ 300 B，新息收敛消息中位 ≤ 450 B，每房 ≤ 6 KB；
  3. 对照的空闲召回和 FPR 一并报告。
- **不过的后果**：精确核不升为基线，学习路线的倍数继续以 ctx 为分母报告。
- **并行做**：A07 的 D2-a 噪声面板（CPU），判据为 cam 档 ctx 膨胀 ≥ 1.5×，且 R8 家具地板 ≤ .80。
- **两者都过以后的 GPU 首批**：S1 学习条件先验。单变量是先验，对照是静态先验，两种子，判据为字节 ≤ 0.70×，1 个租约。
