## 0. 先校准：全场共识，和它的盲点

十份稿全部独立验证了同一个事实：地图 = 光线投射(击中集合, 位姿)；其中八份给出了不学习的精确编解码器，它在 F1 和字节两条轴上同时支配现行学习码。家族谱（自己地图，中位，含位姿，F1 全为 1）：ELS-KT 574 B（A07）、EVS 360 B（A10）、结构化无损 322 B（A05）、GenFact 291 B（A02）、RC-Sheaf 279 B（A08）、光线序 263 B（A01）、ProgSheaf 259 B（A06）、RAY-SHEAF 219 B（A03，已按 P11 换成逐位精确的 float32 位姿；原稿 198 B 用的 44 bit 位姿只有表面 .998、家具 .994）。

**盲点（P13，新）：现行度量根本不计空闲。** 只预测目标的占据体素、其余一律报"未知"（不传位姿、不做任何可见性），K0 和 R8 的表面 / 可变 / 家具 F1 全是 1.000，FPR = 0，只要 569 B。它的空闲 F1 = 0，三态准确率 .13；我们的 3S-X 空闲 F1 .980、三态准确率 .958。所以"F1 = 1"只是必要条件，"可见性白送"有一半其实是"可见性不计分"（A09 先指出，P13 把它量化了）。

## 1. 全场最强的 3 个设计（不含我的）

**① A02-G1 GenFact（事实格 + 生成先验 + 渲染）。**
- 为什么强：它把用户的"压缩再生成"做成了精确的事：生成模型只提供似然（熵模型）和遮挡区补全，不出图。"遮挡区是免费画布"实测省 35–43 %；"采样伤 F1"的推导和实测（家具 −6 到 −14 pp）是对全场生成式路线最硬的约束。
- 最弱的假设：深度 next-scale 先验比计数模型再省 ≥ 30 %。这一条没测；A07 测得留一房计数上下文只省 5 %，A10 省 18 %。
- 我怎样加强：把补全画布从体素换成结构语言。我的实心盒子本来就是"在 [S, ¬F] 里补全"，同样逐位精确，而盒子码（219 B）低于 G1 的体素码（291 B）。所以生成先验应当定义在盒子 / 平面 token 上（P7：相邻差分 + 联合表已到 20.9 bit/盒，比逐字段省 19 %），体素只做残差兜底。

**② A01-Ⅰ+Ⅱ（光线序无损事件码 + 学习的超先验 sheaf）。**
- 为什么强："码长 ≈ H(表面 | 可见性)"的推导干净。Ⅱ 保留了"学习的 sheaf 潜码 + 最大精度 GBP"，又不牺牲 F1，是最贴近用户底线的学习设计。它还自带可检验的门槛：潜码 ≤ 60 B 才划算。
- 最弱的假设：存在一个 ≤ 60 B、能抓住局部上下文看不到的结构的潜码。他自己测得：现码当超先验能省 21–24 %，但它本身要 177–330 B。
- 我怎样加强：潜码换成结构 token。一个 21 bit 的盒子平均解释 34 个击中（P3）；拿"盒子 + 平面"当超先验，光线序事件只编残差，这就是 A01-Ⅲ 的通用（不用家具库）版本，预计自己地图 150–200 B。

**③ A07-D2+D3（按真值评分的噪声世界 + 配准感知 sheaf）。**
- 为什么强：这是唯一让"学习 + sheaf-GBP"变得必要的设定。cam 噪声下无损 ctx ×1.8；max 规则比树上 log-odds 求和的家具低 8–18 pp；机间 5 cm/1° 误差让并集家具 −16 pp，只有能估计相对位姿的融合救得回来。这里才是非恒等限制映射真正的用武之地。
- 最弱的假设：噪声参数没有标定，只有 6 房、1 个噪声种子；把目标改成"干净世界"需要用户认可。
- 我怎样加强：P6 用另一种噪声模型给出同向证据（单帧"占据优先"，σ = 2 cm：ctx +64 %，无损外壳盒子 ×4.9，干净地图对噪声目标的精确表面 F1 只有 .37）。P5 说明结构先验在扰动下优雅退化（家具转 45°：盒子码 ×1.6，仍是 ctx 的 3.8 倍），它正是去噪编码器的自然形态。

## 2. 我要攻击的 3 个设计 / 论断

**攻击一：在这个世界里，所有"学习的有损码"都被一个不学习的有损盒子码支配。**

不学习的 plan+box 码，删掉覆盖 < m 个击中的盒子（24 房 192 张自己地图，P3/P12）：

| m | 自己地图字节（含 float32 位姿） | 表面 | 家具区 | 未知→已知 FPR |
|---|---|---|---|---|
| 1（无损） | 219 | 1.000 | 1.000 | 0 |
| 4 | 203 | .999 | .994 | 未测 |
| 16 | 146 | .993 | .941 | 未测 |
| 32 | 108 | .983 | .857 | .005 |
| 64 | 82 | .969 | .667 | .012 |

（m = 4、16 取自 P3，m = 32、64 是 P12；字节在 P3/P12 的 44 bit 位姿基础上统一加 20.25 B 换成 float32 位姿。对照：3S-X 的 K0 FPR 是 .012。）

对照各家对学习码的预测（都还没训练）：
- A05 RAYFIELD 有损：145–175 B，家具 .85–.93；
- A09 W-Sheaf：收敛消息约 420 B，家具 .72–.82；
- A04 ΔV-Sheaf：333–505 B，家具 .73；A04 PV-Sheaf：330 B，家具 .76–.80；
- 3S-Z2：8 KB，A06 预测家具 .62–.72。

它们在（字节，家具 F1）平面上全部落在这条不学习曲线的右下方：m = 16 用 146 B 就有家具 .941，已经高于 RAYFIELD 在 145–175 B 预测的上沿 .93；m = 4 用 203 B 有 .994，而 W-Sheaf、ΔV、PV 要两倍以上的字节才预测 .72–.80。这不是"还没训好"，而是被一个约 50 行的贪心算法支配。这些设计只能在噪声 / 真实数据上证明价值，不该再占合成基准的 GPU。

**攻击二："家具是词"和"相对 gzip 几十倍"，靠的是生成器泄漏。**

A08-D2（85 B，gzip 25–32×）、A02-G3（115 B，22×）、A10-γ、A01-Ⅲ、A09-C、A04 设计三，都以 22 类家具库的参数为 token。泄漏有多大：通用盒子语言自己地图 219 B，库的 DL 是 107 B，按精确位姿计是 127 B，所以库只多给 1.7–2.0 倍。"几十倍"里有一半是"知道生成器"。这类设计只能作为"知道生成器的上界"单独报告（A09 已经这样定位），不能当下一代模型。

顺带反驳 A04 的"盒子级槽位家具只有 .53"：那是"每件一个包围盒"。外扩一格在光线投射下是致命的（A05：.13–.17）。贪心多盒覆盖（平均每件约 3 个盒子）192/192 逐体素精确。错的是"单盒"，不是"盒子"这个原语。

**攻击三："F1 = 1 的无损"证明得比看上去少（包括我自己的稿）。**
- (a) P13：只传 S 就有 F1 = 1、FPR = 0，而空闲 F1 = 0。所以凡是删掉 known 头的设计（A09 W-Sheaf、A04 PV-Sheaf、我原来的 B）都必须加空闲 F1 保护，否则会白捡 F1。
- (b) 逐位精确要近乎无损的位姿。P11：抖动每坐标 12 bit 时只有 14/48 张逐位精确，16 bit 时 44/48（最多差 3 个体素），float32 时 48/48。A08 的 5 B、A01 估的 13 B、我原来的 44 bit 都不是逐位精确。位姿在 R8 并集里占 8 × 26 = 206 B，是 723 B 的 28 %。
- (c) 世界无噪声：P6 和 A07 表 5 都表明，有噪声时"无损"既贵又不对。

## 3. 合成提案：RAY-SHEAF⁺——精确证据格 + 结构线路语言 + 学习先验，再搬进噪声世界

| 部件 | 内容 | 来源 |

**预计（合成世界，精确位姿；斜线后是学习先验再省 25 % 的估计）：**
- 字节：自己地图 219 / 约 165 B，收敛消息 401 / 约 300 B，R8 并集 723 / 约 540 B；整个协议 6.1 / 约 4.6 KB/房（现在 229 KB）。
- 倍数（自己地图 / 收敛消息）：
  - 对位姿感知的体素无损 ELS（574 / 970 B，没有几何先验的最强无损）：2.6 / 2.4×，学习先验后 3.5 / 3.2×；
  - 对 ctx：5.9 / 4.0×；对 gzip：12.4 / 8.2×；对原始栅格：600 / 327×。
  - 不学习的 RAY-SHEAF 本身就是新的最强无损，学习先验相对它约 1.3×。
- F1：R8 表面、K0、家具区、空闲全部 1.000。

**在这个合成世界里，学习还剩什么价值？** 只剩熵模型。它的上限是从 219 B 到库 DL（127 B，精确位姿）的 1.7 倍，计数上下文已经拿走 5–19 %，所以学习最多再给约 1.5 倍，对 F1 没有贡献。学习的解码器在这里没有立足之地（攻击一）。

**评估必须怎样改（v2，建议在任何新的 GPU 批次之前定稿）：**
1. 传感器：量程噪声 σ = 1–3 cm，加 5–10 % 漏测、0.5–1 % 离群；多帧 log-odds 积分，不用"占据优先"。
2. 位姿：每帧 1–3 cm / 0.5–1°，机间坐标系 3–10 cm / 0.5–2°，智能体不知道真值。
3. 按真值评分：目标 = 干净世界从真位姿看到的壳。加空闲 F1 和三态准确率（P13），加容差 1、部件召回与幽灵（A07）。
4. 家具：任意偏航（P5：转 45° 盒子码 ×1.6），加入圆柱、斜面、网格家具，留出类别做泄漏审计。
5. 码率：以每次融合的全网字节为主指标，同时报 raw、gzip、OctoMap、ctx、ELS、RAY-SHEAF 和经典有损凸包。
6. 真实扫描面板（Replica / Gibson）作为最终检验。

在 v2 下：无损变贵 1.8–3.5 倍（A07），精确渲染失效，结构先验变成去噪器，配准成为融合本身的一部分。只有这样，学习和 sheaf 才各有不可替代的位置。
