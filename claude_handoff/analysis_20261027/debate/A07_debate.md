# A07 辩论稿｜评估与系统怀疑者

A07，2026-10-27。读完 A01–A06、A08–A10。新探针在 `probes/A07/debate/`：d1 测 float32 重投射是否精确，d2 测空闲召回漏洞。两个探针都是单进程，内存小于 1 GB，只用 CPU。噪声数字来自上一轮的 `probes/A07/p3_noise_*.json`。

**立场：** 十个视角各自独立地证明了同一件事——在无噪声基准上，一个不学习的几何精确码已经把现行学习码在两个轴上同时支配。所以下一代实验的问题不再是"学习码能不能更好"，而是"在什么样的评估里，学习和 sheaf-GBP 才有事可做"。

## 1. 全场最强的 3 个设计（不含我自己的）

**① A03-A RAY-SHEAF（平面图 + 贪心盒 + 重投射）**

- **为什么强。** 实测数字最低：自己地图 198 B，收敛消息 317 B，每房下界 4.9 KB。它不用家具库，也不用标签，用浮点位姿时 190/192 张图逐体素精确。
- **最薄弱的假设。** 无噪声的确定性传感器，加上轴对齐。A03 自己测过：家具转 45° 后盒子码 245 → 394 B；σ = 2 cm 测距噪声下，结构外壳 798 → 3,882 B，干净几何对带噪目标的表面 F1 只有 .37。
- **账目问题。** 字节按 44 bit 位姿计（此时 F1 是 .998 / .994），精确性却按浮点位姿验证。要精确，每机还得加约 19 B，自己地图约 217 B。另外 4.9 KB 是"每边只发一次"的下界，不是实现值。
- **我能怎么加强它。** 统一改用 float32 位姿；报告空闲召回；放到 §3 的噪声面板上，用 m 门槛做去噪档，按真值评分。

**② A10-α EVS-Sheaf（精确可见面原子 + 新息中继 + 学习的条件先验）**

- **为什么强。** 账目最诚实。全部是实现出来的 KT 码长，计入了 float32 位姿和 4 B 头。网络总量 8,948 B/房。在 uk-linux 上用生成器自己的位姿核验，12 房逐体素 0 误差。单变量实验（学习先验 vs KT）写得干净。
- **最薄弱的假设。** 先验能省到 .45–.60。计数先验只省 13–19 %，比 A10 自己的预测保守得多。噪声下原子数量会暴涨。
- **我能怎么加强它。** 把 A03 的平面图和盒子当超先验；同一个先验也在噪声面板上考（按真值的 bits–F1）。

**③ A06-1 ProgSheaf（don't-care 补全出的最简一致世界）**

- **为什么强。** 关键命题是：任意满足 O ⊆ W ⊆ ¬F 的世界 W 都投射出同一张图，所以可以挑最短的 W。位姿按 27 B 精确计，口径一致：259 B / 517 B。误差解剖说明了家具 F1 的性质——水平挪 1 格就是 −45 pp，这是零容差的薄壳度量。
- **最薄弱的假设。** 噪声下 O 和 F 会冲突；中继要做规范重拟合。
- **我能怎么加强它。** 同上，上噪声面板，按真值评分。

A01-Ⅰ（光线序，250 B）同样强，但它的 13 B 位姿是估计值。

## 2. 三处攻击

### 攻击一：在无噪声基准上，有损学习码全部被支配，而且度量本身有漏洞

**被支配的设计。**

| 设计 | 每条消息 | 预计家具 F1 | 对照：A03 / A06 精确码 |
|---|---|---|---|
| A09-A W-Sheaf | 收敛 420 B | .72–.82 | 317–517 B，F1 ≈ 1 |
| A04-一 ΔV | 505 B | .73 | 同上 |
| A06-3 RayField | 450–700 B | .80–.88 | 同上 |
| A05-RAYFIELD 有损档 | 145–175 B | ≈ .9 | 约 217 B 精确 |

A05 的有损档只比精确码省 1.2–1.5×，代价是 −10 pp 家具，算不上代际进步。

**度量漏洞（d2 实测）。**

- 只发占据集 S、其余一律报未知：K0 和 R8 的表面 F1、家具 F1 都是 **1.000**，FPR = 0；但空闲召回为 0，三态准确率只有 .13 / .15。成本是 ctx(S) ≈ 569 B，不需要位姿。
- 对照：现模型空闲召回 .970 / .977；经典 2×2×1 为 .966 / .960。

所以"F1 = 1"本身不能证明地图完整。不加空闲召回保护时，有损设计还会白捡 F1。

### 攻击二："DL 级几十倍"是生成器泄漏，账目也混了口径

- **A08-D2 Vocab（85 B；对 gzip 32×，对 ctx 16×，对 raw 1,540×）的三个问题：**
  - 家具字节取自 24 房的 DL，平面图字节取自 6 房，两个面板混用；
  - 用 1 cm 位姿，不精确；
  - 分词器假设已经知道 22 类库。
- **A01-Ⅲ、A09-C：** 解码器直接用生成器自己的 `rasterize`/`_make`。
- **A02-G3：** "对 gzip 20× 以上"同理。
- **为什么 DL 不能当方法的成绩：** DL 定义上就是"知道生成器的编解码器"。我上一轮的 p4 显示，世界一转 45°，ctx 码长 ×1.44、ELS 码长 ×1.76，而 DL 不变。DL 与无损码长之比是生成器的属性，不是方法的属性。
- **要求：** 这类数字一律标为"生成器上界"，并且必须在家具转向面板和留出家具类面板上复测。

### 攻击三：附带信息的口径审查

| 报告 | 头号码字节（自己 / 边） | 位姿怎么计 | 和"精确"同口径吗 | 修正 |
|---|---|---|---|---|

| A02-G1 | 291 / 460 | float32 26 B | 是 | — |
| A03-A | 198 / 317 | 44 bit | 否（精确性用浮点位姿验证） | +19 B/机 |
| A05 | 322 / 540 | 44 bit | 否（同上） | +19 B/机 |
| A06-1 | 259 / 517 | 27 B | 是 | — |
| A08-D1 | 279 / 405 | 5 B | 自报 F1 .998（诚实） | 要精确再 +19 B |
| A10-α | 360 / 510 | 24 B + 4 B 头 | 是 | — |
| A04 | "理想增量" 254 B/边、8.75 KB/房 | — | 是码长之差，不是可实现的码；A04 自己的条件编码只到 0.95× | 用实现值：A10 8.9 KB，我的两趟协议 12.9 KB |

**我撤回一个担心。** d1 实测：12 张图上，float32 光线行进加 float32 位姿与 float64 逐体素一致，0 误差。所以"精确"的数值脆弱性不是问题。真正的前提有两个：

- 位姿精度。1 cm 时 A10 测得每图中位 392 个体素出错，A03 测得 0.8 % 已知体素改变。
- 传感器模型是公开常数：65,536 个 Fibonacci 方向、步长 ½ 格、5 m、首击规则。真实传感器有逐台标定、运动畸变、多回波，"可见性免费"是模拟器的性质。

噪声下，命中集 + 位姿的码长从 573 B 涨到 1,529 B（×2.7，而且已不再精确）；A03 的结构外壳涨 ×4.9。

**算力。** A02-G1 声称 9.5 TFLOP/步只要 0.1 s，相当于 95 TFLOPS 的持续吞吐。项目实测：40 次 Decoder3D 解码约 7.8 TFLOP，占步时约 0.12 s，有效吞吐约 65 TFLOPS。照此估，应为 0.2–0.25 s/步，是 A02 估计的 2 倍。

## 3. 合成提案：NX-Sheaf（噪声感知的精确格层 + 学习先验 + 位姿 stalk）

### 3.1 结构

- **stalk 索引集**（全部公共）：
  - 位姿 3 × SE(2)+z，带协方差，来自 A07-D3、A03-C；
  - 128² 平面列（墙 / 过梁的 log-odds），来自 A03 / A08；
  - 16² 锚点 × 2 个物体槽（盒或圆柱带偏航，每面一个区间），来自 A10-γ；
  - 体素证据原子：量化 log-odds ℓ̂ ∈ [−7, 7]，|ℓ̂| 即精度，来自 A10-α。无噪声极限下就是 {⊥, 空, 占} 精确格。
- **GBP 与能量：** E = E_pose + Φ_atom + Φ_obj。
  - E_pose 是带位姿相关限制映射的鲁棒高斯 sheaf Laplacian。森林二着色，两色交替做块坐标下降，只接受下降步。
  - Φ_atom 是证据因子缺失数。树上对整数 log-odds 求和，每个因子恰好计入一次；有环时退回 CI-max。
  - Φ_obj 是区间宽度亏量，融合是区间交。
  - 源端向下取整量化，线路只发新息，三项都不增。
- **线路：** 两趟汇聚—分发，只发新息。用 p_θ（以接收方状态、渲染出的图元、位姿为条件）做算术编码。噪声档里，编码端先做先验 MAP 去噪，只编码去噪后的世界，噪声不上线。
- **解码器：** 渲染图元与原子 → 从配准后的位姿重投射 → 三态图。先验只在解码端出现一次（A04 的 R5）。
- **损失：** 消息比特 + λ·D_truth（家具加权，零容差） + 首击一致性。扫 λ 得到 RD 曲线。
- **训练阶段：**
  - S0（CPU）：不学习的精确码（A03 + A10）；
  - S1（1 个租约）：先验；
  - S2（2 个租约）：带噪去噪编码器，用生成器真值监督；
  - S3（2 个租约）：位姿配准。

## 4. 我自己的修正

- **放弃 D1 GELS。** 它就是 A10-α / A01-Ⅰ / A02-G1，只是编码器更弱（574 B 对 250–360 B）。我说的"ELS-KT 是最强无损"被推翻了：浮点位姿下，诚实的最强非学习精确码约 220–260 B。我上一轮报告里对 ELS 的倍数要按约 2.4 倍下调。

- **下调学习先验的预期**：计数先验只省 5–19 %，神经先验预计 1.2–2×，上限受 DL（约 2×）约束。
