# A02 辩论稿：精确事实做底座，学习放进先验、去噪与配准

A02（生成式视角），2026-10-27。我读完了 A01 和 A03–A10，没有查文献。这一轮新加了四个探针，都在本机 CPU 上单进程运行，脚本和输出放在 `probes/A02/`：

| 探针 | 测什么 |
|---|---|
| P9 | 噪声下渲染恒等式是否成立，以及并集里的冲突 |
| P9b | 用 float32 做光线步进会不会破坏精确性 |
| P9c | 噪声下精确码要多少字节 |
| P10 | 同一个体素被几个智能体看到（观测重数） |

## 0. 立场

**这个世界里的结论。** 十份稿子都独立得到了同一个恒等式：自己的地图等于"观测到的占据 + 位姿"做光线投射的结果，而未知区是 don't-care。在这个无噪声世界里，不学习的精确码每张自己的地图只要 200–300 B，F1 = 1。它已经支配了所有学习式的有损设计。

**合成底座。** 所以合成方案的底座是：精确事实格 + 结构化线路语言 + 生成先验（作熵模型）+ 渲染解码。在这里学习只能把字节再压 1.2–1.5 倍，F1 已经没有提升余量。

**这个底座的边界。** 它只在无噪声时成立。我的 P9 / P9c 显示，1.5 % 的量程噪声就让精确码相对 ctx 的字节优势归零。学习和 sheaf-GBP 真正的用武之地在噪声、配准和新家具这些面板上。

## 1. 最强的三个设计（不含我自己的）

### ① A03-A RAY-SHEAF：平面图 + 实心盒 + 位姿，光线投射解码，AR 盒先验

**强在哪里。**
- 证据最硬：24 套 VAL 房子，192/192 逐体素精确（用浮点位姿）。
- 字节最低：自己的地图 198 B，收敛消息 317 B，R8 并集 561 B。每套房子整个协议 4.9 KB，现在是 229 KB。
- 它还主动做了旋转、噪声两个反面探针。

**最弱的假设：贪心实心盒就是正确的线路语言。**
- 这门语言是为轴对齐世界量身定做的：家具转 45° 时字节 +61 %，测距噪声 σ = 2 cm 时无损外壳的字节 ×4.9。
- 它的 44 bit 位姿并不精确，F1 实际是 .998 / .994。

**我的加强。**
- 盒子伸进未知区的范围，不再由贪心决定，而由先验挑选概率最高的那一种。我的 P7 显示，即便在体素级，用先验做补全也能省 35–43 %。
- 有噪声时，把生成先验当作盒子拟合里的去噪项（取 MAP），而不是拿来采样。

### ② A01-Ⅰ→Ⅱ：光线序无损编码，加超先验

**强在哪里。**
- 按射线推进的顺序编码，未知区的代价恰好为 0，只需编"这一步停不停"。
- 它不依赖任何几何启发式，所以对旋转、曲面同样成立。
- 自己的地图 250 B，每条边整场会话 538 B；用复原的真实位姿，48/48 张地图逐位精确。
- 增量发送和支配剪枝都有单调性证明，实测 0 违例。

**最弱的假设：Ⅱ 认为一个 ≤ 60 B 的潜码能省下多于 60 B，但没有证据。** A01 自己的探针恰好相反：现行码当超先验只省 62 B，它自身却要 177–330 B。

**我的加强。** "这一步停的概率"正是世界先验最该介入的地方：用 next-scale 的无模态先验去"想象"射线前方的几何，作为事件模型的条件，再用盒子层作超先验（也就是 A01-Ⅲ）。

### ③ A07-D2/D3：噪声世界（按真值评分）+ 配准感知 sheaf

**强在哪里。** 只有它造出了一个学习和 sheaf 都有可测价值的场景。
- 在相机级噪声下，无损传输噪声图的字节是干净时的 1.8 倍（自己的地图）/ 2.4 倍（并集），而按真值打分只有 K0 表面 .918、家具 .775。
- 智能体之间 5 cm / 1° 的坐标误差让并集家具 F1 掉 16 pp。这一点任何编解码器都救不回来，只有带非恒等限制映射的融合能救。

**最弱的假设。**
- 噪声参数是手设的，只用了 1 个噪声种子。
- 把评分目标改成真值，需要用户同意。
- D3 的块坐标下降在对称房间里有局部极小。

**我的加强。**
- 这里正是扩散 / score 先验第一次有原理性位置的地方：做去噪 MAP 和条件补全。一步生成的 consistency / MeanFlow 去噪器装得进 0.2 s/步的预算。
- 计分用的地图仍然不能采样。
- 我的 P9 正好给 D2 补上了直接证据（见 §2.2）。

## 2. 三个攻击

### 2.1 本世界里，学习式有损码被不学习的码支配

攻击对象：A09-A、A04-1/2、A05-1 的有损档、A03-B、A06-3。

| 设计 | 字节（自己的地图 / 收敛消息） | 家具区 F1 |
|---|---|---|
| A09-A W-Sheaf（预测） | 收敛消息约 420 | .72–.82 |
| A04-1 ΔV（预测） | 333–505 | .73 |
| A04-2 PV（预测） | 170–330 | .76–.80 |
| A05-1 有损档（预测） | 自己的地图 145–175 | .85–.93 |
| A03-B RK-Δ（预测） | 自己的地图约 245 | .62–.68 |
| **A08 盒码，丢掉 < 16 体素的盒（不学习，实测）** | **自己的地图 167** | **.930 / .947** |
| **A08 盒码，丢掉 < 8 体素的盒（不学习，实测）** | **211** | **.973 / .979** |
| **A03-A（不学习，精确）** | **自己的地图 198；收敛消息 317** | **1** |

- 学习式有损码要打的对手是不学习的有损盒子曲线，而不是 ctx 或 gzip。表里没有一个设计的预测能打过它。
- A01 和 A03 都已实测：把现模型的占据输出直接接到光线投射上，R8 的未知→已知 FPR 从 .031 涨到 .071。
- 因此，在无噪声基准上：A09 两周计划给 W-Sheaf 的 14 个租约，以及 A04 实验 1 的 1–2 个租约，都不该花。要做，就先搬到噪声面板上。

### 2.2 "事实不冲突、渲染恒等"在 1–2 cm 噪声下就崩溃（全场共识，也包括我自己的 G1）

P9 / P9c 的做法：3 套房子 × 4 个智能体，给每条射线的测距加噪声，再按两种规则积分。
- occwins：任一击中即判占据，这就是现在的规则；
- log-odds：OctoMap 式积分，参数同 A07。

| 噪声 | 恒等残差（占已知体素） | 恒等残差（占占据体素） | 并集冲突（占并集占据体素） | 精确码 = 击中 + 残差 | 噪声图 ctx 三态 |
|---|---|---|---|---|---|
| 无 | 0 | 0 | 0 | 440 B | 1,073 B |
| 1 cm（occwins / log-odds） | 14.6 % / 0.23 % | 73 % / 1.8 % | 15.5 % / 0.35 % | — | — |
| 2 cm（occwins / log-odds） | 18.6 % / 0.49 % | 80 % / 3.7 % | 12.8 % / 0.68 % | log-odds：470 + 234 = 704 B | 1,110 B |
| 量程的 1.5 %（occwins / log-odds） | 21.5 % / 1.28 % | 81 % / 10.0 % | 10.1 % / 4.2 % | log-odds：869 + 696 = 1,565 B | 1,557 B |

（字节一列只测了 log-odds 积分。）

**结论。**
- 用现在的"占据优先"积分，1 cm 噪声就让恒等式失效。
- 改用 log-odds 后：2 cm 噪声时精确码贵了 60 %；1.5 % 量程噪声时它已经和 ctx 一样贵，优势归零。
- 并集里有 0.35–4.2 % 的占据体素互相冲突，所以 join（取 max，即占据优先）不再精确。

**要求。**
- 所有"F1 = 1"的说法都必须注明"无噪声、精确位姿"。这适用于 A01、A03、A05、A06、A07-D1、A08、A10，也适用于我自己。
- 一旦有噪声，底线里的融合应改成树上的证据求和（A04 的 β = 1，或 A07-D2）。这样做仍然有可写的能量。

### 2.3 对重叠观测的潜码做和型高斯 GBP，会把同一个事实重复计数

攻击对象：A09-B（信息相加的教师潜空间），以及 A08-D3（"所有智能体估的是同一个变量，所以相乘有原理"）。

**问题在哪里。** 无噪声时，k 个智能体看到同一个体素，看到的是同一个确定性事实。求和式融合会把它的精度高估 k 倍。

**P10 实测（R8 并集里 k 的分布）。**

| 体素类别 | k 的均值 | 中位 | p90 | 被 ≥ 2 个智能体看到 |
|---|---|---|---|---|
| 已知体素 | 2.87 | 3 | 5 | 76 % |
| 占据体素 | 2.38 | — | — | — |
| 家具占据体素 | 2.16 | — | — | — |

"高斯相乘"只在证据条件独立时成立，比如独立的传感器噪声（A07-D2 的 log-odds）。对"观测本身"编出的潜码，它不成立。

**两种修法。**
- 换成 join，或者协方差交叉（CI）；
- 只发新息：以腔消息为条件，扣掉对方已经有的证据。这样每个事实只计一次，求和才是对的。

**附带两点记账。**
- 位姿：精确位姿实测要 13–17 B/智能体（P1b：0.1 mm 量化时中位错 2.5 个体素，残差 9 B）。A05、A07、A08 只按 5–5.5 B 计，却同时报"F1 = 1"——A08 自己在 1 cm 位姿下的复核结果是家具 .994。
- 浮点精度：我原先担心 GPU 用 float32 步进会破坏精确性。P9b 证伪了这一点：全部用 float32 时，每张图最多错 1 个体素。

## 3. 合成提案 S\*：精确事实格 + 生成先验 + 渲染；到噪声阶段再接学习

| 部件 | 内容（来源） |
|---|---|
| 索引集 | 公共体素格（按 32×32 竖柱记账）+ 位姿槽 + 全局常数（墙高、门高）。来源：A01 / A03 / A10 |
| stalk | **无噪声**：三态事实 {⊥ < 空, ⊥ < 占}，精度只有 0 和 ∞ 两档。**噪声阶段**：整数 log-odds（向零取整）+ 位姿高斯。来源：A07-D2、A03-C |
| 融合与能量 | **无噪声**：join。能量 E = Σ_v Σ_x [ρ(s\*_x) − ρ(s_{v,x})] + Σ_v \|A\*∖A_v\|，单调不增，≤ 直径轮归零；这就是 D8 里的 Tarski 流。**噪声下**：在森林上做整数求和，每个因子只计一次，能量 Φ = Σ_i \|V_comp∖S_i\|。**位姿**：两色块坐标下降，只接受让能量下降的步（A07-D3） |
| 线路 | 平面图 + 高度 + 实心盒（盒子在未知区的范围由先验挑选）+ 光线序的残差事件 + 位姿 13–17 B/智能体；只发腔新息，用两趟调度。来源：A03 / A01 / A02 / A10 |

| 解码器 | 光栅化 + 光线投射，逐位确定（P9b） |
| 损失 | 码长（bit）。有损时只能"删"，不能"糊"（A08）。凡是对边缘概率做判决，阈值取 F\*/2 |
| 阶段 | S0：CPU 上的静态先验 → S1：AR 盒先验，每种子 1 个租约 → S2：事件先验，每种子 1 个租约 → S3：噪声 / 配准面板，学习去噪编码器 + log-odds 融合 + 配准，≥ 4 个租约 |

**在这个合成世界里，学习还剩什么价值？**
- 对 F1：0，精确码已经是 1。
- 对字节：约 1.2–1.5 倍，DL 封顶约 2 倍。依据是 P2、A03-P7（−19 %）、A10（−13 至 −19 %）；A07 的计数先验只有 −5 %。
- 能带来代际差别的，只在这四类面板上：
  - 噪声：P9c 中精确码的优势归零；
  - 配准：A07 测得 −16 至 −29 pp；
  - 旋转：A03-P5，字节 +61 %；
  - 新家具。

**"压缩再生成"（diffusion / MeanFlow）放在哪里？**
- 熵模型：next-scale / 掩码离散扩散，也就是"由比特驱动的生成采样器"。
- 编码端的无模态补全：在看不见的地方由先验补全，换来 35–43 % 的节省。
- 噪声下的去噪先验：MAP，或一步的 MeanFlow / consistency。
- 不能用来生成计分的地图：采样会让家具 F1 掉 6–14 pp（P5），A06 测得 15 / 22 pp。

**评估必须改。** 否则学习只剩不到 1.5 倍的字节余量，"学习 + sheaf-GBP"这项工作就不成立。最少要做五件事：
1. 主口径改成每房网络总字节，位姿按精确字节计，最强无损基线用 S0；
2. 加噪声面板，按真值评分；
3. 加机间配准误差面板；
4. 加旋转面板和留出家具面板；
5. 任何"F1 = 1"都标注"无噪声"。

## 4. 我修正了什么

- **放弃 G1 的体素级线路。** 静态先验下它要 265 B（不含位姿），不如盒语言的 198 B（含 44 bit 位姿）和光线序的 250 B（不含位姿）。我保留"在 don't-care 区由先验挑代表"这个原理，把它并进 S\*。
- **放弃 G2。** A10-β 和我的 P4 / P4b 都显示它被精确码支配：3S-X 的预测作为边信息只值约 100 B。
- **G3 并入程序路线**，即 A08-D2、A09-C、A10-γ。
- **下调深度先验的增益**：从 ×0.6–0.8 改为 ×0.7–0.85。
- **新增两条认识**：G1 的 F1 = 1 只在无噪声时成立；生成模型的第二个正当角色是做去噪先验。

**建议的第一步实验 E0：精确编解码器统一对决，附噪声读数。纯 CPU，0 个租约。**
