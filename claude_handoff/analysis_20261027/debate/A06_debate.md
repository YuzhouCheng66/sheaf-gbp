# A06 辩论稿：家具 F1 视角的交叉审查

A06（Claude），2026-10-27。我读完了 A01–A05、A07–A10。为这一轮新做了两个 CPU 探针，都是单进程、内存 < 1 GB，脚本和输出在 `probes/A06/`：

- `a06_faceerr`：在真世界上给家具的每个竖直面注入"错一格"，模拟学习解码器的误差；3 房 × 8 智能体，K0。
- `a06_noise`：给量程加噪声，按干净真值评分，测家具的地板和结构化天花板；2 房 × 8 智能体。

## 0. 底色

十份稿子各自独立地撞上了同一个事实：首次命中地图 = 光线投射（W, 位姿），其中 W 是 O ⊆ W ⊆ ¬F 区间里的任一世界。全场实测的精确码（自己地图，中位）如下，K0、R8、家具 F1 全部是 1：

| 设计 | A03 盒子 | A01 光线序 | A06 | A08 | A02 | A10 | A07（H + 位姿） |
|---|---|---|---|---|---|---|---|
| 字节 | 198 B（24 房） | 250 B | 259 B | 279 B | 291 B | 360 B | 574 B |

所以在无噪声世界里，家具 F1 = 1 根本不需要学习。真正的分歧只剩三处：
1. 有损学习设计报的家具 F1 预测可不可信；
2. "几十倍"拿谁当分母；
3. 学习还剩什么用。

## 1. 全场最强的三个设计（不含我的）

**1. A03 RAY-SHEAF。**
- 强在哪里：面板最大、数最实。24 房 K0、R8 都是 192/192 逐体素精确；自己地图 198 B，收敛消息 317 B，R8 并集 561 B。它也是唯一给自己的合成偏差做了压力测试的设计：旋转 45° 时 245 → 394 B；σ = 2 cm 噪声时，无损外壳涨到 4.9 倍。
- 最弱的假设：贪心分割在扰动世界里依然成立；"有损 = 删小盒子"是对的旋钮。
- 我的加强：家具占它字节的约 80 %（159 / 198 B），也承担全部的 F1 风险。所以删盒子应该按"每比特换来的家具 F1"排序，而不是按体素数门槛。我的数据：最大的 12 / 41 个家具盒（44 / 135 B）已经给出 .81 / .85；m = 16 档（84 / 226 B）给出 .91 / .94。

**2. A01 LL-Sheaf → Hyper-Sheaf。**
- 强在哪里：光线序事件码不需要分割，也不依赖轴对齐，只编"射线停不停"，250 B 就能精确重建。超先验把学习放在唯一不伤 F1 的位置——熵模型；而且它的实验是干净的单变量。
- 最弱的假设：一个 ≤ 60 B 的竖柱潜码能付得起自己的码率。它自己测得：现码作超先验只省 21–24 % 残差，自身却要 177–330 B。
- 我的加强：A01 测得家具吃掉 40 % 的比特，而我的 furn_bits 说明这部分的"全局结构"就是盒子的范围。超先验应该做成盒子 token 流（也就是 A03 的语言），事件流只编残差。这就是下面合成提案的骨架。

**3. A07 D2：噪声世界 + 按真值评分。**
- 强在哪里：唯一一个让学习在 F1 上变得必要的设计，而且已经测出了地板：cam 噪声下 K0 家具 .775，R8 树上求和 .756、max .627；机间误差 5 cm/1° 就让并集家具掉 16 pp。
- 最弱的假设：学到的去噪码能比"无损传噪声图"高 ≥ 5 pp。
- 我的加强：见第 3 节的探针。纯量程噪声下，经典 log-odds 融合已经拿到 .92–.98，所以面板必须加入位姿误差、机间误差和漏测才有区分度。另外，去噪的单位是"面"（一个家具面中位汇集 121 个命中），所以噪声世界里正确的学习模型是结构化的：盒子或平面拟合，不是体素潜码。

## 2. 攻击

### 2.1 学习型有损解码 + 光线投射报的家具 F1

被攻击的预测：A05 RAYFIELD .85–.93，A09 W-Sheaf .72–.82，A04 PV .76–.80。

`a06_faceerr` 的做法：对每件家具的 4 个竖直面独立抽签，以概率 p_out 外扩一格、p_in 内缩一格，然后分别用光线投射解码和"理想 known 头"直接解码。

| 每面错误率（外扩 / 内缩） | 投射解码：家具 / 表面 / FPR | 理想 known 头：家具 |
|---|---|---|
| 5 % / 5 % | .870 / .970 / .0009 | .905 |
| 10 % / 10 % | .812 / .959 / .0014 | .846 |
| 20 % / 20 % | .664 / .934 / .0036 | .724 |
| 20 % / 0 | .849 / .959 / 0 | .892 |
| 0 / 20 % | .863 / .976 / .0054 | .863 |
| 40 % / 0 | .685 / .919 / 0 | .795 |

读法：
- **投射解码要家具 ≥ .85，大约要 ≥ 90 % 的家具面体素精确，而且外扩 ≤ 5 %；要 .93，得 95–97 %。** 外扩比内缩伤得重：外扩的那一格把真表面挡住，一次错两格。
- 现在的学习码离这个有多远：
  - 侧面体素的召回只有 .33–.53（我的解剖）；
  - 分析者 A 的合成扫描里，离开竖柱边缘的家具面精确率只有 .08–.29；
  - 3S-Z（64²，16k）家具 .50；
  - "现预测 + 投射"是 .51 / .52，A01、A03、A05 三家测得一致；
  - 粗化 2×2×1 再投射是 .53–.55，A05、A08 和我三家一致。
- 结论：RAYFIELD 的 .85–.93 等于假设一两个租约之内把面误差压低 5–10 倍。信息量本身够（家具 DL 约 66 B，它给了 100–130 B），难点在可学性。要让每个面在子块里的偏移精确到体素，码实际上就得变成"面 / 盒子坐标"，也就是程序码。
- **我的预注册预测**：
  - RAYFIELD 在 K0 家具码 ≤ 150 B 时，R8 家具落在 [.62, .80]；
  - W-Sheaf 落在 [.62, .75]；
  - 任一种子超过 .85，就说明我的面误差模型是错的。

### 2.2 词表 / DL 级的"相对 gzip 几十倍"

被攻击的设计：A08 Vocab-Sheaf 85 B，A05 BoxTok 70–140 B，A02 G3 115 B，A01 Ⅲ 110–130 B，A10 γ 110–150 B。

- 这些数字都是神谕：要么用 world_spec 的参数，要么是 DL 估算。解码器里装着生成器的 22 类家具库，也就是 A07 说的"生成器泄漏"。
- 场内已经有反例：
  - A05 的"只发大块"，预言版家具 .85，换成现实实心盒编码器只有 .644；
  - A03 P5 旋转 45° 后，盒子码变成 1.6 倍。
- 我的 furn_bits：贪心家具盒每盒约 27 bit，K0 34 个盒共 116 B，而 DL 约 55 B。两者差约 2 倍，这 2 倍正好就是"知道家具库"值的那部分。
- 诚实的口径：今天能实现、又不偷看生成器的精确码，自己地图是 198–279 B，相对 gzip 10–14 倍。更高的倍数必须在"旋转 + 留出家具类别"面板上测出来才算数。

### 2.3 "F1 = 1.000、家具问题解决了"不能当汇报结论

它同时依赖三件只有合成世界才给的东西：
1. 无噪声的首次命中；
2. 浮点精确的位姿；
3. 轴对齐。

关于位姿：取整到 1 cm 时，每张图有 351–1,838 个体素不同（我的 posequant）；A10 在 96 张图上合计 40,545 个。即使是纯量程噪声，"任一命中即占据"的朴素地图家具也只有 .37–.49；A03 P6 反方向测（干净图对噪声目标）也只有 .35–.37。机间配准误差会让并集掉 16–29 pp，任何编解码器都救不回来。

所以 F1 = 1 只配当"编解码器正确"的单元测试，不能当"家具已经实用"的证据。

## 3. 合成提案：EPR-Sheaf（证据格 + 程序线路 + 光线投射；噪声档学结构化去噪）

- **stalk 索引集与内容**：
  - 公共体素证据：{⊥, 空, 占}^{128×128×32}，精度 0 或 ∞；噪声档换成饱和 log-odds 计数对（A07 D2、A03 C3）。
  - 位姿 stalk：float32，每个智能体 24 B；噪声档换成 SE(2) 高斯。
  - 全局 stalk：墙高、门高。
- **GBP 与能量**：
  - 证据层做逐坐标 join，也就是现在的最大精度选择。能量 E = Σ_i Σ_v [ρ(x\*_v) − ρ(x_{i,v})]，单调不增，不超过直径轮归零。
  - 噪声档在树上做整数 log-odds 求和，不会重复计数；能量取尚未计入的证据数。
  - 位姿部分是高斯 sheaf Laplacian，只接受让能量下降的步（A07 D3）。
  - 线路只是证据的无损再表示，所以变长、只发新息、熵编码都不改变轨迹（A04 的 L-Q / L-S / L-Δ）。
- **线路与熵编码**：
  - 消息是"最短一致世界"，由三部分组成：平面图（约 30 B）、可靠实心盒（A03 / A08 / A06）、盒子解释不了的部分用光线序事件残差（A01）。
  - 发送方以反向消息为条件，只发新息；整网按收集—分发调度（A10、A07）。
  - 中继要重新拟合：A03 实测不重拟合时字节是 2.6 倍。
- **解码器**：栅格化后做光线投射。有损只许"删可靠盒子"，按每比特家具 F1 排序；判决阈值取 F1\*/2。
- **学习只放三处，训练也对应三个阶段**：
  - S0：无训练（CPU）；
  - S1：盒子 token 的自回归先验，加上以渲染盒子为条件的事件残差上下文网络（1 个租约）；
  - S2：噪声档的结构化去噪编码器——用 world_spec 监督盒子 / 平面提议，再做 MAP 精修，在噪声面板上按真值评分（2 个租约）。

| 字节（中位） | 自己地图 | 收敛消息 | R8 并集 | 每房一次融合 |
|---|---|---|---|---|
| 已测（贪心 + 静态先验） | 198–259 B | 307–405 B（只发新息） | 561–821 B | 4.9–9 KB |
| 预计（学到的先验） | 130–170 B | 200–260 B | 400–550 B | 3–5 KB |

倍数（自己地图 / 收敛消息）：

| 分母 | 自己地图 | 收敛消息 |
|---|---|---|
| 诚实最强无损 H + 位姿（574 / 970 B） | 2.2–4.4 倍 | 2.4–4.8 倍 |
| ctx（1,384 / 1,752 B） | 5.3–10.6 倍 | 4.3–8.8 倍 |
| gzip（2,733 / 3,647 B） | 10.6–21 倍 | 9–18 倍 |
| 原始栅格 | 500–1,000 倍 | 320–650 倍 |

**F1 预期**：
- 无噪声：R8 表面 = K0 = 家具 = 1.000。
- 噪声档（量程 2 cm + 位姿 / 机间误差）：家具应当从 A07 的地板 .76–.78 升到 ≥ .90。

**学习在这个合成世界里还剩什么？**
- 无噪声时，只剩比特：先验能再压约 1.3–2 倍，F1 已经被物理封顶。任何有损学习解码器在这里只会把 F1 拉低（见 2.1）。
- 学习只在信息被破坏或缺失的地方对 F1 有用：
  - 量程噪声：用结构把一个面上的几十到上百个命中汇在一起去噪；
  - 位姿和配准误差：用墙平面对齐，这正是非恒等限制映射第一次真正派上用场；
  - 非轴对齐、真实形状：需要形状先验；
  - 极低码率：决定删什么、怎么判。

**评估必须改**：
- 加五样：噪声面板（量程 1–3 cm + 漏测 + 离群）、位姿与机间误差、旋转家具、留出家具类别、按真值评分（干净传感器、真位姿、只评观测区）。
- 无噪声精确面板保留，作正确性测试。
- 汇报时同时给"无损传噪声图"的地板。

**噪声下的家具天花板**（`a06_noise`，纯量程噪声，按干净真值评分）：

| σ | 朴素"任一命中即占据" | log-odds 融合（OctoMap 式） |
|---|---|---|
| 1 cm | .49 | .98 |
| 2 cm | .42 | .96 |
| 4 cm | .37 | .92 |

- 结构化去噪的解析天花板约 .96–1.0，σ 到 8 cm 也不降：家具面中位汇集 121 个命中，只有 1 % 的家具体素落在命中 ≤ 3 的面上。
- 所以只加量程噪声太容易，主要的增益要到位姿 / 机间误差里去找。A07 测得 cam 档地板 .78 / .63–.76；我估计结构化去噪 + 配准之后的天花板在 .90–.95。

## 4. 修正我自己的设计

- **放弃 RayField。**
  - 在无噪声世界里它被精确码支配。
  - 它依赖的"有损体素 + 投射"前提已被多方测试否定：粗化再投射 .53–.55；现模型输出直接投射 .51；外扩误差会被加倍惩罚。
  - 它的零件挪进噪声档：Belnap / log-odds stalk、F1\*/2 判决。
- **ProgSheaf 换零件。**
  - 墙改用 A03 的平面图层（2D 约 30 B，原来结构盒约 41 B）。
  - 残差改用 A01 的光线序事件码。
  - 位姿改用 float32（24 B）。我原来的"0.1 mm + 修正集 27 B"字节差不多，但更复杂。
- **有损旋钮** 从体素数门槛 m 改成"每比特家具 F1"排序，只删不糊（A08）。
- **撤回"学到先验后相对 gzip 17–21 倍"**，改成两步表述：今天实测 ≥ 10 倍；更高的数要等旋转面板和留出家具类别面板。
- **把噪声面板提到最前**，而且必须带位姿误差和机间误差：我的探针显示纯量程噪声没有区分度。

**我的前三名**（不含自己的设计；三者合起来就是 EPR-Sheaf）：
1. A03 RAY-SHEAF，作精确骨架；
2. A01 Hyper-Sheaf，把学习放进先验，只影响比特；
3. A07 D2，让学习在 F1 上有事可做。

**建议的第一步实验**：纯 CPU，不占租约。
- 单变量：编解码器。
- 臂：合并版精确码（平面图 + 可靠盒 + 光线序残差 + float32 位姿 + 只发新息的收集—分发）。
- 对照：3S-X + 校准规则；同时并列 H + 位姿无损（ELS）和 ctx。
- 面板：VAL-24 和 fresh-24（A03 已能在本机重建真位姿）。
- "两个种子"：用两个互不相交的 TRAIN 半集分别拟合静态先验。
- 预注册判据（两个面板、两个先验都要满足）：
  - (i) float32 位姿下，384 张自己地图和全部 R8 并集逐体素精确 100 %；不等算 bug，判 INCONCLUSIVE。
  - (ii) 中位：自己地图 ≤ 260 B，收敛消息 ≤ 420 B，每房一次融合 ≤ 6 KB。
  - (iii) 家具按细 xy / 细 z / 大块和高度分层报告（无损时应全为 1）。
- 同一批里建噪声面板：量程 2 cm + 漏测 5 % + 位姿 2 cm/0.5° + 机间 5 cm/1°。预注册：log-odds 地板的 R8 家具落在 [.65, .90]，否则调整噪声档。
- 成立之后的第二步（2 个租约）：在噪声面板上，结构化去噪提议器对"无损传 log-odds 噪声图"，等字节比较，按真值评分。
