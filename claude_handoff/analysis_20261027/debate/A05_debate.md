# A05 辩论稿：精确几何已经"解完"这个基准；学习与连续场的价值在别处

A05，2026-10-27。我读完了其余 9 份稿子。这一轮新做了两个探针，脚本和输出在 `probes/A05/`，都是单进程、内存 < 4 GB：

- p8：形状神谕在不同分辨率下的表现；
- p9：接收端浮点重放是否仍然精确。

## 0. 立场

- **共识。** 10 份稿子各自独立得到了同一条传感器定理：own map = RayCast(H, 位姿)，并且凡满足 H ⊆ G ⊆ ¬F 的世界 G 都给出同一张图。我、A01、A03、A06、A08、A10 各自逐位验证过。
- **分歧只剩三件事：** 学习放在哪里；结构语言选什么；这个基准还能不能衡量"学习 + sheaf-GBP"。
- **我的判断：** 在无噪声世界里，字节数 ≥ 120 B 的有损学习码，全部被确定性的精确码或"删盒"有损码支配，包括我自己 RAYFIELD 的有损档。学习只剩两种价值：
  - 码率先验，比最好的确定性精确码再省 1.3–1.6 倍；
  - 编码端的"可靠补全"。
- **评估必须改。** 要让学习和 sheaf-GBP 有意义，必须换成"噪声 + 配准误差 + 按真值评分"的基准。连续坐标场在那里才是主角。

## 1. 全场最强的 3 个设计（不含我自己的）

### A03 RAY-SHEAF：平面图 + 贪心实心盒 + 位姿，学习只做熵模型

**为什么强。** 它是唯一在 24 个 VAL 房子、192 张 own map 上实测过的方案。

| | own | 收敛消息 | R8 | 精确性 |
|---|---|---|---|---|
| 44 bit 位姿 | 198 B | 317 B | 561 B | 表面 .998，家具 .994 |
| 精确位姿：u16 抖动（110 bit/智能体） | 207 B | 351 B | 627 B | 44/48 张精确，最多差 3 个体素 |
| 精确位姿：float32 | 219 B | — | — | 48/48 张精确 |

此外：

- 它做了压力测试：家具旋转 ±45° 时盒子数 62 → 109；σ = 2 cm 测距噪声下，无损外壳 ×4.9。
- 底线最干净：stalk 停在体素这一层；结构只出现在线路语言里；每段描述只用它自己的位姿渲染，再做 join。因此不需要跨智能体的关联。

**最薄弱的假设。**

- 中继必须"无损重拟合"发送侧的并集。不去重时字节 ×2.6；把实心盒直接并起来，只有 17/192 张精确。也就是说，每一跳都要跑一次贪心分解加渲染核对。
- 轴对齐：旋转后盒子数 +76 %。

**我的加强。**

1. 把块内的盒子写成 max-plus 支撑函数 stalk。p5 已验证：并集的码就是码的逐元素 max，R8 上 6/6 同态，FPR 按构造为 0。这样中继不用重拟合，join 本身就精确。
2. 盒面改用 1 cm 连续坐标加偏航角，按"格心包含 + 薄件保留中心格"的规则栅格化，旋转后不再碎成阶梯盒。
3. 有损档只许"删"，不许"糊"：
   - p2b：外扩一格，家具降到 .13；
   - A08：粗化成 2×2×1，家具 .548；
   - 删盒的 R–D 前沿（m = 16 时 126 B，家具 .941）才是它的有损曲线。

### A01 LL-Sheaf → Hyper-Sheaf：光线序事件码 + 学习超先验

**为什么强。**

- 它是最一般的精确码：不假设盒子，不假设轴对齐，只编码"射线第一次进入这个体素时停不停"。
- 先验用留一房（LOO）统计，own 250 B + 13 B 位姿。
- 学习被准确地放在总码长 R(z) + E[−log p(x|z)] 里。
- 有损模式是"停下但不标占据"，在构造上不会漏光，正好修掉 VIS-swap 的 R8 FPR +4 pp。
- 这是唯一能平滑过渡到噪声世界的精确码。

**最薄弱。**

- 解码按射线步顺序进行，每个智能体约 480 批；在神经先验下，这意味着几百次前向。
- 超先验必须 ≤ 60 B 才划算。现行码拿来当超先验只能省 21–24 %，自身却要 177–330 B。

**我的加强。** 用我的稀疏 max-pool 家具场当超先验：只在 4³ 家具块上有码，K0 中位 187 块。这个场直接给出首次命中概率 P(s) = σ_s∏_{j<s}(1−σ_j)。它同时是：

- 事件熵模型；
- 有损解码器；
- 融合时精确的同态 stalk，不再需要按精度选源。

### A07 D2 + D3：按真值评分的噪声世界 + 配准感知的位姿 stalk

**为什么强。** 它是唯一回答"学习 + sheaf-GBP 在哪里有意义"的设计。

- cam 噪声下，把自己的地图无损送到也只有 K0 .918 / 家具 .775（R8 .875 / .756），ctx ×1.8。
- 机间误差 5 cm/1° 会让并集家具掉 16 pp。任何编解码器都救不回来，只有带位姿 stalk、限制映射非恒等的 sheaf 能救。
- 有噪声时，max 规则比树上 log-odds 求和差 8–18 pp 家具。

**最薄弱。**

- 目标定义需要用户认可。
- 噪声参数是手设的，只用了 6 个房子、1 个噪声种子。
- 两色位姿块坐标下降在对称房间里可能陷入局部极小。

**我的加强：连续坐标在这里是主角。**

- 一块平面被 N 条射线命中，偏移估计的误差是 σ/√N。σ = 2 cm、N = 50 时只有 2.8 mm，远小于 6–16 cm 的体素。所以先连续拟合、再按格心规则栅格化，结果近乎精确。体素码要么原样传噪声（字节 ×1.8–2.7），要么把它糊掉。
- A03 P6 显示：用干净几何去比噪声目标，精确 F1 只有 .37。这说明评分目标必须是干净几何，解码器必须去噪。
- 首次命中似然（体渲染）就是噪声深度的正确似然；点到面的配准也需要连续的面。

### 攻击 2：A04 的形状神谕支持不了 ΔV-Sheaf（p8 实测）

A04 用 P5 的"实例盒 .53 对竖柱区间 .93"，劝退盒子 / 物体路线，并据此在 64² 竖柱上放 8 个通道。我在同一批 R8 目标上按 A04 的协议复算：

| 神谕（R8 家具区 F1） | A04 协议（直接填） | 光线投射解码 |
|---|---|---|
| 每个 26 连通实例一个 AABB（A04 的"盒子"，餐桌和椅子会并在一起） | .532（复现） | .608 |
| 图元盒（贪心分解） | **1.000** | **1.000** |
| 1×1 体素竖柱区间（A04 的 ".93"） | .934（复现） | .933 |
| 2×2 竖柱区间（ΔV-Sheaf 的实际分辨率） | **.669** | **.507** |
| 2×2 区间 + 精确的 4 bit 子柱足迹 | .871 | .865 |

（K0 的结果几乎一样：.564 / 1.000 / .930 / .655 / .870。）

读法：

- "盒子不行"是粒度选错了：用的是实例，不是图元。
- ".93"在 64² 上只剩 .67 / .51。要回到 .87，每个家具竖柱得多传 4 bit 足迹。
- 所以 A04 的码率估计（3.0 bit/stalk，其中家具 6 bit）少算了；家具 .73 这个预测没有神谕支撑。
- 这和 A06 的结论一致：水平错 1 格就掉 45 pp。

### 攻击 3：程序 / 词表码的字节估计默认了"神谕分词器"

被质疑的估计：

- A08 Vocab-Sheaf own ≈ 85 B；
- A02 G3 ≈ 115 B；
- A09 C 100–150 B；
- A01 Ⅲ 110–130 B。

它们都以 DL（可见物体的真参数）为底。实测反例有四条：

1. **p6 / p7**：只看自己地图的现实编码器，词元比预言多 52 %（90.5 对 59.5，R8 多 85 %），而且把大块家具切碎了。只发大块时，现实版家具只有 .525，预言版是 .810。
2. **A04 P5**：同一实例在 16² 锚点上，跨视角一致率只有 63–80 %。
3. **A03 P5**：家具转 45° 时，盒子 +76 %。
4. **位姿口径**：1 cm 位姿每张图中位有 392 个体素不一致（A10）。精确位姿需要 110–206 bit/智能体，而不是 40–44 bit。所以按 5 B/智能体计位姿的估计（A04 PV、A08，也包括我的原稿）在 R8 上少算了 65–165 B，约占 A08 R8 估计（220 B）的 30–75 %。

结论：这类设计的瓶颈是部分视角下的可靠补全与关联，不是先验。DL 级字节只有在编码器学会可靠补全之后才可信。

**撤回一个我自己的怀疑。** 我原以为 GPU 用 float32 步进会破坏"精确重放"。p9 证否了这一点：float32 算术 24/24 张图精确；float32 位姿配 float64 步进是 23/24，最多差 1 个体素。精确重放的唯一前提是位姿精度。

## 3. 合成提案：双层 sheaf，学习只在先验与编码器

**来源。** L1 由 A01、A03、A06、A08、A10 合成；L2 由 A07 D2/D3、A03 C 和我的连续场合成。能量引理用 A04 的 R1–R5 与 L-Q / L-S / L-Δ；训练纪律按 A09。

**stalk 索引集与内容。**

- **L1 精确格层**（今天的基准）：

  | 索引 | 内容 | 格与 join |
  |---|---|---|
  | I_pose：8 个智能体槽 | u16 抖动位姿 | 精度 ∞ |
  | I_glob | 墙高、门高 | 平坦格 |
  | I_plan：128² | {⊥, 墙, 过梁} | OR |
  | I_box：16² 锚格 | 可靠盒子的反链（max-plus 编码） | 并 + 去包含 |
  | I_res | 残差击中 | 幂集格 |

  信念 = 体素三态格：每段描述用它自己的位姿渲染，再 join。
- **L2 连续参数层**（噪声基准）：墙面段和盒面的连续偏移（含偏航），写成高斯信息形式 (η, Λ)；位姿 stalk 带协方差；限制映射 = 按估计位姿搬到公共坐标。

**GBP 能量。**

$$E=\underbrace{\sum_v\sum_{i}\big[\rho_i(x^*_i)-\rho_i(x_{v,i})\big]}_{\text{L1：格秩亏量}}+\underbrace{\tfrac12\!\!\sum_{(u,v)}\!\sum_k\big\|A_k(T_u)\theta_{u,k}-A_k(T_v)\theta_{v,k}\big\|^2_{\Gamma}+\tfrac12\sum_v\|\theta_v-\hat\theta_v\|^2_{\Lambda_v}}_{\text{L2：高斯 sheaf 能量}}$$

为什么下降：

- L1：join 是膨胀的，量化单调，变长码无损，delta 不改变轨迹，所以每轮不增。
- L2：在森林上做两色块坐标下降（线性化 GBP），只接受能让能量下降的步。这是块坐标下降，所以单调；精度用 floor 量化，只会更保守，不会夸大。

**线路与熵编码。**

- 收集—分发两趟，只发新息，以反向消息为条件（A04 L-Δ、A10 α）。
- 盒子词元用 AR Transformer 先验（A03 A-1），残差事件用光线序上下文模型（A01），平面图用 2D 上下文模型。
- 位姿 110 bit；接收端用 float32 重放，并在编码端做渲染自检。

**解码器。**

- L1：精确栅格化 + 光线投射。
- L2：L2 GBP 不动点 + 学习先验做连续 MAP，再栅格化。
- 有损只删不糊；概率读出时按 F*/2 判决（A02 / A06）。

**损失。**

- L1：只训先验，损失是 NLL（bit）。
- L2：首次命中（测距）似然 + λ·码率 + 配准项。

**训练阶段。**

| 阶段 | 资源 | 内容 |
|---|---|---|
| S0 | CPU | 正式复核 |
| S1 | 1 个租约 | 学习先验 |
| S2 | CPU | 生成噪声基准 v5 的各项"地板" |
| S3 | 2–4 个租约 | L2 层 |

**预计（无噪声，精确模式）。** 起点是 A03 的实测值（u16 位姿）：own 207 B、收敛消息 351 B、R8 627 B。盒子与平面部分按先验 −30 % 计，位姿不压：

| | 字节 | 相对最强非学习精确码 | ctx | gzip | 原始 |
|---|---|---|---|---|---|
| own | ~160 B | 1.3×（207 B） | 7.9× | 16× | 820× |
| 收敛消息 | ~270 B | 1.3× | 6.1× | 12.9× | 485× |
| R8 并集 | ~450 B | 1.4× | 4.7× | 9.4× | 290× |
| 每房协议总量 | ~4 KB | 1.35×（5.4 KB） | — | — | — |

- 每房协议总量 ~4 KB，是现在 229 KB 的 1/57。
- F1：R8 表面、K0、家具区都是 1.000（位姿 u16 时 ≥ .9995）。
- 有损档（删掉覆盖 < 16 个体素的盒子）：own ~100–110 B，表面 .99，家具 .94，相对 gzip 约 25×。

**噪声基准（v5，cam 级噪声）上的目标值，不是测量值。** 对照的无损地板是 K0 .918 / .775，ELS 1,529 B。L2 的目标：

- K0 表面 ≥ .95、家具 ≥ .85，字节 ≤ 500 B；
- R8 在消掉机间误差后 ≥ .95 / .90。

### 对三个特别问题的回答

**(1) 学习还剩什么价值？**

在这个世界里，F1 已经不是学习问题。A03 p13 和 A09 指出：只发击中集 S、其余一律报未知，四个 F1 全是 1，FPR 为 0，只是空闲召回为 0——度量根本不对空闲区计分。学习只剩下：

- 码率：比最强的非学习精确码再省 1.3–1.6×，上限是 DL（own 126 B）；
- 编码端的可靠补全：把现实编码器的词元从 90.5 降回 59.5；只发大块时，家具从 .52 提到 .81；
- 速度：贪心编码每张图 0.2–5 s，学习编码器可到毫秒级。

**(2) 评估设置是否必须改？** 必须改。具体建议：

- 测距噪声 1.5 % r、漏测、离群；
- 帧位姿误差 2 cm / 0.5°，机间配准误差 3–10 cm、0.5–2°；
- 家具偏航 ±45°；
- 留出若干家具类不参与训练；
- 评分目标 = 干净传感器在真位姿下的观测区；
- 加一项空闲召回保护；
- 必报"无损噪声图的地板"。

不改的话，任何学习模型在 F1 上最多只能追平一个 50 行的贪心编码器。

**(3) 连续坐标解码在噪声数据上才显出价值吗？** 是。

- 在这个体素精确的世界里，它只是免费的副产品。
- 在噪声里它有四个用处：σ/√N 的平均把噪声压到体素以下；连续偏航收回旋转带来的 +76 % 盒子；点到面配准需要连续的面；分辨率无关，R1 和 R2 共用一份码。
- 我的 RAYFIELD 应当整体移到这里。

## 4. 修正我自己的设计

**放弃：**

- RAYFIELD 作为"本基准的下一代模型"：它的有损档被支配（见攻击 1）。
- 设计三"码让位给家具"：现行稠密码怎么腾容量都被精确码支配，不值一个租约。

**合流：** 我的设计二（盒子词元 + 生成先验）与 A03 / A06 / A08 合流。A03 的联合表先验已经做到 20.9 bit/盒，我的粗糙先验没有优势。我的独有贡献是 p6/p7 的"现实编码器 vs 预言"差距，它指明学习应该放在可靠补全上。
