## 1. 家具损失按来源分解（VAL，V3，R8 森林求和）

**机理（均值 F1，s1 / s2）**【文件】。range 与 pose 的分摊用两种加入顺序的平均（Shapley）。

| 来源 | 损失 pp | 可辨识 / 学习能否拿到 |
|---|---|---|
| 机间误差（cam − cam_nf） | 15.6 / 13.5 | 一部分不可辨识（E4 审查 §1.10：岛间没有共同墙面）。归配准，不算去噪的账 |
| 逐帧位姿 | 8.9 / 10.4 | 可辨识：同一机 3 个位姿只差每轴 ±10 cm 的抖动，视野几乎全部重叠 |
| 测距噪声 | 5.9 / 5.7 | 可辨识，可学 |
| 其中漏测 10 %、早返回 0.5 % | ≈ 0 | 【探针】只漏测时 R8 .999，只离群 1.000；从 cam_nf 去掉其中一项，变化分别 +0.2、0.0 pp。只 σ 时 .943，去掉 σ 时 +3.7 pp |
| 合计 = cam 档损失 | 30.4 / 29.6 | |

**误差类型**【文件】：cam_nf 上 R8 精确率 .807 / .801，召回 .937 / .933。损失的 78 % 是虚警（变厚、贴面伪占据），不是漏检。

**按层加性拆分**【文件】。用的恒等式是 1 − F1 = Σ_s (FP_s + FN_s) / (2TP + FP + FN)。cam_nf 合并 F1 为 .867 / .862：

| 层 | 目标体素占比 | F1 | 占损失 |
|---|---|---|---|
| 观测重数 m = 1 | 36 % | .80 / .79 | **54 %** |
| m = 2 | 27 % | .88 | 25 % |
| m ≥ 3 | 37 % | .90–.95 | 21 % |
| 高度 < .3 m | 19 % | .77 / .74（精确率 .65 / .62） | **38–41 %** |
| .3–.9 m | 54 % | .91 | 33 % |
| ≥ .9 m | 27 % | .86 / .87 | 25–28 % |

**读法**
- cam 档最大的一块是机间误差。cam_nf 内部，逐帧位姿大于测距 σ。
- 按体素看，损失集中在单次观测体素和贴地带，主要是虚警。贴地带的 K0 精确率只有 .46。【推测】机理是地板顶面落在体素边界上，测距短读把端点推进地板上方第一层。
- 去噪能拿到的是 cam_nf 那 14–16 pp 的大部分：m = 1 的部分求和帮不上，只能靠单机证据的质量。
- 漏测和早返回离群在 V3 下可以忽略，不值得为它们花模型容量。

## 2. V1 降到 .32：猜想部分成立，但主因不是阈值

- 【文件】V1 在 cam 档：K0 精确率 .17、召回 .90；R8 求和精确率 .20，虚警占损失 .65。
- 【代码】`POSES = 3`（`mapping_3d_storey_data_v420.py`），每扫描最多一次更新，所以 L = 17h − 8m，且 h + m ≤ 3。读出规则 L > 0 等价于 h ≥ 1（17 − 16 = 1）。也就是说，三次扫描里只要有一个噪声端点落进体素，就判占据。"3 次更新与阈值不匹配"这一点成立。
- 但调阈值救不回来：
  - 【文件】B5 用 ≥ 17 / ≥ 34，家具只到 .40 / .41；V3 是 .69。
  - 【探针】TRAIN cam_nf：V1 原样 .376，调阈值 .468，标定表 .617；V3 原样 .879。
- **主因**：V1 在一次扫描内"有击中就算击中"，把同一扫描里穿过该体素的几十条束的未命中证据丢掉了。信息在积分阶段就没了。
- **对 E3 的影响**：输入必须是逐束计数，不能用 V1 或 V3 截断后的图。E3 只适用于能拿到逐束计数的传感器管线，OctoMap 库式插入不在适用范围内。

## 3. 关键新证据：零学习的标定表就有 +5 pp，而且求和过度自信【探针】

**标定表 B6**：每台机器一张表 c(L) = log P(L | 占据) / P(L | 空闲)，共 111 个数，留一房拟合。融合用 ℓ_π + Σ c，先验只计一次。阈值在其他房上选，约束是空闲召回不降。

| TRAIN cam_nf，R8 | 合并 F1 | P | R | 空闲召回 |
|---|---|---|---|---|
| B4（Σ L > 0） | .879 | .826 | .941 | .980 |
| B4 + 调阈值 | .884 | .910 | .861 | .990 |
| **B6 标定表** | **.928–.930** | .93 | .93 | **.991** |

- 拟合出的表**不单调**。整数 L 实际上是对 (击中数, 未命中数) 的有损哈希；OctoMap 的 +.85 / −.40 对这个传感器没有标定。
- **条件独立检验**：对真值做逻辑回归，看融合 logit 的斜率，按有噪观测机数 k 分层。

| k | 1 | 2 | 3 | 4 | ≥ 5 |
|---|---|---|---|---|---|
| B6 斜率（全部体素） | 1.04 | .75 | .61 | .62 | .64 |
| B6 斜率（家具区） | 1.07 | .75 | .62 | .63 | .63 |

  单机是校准的，多机求和过度自信约 1.6 倍，说明机间证据正相关。学习去噪器引入空间上下文以后，这种重复计数【推测】只会更重。

## 4. E3 预注册草案（可直接抄用）

- **问题**：学习去噪证据 stalk 能否在 cam_nf 上超过最强的零学习证据？
- **单变量**：每台机器 stalk 的产生函数。融合、读出、线路三者对各臂相同。
- **输入**：只用本机数据。逐扫描逐束的 (n_hit, n_miss)，3 次扫描共 6 个通道；另加到本机中心的距离和高度，共 8 个通道。不输入任何截断后的 log-odds。
- **输出**：e_a = logit p_θ(占据 | 本机) − ℓ_π(z)，只在本机观测到的体素上非零。
  - ℓ_π(z) 是公开先验，用 TRAIN 按 3 个高度带各估一个数；在读出时只加一次。
  - e_a 量化成 int8（单位 .05），线路无损。
- **消息与读出**：
  - 每条消息发两个和：(Σe, Σ1)。仍是排除回传的森林求和，provenance 断言照旧，能量就是未吸收来源数。
  - 读出：ℓ = ℓ_π + w(k)·Σe > t。w(k) 共 5 个数，与阈值 t 都只在 TRAIN 上拟合。B6 用同一个读出族；另报 w ≡ 1 一行。
- **网络**：3D U-Net，3 层，基宽 16，参数 ≤ 1 M，感受野 ≥ 9 体素。
- **损失**：单机 BCE（使 e 校准）+ 0.5 × 分量求和 BCE（求和可导）。权重在 TRAIN 上定死。
- **数据**：
  - 只用 TRAIN 房子。导入冻结的 `g4_noise_panels`（trace_pose / measure / scan_events）重新抽噪声，噪声种子 ≥ 100，与 1、2、7 都不相交。90 % cam_nf、10 % clean。
  - 约 600 房 × 3 次抽样，在租约前用 CPU 生成：轨迹每房只算一次，每次抽样约 25 s。
  - TEST 永不生成。
  - VAL / fresh 的输入在训练结束后由导出器用 E1 的种子 1、2 生成（公共随机数），并断言 V3 地图能逐值复现 E1 的 K0 读数。
- **租约**：2 个，训练种子 342101 / 342202 各一个。每个 ≤ 7,200 s，其中训练 ≤ 6,000 s，其余给推理。计分在 CPU 上用冻结函数完成。
- **面板**：VAL cam_nf 主判（24 房 × 噪声种子 1、2）。cam 与 fresh 只报告；fresh 符号相反时降为 ambiguous。
- **对照**：
  - B4：E1 已有，.852 / .839。
  - B6：计数标定表，两维 (n_hit, n_miss) × 高度带，零学习。
  - B5 凸包：取 E1 cam 档的 truepose 读数，即 cam_nf 地图。
- **判据**：2 个训练种子 × 2 个噪声种子，4 格都要满足。

| 档 | 条件 |
|---|---|
| 杠杆 | R8 家具 − max(B4, B6) ≥ +3 pp，且 K0 家具 − B6 ≥ +5 pp，且保护项与校准全过 |
| 不够 | 任一训练种子 R8 − B6 < +1 pp → 停掉学习去噪，交付 B6 |
| ambiguous | 其余 |

- **保护项**：FPR ≤ B4 + 0.3 pp；空闲召回 ≥ B4；R8 表面 ≥ B4 − 0.5 pp；clean 档家具与空闲召回都 ≥ .99。
- **校准**（判决条件，只测不调）：
  - 按 k = 1…≥ 5 分层：单机 e 在 k = 1 时斜率 ∈ [.85, 1.15]；读出后各层斜率 ∈ [.8, 1.25]，ECE ≤ .02。
  - w ≡ 1 时，若 k ≥ 3 的斜率 < .5（B6 是 .61–.64），判为"学习先验被重复计数"，杠杆降为 ambiguous。
- **字节**：判决按无损传输，字节只报告。另报 3×S0 和 6×S0 两个预算下与 B5 凸包的比较；B5 在这两点是 .61 / .59 和 .72 / .71（s1 / s2）。
- **出结果前的预测**：E3 − B6，R8 +1 到 +4 pp；判杠杆的概率约 .3。

**对"全网 ≤ 3 × S0"的评估：不宜作判决门槛。** 理由有三：
1. 经典 B5 在 3×S0（18.2 KB）只有 .61 / .59，比无压缩的 .85 低约 24 pp。
2. 就算去噪后的图恰好等于干净三态图，用 ctx 中继也约需 28 KB（D8-38 R-B 的估计），即 4.6×S0。只有光线投射式的结构语言能逼近 S0，而它不携带分级证据。
3. 设成门槛会把"去噪"和"压缩"两个变量绑在一起，违反单变量。

建议把它留作次级读数；压缩归 E2 / E0 线。
