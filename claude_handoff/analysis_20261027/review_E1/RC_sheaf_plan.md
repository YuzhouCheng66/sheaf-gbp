## 2. 底线：学习的证据 stalk 怎样仍是 sheaf-GBP

### 2.1 能量与"先验只计一次"

**stalk 的定义。** 智能体 i 的证据 stalk 是 e_i = Q(f_θ(z_i)) ∈ ℤ^V：
- 它是相对公共先验的 log-odds 增量，即似然，不是后验；
- 量化 Q 只在源端做一次；
- 硬掩码：v 不在 i 的触及集 τ_i 内时，e_i(v) = 0（断言）。

**能量。** 给定位姿时，负对数后验对应 b(v) = ℓ0(v) + Σ_i e_i(v)。

**GBP 与单调量。**
- 消息 m_{i→j} = e_i + Σ_{k∈N(i)∖j} m_{k→i}；信念 b_i = ℓ0 + e_i + Σ_k m_{k→i}。
- 在森林上，收集—分发两遍即得到精确 BP（Bethe 自由能 = Gibbs 自由能）。
- 单调量是来源亏缺 Φ = Σ_i |C(i) ∖ prov_i|，即每个节点所在连通块中还没进入它信念的来源数。Φ 每遍严格下降，两遍归零。来源位图已在 `g4_noise_panels` 中断言。

**先验只计一次。**
- ℓ0 是 TRAIN 上按高度带拟合的常数，不进入任何 stalk 或消息，只在读出端加一次。
- 学习的结构先验 p_φ 也只在读出端用一次：x̂ = argmin_x [−log p_φ(x) − Σ_v x_v b(v)]，可以用摊销网络 D_φ(b) 实现。读出端只读 b_i；K0 读 ℓ0 + e_i。

**训练方法：穿过求和来训练。**
- 损失为 BCE(y, σ(ℓ0 + Σ_{i∈S} f_θ(z_i)))，S 是随机抽取的智能体子集，|S| 取 1–8。
- 这样 f_θ 被迫学成"相加后仍校准"的似然；⊕ 始终是固定的整数求和。

### 2.2 条件独立的检验

只在 cam_nf 上判（真机间位姿，否则错位会混进相关性），cam 档只报告。按房子做 bootstrap。

**T1 校准斜率比 κ。** 在每个重数 m（1–4、≥ 5）内做逻辑回归：y_v ~ σ(a_m + β_m · Σ_i e_i(v))。
- 证据独立且校准时，β_m 应与 m 无关。
- 重复计数会使 β_m 随 m 下降。
- κ = β_{≥5} / β_1。保护条件：κ ≥ 0.8，且 κ ≥ κ_V3 − 0.1（V3 本身未校准，所以必须以它为基线）。

**T2 成对残差相关 ρ̂。** 对同时观测到 v 的两台机器 i、j，定义 r_i = e_i(v) − μ(y_v, 高度带)，计算 Corr(r_i, r_j)。保护条件：ρ̂ − ρ̂_V3 ≤ 0.05。

**单元测试。**
- 加入一个零观测的智能体，所有信念逐位不变。
- 同一个 stalk 发两次，来源断言必须拒绝。

**可直接利用的事实（E1 cam_nf）。** 36–40 % 的家具体素只被 1 台机器看到，这一层 F1 只有 .79–.80。在 m = 1 层，源端去噪和读出端先验等价，没有重复计数风险。所以必须按 m 报告增益：如果增益集中在 m ≥ 2，同时 κ 下降，就怀疑是重复计数。

### 2.3 位姿 stalk 与证据 stalk 联合

**两层 sheaf。**
- 底层：位姿 sheaf，限制映射是相对 SE(2)。
- 上层：地图 sheaf，限制映射 ρ_Δ 由位姿参数化。

**联合目标。** J(Δ, b) = E_pose(Δ) + Φ(b; Δ)。每一轮做三步：
1. 在当前 Δ^k 下，从原始观测重新积分得到 stalk，再收集—分发，使 Φ = 0。
2. 从根出发按广度优先逐边做位姿步。边因子只用这条边两侧排除回传的消息 A_e、B_e（两侧来源不相交，即 E4b 的 E_msg），只接受让全局 E_pose 下降的步（断言）。
3. 进入下一轮。

E_pose 只依赖 Δ，因为面元来自各机自己的证据，只随 Δ 平移旋转。所以在每一轮结束时，J 不增，这就是块坐标下降。轮内位姿刚更新、信念还没重算时，Φ 会暂时大于 0，因此**只能声称"每轮结束时下降"**。

E3 中的配准面元固定取自 V3 证据，不取自学习 stalk，保证 E3 是单变量；学习配准特征属于 G5-B。

### 2.4 离开底线的风险点

1. 源端输出后验，或在触及集之外输出非零值（把补全写进了 stalk）。
2. 读出端读的是消息或各机的 stalk，而不是 b；或者 ⊕ 被注意力等学习聚合替代。
3. 逐跳量化或重编码学习 stalk。
4. 位姿步用包含本子树证据的完整信念去配准（自匹配）。
5. 位姿更新后对已融合的信念重采样，造成重复计数。必须从 stalk 重算。
6. 对学习 stalk 做"推"式最近邻旋转重采样，两个源体素被加到同一个目标体素上。应改用"拉"式重采样，或者先在公共坐标系重新积分，再过网络。
