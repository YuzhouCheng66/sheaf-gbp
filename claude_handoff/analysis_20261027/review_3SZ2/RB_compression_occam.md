# R-B 审查：压缩率与奥卡姆剃刀（3S-Z2 之后）

R-B，2026-10-27 04:18 UTC 起笔（`date -u`）。依据：D8-35/36/37、`synthesis_C1.md`、`synthesis_C2.md`、文献报告、A01/A03/A10 探针、G4-E0 冒烟日志。本机 CPU 单进程跑了三个小脚本（`probes_RB/`）。没用 GPU，没碰 uk-linux，没改别人的文件，没做 git。标注：【实测】= 材料里的数或本人重跑的数；【估计】= 推算；【构造】= 由协议直接算出的定值。

## 0. 结论

1. **3S-Z2 改走诚实线路后，字节和无损 ctx 中继持平。** 每条自己地图约 1.1 KB，每房一次融合约 25 KB【估计，区间 13–32 KB】。无损 ctx 中继是 28 KB，S0 是 6.5 KB，所以 3S-Z2 是 S0 的 3.9 倍，家具却只有 .68。坐标阶梯从 32 到 64：诚实字节 ×3.6，家具 +9 pp。这一步在离开前沿，不是在靠近。
2. **有损码比它要近似的无损内容还贵。** 64×64 下，每个有证据的竖柱码要付约 13.6 bit；同一竖柱的无损内容（S0）只要约 3.0 bit，码贵 4.5 倍。32×32 时这个倍数是 1.3。可见性占了码的比特，3S-Z2 上更严重。
3. **奥卡姆：主推架构可以收成"四个一"。** 一种状态：整数 log-odds，干净档是 ±∞ 的特例。一个算子：森林上带排除回传的求和，用收集—分发调度。一种线路语言：盒 token。一个学习模型：条件先验 p_θ，同时当熵模型和 MDL 去噪正则。位姿 stalk 只在有机间误差的面板上启用。可删或可并的有 6 件：平面 / 全局 stalk、max 算子、同步 8 轮调度、光线序残差语言、单独的去噪网络与 MeanFlow 提议器、潜码 stalk。
4. **下一个 GPU 实验做 E2，1 个租约。** 在同一 W3 token 流上，比"学习先验"和"用同一份数据重拟合的手写计数先验"。两种子都省 ≥ 10 % 算杠杆，≥ 15 % 算强杠杆；每条消息带 1 bit 逃逸位。必须等 G4-E0 全量过了判据 (i)、定下线路语言后再发射。
5. **"几十倍"只对 gzip 洪泛成立，而且要拆成协议 × 编码。** 相对最强无损，全保真下至多约 1.7 倍（摘要句见 §4）。

## 1. 3S-Z2 的诚实字节（问题 1）

**算法**（同 A01 / C1 表 A）：
- 只发有证据的 stalk。键用覆盖率代理：精度为 0 当且仅当无观测，所以 stalk 计数是精确的。
- 每条消息 2 B 头，加地址：取枚举界和 2-D 上下文码中较小的那个。
- 载荷按 3S-X 实测的边际熵 13.63 bit/stalk 计。3S-Z2 自己的码熵没有测（本机没有检查点），所以 3S-Z2 的字节全部是【估计】。

**新增的收集—分发（CD）**：上行发全部有证据的 stalk；下行只发胜过对方上行消息的 stalk。在 6 房 × 8 机上，CD 的信念逐 stalk 等于同步收敛的信念（断言通过）。校准：同一脚本在 32×32、10 bit/stalk 下得 5.7 KB/房（均值），与 A10 报的"约 5.7 KB"一致；池化中位复现了 A01 的 1,146 / 2,312 B。

**读法：**

- **倍数。** 3S-Z2 诚实 CD 相对 S0：每条 4.6 倍，每房 3.9 倍。相对 ctx 中继：每条 0.83，每房 1.00（均值比均值）。相对 gzip 中继 0.43–0.48。相对 gzip 洪泛只省 5.9 倍。
- **区间 13–32 KB 的来源。** 下界是再量化到 4+4，F1 没测。上界是不做支配剪枝（14 × 2,312）。支配剪枝要知道每个 stalk 谁胜出，这里用覆盖率代理；它和学习键只在 37–58 % 的争夺块里选出同一个胜者（分析者 A）。这是整张表最大的不确定项。
- **3S-Z2 从定长到诚实 CD 一共省 36.6 倍。** 拆开是：停止重发 8 × 稀疏加支配 4.0 × 熵编码 1.14。这 36 倍任何编码都拿得到，不能算成学习的功劳。
- **每竖柱比特。** 64×64 下，K0 中位有 658 个有证据的竖柱，S0 只要 248 B × 8 / 658 ≈ 3.0 bit；32×32 下是 10.7 bit。码的载荷固定在 13.6 bit，不随网格变化。所以网格每细一级，码与无损内容之比就从 1.3 倍涨到 4.5 倍。

## 2. 奥卡姆：逐件问"去掉它会损失什么"（问题 2）

| 部件（D8-36） | 去掉或合并的代价（证据） | 裁决 |
|---|---|---|
| 干净档 {0, ∞} 三态与噪声档整数 log-odds 两种状态 | **无代价。** 干净档就是 ℓ ∈ {−∞, 0, +∞}：<br>• 一致性（C1 F3）保证不会出现 +∞ + −∞；<br>• 树上排除回传让每个来源只计一次，不需要幂等，不动点就是 join（A04 角点命题；C1 R8 并集 48/48）。<br>实现：int16，L∞ = 1,024 > 8 机 × 15。消息内部不截断（截断破坏结合律），只在判决时截断 | **合并** |
| max / join 与求和两种融合算子 | 只损失环图上的幂等，而无线图是森林。噪声下求和比 max 的家具高约 13 pp（C1 第二种子 .909 对 .780；A10 .918 对 .788） | **合并为森林求和** |
| 同步 8 轮与收集—分发两种调度 | 只损失"任意时刻都有部分信念"。字节：3S-Z2 从 40.2 降到 25.1 KB；E0 冒烟 W3 的 SYNC-c 7.3 KB 对 CD-c 4.4 KB | **默认 CD** |
| 平面列 stalk、全局 stalk（作为状态） | **无代价**：它们是体素证据的确定性函数 | **删** |
| 平面层作为线路语言 | 约 5 % 字节：A03 p3 无标签纯盒 212 B 对平面 + 盒 201 B（K0 中位，24 房） | **并入盒 token**：墙柱写成 dz = 墙高的盒，加 1 个类型位，这 5 % 交给 p_θ 收回 |
| 光线序残差语言 | E0 的 W3 已改成"盒覆盖全部命中 + 体素索引残差（几乎总为空）"。光线序单独做唯一语言更贵：A01 在同 48 张图上配对 281 B 对 248 B（只有 4 % 的图更便宜）；E0 冒烟 W2 592 B 对 W3 188 B | **删**；残差只当逃逸 |
| 学习先验 | 干净世界里学习对码率唯一能起作用的地方，上限 S0/DL = 1.67（自己）/ 1.43（并集） | **留** |
| 单独的去噪结构编码器、MeanFlow / consistency 提议器 | 去噪就是 argmin_盒 [bits(盒 \| p_θ) + bits(证据 \| 盒)]，用同一个 p_θ 做 MDL 正则即可。少步模型不给似然（文献），独立出来只省编码时间 | **并入 p_θ**；只有速度不够时再加提议器 |
| 编码端不关心区补全 | 就是 MDL 拟合在 [O, ¬F] 里挑最便宜的一致世界 | **并入 MDL** |
| 位姿 stalk（SE(2) × ℝ 高斯，GN 配准） | 干净档里它只是 float32 载荷（Λ = ∞），不起作用。有机间误差时删不得：5 cm / 1° 让 R8 家具掉 16 pp，任何编解码器都救不回 | **留，只在有机间误差的面板上启用** |
| 潜码超先验 stalk S5、LF-Sheaf、Prim-Sheaf | 现码当超先验能省 62 B，自己却要 177–330 B（A01） | **移出主线**，作为备选写进文档 |

### 最小系统（暂名 ℓ-Sheaf）

- **状态**：每个公共体素一个整数 log-odds（干净档取 ±∞）；每个智能体一个位姿（信息形式，干净档 Λ = ∞）。这就是"中间 sheaf 向量"。
- **GBP**：森林上的排除回传求和，收集—分发调度。能量 Φ = 尚未吸收的证据源数，加上 E_pose；Φ 单调不增，2 × 树深轮内归零。
- **线路**：只有一种语言——盒 token（含墙柱类型位；噪声档另带 2–4 bit 精度档），加体素索引的逃逸残差和 float32 位姿。
- **学习**：一个条件先验 p_θ(token | 接收方已知)，一模两用：当熵模型管码率，当 MDL 去噪正则管精度。
- **解码**：栅格化 + 光线投射，再按 ℓ 的符号（干净档）或 F\*/2 阈值（噪声档）判决。

它守住了底线：向量 stalk、排除回传消息、能写出来且单调下降的能量。部件比 D8-36 少 6 件。

学习价值在加固面板上正好落在两处：
1. 同一个 p_θ 带来的码率增益（E2）；
2. MDL 去噪相对 B5 在等字节下的家具增益。先在 cam_nf 面板上测，不混入配准。

配准之后单独加（E4，经典版 0 个租约）。

## 3. 下一个 GPU 实验：E2 预注册草案（问题 3）

**问题。** 在同一个几何码上，学习先验比手写上下文编码还能省多少？

**变量与两臂。**
- **单变量**：W3 token 流的概率模型。token 流包括平面栅格符号、盒字段和残差头。以下全部冻结：token 顺序、range coder（沿用 E0：48-bit 窗口，2^20 整数频率表，每个符号频数 ≥ 1）、位姿（float32 均匀模型，不学习）、协议（CD，c 档以腔为条件）、解码。
- **臂 L**：盒 token 用约 5 M 参数的因果 Transformer，交叉注意力读接收方已知的 S 和已解码的平面；平面栅格用固定两遍棋盘分组的条件卷积。文献表明，固定顺序、组内并行的离散分解能给出精确码长。概率量化成同一套整数频率表。
- **对照 C**：E0 的手写计数表，**在与 L 完全相同的 TRAIN 集上重拟合**。上下文集在 E0 现有的一套和一套加大的上下文之间，按 TRAIN 留出集选一次，之后冻结（A07 见过上下文稀释）。
- **逃逸位**：每条消息先编 1 bit（p = ½），在 L 和 C 中取较短者。主指标用含逃逸位的字节；同时报纯 L 的字节，以及逃逸选中 L 的比例。

**数据、种子与面板。**
- **数据**：TRAIN 4,708 套（与 3S-S、3S-Y 同一集合），用 E0 的编码器在 CPU 上生成 token。冒烟时 W3 约 9 s/房，6 个进程约 2–4 h，0 个租约。
- **种子与面板**：342101 / 342202（初始化与数据顺序）。VAL-24 判决，fresh-24 复核。

**判据**（两种子都要满足；VAL 判决，fresh 不得给出相反结论）：
- **杠杆**：自己地图中位字节（含位姿、头、逃逸位）≤ 0.90 × C，且 CD-c 每房中位 ≤ 0.90 × C。两项都 ≤ 0.85 × C 时记为强杠杆。
- **无价值**：两个种子两项都 ≥ 0.95 × C → 干净世界里学习对码率也没有贡献，学习只剩噪声面板。
- **其余**判 ambiguous。

**保护**（任何一项不过 → INCONCLUSIVE）：
- GPU 编码、CPU 解码，全部消息逐体素精确往返；
- L 的字节不得低于 0.9 × DL（127 B，24 房），低于这个数就先查泄漏或 bug。

**只报告：**
- 几何部分（去掉位姿与头）的比值；
- 按消息类型（K0 / 上行 / 下行 / 腔条件）分开的结果；
- 留出类别面板和家具偏航面板上的 L / C（若生成器 v440 已就绪）——增益不到 VAL 的一半就标为"生成器记忆"；
- 单核 CPU 的解码时间。

**出结果前的预测（R-B）**：自己地图省 8–18 %，CD-c 省 12–25 %。理由是接收方已知内容是最强的上下文，文献里条件编码的同类增益是 20–26 %（DCVC）。若不过，最可能的原因是 200 B 的消息里几何符号太少，被位姿和头稀释。

**租约**：1 个，两种子顺序跑。

**对 G4-E0 的依赖：**
1. E0 判据 (i) 必须通过：真 range coder 往返全部逐体素精确。否则就没有一个验证过的编码器可以接学习先验。
2. E0 决定线路语言。E2 学的是 E0 最优臂的 token 流（冒烟结果是 W3）。若全量结果中 W2 与 W3 相差 < 10 %，按奥卡姆仍选 W3，因为噪声档要用盒做 MDL。
3. E0 的 token 顺序、range coder 和计数表代码原样复用。E2 只换概率模型和训练数据量，对照也走同一条代码路径。
4. E0 判据 (iii)（两个先验半集的字节差 ≤ 5 %）若不过，说明 35 房的计数表缺数据。此时 E2 的对照必须在 4,708 房上重拟合，否则会把"数据量"的增益算到"学习"头上。
5. E0 的比特去向会给出位姿与头的占比。占比若 > 30 %，总字节省 10 % 就相当于几何部分省 ≥ 14 %，结果里要写明。

## 4. 能写进摘要的一句话（问题 4）

> 在无噪声的合成楼层上，sheaf-GBP 网内融合配合不学习的精确结构码，以逐体素无损的质量（四项 F1 与空闲召回均为 1），把一次 8 机融合的全网流量降到 gzip 洪泛的约 1/24（网内融合 2.9 倍 × 编码 8.5 倍）；而相对同一内容的最强无损编码，按描述长度估计，任何编解码器（包括学习先验）在全保真下至多再省约 1.7 倍。

E2 出结果后，在句末补上"学习先验实测再省 X %"。
