## 0. 结论

1. **坐标阶梯不是"每级 +9 pp"，而是每级增量减半。** 两周期配方下，家具增量从 +17.8 pp 降到 +9.1 pp。机理是：家具 F1 由码的水平量子（按体素计）决定，字节只通过量子进来。下一级 128×128×1（32 KB）【估】家具约 .73（.72–.75，乐观 .77），K0 fresh 约 .956。追不上 S0（1.000）。
2. **干净世界的精度问题已经结案。** S0 在天花板上，学习型设计最多打平。能打平的只有一类：学习不碰计分重建，并保留精确残差通道。所以在干净世界里，学习只服务于第二优先级（码率）。
3. **精度的战场在加固面板。**
   - R8 上最大的剩余损失是配准，应先用经典方法拿下。
   - **学习最可能带来最大家具增益的一环是编码端去噪**，也就是把去噪后的证据当作 stalk，再做森林求和 GBP：K0 余量 25–31 pp，经典去噪在这里一点没帮上。
   - 融合规则的收益最大（+14–19 pp），但它是解析的，没有可学的东西。
   - 先验补全按度量定义几乎不得分。
4. **GPU 只做一件事**：G5-A，学习去噪证据 stalk，2 个租约，前提是 G4-E1 通过。G5-B 是学习配准，2 个租约，只在经典配准（E4，CPU）失败时才做。
5. **旧路线（第三周期、128×128×1、4+4 部署）一律不做。**

## 1. 坐标阶梯说明了什么，再上一级能到多少

**阶梯数据**：R8 家具区 F1，VAL-24，两种子均值；q 是码竖柱的水平宽度（体素）。

| 级 | q | 字节/条 | 两周期 | 16k 次更新 |
|---|---|---|---|---|
| 16×16×1 | 8 | 512 | .390（v420）【实测】 | .305 |
| 32×32×1 | 4 | 2,048 | .568（v420）/ .588（校准） | .425 |
| 64×64×1 | 2 | 8,192 | **.679**（校准） | .503 |
| 128×128×1 | 1 | 32,768 | 【估】**.73**（.72–.75，乐观 .77） | — |

**这个规律说明了四件事**：

1. **收益递减，不是线性。**
   - 两周期的增量是 +17.8 → +9.1 pp，16k 的增量是 +12.0 → +7.8 pp。
   - 换成"离 1 的差距"看，每级只关掉 29 % → 22 %，差距比从 .71 升到 .78【算】。
   - 若拟合成 差距 ∝ 字节^(−α)，α 从 .25 降到 .18【算】。
2. **约束是按体素计的水平量子，字节只通过它起作用。**
   - 只加比特无效（D8-24 L2）。
   - 增益与房子尺寸无关（D8-34）。原因是量子按体素计，与房子有多少米无关。
   - A06 在出结果前预测 [.62, .72]，实测 .679，命中。
3. **约束正在换人。**
   - q = 4 时，学习码比同量子的完美 4×4×1 降采样还高 20 %（.588 对 .488）。
   - q = 2 时，学习码只到完美 2×2×1 降采样的 88 %（.679 对 .770）【算】。
   - 量子变细之后，开始卡住的是"一个 8 bit 标量要描述 2×2×32 = 128 个体素"的容量和解码器。到 q = 1 时，降采样天花板平凡地等于 1，可学习码仍然只有一个标量对应 32 个体素。
4. **字节效率按级恶化。**
   - 每多 1 pp 家具，阶梯的边际成本是 87 → 550 → 约 5,000 B【算】。
   - S0 有损曲线是 1.4–27 B/pp（K0 自己地图口径），在可比的家具 .86–.99 段是 4.5–11 B/pp。阶梯后两级比它贵约 50–1,100 倍。

**128×128×1 的外推**（三种模型都由实测增量外推）：

| 指标 | 外推值 | 依据 |
|---|---|---|
| 家具 | .726 / .728 / .738 | 增量按同比例减半 / 差距比按趋势升到 .85 / 套用 16k 的增量比 |
| 家具，乐观 | .750 / .773 | 差距比保持 .78 / 退回到 .71 |
| R8 表面（VAL） | .937–.944 | |
| K0 fresh | .956–.960 | |
| K0 VAL | .950–.954 | |

**能否追上 S0：不能。** 32 KB 是原始 2 bit 栅格的 ¼，是自己地图 gzip 的 12 倍、S0 的 150 倍；按现协议全网 3.67 MB/房【算】。

即使到乐观的 .77，也只是追平约 1.2–1.3 KB 的完美 2×2×1 降采样（.770，D8-35 与 A06 两次实测），字节是它的 25–28 倍。按 α = .18–.25 外推：
- 阶梯到原始栅格大小（131 KB）时，家具也只有 .81–.84，而原始栅格本身无损传输就是 1。
- 要到家具 .99，需要 10¹⁰ B 以上【估】。

**阶梯在离开"压缩"区之前到不了精确。**

## 2. 干净世界里谁能不输 S0，精度的真正战场在哪

### 2.1 干净世界：只能打平，打平的条件很窄

S0 已经在天花板上【实测，24 房】：四个 F1、空闲召回、三态准确率都是 1，前提是 float32 位姿（1 cm 取整就会错 326 个体素）。

"不输"只能是"打平"。打平的唯一办法是：学习不产生计分地图，精确性由往返断言和残差通道保证。符合条件的有：
- (a) S1：学习熵模型或先验；
- (b) 摊销编码器：提议盒子，渲染自检，失败的部分退回光线序残差；
- (c) M+ / S5 超先验潜码 stalk；
- (d) 带残差通道的同态潜码场。

它们的家具 F1 都是 1，学习的贡献只在字节。文献对强手写码的增益是 10–15 % 可信，31–35 % 偏乐观。

凡是让网络直接给计分图的设计，在精度上都严格输：3S 全系、RAYFIELD、W-Sheaf、生成采样（采样会让家具低 6–22 pp）。

- C1 第二噪声种子，6 房，按体素汇总，V2。

**学习的边际，逐环判断：**

| 环节 | 余量 | 学习的边际 |
|---|---|---|
| 融合规则 | 求和 − max_occ = +14–19 pp，单项最大 | 树上求和就是 channel filter，也就是精确 BP，在独立噪声下最优，没有可学的东西。由 E1 (c) 定 |
| 配准（机间 + 逐帧） | R8 上合计 17–20 pp，是 R8 最大的剩余项 | 本世界的墙是轴对齐平面，家具是盒子，误差只有 5 cm / 1°；经典的平面 / 盒地标加位姿 stalk 的 GN 预计能收回大部分（文献：CoAlign 在 0.6 m 噪声下仍有 .868）。学习只在经典失败时才有边际 |
| **编码端去噪** | K0 余量 25–31 pp；R8 cam_nf 余量 9–15 pp | 经典去噪 B5 不但没帮上，反而比 B4 低 2–4 pp（E1 审查），所以学习的边际约等于整个余量。增益应集中在少观测的体素：求和 F1 在 m = 1 时 .837，m ≥ 4 时 .986（C1）。文献也是同一规律：弱输入上细化收益大（+13 IoU），强输入小（+2.5） |
| 先验补全 | 按度量定义近乎 0 | 只在干净已知区计分。唯一得分的是已知区内的漏测空洞，去噪器顺带就补了；另有幻觉和抹掉 frontier 的风险 |

**判断**：学习最可能带来最大家具增益的是编码端去噪。【估】K0 +6–12 pp，R8 +2–5 pp。R8 最大的余量在配准，但应先由经典方法拿走。

**一项免费的精度**：截断积分（V3）比不截断（V2）在 cam_nf 上 K0 低 6.1 pp、R8 低 5.9 pp。代价是字节：V2 的 B4 中位 1.73 MB/房，V3 约 0.56 MB/房，约为 3.1 倍。这些数还没按 F\*/2 标定阈值，差距可能会缩小。精度第一时，噪声档不应默认用 OctoMap 的截断（它是为动态环境设计的）。建议 E1 至少把 V2 列为报告行。

**旁证**（跨面板，只作参考）：3S-Z2 用干净输入得到的 R8 家具 .679，低于"无损传噪声证据 + 求和"的地板：cam 档 .73–.78，cam_nf 档 .85–.91。

## 3. GPU 实验预注册草案

### G5-A：学习去噪证据 stalk（主推）

- **问题**：在噪声下，把学习去噪器的输出当作 sheaf stalk、用森林求和 GBP 交换，家具 F1（按干净真值）能否超过最强的经典证据？
- **单变量**：每个智能体 stalk 的内容。
  - 对照：ℓ_raw，即逐束 log-odds。判决用 V2，因为它在 E1 探针里处处 ≥ V3；V3（E1 正式的 B4）并列报告。
  - 臂：ℓ_θ = f_θ(本机 n_hit, n_miss) − ℓ_π。
    - f_θ 是 3D U-Net，参数量 ≤ 2 M。
    - 先验 ℓ_π 是公开常数，只在接收方加一次，即"后验除以先验"，防止 8 个智能体把先验重复计 8 次。
    - 输出量化到与 B4 相同的整数字母表。
- **固定不变**：
  - 森林排除回传求和；能量 Φ(t) = 未吸收来源数，逐轮断言不增，直径轮内归零。
  - 线路无损：字节只报告，不判。
  - 两臂各自在 TRAIN-24 上用同一流程标定区域 F\*/2 阈值。
  - 与 E1 共用公共随机数，房子、噪声逐项配对。
- **损失**：K0 家具加权 BCE + 穿过求和的 R8 BCE（树上不动点就是和，可以直接求导）+ 干净已知空闲 BCE。权重在 TRAIN 上定死。
- **训练数据**：TRAIN 上做 GPU 在线噪声仿真，参数用 cam_nf 档，与评估用的噪声种子不相交。
- **面板**：cam_nf 判决（排除配准）；cam 只报告，E4 有结果后加报"cam + E4 位姿"。VAL-24 判决，fresh-24 必须同号，TEST 封存。留出类别面板报告并作保护；若生成器 v440 就绪，加报偏航面板。
- **种子**：训练种子 342101 / 342202 × 噪声种子 1 / 2，共 4 格。
- **判据**（每一格都要满足）：

| 判决 | 条件 |
|---|---|
| 杠杆 | ΔK0 家具（本机坐标）≥ +5 pp，且 ΔR8 家具 ≥ +2 pp |
| 只对 K0 是杠杆 | ΔK0 ≥ +5，ΔR8 ∈ [−0.5, +2) |
| 不比对照好 | ΔK0 < +2 且 ΔR8 < +1 → 停学习去噪 |
| 更差 | 任一格 ΔR8 ≤ −1，或任一保护没过 |
| ambiguous | 其余 |

- **保护**：
  - 空闲召回 ≥ .95，且不低于对照 1 pp 以上；
  - 未知→已知 FPR ≤ 对照 + 0.3 pp；
  - R8 表面 ≥ 对照 − 0.5 pp；
  - 干净面板的家具 ≥ .99、空闲召回 ≥ .99（去噪器不得在无噪声时幻觉）；
  - 占家具体素 ≥ 2 % 的类别，没有一类掉超过 2 pp；
  - 留出类别面板不低于对照。
- **机制读数**（只报告）：增益随观测重数 m 下降；m ≥ 4 处 ΔR8 ≤ 1 pp。
- **出结果前的预测**：ΔK0 +6–12 pp，ΔR8 +2–5 pp；判为杠杆的概率约 .45，只对 K0 是杠杆约 .30。
- **租约**：2 个（每个种子 1 个，≤ 1.6 h）。预检实测步时；装不下就判 INCONCLUSIVE。

### G5-B：学习配准特征（有条件）

- **触发条件**：E4（经典位姿 stalk：平面 / 盒地标 + 二色阻尼 GN，只接受下降步，纯 CPU，尚待预注册）在 cam 档的任一噪声种子上，收回的 cam_nf − cam 差距不到 85 %。
- **单变量**：位姿残差的对应来源，经典地标对学习描述子。位姿层、证据、融合都不变。
- **判据**：4 格都要满足
  - 收回 ≥ 85 % 的差距，且比 E4 高 ≥ 3 pp；
  - E_pose 逐轮不增（断言）；
  - cam_nf 不低于 −0.5 pp。
- **租约**：2 个。E4 成功就不做；G5-A 的检查点改用 E4 的位姿在 CPU 上重评。

## 4. 旧路线：明确不做

1. **3S-Z2 第三周期：不做。**
   - 参照 3S-X：第二周期只多了 +1.7 pp，而且后半段走平（.874 → .877）；3S-Y 已证明数据量不是杠杆。
   - 【估】第三周期表面 +0.5–1 pp，家具 ≤ +2 pp，到 .69–.70。仍被 S0（219 B，1.0）和 2×2×1 降采样（约 1.2–1.3 KB，.770）同时支配。
   - 唯一的收益是让第二个种子的 K0 也过旧目标 .95。这个目标是在 S0 出现之前定的，只有存档价值。
2. **128×128×1：不做。** 外推见 §1：最好 .77，字节是降采样的 25–28 倍；要 4 个租约，还要用户重新批准 32 KB。三级阶梯已经足以写清"递减律"。
3. **4+4 部署预算：不做。**
   - 任何 4+4 配置都落在现有两级之间。
   - 部署问题本身已经不成立：干净世界的交付物是 S0，噪声世界的交付物是证据 sheaf。
   - 干净训练的稠密码从没见过噪声，它的瓶颈（干净输入下 .68）低于经典噪声地板。
4. **也不拿它当 G5-A 的骨干**：它的竖柱瓶颈，正是压住家具 F1 的那个东西。
5. **唯一的例外**：用户在 D8-36 第 3 条裁定"融合路径上必须有学习潜码 stalk"。即便如此，该用的载体也是 M+ / S5，或在加固面板上做 LF-Sheaf，而不是 3S 阶梯。

GPU 在 E1 出结果前闲着，对精度没有任何损失。这段时间应该用来完成 CPU 上的 E0、E1、E4 预注册，以及 TRAIN 噪声数据的准备。
