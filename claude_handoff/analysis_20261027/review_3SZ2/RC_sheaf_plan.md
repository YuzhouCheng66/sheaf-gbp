## 0. 结论

1. **新架构仍是 sheaf-GBP。** 在噪声档，它比现系统更接近本义：融合是真正的推断，位姿层第一次用上非恒等的限制映射。学习不在 ⊕ 里，而在证据的产生、码长、读出和配准因子里。离开底线最容易走的三条路：学习出来的消息更新；解码器读消息集合而不是信念；先验进入融合。
2. **四件事的默认：只加不删。** GPU 只花在四种答复下都有用的实验上；用户答复之前最多 3 个租约。
3. **排程。** 到明早 GPU 基本空着，这是对的：没有一个已审查、已预注册、又不依赖 E0/E1 的 GPU 实验，不该为了占卡去续训已被支配的 3S 点。第一个 GPU 实验是 E2（学习先验，1 个租约，只依赖 E0）；B6 可选（1 个租约，只报告）。精度方向今晚靠 CPU 做 E4 经典配准；E3 的代码要 1–1.5 天，最早明晚上 GPU。
4. **最大的三处风险：** B4 分母太大（约 500–560 KB/房，¼ B4 ≈ 23 倍 S0，几乎不约束字节）；源端学习去噪把先验重复计数；E4 计分的规范自由度。

## 1. 底线

### 1.1 可写进报告的表述

**新一代 EV/ESR-Sheaf 中的 sheaf-GBP。**

- **通信图和索引集。** 通信图 G 取无线电图的 Kruskal 森林。索引集是公共、有界的：I = 体素 128×128×32 ⊔ 平面列 128² ⊔ 全局高度 ⊔ 位姿槽（8 机 × 3 帧）。
- **stalk 是每个索引上的证据。**
  - 干净档：三元格 {⊥ < 空, ⊥ < 占}，等价于精度只取 0 或 ∞ 的饱和 log-odds。
  - 噪声档：整数 log-odds ℓ ∈ [−15, 15]，也就是指数族的自然参数，|ℓ| 就是精度。
  - 位姿槽：SE(2)×ℝ 切空间上的高斯信息对 (η, Λ)。
- **限制映射。**
  - 干净档体素层：在公共坐标系下取恒等。
  - 噪声档体素层：由位姿 stalk 参数化的重采样算子，把节点 i 的证据按估计位姿 T_i 搬到公共格上。
  - 位姿层：相对变换 T_i⁻¹T_j，在切空间线性化。这是本项目第一次出现非恒等的限制映射。
- **融合。**
  - 干净档：join。它幂等，在任意图上都精确。
  - 噪声档：自然参数相加。在树上带排除回传的相加就是 channel filter，等价于联结树上的精确 BP。
- **迭代。** 消息和信念分别是

  m_{u→v} = a_u ⊕ ⊕_{w∈N(u)∖v} m_{w→u}，b_v = a_v ⊕ ⊕_{u∈N(v)} m_{u→v}。

  这与现行的 `rollout_max` 是同一个式子，按收集—分发顺序调度。
- **能量。**
  - 干净档：Tarski 秩亏 E_I。在精度只取 {0, ∞} 的角点上，sum-GBP、CI 和 join 的不动点相同。
  - 噪声档：未吸收的证据源数 Φ，加上位姿图能量 E_pose。E_pose 用二色阻尼 Gauss–Newton 求解，只接受让能量下降的步。
  - 这几项能量每轮都不增。E_I 和 Φ 在直径轮数内归零；不动点在树上就是"逐束观测独立"假设下的精确后验。
- **学习在哪里。**
  1. 熵模型 p_θ(消息 | 接收方已知)。它只改码长，往返断言保证地图不变。
  2. 证据的产生与读出。源端编码器决定 a_v 取什么值、用多少比特说出来；输出必须是相对公共先验的似然证据，没有观测的地方为 ⊥。读出端用一次结构先验，并按 F\*/2 判决。
  3. 配准特征。它为 E_pose 提供相对位姿因子 (Ẑ_ij, Σ_ij)。
  4. 可选：同态学习潜码 stalk（max-pool 加单调量化，使并集的码恰好等于各自码的 join），作为超先验随消息交换。

  一句话：学习决定"带什么证据、说得多短、怎么读出来"，不决定"证据怎么合并"。合并由代数和单调下降的能量保证。

### 1.2 文献给出的两条边界

- **求和的正当性有前提。** 树上求和等于精确 BP，前提有三条：证据条件独立；公共先验只计一次；只在森林上做（环上要用来源位图或 CI）。
- **格值 sheaf 只适合干净档。**
  - 格值 sheaf 要求位姿精确。有配准误差时，join/max 会把错位的占据当成"更确定"保留下来，形成双层表面。所以噪声档的体素层和位姿层都必须是向量值（二次能量）的 sheaf。
  - E1 审查探针测得 sum − max_occ 在 +10 到 +18 pp 之间，与此一致。
  - A04 的 R3（对角闭包）只约束大体素 stalk；位姿 stalk 很小，用满 3×3 信息矩阵是标准的 GBP 做法（Robot Web）。

### 1.3 怎样做就离开了底线

| 做法 | 为什么离开底线 | 守住底线的替代 |
|---|---|---|
| 用 GNN 或注意力替换 ⊕，或在中继里"学习地重编码信念" | 失去交换律和结合律，没有能量，就不再是 GBP | ⊕ 只用 join 或求和；学习只放在 a_v 的产生和读出上 |
| 解码器逐条读收到的消息，或 K0 用到别人的码 | 违反 R5，融合被网络替代 | 解码器只读 b_v 和公共信息 |
| 中继原样转发各机的 token 列表 | 索引集随 \|V\| 增长，违反 R1；这是路由，不是融合，字节 ×2.6 | 中继先在证据上做 join 或求和，再规范地重编码 |
| 先验进入融合：补全写进 stalk、精度键被补全抬高、源端把后验相加 | 违反 R5；8 机就重复计数 8 次 | 源端发似然；补全只放在不可见区或可视化层；先验只在读出端用一次 |
| 学习潜码用求和融合 | 重叠观测会被重复计数，A04 估计最多高估约 2.9 倍 | 潜码只用同态码加 join，或按源记账 |
| 能量只声称、不断言：中继逐跳有损重拟合、逐跳重量化、在环上求和 | 全局截面被破坏（A04 P10），下降不再成立 | 有损只在源端做一次；整数和精确；断言通信图是森林；每轮记录并断言 E_I、Φ、E_pose 不增 |
| 用网络直接输出"对齐后的地图"，不估位姿 | 没有位姿 stalk，也没有能量 | 学习只提供相对位姿因子，由位姿层做下降 |
| 用采样直接生成计分地图 | 代数上没问题，但读出不是 F1 最优（家具低 6–22 pp）；样本一旦写回证据，就违反 R5 | 生成器只给概率，不给样本 |

| 情况 | 做法 |

| **E1 触发止损**（B4 家具 ≥ .92，或字节 < 1.3×） | 取消 E3、E5b、B6。E2 照跑，它与 E1 无关，而且这时成了学习唯一可能的价值。E5a 只在 E2 < 0.95× 时跑。E4 经典版仍然跑（只要 (d) ≥ 10 pp），因为配准是 sheaf 的非平凡部分，不依赖学习空间。之后 GPU 留空。交付物：S0 + 精确格层 + 噪声档求和 + 经典配准。建议在真实扫描面板上复核止损，排除"合成世界太干净"的假象 |
| E1 判 AMBIGUOUS 或 INCOMPLETE | 不发射 E3。先做一次审查，必要时补跑。E2 和 E4 照常 |
| E0 (i) 不过（是 bug） | E2 不发射（它依赖往返编码器），只剩 B6 |
| E0 (ii) 不过 | E2 照跑，对照换成 E0 实测的最优静态臂，字节目标上调 |

按目前的审查探针（4 房、1 个种子），V3 积分器下 B4 的家具为 .734，B5 比它低 2–4 pp。止损的可能性很低，大概率会判"有学习空间"。

### 3.5 链脚本必须照抄 3S-Z2 的写法

- sha 钉住所有脚本、数据模块和缓存清单；`mkdir` 锁；已有历史一律不覆盖；`busy()` 检查任何 GPU 进程、训练器和其他链，保证 SOLO。
- 先预检；装不下就记 INCONCLUSIVE，不发射。租约 JSON 含 7,200 s（训练截止 +6,600 s，总截止 +7,150 s），每个运行用 `timeout -k 30 $((DT-now))` 包住，不续租；第二周期须事先预注册，在新租约里 `--init-from` 热启动。
- 分析块从文件直接算判决；缺种子或房子不全记 INCOMPLETE。E2 链的门控是 E0 `analysis` 的 (i) 通过。

## 4. 风险：看起来守住了，实际没守住

| 风险 | 会怎样骗过我们 | 预注册的检测 |
|---|---|---|
| 先验重复计数、相关证据 | 源端去噪输出的是后验，8 机一求和，先验被算 8 次；同机 3 帧共享机间误差，独立求和过度自信 | 断言没有观测的节点发 ⊥。按观测重数 m 分层画可靠性：m ≥ 3 层的预测 log-odds 对经验 log-odds 的斜率必须在 [0.8, 1.25] 内。公共先验用 posterior ÷ prior 去掉；同时报 cam 与 cam_nf |
| 量化或有损累积 | 中继逐跳重拟合或重量化，误差沿深度（6–7 跳）累积；环上会重复计数 | 有损只在源端做一次；断言森林、来源位掩码互不相交；报告每跳与精确整数和的偏差 |
| 空闲召回漏洞 | 四个 F1 都不给空闲计分；E1 里 FPR 在并集已知下恒为 0，这条保护形同虚设 | 报空闲召回（≥ .95，且不低于对照 −1 pp）、"真值空闲而判占据"的比例、三态准确率 |
| 分母 | B4 约 500–560 KB/房，其中 85–90 % 是幅值流；"相对无损噪声图 N 倍"的大部分来自不传幅值 | R_net 作主指标；同时报相对干净 S0、相对 B5 在等 F1 下的 BD-rate、协议 × 表示 × 编码三个因子；另报单条消息、每机、每次更新的字节；全部计入位姿、头部、escape 和精度档 |
| 码长不是真码长 | 把熵估计当字节；B4 现在用的是自适应码长，没有做往返 | 学习臂必须用真实区间编码往返，PMF 整数化；声明模型参数规模（不计入字节） |
| 对照数据不匹配 | 学习模型用 1,000 多套房训练，计数表只用 35 套 | 计数表在同一批数据上重拟合 |
| 学会了生成器 | 程序化世界里在同分布上拿到虚高的增益 | fresh 面板差 ≤ 0.05；以后加留出类别面板和真实扫描 |
| 规范自由度 | 每台机器都有机间误差，全局偏移不可观测；E4 的收益里可能混进了白送的对齐 | 所有臂都报"原样"和"一次全局对齐"两行，判决口径事先写定 |
| 挑选面板、种子、积分器 | 只报对自己有利的那个 | VAL 判、fresh 复核、TEST 封存；2 训练种子 × 2 噪声种子都要过；积分器 V3 判决、V1 必报；F\*/2 在 TRAIN 上标定 |
| K0 偷看 | 噪声档的 K0 读了融合后的信念 | K0 只从自己的码解码，用断言保证 |
