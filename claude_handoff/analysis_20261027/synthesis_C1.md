## 0. 结论

1. **这个合成世界的可见性和几何都已被"解完"。**
   - 自己的地图，等于用它的 3 个位姿、只穿过它观测到的占据体素做首次命中光线投射（◎）；R8 并集同理（◎）。未观测区是 don't-care（●）。
   - 因此一个不学习的结构化精确码（平面图 + 一致集内的实心盒 + float32 位姿，光线投射解码），在 24 个 VAL 房子上实测：自己地图 219 B，一条收敛消息 401 B，每房一次融合 6.1 KB；四个 F1 和空闲召回为 1（无标签切分时 190/192 张逐体素精确，其余 2 张 F1 ≥ .9995）。
   - 现行学习码是 2,048 B/条、229 KB/房、家具 .58，在两条轴上同时被它支配。
2. **家具差是表示问题。** 家具区 F1 是零容差的薄壳 F1；我们的 .52–.58，正好等于"每件家具水平错一格"的水平（.52/.57）。码的水平量子是"一根竖柱一个标量"，坐标阶梯只是把量子缩小（3S-Z2 预计 .62–.72 @ 8 KB）。
3. **压缩率："几十倍"要看对谁。**
   - 相对原始栅格"几百倍"成立，但没有信息量。
   - 相对 gzip 洪泛的网络总账"几十倍"成立：精确码 27×【实测】= 中继 2.9× × 编码 9.6×，必须拆开报告。
   - **相对诚实的最强无损"几十倍"，在干净世界、全保真下信息论上不可能**：最多 1.7–2.7×；相对 ctx 也只有 11–17×。
   - 唯一能诚实地把"十几到几十倍"记在学习名下的场景，是噪声世界里相对"无损传输噪声图"。
4. **学习的价值。** 干净世界里，学习对 F1 的价值是 0，对码率 ≤ 1.3–2×。价值主张要改成：sheaf-GBP 是一个正确、流量最小的分布式融合协议；有噪声和配准误差时，它的融合变成真正的推断；学习提供先验、去噪和配准。评估必须换成加固面板（§3）。
5. **主推 EV-Sheaf（两层证据 sheaf）。**
   - stalk 停在公共体素证据上（干净档三态，噪声档整数 log-odds），外加位姿 stalk。
   - GBP 是森林上带排除回传的 join 或求和；位姿层是 SE(2) 高斯 sheaf。
   - 结构只活在线路语言里，由学习的生成式先验做算术编码，只发新息。
   - 预计：干净档自己地图 160–190 B，每房约 4–4.5 KB，F1 全为 1；噪声档目标 K0 家具 ≥ .85、R8 家具 ≥ .88–.90。
6. **备选 Prim-Sheaf（连续图元参数 sheaf）。** 把融合搬到带精度的连续几何参数上：码长不随噪声变长，天然是配准地标。风险是关联问题和工程量。
7. **第一个实验 E1**：纯 CPU，0 个租约，"精确核决赛"。在 fresh-24 上用真区间编码器往返，可直接证伪主推的干净档主张。
8. **投票。**
   - A03-A RAY-SHEAF 均分 19.1/20，第一，其余 9 份稿全都把它放进前三。
   - A07-D2"噪声世界"按分数只排第 17，却同样被其余 9 份稿放进前三。评分表只看干净基准，低估了它。

## 2. 对用户两个担心的直接回答

### 2.1 家具区 F1：为什么差，能做到多少

**误差解剖**（A06、A05 p3；3S-X + 校准规则，6 个演示房子，K0 / R8）：

- **度量本身**：家具区 F1 只在"既非楼板、也不在墙 ±1 格内"的体素上计，零容差；家具目标体素 80 % 在竖直侧面上。对完美目标各做一次扰动：

  | 对完美目标的扰动 | 家具区 F1（K0 / R8） |
  |---|---|
  | 每件家具整体水平挪一格 | .52 / .57 |
  | 水平加厚一格 | .63 |
  | 竖直加厚一格 | .82 |
  | 细部件全删 | .83 / .87 |
  | 完美的 2×2×1 降采样 | .76 / .77 |

  **我们的 .52 / .54，正好是"水平错一格"的水平。**
- **错在哪里**：召回 .48 / .45，精度 .77 / .74，漏检是虚构的 3.5–3.8 倍。
  - 漏检里 71 % / 82 % 是占据头判"空"，known 头否决只占 29 % / 18 %。
  - 虚构里 67–69 % 紧贴真家具一格，整件凭空虚构约 5 %。
- **不只是细部件**：大块家具（占家具体素的 73–75 %）召回也只有 .51 / .48；面落在码竖柱边上时召回 .33，只有顶面朝空闲时 .71；独立摆放 .29，靠墙 .58。
- **也不是解码器**：把我们的解码结果当边信息，精确地图只省约 100 B（A02 P4b）；家具区精确残差给预测时 249 B，不给 238 B（A10）。信息恰好在解码器错的地方。码的比特花在了可见性上：μ 与竖柱空闲比例的 Spearman 相关是 .90（分析者 B）。
- **结论**：瓶颈是码的水平量子（一根竖柱一个标量），不是字节、数据、训练或解码器。坐标阶梯只是在缩小量子：64×64×1 仍是 2 格量子，而完美的 2×2×1 也只有 .77。A06 预注册 3S-Z2 家具在 [.62, .72]（8 KB），要过 .8 得再上一级（32 KB）。

**新一代能做到多少：**

- **干净世界：精确结构码家具区 = 1.000【实测，24 房】**，同时空闲召回 = 1、三态准确率 = 1，不是靠度量盲区换来的。要省字节就按"每比特换来的家具 F1"删盒：146 B 时 .941，108 B 时 .857【实测】。
- **学习解码 + 光线投射的有损路线**：要到 .85，大约需要 ≥ 90 % 的家具面体素精确，且外扩 ≤ 5 %（A06 faceerr）。现模型侧面召回只有 .33–.53，一两个租约内不可信。
- **噪声世界**（相机档，按干净真值）：
  - 地板（无损传输噪声图）：K0 .78–.83；R8 求和 .75（有机间误差）/ .91（无）。
  - 上限（去掉位姿误差）：R8 .94–.98。
  - 主推的目标【估计】是 K0 家具 ≥ .85、R8 ≥ .88–.90，要靠逐帧与机间配准。
- **"家具已经实用"只能在加固面板上宣称。** 干净世界的 1.000 只是编解码器正确性的单元测试。

## 3. 学习还有没有价值：裁决

**裁决。**

1. **当前评估下**，学习对 F1 的价值是 0；对码率 ≤ 1.3–2×（计数先验已经拿走 5–19 %，DL 封顶）。
   - 在干净世界里继续给学习型有损稠密码花 GPU，就是在打磨一个已被 50 行贪心算法支配的点。这包括坐标阶梯、3S-Z2 之后的续训、W-Sheaf 加率项、ΔV、RAYFIELD、RK-Δ。
2. **新一代工作的价值主张：sheaf-GBP 是一个正确、流量最小的分布式融合协议。** 当传感器有噪声、位姿和机间坐标有误差时，它的融合变成真正的推断：
   - 森林上的 log-odds 求和，把观测冗余变成精度；
   - 位姿 stalk 的非恒等限制映射完成配准。

   学习在其中提供三样东西：生成式先验（码率）、去噪与结构拟合（精度）、配准特征。干净世界的精确码是它的退化特例，也是单元测试。
3. **评估必须改。** 不改的话，诚实的论文标题只能是"经典精确码在两条轴上都赢"。

## 4. 新一代架构

### 4.1 主推：EV-Sheaf（两层证据 sheaf）

十份辩论的合成提案本质相同：A01 RAY-PROG、A02 S\*、A03 RAY-SHEAF⁺、A04 EX-Sheaf、A05 双层、A06 EPR、A07 NX、A08 TRS、A09 LRS、A10 FACT。这里统一记作 EV-Sheaf。

**stalk 的索引集和内容**

$$\mathcal I=\mathcal I_{\rm vox}(128{\times}128{\times}32)\ \sqcup\ \mathcal I_{\rm plan}(128{\times}128)\ \sqcup\ \mathcal I_{\rm glob}(\text{墙高、门高})\ \sqcup\ \mathcal I_{\rm pose}(8\ \text{智能体}\times3\ \text{帧})$$

| stalk | 干净档 | 噪声档 |
|---|---|---|
| 体素 | {⊥ < 空, ⊥ < 占}，精度 q ∈ {0, ∞} | 整数 log-odds ℓ̂ ∈ [−15, 15]（向零取整），精度 \|ℓ̂\|；环图上附 8 bit 来源位图 |
| 平面列 | {⊥, 墙, 门楣}，按 OR 合并 | 同左，换成 log-odds |
| 全局 | 平坦格 | 同左 |
| 位姿 | 所有者的 float32 值，精度 ∞ | (μ, Λ)，定义在 SE(2) × ℝ 上，逐帧加逐智能体坐标系 |

盒子和平面段只是线路上的编码，不是状态。每段描述只从它自己的位姿集渲染，再在体素格上 join，所以不需要跨智能体的物体关联（A03 的论证）。

**GBP 迭代和下降的能量**

干净档，就是现在 `rollout_max` 的形式，只是元素从高斯坐标换成了证据：

$$m^{t}_{u\to v}=o_u\vee\!\!\bigvee_{w\in N(u)\setminus v}\!\! m^{t-1}_{w\to u},\qquad b^{t}_v=o_v\vee\!\!\bigvee_{u\in N(v)}\! m^{t}_{u\to v}$$

$$E_{\rm I}(t)=\sum_{v}\sum_{s\in\mathcal I}\Big[\rho\big(s^{*}\big)-\rho\big(b^{t}_v(s)\big)\Big]\ \ge 0,\qquad s^{*}=\bigvee_{u\in c(v)}o_u(s),\quad \rho(\bot)=0,\ \rho(\text{空})=\rho(\text{占})=1$$

- 由 m⁰ = ⊥ 归纳得 mᵗ ⊒ mᵗ⁻¹，所以 bᵗ 单调上升，E_I 不增。
- 轮数 t ≥ 树的直径（实测 ≤ 6–7）时 E_I = 0，不动点就是 R8 目标。这正是 D8 已认定的 Tarski Laplacian 调和流。
- **{0, ∞} 角点**（A04）：对 β 族 $Q_\beta=(\sum_i q_i^\beta)^{1/\beta}$，若证据精度只取 0 或 ∞ 且彼此一致，则对所有 β ∈ [1, ∞] 都有 Q_β = ∞、均值相同。也就是说，sum-GBP、协方差交叉、格 join 三者的不动点逐点相同。

噪声档的体素层，是森林上的精确 BP：

$$m^{t}_{u\to v}(x)=\hat\ell_u(x)+\!\!\sum_{w\in N(u)\setminus v}\!\! m^{t-1}_{w\to u}(x),\qquad b^{t}_v(x)=\sum_{u\in S^t_v}\hat\ell_u(x),\qquad \Phi(t)=\sum_v\big|c(v)\setminus S^{t}_v\big|$$

- 每个智能体的证据恰好计一次，Φ 单调不增，直径轮内归零。
- 在树上，Bethe 自由能等于 Gibbs 自由能，不动点就是"逐束噪声独立"假设下的精确后验 log-odds。
- 环图上用来源位图，只加不同来源（幂等），或者退回 CI。

位姿层负责配准。这是 sheaf 第一次真正需要非恒等的限制映射：

$$E_{\rm pose}(T)=\sum_{(i,j)}\sum_{k\in\mathcal K_{ij}}\rho_\delta\!\Big(\big\|r_k(T_i,T_j)\big\|^2_{\Sigma_k^{-1}}\Big)+\sum_{i,f}\big\|\mathrm{Log}\big((T^0_{i,f})^{-1}T_{i,f}\big)\big\|^2_{\Sigma_{i,f}^{-1}}$$

- r_k 是相邻智能体消息里匹配上的平面或盒面，在公共坐标系下的残差；限制映射就是位姿变换。ρ_δ 是截断二次。
- 森林二着色，两种颜色交替做阻尼 Gauss–Newton（即线性化的 GBP 消息），只接受让 E_pose 下降的步，所以单调。
- 位姿更新后，体素证据无状态地重算。

量化、变长、新息不破坏下降（A04 的 L-Q / L-S / L-Δ；A01、A10 已逐轮逐位断言，0 违例）：
- 源端单调地向下量化，与 join 可交换。
- 省略 ⊥ 是精确的。
- 只发高于接收方已知下界的分量，信念逐位不变。
- 整数 log-odds 求和没有舍入。
- 干净档里有损只在源端做一次。中继有损重拟合会破坏全局截面（A04 P10），对 F1 的影响虽然 ≤ 0.25 pp，规则仍要写死。

**用户可能的质疑和回答**

- **"中间向量变成了观测原子，GBP 变成了集合并，这还算 sheaf-GBP 吗？"**
  - 形式上满足底线：公共、有界索引集上带精度的 stalk 向量；与 `rollout_max` 逐字相同的排除回传消息；能写出来、单调下降的能量（同一个 Tarski 能量，见 {0, ∞} 角点命题）。
  - 干净档退化成并，是世界无噪声的诚实后果：在这里任何正确的融合都会退化成并。
  - 噪声档里它恢复为真正的推断：自然参数求和，加上非恒等限制映射的高斯 sheaf。这比现在"限制映射恒等、融合只做选择"的系统更接近 sheaf + GBP 的本义。
- **"学习在哪里？"**
  - 干净档只在先验（码率）和摊销编码（速度）里，对 F1 的贡献为 0。这是实测结论，不是取舍。
  - 噪声档在去噪与结构拟合的先验、配准特征和判决校准里。
  - 如果一定要"学习的 sheaf 向量在融合路径上"，有两条路：一是加可选阶段 S5，即 A01-Ⅱ 的学习潜码超先验 stalk（每列 4 维整数；用 max-pool 同态编码，使 join 恰好等于并集观测的码），门槛是"潜码 ≤ 60 B，且总比特 ≤ 0.85×"；二是转向备选 Prim-Sheaf。
- **"这不就是经典压缩加光线投射吗？"** 新的东西有四点：
  - 把融合写成格值 / 高斯 sheaf 上的 GBP，并证明量化、变长、新息下能量单调；
  - 网内 join 相对洪泛的码率优势等于观测重数 μ，可以写成命题；
  - 噪声下求和把冗余变成精度，max 反而随重数恶化（两个噪声种子实测）；
  - 配准作为限制映射。

**线路与熵编码**

- 调度：收集—分发两趟（≤ 2 × 树深轮），去掉"盲"的第一轮。
- 每条消息依次包含：
  - 4 B 头；
  - 未发过的位姿；
  - 平面列的新息（2D 上下文算术码）；
  - [O, ¬F] 内的实心盒 token（Δx0, y0, z0, 宽, 深, 高），用自回归先验编码；
  - 盒子解释不了的部分，用光线序残差事件编码。
- 全部概率都以反向消息（腔）、公开的可达性和已解码内容为条件。这些两端都有，所以不是 Wyner–Ziv。概率整数化，保证跨设备逐位一致。
- 中继：解码 → join → 规范重拟合 → 编码。
- 噪声档：线路传编码端 MAP 去噪后的结构，加上每段的精度档（2–4 bit）；接收方把它渲染成隐含的 log-odds 再求和。中继要把子树之和重新拟合成结构码，这一步是有损的：精度向零取整只会更保守，Φ（已吸收的证据数）仍单调，但不动点只在量化误差之内等于精确和。这个近似的代价由 E3、E5 实测，不预设。

**解码器**：栅格化（格心规则；细部件保留中心格），再做整数 DDA 首次命中投射。干净档没有任何学习参数参与计分。噪声档读融合后的 log-odds，按区域取 F\*/2 阈值（结构约 .45，家具约 .28），阈值在 TRAIN-24 上按 3S-DR 的流程标定。

**"压缩再生成 / diffusion / MeanFlow"放在哪里**

- **熵模型**：next-scale、掩码离散扩散或自回归先验，给出 −log₂ p_θ(消息 | 接收方已知)。算术解码器就是被比特流驱动的生成采样器——这就是"压缩再生成"的精确形式。
- **编码端的无模态补全**：在 don't-care 区让先验挑最可能的一致世界（体素级实测省 35 % / 43 %）；渲染保证这些补全不可见。
- **噪声档的去噪先验**：做 MAP。一步的 MeanFlow / consistency 模型可以当摊销提议器，快速给出盒与平面参数的初值，再由能量下降的精修把关。
- **可视化补全**：不计分，也不得写入已知区。
- **不放在计分地图的出图上**：采样会让家具 F1 低 6–22 pp，联合众数也低 10 pp；F1 最优判决是边缘 ≥ F\*/2。

**损失**
- 干净档只有比特：L = E[bits(自己)] + E[bits(边新息)]。
- 噪声档：L = λ·bits + D_truth + β·NLL_pose。其中 D_truth 是对干净真值首击的射线终止交叉熵（家具加权、零容差），加上干净已知空闲体素上的 BCE（保护空闲召回）。

### 4.2 备选：Prim-Sheaf（连续图元参数 sheaf）

**为什么选它当备选。** 主推在噪声档的风险是："体素 log-odds + 结构 MAP 线路"去噪不够，码长随噪声变长。Prim-Sheaf 把融合本身搬到连续几何参数上：
- 一块平面被 N 条射线命中时，偏移误差是 σ/√N（σ = 2 cm、N = 50 时只有 2.8 mm）；
- 码长不随噪声变长；
- 图元天然是配准地标。

所以它同时押注精度和压缩两条轴。这条线汇集了 A07-D3、A08-D2 / TRS、A05 的 L2、A09-C、A10-γ、A04 设计三、A01-Ⅲ。

**stalk 的索引集和内容**
- 公共锚点 𝓘_prim：16×16 锚格 × 2 槽，按图元最小角归属。
- 槽里存连续图元参数 θ_k：墙段是法向偏移加端点；家具是带偏航的盒或圆柱的 6 个面（或尺寸）加高度。每个参数带高斯信息 (η_k, Λ_k)。
- 位姿 stalk 同主推。
- 体素证据层保留，作为残差和仲裁者。
- 干净档里 Λ ∈ {0, ∞}：看见的面被钉住。

**GBP 与能量**

$$E_{\rm prim}(\theta,T)=\sum_i\sum_{k\in K_i}\tfrac12\big\|A_k(T_i)\,\theta_k-\hat y_{i,k}\big\|^2_{\Lambda_{i,k}}+\sum_{a\sim b}\rho_\delta\big(\|\theta_a-P_{ab}\theta_b\|^2_{\Gamma}\big)+E_{\rm pose}(T)$$

- ŷ_{i,k} 是智能体 i 对图元 k 的局部拟合；A_k(T_i) 是限制映射，按估计位姿把参数搬到公共坐标；P_ab 把跨锚点的同一物体参数平移对齐；ρ_δ 用截断二次处理关联的不确定。
- 给定 T，二次部分在森林上做信息形式的 GBP，是精确的；ρ 用 IRLS（majorize–minimize）；T 用二色块坐标下降。三者都只接受下降步，所以 E 单调不增。
- 证据相关性的处理：
  - 同一智能体的面共享位姿误差，这一相关性由显式的位姿 stalk 承担，而不是去虚高面精度；
  - 不同智能体的逐束噪声互相独立，信息相加是合法的；
  - 重复转发由排除回传和来源记账防止。

**线路与熵编码**
- token 流：锚点、类型、量化参数（到 R1 格或 1 cm）、偏航 5 bit、面精度档 2 bit。
- 先验：自回归或掩码离散扩散，条件是平面图、房间几何和接收方已有的 token。
- 只发新 token，或精度提升了的 token；体素残差事件保证干净档逐位精确。
- 带类别的家具库版本只作为"知道生成器"的上界单列。

**解码器**：图元栅格化（OBB，格心规则）+ 残差 + 光线投射。噪声档先在 E_prim 加学习先验上做 MAP，再栅格化，按 F\*/2 判决。

**生成模型的位置**
- token 先验就是熵模型。
- MeanFlow / consistency 一步生成器作摊销提议器 q(θ | 局部证据)，给出半可见物体的不可见范围：编码端用于 don't-care 补全，解码端用于可视化。
- 不采样计分体素。

**损失与阶段**

| P0 | CPU 神谕门槛：真值可见图元 → 渲染 + 残差，测字节和逐位精确；再在偏航 45° 和留出类别面板上复测 | CPU |

  - 自己地图 130–160 B（通用图元 + 学习先验），相对 S0 1.4–1.7×、ctx 8–10×、gzip 16–20×、原始 820–1,000×；

## 7. 留给文献阶段的具体问题

下面提到的系统和方法名只是待查的线索，名称和数字都要在文献阶段核实。

1. **多机器人建图实际传什么、传多少。** 分布式 SLAM 系统（例如 Kimera-Multi、Swarm-SLAM、DOOR-SLAM、COVINS、CCM-SLAM）交换的是关键帧描述子、子图、点云还是 OctoMap？每帧、每秒多少字节？机间配准误差多大？这决定我们"部署中的分母"（B1、B2）是否站得住，也决定"网内中继相对洪泛 2.9×"是否早已有人报告。
2. **学习型点云 / 占据几何压缩的现状数字。** G-PCC / V-PCC 与学习熵模型（例如 OctSqueeze、VoxelContext-Net、OctAttention、SparsePCGC）在无损或近无损几何上的每占据体素比特，以及相对 G-PCC 的增益。用来检验"学习先验相对计数先验 1.2–1.6×"的预期，以及我们的 ctx / ELS 离这些基线有多远。
3. **生成式熵模型。** next-scale（VAR 式）、掩码离散扩散、自回归 Transformer 作为算术编码的概率模型，在离散体素或图元 token 上的无损码长和开销；bits-back、"扩散模型做无损压缩"一类方法的实际结果。判断"压缩再生成"在 token / 体素层能否落地。
4. **MeanFlow / consistency 一步模型。** 能否给出可计算的条件似然用作熵模型（离散化、整数流、变分去量化）？能否作为去噪先验或摊销 MAP 提议器，用于噪声档拟合图元参数？有没有"一步生成 + 编码"的先例？
5. **GBP 与 sheaf 在分布式估计里的先例。** 高斯 BP 用于分布式 SLAM / 定位（例如 Robot Web 一类工作）；sheaf Laplacian 的分布式一致（Hansen–Ghrist）；格值 sheaf 与 Tarski Laplacian（Ghrist–Riess）的应用；"精确证据下 sum / CI / join 不动点重合"有没有现成表述；量化消息下 GBP 的收敛结果。
6. **噪声下的融合规则与重复计数。** 多机器人占据栅格融合里 log-odds 求和、max / min、协方差交叉（CI / split-CI）的用法；环路网络怎样避免重复计数（来源记账、channel filter）。用来验证"森林求和 + 来源位图 + 环上 CI"这套组合。
7. **机间地图配准与合并。** 基于平面、物体、结构基元的配准，与扫描匹配、ICP、占据图 Hough 合并相比的精度与失败模式；配准误差对融合地图质量的定量影响；对称房间的局部极小怎么处理。直接对应 E6。
8. **协同感知（V2X、多车 BEV）的带宽–精度曲线。** 例如 Where2comm、When2com、V2VNet、DiscoNet 声称"相对原始特征几十到几千倍"时用的口径和分母，以及它们怎样处理定位误差（例如 CoAlign 一类）。作为我们"几十倍"诚实口径的外部参照。
9. **结构化 / 语义级场景压缩与形状先验。** 基元抽象（超二次体、带朝向的盒子）、CAD 检索（例如 Scan2CAD）、把场景图当压缩表示、物体级 SLAM 交换物体地标——在真实扫描上的描述长度与几何保真度如何？检验 Prim-Sheaf 在真实数据上能否到"DL 级字节"。
10. **评估协议。** 深度相机与 LiDAR 噪声模型的常用参数（例如 Habitat / Redwood 的深度噪声、典型 LiDAR 1–3 cm）；多机器人建图基准里包含空闲空间的完整度、精度、IoU 指标；Replica / HM3D / Gibson 上多智能体建图的常用设定。用来标定 v5 的噪声档，替换对空闲不敏感的 F1。

## 8. 少数意见（有分量，但没进主推）

1. **在量化位姿上感知**（A07、A08、A10）：协议规定传感器在 1 mm 格点位姿上工作，位姿只要 8–10 B 就逐位精确，比 float32 每房省约 0.9 KB。仿真里合法，真实传感器不适用；作为选项披露。
2. **保留一个学习的潜码 stalk**（A04、A06 提名 A01-Ⅱ）：让"学习的 sheaf 向量"留在融合路径上。证据目前偏负：现码当超先验能省 62 B，自身却要 177–330 B。已作为主推的可选阶段 S5，门槛 ≤ 60 B。
3. **max-plus / max-pool 同态码**（A05）：join 之后的码恰好等于并集观测的码，中继不用重拟合；4³ 家具块 AABB 在 R8 上 6/6 同态，FPR 按构造为 0。可以替代主推的"中继规范重拟合"。
4. **由先验而不是贪心挑补全**（A02）：体素级无模态补全省 35 % / 43 %，腔条件再到 0.76×。主推把它并进了盒子补全，但"先验挑补全"本身是一个可单独测的杠杆。
5. **GPU 在线传感器仿真**（A09）：噪声缓存不预生成，缓存只存干净世界和位姿，每步在 GPU 上重投射并加噪，步时只增加 5–15 %。省掉数小时 CPU，噪声样本无限。
6. **评分坐标系与拆轴**（A08）：K0 在本机坐标系计、R8 在公共坐标系计；噪声面板拆成"传感器噪声"与"配准误差"两轴。已采纳，并按 C1 的拆分扩成三轴。
7. **按每比特家具 F1 删盒，以及对 3S-Z2 的可检验预测**（A06）：有损档按"每比特换来的家具 F1"排序删盒，而不是按体素数门槛。A06 还预注册 3S-Z2 家具在 [.62, .72]；若 ≥ .80，"水平量子"模型即被否定，学习型稠密路线需要重新评估。
8. **"停止且未知"的有损语义**（A01）：射线只在被告知为空的体素里前进，构造上不会漏光（对照 VIS-swap 的 +4 pp FPR）。适合作为主推有损档的另一种实现。
9. **split-CI 与 β 桥**（A04）：独立证据求和，重复转发和共享先验走 CI；β 族在 β = 1（Bayes）与 β = ∞（CI / max）之间连续过渡，可作为论文里统一 sum 与 max 的理论工具。
10. **融合 = 解码**（A09-B 教师潜空间、A08-D3 潜空间世界 GBP）：在干净世界被重复计数的论证否定（4 份稿），但在噪声档证据独立、真实扫描、非盒形状时，可能是唯一能自然处理的路线；留给 S6 之后。
11. **持续建图口径**（A07）：12 个位姿的步行里，ELS 增量每次更新 237 B，定长重发 2,048 B。这是比"一次融合"更贴近部署、也更有冲击力的场景。
12. **线路先改诚实**（A10-β、A04 实验 0）：不换模型，只把现系统的线路改成稀疏 + 新息 + 熵编码，F1 逐位不变，网络总量降到 5.7–13.7 KB/房。它不是新一代模型，但应立刻做，否则任何报告里的现系统码率都不诚实。另外，Slepian–Wolf 分箱或显式拉取在网络层面最多再省 8–15 %，不值得（A10）。
