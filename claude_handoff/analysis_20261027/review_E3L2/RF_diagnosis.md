## 0. 结论先行

1. **精度区间（事实）**：E3-L2 隐码在判决 K\*（0.087–0.112 倍对照字节）下，VAL cam_nf 的 R8 家具 F1 如下（对照 NET 为 .966–.973）：

   | 条件 | 342101（K\* 1,024） | 342202（K\* 512） |
   |---|---|---|
   | 预注册结构（已知头），阈值在 TRAIN 上联合选、FPR ≤ 对照 + 0.3 pp | .130（空闲召回 .791） | .233（空闲召回 .883） |
   | 已知区换成精确的体素 k > 0 掩码 | .166 | .273 |
   | 已知区换成真值（只作诊断） | .169 | .277 |
   | 加上空闲召回 ≥ 对照 − 0.5 pp 的保护 | ≤ .007 | ≤ .014 |

   所有检查点、所有 K 里最好的一格是 upd6510 / 342202 / K = 1,024（0.124 倍）：真值已知区下 .412，满足空闲保护时 .24–.29。但这个检查点的读数依赖 GPU 的平局次序，见 1.5 节。

   **所以 E3-L2 隐码的真实家具 F1 约在 .13–.28（判决字节、只受 FPR 约束），上界 ≤ .42。** 同一条管线下，E3-L 是 .86–.87（0.114–0.119 倍），对照是 .97。

2. **主因（事实 + 机制估计）**：失败的主因是隐码本身的占据信息塌了，已知头只是次要因素。
   - **事实一：给真值已知区也救不回来。** 真值已知区只让 F1 比已知头多 +3.7 到 +4.5 pp（VAL，K\*）。
   - **事实二：源端 Λ 退化成了排序分数。**
     - 选中格的原始 Λ 中位约 2.65 × 10⁵（342101）和 2.76 × 10⁵（342202）；upd6510 / 342202 则塌在下限 3.35 × 10⁻⁴。
     - 于是线路上的 Λ_q 恒为 15（或 1），Λ 通道熵为 0.00 bit。
     - 342101 的 h 有 97 % 饱和在 ±7，h_q 熵只有 1.22 bit/通道，隐码约等于 8 个符号位。
   - **事实三：top-K 的选择不再看内容。**
     - E3-L 学到的支撑只覆盖 34–36 % 的已知体素，却装下了 90–91 % 的家具体素（富集 2.5–2.7 倍）。
     - E3-L2 在 K\* 下，家具进入被发送格子的比例是已知体素平均比例的 1.07 倍（342101）和 0.64 倍（342202）。也就是没有富集，甚至反向。
   - **事实四：被发送的格子里也解码不好。** 只在 Λ_b > 0 的格子上计分、已知区用真值时，TRAIN 上最好的 F1 只有 .16（342101 K\*）和 .28（342202 K\*）。
3. **已知头的问题（事实）**：
   - **构造上无法区分。** 未被 top-K 选中的触及格在接收方是 x = 0、Λ_b = 0，与从未观测的格子在解码器输入上逐位相同。
   - **规模。** K\* 下 VAL 的目标已知体素里，42.6 %（342101）/ 71.0 %（342202）落在"所有机器都没发"的格子中；其中 99.99 % 在某机的触及足迹内。
   - **已知头的表现。** 它只能靠上下文去猜：在这些格子里召回目标已知 74 % / 89 %，未知与已知的 AUC 为 .93 / .96（E3-L 是 .998）。漏判的已知体素里，62 % / 94 % 出在这些格子。
   - **Λ_b = 0 本身不是病。** E3-L 也有 64–66 % 的已知体素落在 Λ_b = 0 格里，却几乎全判对（漏判 0.3 %）。差别在于：
     - E3-L 的"不发"是编码器对内容的确定函数，意思接近"这里是空闲内部"；
     - E3-L2 的"不发"取决于随机的 K 和一个已经饱和的排序分数，没有稳定含义。
4. **足迹能否补回（事实）**：不能。
   - **字面版不可行。** 4 × 4 × 2 块级足迹每房只要约 2.7 KB（0.0036 倍）。但把足迹内 Λ_b = 0 的格子整块判为已知，会把块内的未知体素也判成已知：即使已知头取最严阈值，TRAIN 上 FPR 也有 4.6–11.9 %（对照 1.90 %，保护线 + 0.3 pp）。E3-L 用同样做法 FPR 也有 5.5–6.1 %。
   - **门控版增益很小。** 改成"足迹 ∧ 已知头"，VAL F1 只升 +1.6 / +1.7 pp（.146 / .250）。
   - **体素级 k > 0 掩码。** 它的 FPR 与对照逐位相同，额外字节 0.044–0.045 倍（每房约 34 KB），总字节 0.154 / 0.132 倍。F1 也只有 .166 / .273；要求空闲召回 ≥ 对照 − 0.5 pp 时降到 .004 / .008。
   - 瓶颈在占据信息，补已知区补不回来。
5. **对下一版的建议**（保持底线：学习隐码 + 二次 sheaf 能量 GBP + 解码），详见第 7 节：
   - 源端参数化去掉无界的 Λ 和直通限幅：Λ = 1 + 14σ(a)，z = 0.5·tanh(u)；
   - "发不发"用独立的打分头决定，不再借用 Λ；
   - 观测足迹作为结构通道无损发送，并作为解码器输入；
   - 训练用固定 K，或把 K 作为输入；
   - 训练中加"真值已知区 F1 / Λ_q 熵 / h 饱和率"的早停探针；
   - 阈值改为联合选。

## 4. 任务 3：已知头的问题（事实）

### 4.1 构造上的不可区分

- 解码器输入只有三样：x_i = h_b / Λ_b（Λ_b = 0 时为 0）、log1p(Λ_b) 和高度。
- 触及但没被 top-K 选中的格子（Λ_q = 0、h_q = 0），经 GaBP 后若分量里没有任何机器选中它，Λ_b = 0、x = 0。这与"没有任何机器观测过"在输入上**逐位相同**。
- 所以，接收方对"这里是否被观测过"只能从邻域上下文去猜。

### 4.2 规模与已知头的判断（VAL cam_nf，K\*，合并到体素）

| | final 342101 K1,024 | final 342202 K512 | E3-L 342101 | E3-L 342202 |

  - 342202：84.2 % / 71.0 % / 47.3 % / 16.9 %。
  - 但 F1 几乎不随之上升（2.2 节），所以"已知区缺失"不是主导项。

### 4.3 读法

- **已知头确实被 top-K 削弱。** 342101 K\* 漏判 17.8 % 的已知体素，62 % 出在没发的格子里；而且它在发了的格子里也漏判 12 %，因为符号位隐码表达不了块内的已知边界，见第 6 节。
- **但"Λ_b = 0"本身不是病根。** E3-L 有更多已知体素落在 Λ_b = 0 格（64–66 %），已知头仍几乎全对（AUC .998，漏判 0.3 %），这些格子的空闲也 99.9 % 判对。
  - E3-L 的"不发"是编码器学到的、关于内容的确定函数：它把家具装进支撑，空闲内部不发，解码器就学会了"没发而且挨着发了的地方 = 已知空闲"。
  - E3-L2 的"不发"由每个样本随机的 K 和一个饱和的排序分数决定（第 6 节），同一处内容在不同 K 下发与不发不定，解码器学不到确定含义。
- 所以 D8-61 第 2 条"被触及而没被选中的格子与没观测到完全一样"在输入层面成立，但它造成的损失只是：
  - 已知头一项：真值已知区比已知头多 +3.7 到 +4.5 pp；
  - 远小于占据头本身与对照的差距：−63 到 −81 pp。

## 5. 任务 4：足迹作为额外无损通道（事实）

### 5.1 字节（VAL 每房中位，种子 1 / 2）

- 块级足迹 2,721 / 2,747 B，即 0.0036 倍对照。
- 体素级 k > 0 掩码 33,632 / 34,380 B，即 0.044–0.045 倍对照。
- 两者都按 ctx 二值码、对每条有向边发送方一侧的并计；没有以已发送支撑为条件，所以是上界。

| | final 342101 K1,024\* | final 342202 K512\* |
|---|---|---|
| 隐码 | .112 / .111 倍 | .087 / .086 倍 |
| 隐码 + 块级足迹 | .116 / .115 倍 | .090 / .090 倍 |
| 隐码 + 体素 kmask | .154 / .154 倍 | .132 / .131 倍 |

### 5.2 精度

- **字面版（fp_lit：足迹内 Λ_b = 0 的格子整块判为已知）在 FPR 约束下不可行。**
  - 即使已知头取最严阈值，TRAIN 合并 FPR 仍有：342101 K\* 8.8 %、342202 K\* 10.9 %；全部配置 4.6–11.9 %。对照是 1.90 %，保护线是 + 0.3 pp。
  - 原因是块的粒度：一个 4 × 4 × 2 块只要有一个体素被触及就整块进足迹，块里的未观测体素被一并判为已知。E3-L 用字面版同样是 5.5–6.1 %。
  - 不管 FPR、只看空闲召回 ≥ .99 时，字面版的家具 F1 在 E3-L2 上是 .004–.37。
- **门控版（fp_and = 足迹 ∧ 已知头）可行，但只多 +1.6 / +1.7 pp。** VAL 规则 A 下为 .146 / .250，已知头是 .130 / .233。FPR 在 VAL 上 +0.29 到 +0.46 pp。
- **体素级 kmask**：FPR 与对照逐位相同。F1 为 .166 / .273（规则 A），要求空闲召回 ≥ 对照 − 0.5 pp 时为 .004 / .008。
- **结论**：在不重训的前提下，"足迹 + 隐码"补不回来。即使已知区完全正确，也只到 .17 / .28，因为占据头本身不行。

## 6. 失败的主因（第 6.1 节为事实，第 6.2 节为机制估计）

### 6.1 事实

**源端统计**（`RF/source_stats_val.json`，VAL cam_nf 48 个任务、K\* 下的选中格）：

| | final 342101 K1,024 | upd6510 342101 K2,048 | final 342202 K512 | upd6510 342202 K768 |
|---|---|---|---|---|
| 选中格原始 Λ 中位（10 %–90 %） | 2.65e5（2.64e5–2.66e5） | 2.98e4（2.91e4–2.99e4） | 2.76e5（2.29e5–3.10e5） | **3.35e-4（下限 softplus(−8)，96 % 的选中格）** |
| 未选中触及格原始 Λ 中位 | 2.62e5 | 2.92e4 | 1.51e5 | 3.35e-4 |
| 线路上 Λ_q 的取值 | 全部为 15 | 全部为 15 | 15（0.06 % 为 1） | 1–15，96 % 被下限钳到 1 |
| \|z\| 中位 / 90 % | 10.8 / 44.6 | 19.5 / 48.3 | 0.20 / 0.45 | 0.93 / 3.06 |
| \|Λ_c z\| > 7.5 的占比 | **97.2 %** | **99.7 %** | 6.0 % | 0.9 % |
| h_q 符号熵（bit / 通道） | **1.22** | **0.84** | 3.85 | 2.94 |

- 官方 eval 的通道统计一致：
  - 342101 的 Λ 通道熵 0.00 bit，h 各通道 1.1–1.5 bit；
  - 量化信念与浮点信念的平均差 45.9（342202 是 0.065）。也就是说，342101 的浮点隐码幅度在几十，线路只留下了符号。
- 训练曲线（`g4/e3l2/rate_curve_*.json`，最后 40 次实测）：
  - 342101：Λ > 15 的占比 1.00，h 饱和 0.97，原始 Λ 中位 2.6 × 10⁵；第 100 次更新起，99 % 的实测里 Λ 都已上饱和。
  - 342202：先在下限塌缩（第 1,717、5,151 次更新时 lam_clip_lo = 1.0），再上饱和（第 3,434、6,868 次及第 10,302 次以后 lam_clip_hi ≈ 1.0）。
  - 原始 Λ 中位单调膨胀：2.7 × 10³ → 2.6 × 10⁵。
- **发送格是否装下家具**（VAL，K\*；用"家具体素在已发送格的比例 ÷ 已知体素在已发送格的比例"表示富集）：
  - E3-L：.900 ÷ .356 = 2.53 倍、.907 ÷ .340 = 2.67 倍；
  - E3-L2 final：342101 是 .612 ÷ .574 = 1.07 倍；342202 是 .185 ÷ .290 = **0.64 倍**；
  - E3-L2 upd6510：0.54–0.96 倍。
- **发送格里的解码也差。** 规则 A 下，已发送格的目标家具只有 45–56 % 被判占据，E3-L 是 89–90 %。只在已发送格上计分、已知区用真值，TRAIN 最好的 F1 是 .16 / .28；E3-L 是 .90 / .91。
- **等步数快照对比，结果不一致。**
  - 342202：upd6510 比 final 好。同为 K = 1,024、TRAIN、真值已知区时 .418 对 .346；只计已发送格 .594 对 .331。也就是多训的 1.07 万次更新反而变差（upd6510 这一侧依赖 GPU 平局次序）。
  - 342101：upd6510 比 final 差（.09 对 .14）。

### 6.2 机制（估计，未做消融）

1. **top-K 按原始 Λ 排序，把 Λ 变成了无界的排序分数。**
   - 未被选中的触及格对 Λ 是恒等直通（P2），损失希望这些格子"也有信息"，梯度就把它们的 Λ 往上推。
   - 选中格超过 15 时，只放行向下的梯度（M1）。没有任何力量把整体尺度拉回来，于是原始 Λ 膨胀到约 10⁵；在另一些阶段则整体塌到下限。
   - 两种状态下 Λ_q 都是常数（15 或 1）。精度通道不再携带信息，选择也不再看内容：342101 选中格与未选中格的原始 Λ 只差约 1 %；upd6510 / 342202 有 96 % 的选中格原始 Λ 完全相同，顺序由 `torch.topk` 的平局规则决定。
2. **Λ_c 被钉在 15 时，h = 15z 的 ±7.5 限幅要求 |z| ≤ 0.5。**
   - 342101 的编码器没有学会收缩（|z| 中位 10.8），97 % 饱和，单侧直通又挡住了"继续变大"的梯度。隐码因此只剩约 1.2 bit / 通道。
   - 这正是 M1 审查想防的"上饱和"：M1 修住了 Λ_c 的范围，但没修住原始 Λ 的膨胀，于是饱和换了一个位置出现。
3. **342202 学会了收缩 z**（每通道 3.85 bit，饱和 6 %），但仍只到 .28。估计有两个原因：
   - 选择不富集家具（0.64 倍），而解码器在约 71 % 的已知体素上没有任何数据，只能补；
   - Λ 在下限与上饱和两种状态之间切换时，解码器输入 x = h / Λ 的尺度相差 15 倍，解码器要反复重学（与 E3-L 的振荡同类）。

   这一条只有相关证据：342202 的 upd6510 比 final 好；容量探针（D8-58）表明 8 通道可到 .90。
4. **阈值规则**是 D8-61 读数为 0 的直接原因，但不是精度低的原因。联合选阈值也只能把 .000 提到 .13 / .23。

### 6.3 主次

| 因素 | 量化 | 判断 |
|---|---|---|
| 隐码的占据信息塌了：源端 Λ 退化、h 饱和、选择不看内容 | 对照 − 真值已知区 F1 = −63 到 −81 pp | 主因 |
| 已知头被 top-K 削弱：发了与没发不可区分 | 真值已知区比已知头多 +3.7 到 +4.5 pp | 次要 |
| 预注册阈值规则 | 不可行，回落到 F1 = 0；联合阈值 +13 / +23 pp，但仍远低于对照 | 读数为 0 的直接原因，不改变结论 |

GaBP 与二次能量这一层仍然精确（D8-61：相对误差 6e-14，违例 0），不在原因里。

## 7. 对下一版的建议（底线不变：学习隐码 + 二次 sheaf 能量 GBP + 解码）

每条都标了先后。若用户给算力，可在 bigboy GPU 0 上做：先用约 2,000 次更新的预跑核对探针，再决定是否全跑。

1. **（必改）源端参数化去掉无界量与直通限幅。** 能量与 GaBP 公式不变，只改 Enc 的输出层。
   - Λ = Λ_min + (Λ_max − Λ_min)·σ(a)，例如 [1, 15]；
   - z = z_max·tanh(u)，z_max = h_lim / Λ_max，使 |h| = Λ|z| ≤ 7.5 由构造保证；
   - 不再用单侧直通限幅。量化仍用直通取整，这本身无害。
2. **（必改）"发不发"与精度分开。**
   - 用独立的打分头 s 选格子：硬 top-K 加打分头上的直通或 Gumbel-top-K；
   - Λ 只表示精度。不能再出现"Λ 既是精度又是排序分数"的情况，这是 6.2 第 1 条的根。
3. **（推荐）观测足迹作为结构通道无损发送，并作为解码器的第 4 个输入（需重训）。**
   - 在能量里，它就是数据项的支撑：Λ_i(c) > 0 ⟺ 观测到。被 K 预算砍掉的只是"高精度值"；没发值、但被观测过的格子可以发一个学到的缺省隐码，或只发一个标记。
   - 块级 0.0036 倍；体素级 k > 0 掩码 0.044 倍，此时 FPR 与对照逐位相同，已知头这一失败模式整个消失。
   - 在 0.15 倍的线下，块级足迹几乎不占预算。体素级要与 K 共享预算：0.044 倍 + K 约 512 的隐码约为 0.13 倍。
4. **（推荐）训练的 K 固定**为字节目标对应的值（或窄带 ±25 %），或把 K 作为解码器输入。log-uniform 128–2,048 让"没发"没有确定含义（4.3 节）。
5. **（必加）训练中的早停探针**，每 1,000 次更新在留出房上算一次：
   - 真值已知区的家具 F1（本报告的 oracle 列）；
   - Λ_q 熵；
   - h 饱和率；
   - 原始 Λ 的分位数。

   Λ_q 熵 < 0.5 bit、h 饱和 > 30 %，或真值已知区 F1 在 5,000 次更新时 < .6，就中止。这些量在 E3-L2 里都可以在第 100 到第 1,000 次更新内看到。
6. **（评估）阈值改为联合选**：在 TRAIN 上搜 (t_known, t_occ)，约束 FPR ≤ +0.15 pp、空闲 ≥ −0.25 pp。在 E3-L 上，这一条单独就让 VAL 家具多 +6 到 +13 pp（.796 → .859，.741 → .871）。要预注册，并给 VAL 的 FPR 漂移留余量。
7. **（预期）**：以上都是估计，没有验证。
   - E3-L 是同一能量、同一编解码器结构，并且没有 6.2 的病。它在约 0.12 倍字节下、联合阈值时是 .86–.87。修好源端以后，这是 E3-L2 类设计的合理起点。
   - 能不能逼近 .97，取决于第 2、3 条能否让选择重新富集家具（E3-L 是 2.5 倍），以及训练步数。这一点没有证据。
