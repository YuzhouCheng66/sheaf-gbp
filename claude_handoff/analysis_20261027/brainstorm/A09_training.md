# A09｜训练、数据与算力的现实派：下一代 Sheaf-GBP 怎样在一块 5090 上做成

数字来自证据包、报告 D8-19…34、分析 B / C 的曲线与时间模型，以及本机 CPU 上的 6 个探针（`probes/A09/`，6 个 VAL 演示房子 × 8 个智能体；度量的 numpy 复刻与导出的 K0 / R8 指标逐智能体对账，误差 < 1e-3）。没用 GPU，没碰 uk-linux。

## 0. 结论先行

1. **被计分的只有 S（观测到的占据体素）**；而且对区间 [S, S ∪ U] 里任何世界 W，observe(W, 位姿) 逐体素等于自己的地图。真正的无损码是"最便宜的相容世界 + 位姿"：一条收敛消息 589–1,032 B、F1 = 1，比证据包的"最强无损"（ctx 三态 1,752 B）小 1.7–3.0 倍。
2. **头号方案 W-Sheaf**：删掉 known 头，码只描述一个相容世界（U 区由率项自动补全），接收方用位姿重演光线得到可见性；64×64 竖柱 × 8 通道 stalk + 学习熵模型 + 只发变化；融合仍是逐坐标最大精度 join。预计收敛消息约 420 B（相对 gzip 8.7 倍、原始 310 倍；每条边 8 轮合计相对现在约 27 倍），R8 表面 .93–.95、K0 .945–.96、家具 .72–.82。
3. **最小可证伪实验 2 个租约**：从 3S-Z2 周期 2 终点函数保持续训，唯一变量是率项。
4. **两周约 40 个租约**：第 1 周三条线各过一个 ≤ 1 租约的门槛、W-Sheaf 走两步；第 2 周立 W-Sheaf 新谱系并归因。

## 1. 先测出来的事实

### 1.1 被计分的内容只有 S

`metrics3d` 的四个 F1 只数"目标已知区里预测为占据"的体素：目标空闲体素只会以 FP 出现，报成"未知"不扣分；FPR 只罚把未知说成已知。所以 F1 的充分统计量是 S（自己的图中位 7,564 个体素，家具占 18 %）。只发 S、其余全报未知，四个 F1 都是 1.000、FPR = 0——**空闲区知识不计分**，去掉可见性的设计必须加 free-space recall 保护。

| 内容（中位，字节） | 原始 | gzip | ctx 三态 | **ctx(S)** | S / 三态 |
|---|---|---|---|---|---|
| 自己的图（K0） | 131,072 | 2,733 | 1,384 | **569**（p10–p90：221–1,090） | 43 % |
| 收敛消息（树边发送侧并集，84 条） | 131,072 | 3,647 | 1,752 | **936** | 49 % |
| R8 并集 | 131,072 | 6,060 | 2,813 | **1,538** | 58 % |

### 1.2 相容世界区间：可见性免费，补全也免费

`observe()` 是首击光线步进：射线在首击之前只采样 GT 空闲体素，首击体素在 S 里。于是对任何 S ⊆ W ⊆ S ∪ U（U = 从未被采样的体素，占 87 %），同样位姿重演时每条射线走过同样的采样点、停在同样的体素：**observe(W, poses) ≡ 自己的地图**。并集同理，融合规则 W = (∪W_a) \ (∪F_a)。推论：给定 S，known 掩码（ctx 的 69–77 %）只差 3 个浮点位姿（每智能体 24 B）；编码器可以在区间里挑最便宜的世界。

| 一条收敛消息的无损码（中位） | 字节 |
|---|---|
| 我们：2,048 B × 8 轮同步（每条有向边，3S-X） | 16,384 |
| gzip-9 / ctx 三态（证据包的"最强无损"） | 3,647 / 1,752 |
| S + 位姿（发送侧中位 4 个智能体 × 24 B） | 1,032 |
| 重力 / 夹缝填充世界 + 位姿（不用真值：竖柱里 S 下方、两个 S 之间的 U 填满） | 766 |
| 真值竖柱补全世界 + 位姿（学得好的先验能逼近的程度） | 589 |
| 参数描述长度 DL（按 K0 / R8 的 DL/ctx 比 .085–.145 插值） | ≈ 200 |

自己的图：S 569 → 重力填充 456 → 真值补全 345 B；R8 并集 1,538 → 1,129 → 815 B；整栋房子的真值世界只要 739 B（`p1b`），其中只编家具 711 B、只编墙与过梁 76 B——**世界的信息几乎全在家具**，而定长码给墙、空地、家具竖柱一样的 16 bit。

### 1.3 重演：原理精确，旧权重会漏光（`p2`）

只用导出的中心位姿经由 S 重演：复原 96.0 % 的已知体素，FPR .09 %，与经由真值世界重演（96.0 %、.05 %）几乎一样——S 就够，差的只是位姿。1 cm 网格搜 3 个抖动位姿：一个智能体只差 0.50 %（315 / 63,524），另一个卡在局部最优（4.3 %）；浮点位姿按构造精确。**但经由现有 K0 预测的占据体素重演，FPR 1.96 %，known 头是 1.22 %（+0.74 pp，超出保护线）**：现在的占据头靠 known 头的否决兜底，墙面有洞，光线漏出去。所以必须训练"不漏光"的世界。

### 1.4 只发变化（`p5`）

`rollout_max` 每轮每条有向边都发满 D 维。按它的规则在 6 套房子的森林上模拟（精度键用 64×64 竖柱覆盖率代理）：一条边 8 轮里真正变化的 stalk 只有收敛消息非空 stalk 数的 **1.44 倍**（p90 1.88），中位第 3 轮、最晚第 6 轮收敛；定长发送是它的 24 倍。诚实的码率单位是每条边全程字节（3S-X 现在 16,384 B）。

### 1.5 算力与数据账（`p3` + 分析 C 的时间模型）

t(update) ≈ 0.085 s + 0.0041 s × 单次解码 GMAC × (解码次数 / 40)。Decoder3D W2 单次解码 32.7 GMAC（逐层数得与分析 C 一致），40 次解码（8 智能体 × 5 hop）占步时约 60 %。

| 配方 | s/update（估） | 每租约（6,600 s 训练）更新数 |
|---|---|---|
| 3S-X / 3S-Z（实测 .20 / .206） | .21 | 约 31k |
| W-Sheaf（64×64 × 8 通道，只有占据头） | .21 | 约 31k |

| BEV 检测器（2D U-Net，8.2 GMAC / 图，8 图 / 步） | .027 | 约 247k |

数据：4,708 套缓存约 4,400 s、全量 1.6 万套约 3–4 h（射线步进占大头）。4,708 套里约 23.5 万件家具（22 类，每类约 1 万件），对参数化先验已经过量——**数据量对新结构也大概率不是杠杆**。该花 CPU 的是给缓存补三样：浮点位姿、真值世界位图、物体参数与可见列表（约 1 小时）。

## 2. 设计 A（主推、近期）：W-Sheaf——世界码 + 传感器重演

**一句话**：删掉 known 头和它逼码去背的可见性边界；每个智能体发"与观测相容、在学习熵模型下最便宜的世界"（64×64 竖柱 × 8 通道量化向量），接收方用位姿重演 65,536 束光线得到三态图；融合仍是逐坐标最大精度 join，消息变长、只发变化。

**为什么两个指标一起涨**：
- 比特不再付给可见性：known 掩码是 ctx 的 69–77 %，known-BCE 是损失的一半，known 头在表面的否决是 K0 剩余缺口的主因（分析 C：无否决上限 .947）。
- 比特跟着信息走：K0 时定长码 80 % 的坐标落在空竖柱上，而世界比特 96 % 在家具；率项把字节挪到家具竖柱，空竖柱趋于 0 bit。
- 自由度继续上台阶而不付字节：坐标阶梯每级 +4–6 pp、家具 +7–12 pp，定长下每级字节 ×4，变长后由内容决定。
- 补全免费：U 不计分也不改变重演，率项会把 U 填成最便宜的形状——不用真值的重力填充已省 20–28 %，真值补全省 39–47 %。
- **量级**（熵编码后，含存在图与边信息；位姿另计 24 B / 智能体）：K0 消息 200–300 B（经典参照：重力填充世界 2×2×1 OR 225 B 已有表面 .865、家具 .69，学到的解码器只需把子格位置放对）；收敛消息 300–400 B + 4 个位姿 ≈ 420 B；每条边全程 ≈ 1.44 × 420 ≈ 600 B。
- **倍数**（按收敛消息 420 B）：相对 ctx 三态 4.2、gzip 8.7、原始 310、真正无损（589 B）1.4 倍；每条边全程相对现在（16,384 B）约 27 倍。
- **F1 预计**：R8 表面 .93–.95，K0 .945–.96，可变 .87–.90，R8 家具区 .72–.82（3S-Z 在 16k 下家具 +7–9 pp；否决消失 K0 +1–2 pp；字节集中到家具竖柱）。

**底线**。索引集 I = C ⊔ A：C 是 64×64 公共竖柱（L/64 × L/64 × 3.2 m），A 是 8 个智能体顶点。竖柱 stalk x_{i,c} = (π_{i,c}, ẑ_{i,c})：π ∈ {0,…,255} 是 8-bit 精度键（0 = 无证据），ẑ ∈ ℤ⁸ 是学习步长量化的潜向量；智能体 stalk 是 3 个浮点位姿，精度 ∞。每个竖柱 stalk 落在 (π, 序号) 字典序全序链上，限制映射为恒等，融合是格值 sheaf 的 Tarski 调和流 x_i ← x_i⁰ ∨ ⋁_{j∈N(i)} m_{j→i}（BP 式排除回传，即现在的 `rollout_max`）。下降的能量是秩亏量

$$\Phi(t)=\sum_i\sum_{c\in C}\big[r(x^*_c)-r(x^{(t)}_{i,c})\big]\ \ge 0,\qquad x^*_c=\bigvee_{j\in\mathrm{comp}(i)}x^0_{j,c},$$

r 是链上的秩（报告 D8 的协方差交叉 / Tarski Laplacian 能量的离散形式）。每轮消息是更大子树上的 join，单调，所以 Φ 不增，森林上 ≤ 直径（实测 ≤ 6）轮到 0。量化：π 的量化 q 是链上的单调映射，q(a ∨ b) = q(a) ∨ q(b)，量化后的流是原流的像；ẑ 随赢家原样转发、熵编码无损，中继不重新量化。只发变化：join 幂等（a ∨ a = a），省略未变的坐标等价于重发旧值，轨迹逐位相同。位姿集合的并也是 join。

**架构草图**。编码器：现在的 PatchTrunk3D @ 64×64×1（竖柱剖面编码器），head 输出 8 + 1，另加"竖柱到本传感器的方向"平面。线路：ẑ = round(z / Δ)，率用加性均匀噪声代理、解码器用 STE；熵模型 = 每通道分解先验 + 16×16 超先验（边信息计入码率）；存在图 2D 上下文编码；真正的算术编码器做往返测试。融合：`rollout_max` 原样（D = 4,096，载荷 2 → 9 维）。解码器：Decoder3D W2，折叠 4 → 首层 144 通道 + 4 个位姿热图平面，只出占据 logit。评估：占据阈值 → GPU 光线重演（须与 `observe` 在 100 个智能体上逐体素一致）→ 三态图。损失：表面加权占据 BCE + **射线终止损失**（每步每智能体抽 4,096 条自己的射线，按透射率 Π(1 − p) 得预测首击分布，对真实首击做交叉熵，专训不漏光）+ λ·R；没有 known-BCE。分阶段：从 3S-Z2 周期 2 终点函数保持扩展（新通道在解码器首层零初始化，λ 在 2k 次更新内从 0 升到 λ*），一个周期 25.5k @ 1e-4，新谱系稳定后从头两周期确认。参数约 3.2 M；fp32 约 .21 s/update，hop 采样 .12 s，bf16 估 .09 s；显存约 9 GB。

**风险**：(1) 最可能的失败——选择式融合遇上世界码：A 观测竖柱下半、B 观测上半，各自补全另一半，若精度键被补全抬高，补全会压掉观测。对策是 π 只由本智能体在该竖柱的首击数决定，学习精度只作解码器输入；但 3S-Q 显示确定性覆盖精度 −2 pp。(2) 漏光：旧权重实测 +0.74 pp FPR，射线终止损失若压不住，保护过不了。(3) 重演看首击，一个空闲区 FP 会遮住后面的真表面，K0 可能比逐体素 F1 低 0.5–1 pp（照 3S-DR 在 TRAIN-24 上标阈值）。(4) 率项先吃掉稀有小家具，λ 要定在拐点。

**最小可证伪实验**：
- **E1（0 GPU，先做）**：在 3S-X 与 3S-Z2 检查点上 (a) 用真正的算术编码器测现有码的字节（存在门控 + TRAIN-24 拟合的自适应分布），预测 3S-X K0 ≤ 600 B、3S-Z2 ≤ 1,500 B；(b) 同一权重用精确位姿重演代替 known 头，预测 FPR +0.5～+0.8 pp、过不了保护——这是诊断，给射线终止损失定基线。
- **A1（2 个租约，单变量 = 率项）**：臂 = 3S-Z2 周期 2 终点 + λR（λ 发射前在 TRAIN-24 上标定，使率项初值约为失真项的 10 %），续训 25.5k @ 1e-4；对照 = 3S-Z2 周期 2 终点（已有 run；若 3S-Z2 不被采纳，改从 3S-X 出发，字节线除以 4）。两种子都满足"实际 K0 消息 ≤ 1,024 B、收敛消息 ≤ 1,536 B（现 8,192 B），Δ R8 表面 ≥ −0.5 pp，Δ 家具 ≥ −1.5 pp，三项保护过"→ 率杠杆成立。披露：臂多一个周期（历史上 +0.3～+1.5 pp），落在 [−0.5, +0.5] 时采纳前补跑 λ = 0 同起点续训（再 2 个租约）。预测：K0 450–700 B，Δ R8 −0.3 ± 0.6 pp；任一种子字节 > 1,024 或 Δ R8 < −0.5 即证伪。

## 3. 设计 B：先验优先的教师潜空间 + 真高斯 GBP

**一句话**：先在整房真值世界上训练带熵模型的世界自编码器（教师），再让每个智能体从局部观测预测教师潜变量的高斯后验（Gaussian NLL 蒸馏），智能体之间做信息相加的高斯 GBP（森林上精确），解码器 = 教师解码器 + 传感器重演。

**为什么两个指标一起涨**：世界比观测便宜也好画——整房真值世界 739 B < R8 并集的 S 1,538 B；同为 2×2×1 OR，世界 485 B 时家具 .825，观测 S 703 B 时只有 .754（`p4`）。监督密度 ×3–8：现在目标只有 13 %（K0）/ 36 %（R8）体素已知，教师每个体素都有标签，矮家具和细部件在完整世界里是连续形状。融合差的一半来自选源，校准过的共享潜空间里两半观测可以相加而不是二选一。**量级**：教师整房码 400–600 B；每个智能体只发 Λ 超阈值的竖柱（K0 约覆盖整房 25–40 %）：K0 150–250 B，收敛 250–350 B + 位姿 ≈ 330 B——相对 ctx 三态 5.3、gzip 11、原始 400、真正无损 1.8 倍；熵模型以本边已交换内容为条件，只算新息。**F1 预计**：家具 .80–.88，R8 表面 .94–.96，K0 .95–.97，可变 .89–.92。

**底线**。索引集同 A；竖柱 stalk 是教师潜变量 z_c ∈ ℝ⁸ 的对角信息形式 (η_{i,c}, Λ_{i,c})，发"似然消息"（后验减先验 N(0, I)，防止先验重复计数）；Λ 在对数网格上向下取整，η 在均匀网格上。能量是恒等限制映射下的高斯 sheaf Laplacian：

$$E(z)=\sum_i\sum_c\tfrac12\,(z_{i,c}-\mu_{i,c})^{\top}\Lambda_{i,c}(z_{i,c}-\mu_{i,c})+\tfrac{\gamma}{2}\sum_{(i,j)\in T}\sum_c\lVert z_{i,c}-z_{j,c}\rVert^2,\quad \gamma\to\infty .$$

森林 T 上 GBP 是有限步精确消元：直径轮后信念 = (Σ_comp η, Σ_comp Λ) = E 的最小点。Lyapunov 量 Φ(t) = Σ_i Σ_c tr(Λ*_c − Λ^{(t)}_{i,c}) ≥ 0，消息是增长子树上非负信息的和，单调不增。Λ 向下取整只让融合更保守，Φ 仍不增；变长消息省略的竖柱就是 0 信息。电台图若有环，改用协方差交叉。

**架构草图**。阶段 A（教师，无通信）：E_T 把真值世界编成 64×64×8 潜变量 → 量化 + 超先验 → G（Decoder3D W2 族）→ 全体素占据；损失 = 全体素表面加权 BCE + λR；随机遮掉 50–80 % 竖柱，逼潜变量"可局部解码"。.057 s / 步，一个租约约 11.6 万步；数据 = 全部 20,366 个 TRAIN 户型的真值世界（不做射线）+ 家具重采样 + 8 种二面体对称（生成规则对翻转与转置不变，免费且精确）。阶段 B（学生）：E_S 把自己的地图 + 位姿编成 (μ, log Λ)，损失 = 对冻结教师潜变量的高斯 NLL；.03 s / 步，3 万步约 15 分钟。阶段 C：`rollout` 的 select 换成信息相加 → G → 各 hop 的 BCE + 射线终止损失 + λR，一起微调一个周期。参数约 3.8 M。

**风险**：竖柱内看得见与看不见的内容纠缠在同一个潜向量里，学生在决定可见部分的维度上也不确定，高斯相加会把不一致的假设平均成模糊；遮挡训练只能缓解。三阶段 × 两种子，租约多；学生上限就是教师的率失真点。

**最小可证伪实验 B-gate（新族门槛，1 个租约，两种子各约 2,600 s 顺序跑）**：只训教师。预注册：24 个 VAL 真值世界上，实际码长中位 ≤ 500 B 时表面 F1 ≥ .95、家具区 ≥ .90（对照：经典 2×2×1 OR 在 485 B 只有 .854 / .825）。两种子都过才进阶段 B，否则 B 线只花这 1 个租约。

## 4. 设计 C（激进）：程序 + 残差 sheaf

**一句话**：把世界写成生成器的"程序"——每个公共锚点（L/16，约 1 m）2 个物体槽（类别、足迹、朝向、≤ 3 个高度），64×64 墙格，每个智能体一个位姿；用生成器免费给出的真参数做有监督训练（不需要可微渲染），解码器 = 生成器自己的光栅化 + 传感器重演；程序解释不了的体素由 A 的码兜底。

**为什么两个指标一起涨**：这个世界里地图是约 300 B 程序的确定性函数（DL：自己的图 107 B、R8 并集 306 B、收敛消息约 200 B）。精确渲染按生成器约定画出 4–5 cm 桌腿、3 cm 层板——正是体素码系统性漏掉的（0–0.3 m 家具召回 .58）。学习问题从"重建 52 万体素"变成"检测约 14 件轴对齐物体并回归 7 个参数"，标签精确，BEV 检测器一个租约 20 万步以上。**量级**：K0 100–150 B，收敛 200–250 B + 位姿 ≈ 230 B——相对 ctx 三态 7.6、gzip 16、原始 570、真正无损 2.6 倍。**F1（合成世界）**：检测召回与精度 ≥ .95、参数按 R1 格量化时，家具区 .85–.95，R8 表面 .95–.98，K0 .96–.98。

**底线**。索引集：锚点槽 (a, s)（16×16 × 2）⊔ 墙格 64×64 ⊔ 智能体。槽 stalk：存在与朝向 log-odds、类别（top-1 + 置信）、足迹偏移 b ∈ ℝ⁴ 与高度 h ∈ ℝ³ 的高斯信息形式；墙格：log-odds + 子格偏移的高斯；位姿。给定关联时能量是森林上的 Bethe 自由能（树上等于 Gibbs，精确）；关联由相邻锚点之间的鲁棒项处理：

$$E(\theta)=\sum_i\sum_{a,s}\Big[\tfrac12\lVert\theta_{a,s}-\mu_{i,a,s}\rVert^2_{\Lambda_{i,a,s}}-\ell_{i,a,s}(e,\kappa,\sigma)\Big]+\sum_{a\sim b}\rho\big(\lVert\theta_a-T_{ab}\theta_b\rVert^2\big),$$

T_ab 是平移限制映射（物体中心估计跨锚点时把参数平移过去，非恒等限制映射正是 sheaf 的用处），ρ 取截断二次。迭代是 IRLS 形式的 GBP：每轮最小化 ρ 的二次上界（majorize–minimize），能量单调不增；按 R1 格量化的误差 ≤ ΛΔ²/12，量化后的替代目标同样单调。

**架构草图**。编码器：BEV 2D U-Net（z 折进通道 32 × 3 = 96，128×128 → 16×16，宽 64–256），头：锚点热图（focal）、类别、足迹 / 高度回归（L1）、朝向；墙头：2D 分割 + 过梁 + 墙高 / 门高；约 4–6 M 参数、8.2 GMAC / 图。线路：参数熵编码（类别以房间类别、位置以墙为条件）；残差只编"目标 S 与渲染首击不一致"的体素（A 的码）。融合：参数信息相加 + 关联 IRLS。解码器：torch 版 `_make` + `rasterize`（须与 numpy 生成器在 100 套房子上逐体素一致）+ 光线重演。训练：阶段 1 有监督（标签来自 `world_spec`，只标至少一个体素落在 S 里的物体）；阶段 2 融合与精度校准（NLL）；阶段 3 残差码。

**风险**：漏检一件衣柜就是几百个体素，F1 对检测召回极敏感；关联错误产生重复物体；只对生成器自己的家具库成立，真实数据上全落到残差（即设计 A），所以 C 的数字只能作为"知道生成器的编解码器"的上界单独报告；渲染约定必须逐体素复刻。

**最小可证伪实验**：C-gate-a（0 GPU，uk-linux CPU ≤ 15 分钟）：真参数量化（每件 31 bit、每顶点 14 bit）→ 渲染 → 精确位姿重演 → 与自己的地图比，预计 F1 ≥ .98、约 107 B；不过则 C 线不开 GPU。C-gate-b（新族门槛，1 个租约，两种子各约 1,400 s）：只训阶段 1（K0、无通信），预注册两种子 K0 家具区 ≥ .70、K0 表面 ≥ .93、每智能体 ≤ 200 B（对照 3S-X K0：2,048 B，家具 .55–.57、表面 .93）。

## 5. 大架构切换的纪律：单变量、两种子、对照是已有 run

1. **先复刻、后替换**。v500 默认路径与 v431 逐位一致（CPU 上 3 次更新后权重哈希相同），已有 run 继续当对照。不能逐位一致的改动（bf16、向量化 rollout、hop 采样、WSD 日程）合成一个**数值等价批**：L1 配方 16k × 两种子对已有 `l1-s*`，|Δ R8| ≤ 0.7 pp 且提速 ≥ 1.6 倍才启用，否则全线 fp32。
2. **函数保持扩展 + 同起点续训**。新部件初始化成零作用（新通道零初始化、λ 从 0 爬升），从当前最好检查点开始；对照是同起点同日程不加部件的续训，或已有终点（披露续训偏差、收紧判据）。每种子只要一个周期（1 个租约），不是从头两周期。A 的每一步都这样走。
3. **不能扩展的新族单独立系**。B、C 先过 ≤ 1 个租约的绝对门槛，再做预注册组合批（像 D8-25，判据是在 (F1, 每边全程字节) 上 Pareto 支配当前最好），通过后它自己的两种子 run 成为新谱系对照，再做单变量归因；两类结论不混写。
4. **四级便宜代理**：(a) CPU 天花板（本文的 S / W / 参数曲线）；(b) 只评估批（像 3S-DR）；(c) K0-only 筛选：8 次解码、.08 s / 步，一个租约装 5 个 16k 运行；3S-W、3S-C、3S-Q、3S-T、L1、L3、3S-Z 七批里 K0 与 R8 方向全部一致（L2、3S-S、3S-Y 两边都约为 0），但 64×64 时 R8 增益是 K0 的 2–3 倍，所以只筛表示与编解码器，不筛融合；(d) 单租约 16k：已结案两例（L1 → 3S-X、3S-S → 3S-Y）里 16k 的判读方向在 51k 上都成立，3S-Z → 3S-Z2 是第三例。
5. **止损**。12k 之前不按 VAL F1 掐（3S-C 在 12k→16k 跳了 +13 pp）。只在这些情况掐：发散；率塌缩（8k 时字节低于目标 30 % 且 VAL 掉 5 pp 以上）；两种子在相同 ∫lr 处每单位 LR 积分的损失下降都低于对照的一半（分析 B 的效率度量）；结果落在预注册预测区间之外——先诊断再花下一个租约。每族两次门槛不过就停；两周上限 A ≤ 14、C ≤ 8、B ≤ 8 个租约。
6. **多少步才"可判读"**。漂移受限区里进展 ∝ ∫lr（分析 B）：先跑 4k，按 2k 块拟合 loss = a − b·ln S（S = ∫lr），外推到对照终点损失所需的 S；超过对照 2 倍预算而渐近值又不明显更好的不进全程。判读线 = 两种子差 < 1 pp 且最后 1/4 的增益小于配对 SE（.5–.8 pp）。WSD 日程（75 % 恒定 + 25 % 线性降到 5 %）同样步数 ∫lr ×1.68，可把两周期压进一个租约，放进数值等价批一起验。
7. **课程、蒸馏、混合精度**。λ 爬升防早期塌缩；hop 课程（前 1/4 只训 K0）省约 20 % 时间；蒸馏两处——B 的教师 → 学生，以及用"并集直编"oracle 解码器的软目标教融合后验的解码器；bf16 只给 3D 卷积，融合、熵模型 CDF 尾部和损失保持高精度。
8. **数据**。A 不加数据（3S-S、3S-Y 两次否定）；B 的阶段 A 用全部 TRAIN 户型的真值世界；C 只需物体标签；位姿重采样（GPU 重演）现在不是瓶颈，不排。

## 7. 排序推荐与别的视角最可能犯的错误

**排序**：
1. **W-Sheaf（A）**：成功概率最高，两条轴同时动，改动最小；它的重演和变长线路是 B、C 的必经部件，也是 C 在真实数据上的退路。
2. **程序 + 残差（C）**：唯一能到"相对 gzip 15 倍以上、家具 .9"的路线；标签精确、门槛只要 1 个租约，但只在合成世界成立，单独作上界报告。
3. **教师潜空间 + 高斯 GBP（B）**：理论最干净（真正的信息融合），但三个阶段、纠缠风险最大；门槛不过就停。

**别的视角最可能犯的错误**：
1. 拿 ctx 三态当"最强无损"。观测是 (相容世界, 位姿) 的确定性函数，真正的无损每条收敛消息 589–1,032 B，ctx 三态把"相对无损 N 倍"夸大 1.7–3.0 倍；全保真时相对真正无损最多再省约 3 倍，"几十倍"只能对 gzip、原始栅格或有损地说。
2. 没注意空闲区不计分：丢掉可见性的码会白捡 F1 和码率，必须加 free-space recall 保护；反过来，把重演直接套在旧权重上会漏光（+0.74 pp FPR）。
3. 用扩散 / flow 做逐体素解码。逐体素 F1 的最优判决是后验边缘阈值，采样只加伯努利噪声（感知—失真权衡）；生成模型该放在熵模型（码率 = 先验下的交叉熵）和 U 区补全（免费）里。20 步采样每步就是 20 倍解码器算力，一个租约训不出东西。
4. 按"每轮每条消息"报字节：定长同步 8 轮是每边 16 KB，只发变化后约 1.44 倍收敛消息。
5. 低估新结构的训练时间：DETR 式集合匹配要上百个 epoch，一个租约装不下，应当用锚点式稠密头 + 生成器免费标签。
6. 以为新结构需要更多数据而先花几天 CPU 生成缓存：缺的只是三个补充字段（约 1 小时）。
7. 熵模型的 −log₂p 不经编码器往返就当码率（存在图、边信息、CDF 精度、头部常差 10–30 %）；把 sum 型高斯 GBP 搬到有环的通信图上（精度放大 875–1,582 倍）。

探针：`probes/A09/` 的 `p1_surface_rate`、`p1b_world_interval`、`p2_raycast`、`p3_compute`、`p4_lossy_world`、`p5_change_only`（各有同名 `.json`）；`a09lib.py` 是不依赖 torch 的度量与 ctx 编码复刻。
