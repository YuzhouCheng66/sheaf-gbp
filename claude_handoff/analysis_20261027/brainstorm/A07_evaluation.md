# A07｜评估设计与系统层面的怀疑者：什么样的结果才"有意义"

A07，2026-10-27 UTC。只用本机 CPU，没查文献，没碰 GPU、uk-linux、`runs/`、`scripts/`。数据是 6 套 VAL 演示房子（原始自己地图与 3S-X 预测）。另外我用已知位姿把这 6 套房子按 v420 传感器重新模拟了一遍（`sim_cache/`，光线行进与原代码逐位一致），用来测"解码端重投射"类方案。脚本和 JSON 都在 `probes/A07/`（p0–p9，文件头写了方法）。除另注外，字节取 48 张自己地图或 48 行 R8 并集的中位数，F1 取 metrics3d 拷贝的均值。

## 0. 结论

1. **证据包里的"最强无损"并不最强。**
   - 自己的地图是"命中集 H（被打中的占据体素）+ 位姿 + 公开波束"的确定性函数。射线一定停在路径上第一个 H 体素，因为 H 全是真占据，射线经过的体素全是真空闲。
   - 把 H 用同样的 9 邻域 KT 编码、附上位姿，接收端重投射，48 张自己的地图和并集**逐体素 0 误差**（p1）。位姿必须在建图前量化（约 10 B/机；表中按 5.5 B/机计，差 4.5 B，不影响结论）；事后把位姿取整到 1 cm 会错 40–1,683 个体素。
   - 码长：自己的地图 **574 B**（ctx 的 1/2.4），R8 并集 **1,582 B**（1/1.8），树边内容 **970 B**（1/1.8）。
   - 这个编码本身就满足底线：stalk = 每根公共竖柱的三态体素向量（精度 0/∞）；融合 = 现有的逐格 max（stream_targets 就是它）；能量 = 格上的缺失量。下文叫它**精确格层 ELS**。它的 K0、R8、家具 F1 恒为 1。
2. **我们在率—失真平面上被支配。**
   - ELS 用 573 B 得到 F1 = 1；三态 2×2×1 降采样用 584 B 得到家具 .764（容差 1 .964，物体部件召回 .961，幽灵 0）；我们用 2,048 B 只得到家具 .524（容差 1 .703，部件召回 .462，每机 0.4 个幽灵部件）（p2、p7）。
   - 放宽一格后差距仍有 26 pp。所以问题不在度量太苛刻，而在码里没有家具信息。
   - 把现有码改成"只发有证据的坐标 + 4+4 bit + 索引按组合熵"约 260 B，也只是勉强压在经典 4×4×1 曲线（248 B，家具 .465）上方。
   - **64×64×1 即使稀疏编码也要约 925 B，比 ELS 还贵。** 3S-Z2 即使把家具做到 .65–.70，在这个世界里仍被精确无损支配。
3. **按网络总账，现系统比无损贵 18 倍。**
   - 训练器模拟的是 8 轮 × 14 条有向边 × 2 KB = 229 KB/次融合；ELS 两趟协议只要 12.9 KB；ctx 洪泛 69 KB（p5）。
   - 网内 join 相对洪泛省 **2.4×**（30.6 → 12.9 KB）。这是 sheaf/GBP 融合目前唯一被实测、能写进论文的码率优势。
   - "定长消息不随并集增长"在有界的房子里不是优势：无损边内容从 1 个智能体到 7 个只涨 2.2×。
4. **在无噪声世界里，"相对最强无损几十倍"在全保真下不可能。** 参数描述长度只比 ELS 小 5.4×（107 vs 574 B）/ 5.2×（306 vs 1,582 B）。"几十倍"只有三种诚实的写法：(a) 相对部署中的做法（gzip 或 OctoMap .bt 洪泛，约 150 KB/次融合）；(b) 相对 raw（7.3 MB）；(c) 在真实噪声下，相对"无损传输噪声图"。
5. **真实噪声让无损既更贵、又不再"无损"**（p3）。
   - 以类深度相机噪声为例：1.5 % 量程、10 % 漏测、0.5 % 离群、位姿 2 cm/0.5°、机间 5 cm/1°。自己地图的 ctx 变为 ×1.8，并集变为 ×2.4。
   - 无损送达后按真值打分，K0 表面只有 .918、家具 .775；R8 .875 / .756。
   - 机间坐标误差单独就让并集家具掉 16 pp（5 cm/1°）到 29 pp（10 cm/2°）。任何编解码器都救不回来，只有能估计相对位姿的融合能救。
   - 噪声下，现行 max 规则比树上 log-odds 求和差：表面 5–9 pp，家具 8–18 pp。
6. **合成世界的偏差是双向的。**
   - 轴对齐让体素无损占便宜：世界整体转 45°，ctx ×1.44、ELS ×1.76，而参数 DL 不变（p4）。
   - 但 22 类、每件约 31 bit 的家具库让语义码占的便宜更大（生成器泄漏）。
   - 净效应只能由旋转、留出家具和真实扫描面板回答。
7. **头号设计 D1（GELS）= ELS + 学习的条件生成熵模型。**
   - 无噪声基准上 F1 恒为 1；自己的地图 574 → 预计 320–430 B；网络 12.9 → 7–10 KB/次融合。
   - 对现系统 23–33×，对 gzip/OctoMap 洪泛 15–22×。
   - 用户说的"压缩—生成"在这里是字面意思：码长 = −log₂p，算术解码器就是被比特流驱动的生成采样器。

## 2. 压缩率怎样定义才诚实

**2.1 定义**

- 码率只认实际熵编码后的比特。位姿、索引、头部（≥ 2 B/消息）全部计入。
- 分三层报告：单条消息 R_msg；一次 R8 融合全网所有链路、所有轮次的 R_net（**主指标**）；单机最大发送 R_agent（瓶颈链路）。持续建图另报每次更新的字节和每秒比特。
- 质量点 Q 由五项组成：家具区 F1（容差 1）、家具区 F1（精确）、物体部件召回、表面 F1、FPR。
- 比率只在同一质量点上比：CR_X = R_X(Q) / R_ours(Q)，其中 R_X(Q) 是基线族 X 达到 Q 所需的最小码率。
- 无损基线的 Q 恒为 1，所以"相对无损多少倍"只是一个宽松的说法。主标题必须是两项：在家具 F1 容差 1 ∈ [.85, .98] 上对经典有损凸包的 BD-rate，以及对 ELS 的 R_net 比。

**2.2 必备基线**（全部用同一 metrics3d 打分，在 p1–p9 里都已实现）

- B0 raw：只放附录。分辨率换成 R2，它会白涨 8 倍。
- B1 gzip 和 lzma。
- B2 OctoMap .bt（+gzip）：这是部署中的 ROS 系统真正在发的东西。
- B3 ctx。
- B4 ELS-KT：最强无损，也是"不学习的 sheaf"对照。
- B5 经典有损凸包：三态块降采样 + ctx。
- B6 只传墙：自己的地图约 60 B，并集约 150 B；精确解码时 K0 表面 .915、R8 表面 .900（D8-18）。这说明表面 F1 不能当主指标。
- B7 洪泛与网内 join 的消融。
- B8 集中式上限。

**2.3 评估协议 v5**

1. 面板：VAL-24 两种子主判，fresh-24 复核，TEST 封存。另加三块"真实性面板"：
   - 噪声面板：p3 的 cam 和 harsh，按真值打分；
   - 旋转面板：世界整体转 15° 和 30°；
   - 留出家具面板：训练时去掉书架、圆桌、汽车，测试只看含它们的房间，专门抓生成器泄漏。
2. 质量（K0、R8 都报）：
   - 家具区 F1（精确与容差 1）；
   - 部件召回与幽灵；
   - 表面 F1；
   - 二维障碍 F1（容差 1）；
   - FPR；
   - 以上按 0–0.3、0.3–0.9、> 0.9 m 分层。
3. 判据：任何"压缩"主张必须同时满足三条：
   - 在 RD 平面上不被 B5 支配；
   - R_net 低于 B4；
   - 两种子与三块真实性面板的方向一致。
4. "实用"线：家具容差 1 ≥ .95，部件召回 ≥ .95，幽灵 ≤ 0.1/机。经典 2×2×1 已经做到 .96、.96、0。

## 3. 三个设计

### D1（头号，1 个租约可证伪）GELS：精确格层 + 学习的条件生成熵模型

**① 一句话。** stalk 是每根公共竖柱上自己观测到的三态体素（精度 0/∞）；融合沿用现有逐格 max-join；消息只发"新命中 + 位姿"，用一个以接收方已有内容为条件的学习生成模型做算术编码；解码端用公开波束重投射。结果是所有 F1 恒为 1，码率只取决于生成模型有多好。

**② 论证与量级。**

- 地图 = f(H, 位姿)，所以信息量就是 H 在最好概率模型下的码长加上位姿。可见性边界占 ctx 码长的 77 %，给定位姿后它是免费的。
- 因为解码是精确的，家具 F1 = 1 不需要任何容量，学习只用来压码率。
- KT 9 邻域已测得 574 B。预训练计数上下文只再省 5 %，所以要靠神经模型去学平面延伸、遮挡边和家具形状。我估计能到 0.55–0.75×：**320–430 B/自己的地图**（取 380 B），并集约 1,000 B，**网络约 8.5 KB/次融合**。
- 倍数，按自己的地图 / 一次融合的网络总账计：

  | 对比对象 | 自己的地图 | 网络 |
  |---|---|---|
  | ctx（网络列为 ctx 洪泛） | 3.6× | 8.1× |
  | gzip | 7.2× | 18× |
  | OctoMap .bt+gzip | 7.1× | 17.7× |
  | raw | 345× | 864× |
  | 现系统 | 5.4× | 27× |
- 不训练的 KT 版今天就能做：574 B / 12.9 KB。
- 预计 R8 表面 = K0 = 家具 = **1.000**（无噪声；解码逐体素断言）。
- 持续建图每次更新 237 B，比定长重发少 8.6×。KT 对每条小消息都要重学统计：12 次增量累计 2,672 B，是终图 963 B 的 2.8×。这一块恰好是预训练模型能拿掉的。

**③ 底线。**

- 索引集 C = 公共竖柱，按 32×32 分组以便稀疏索引。
- stalk：x_{i,c} ∈ L^{32}，其中 L = {⊥ 未知（q = 0） < 空（μ = 0，q = ∞） < 占据（μ = 1，q = ∞）}。另加位姿 stalk（集合格）。
- 消息与信念（与 rollout_max 同式，元素从高斯坐标换成体素）：

$$m_{i\to j}(t)=x_i\sqcup\bigsqcup_{k\in N(i)\setminus j}m_{k\to i}(t-1),\qquad b_i(t)=x_i\sqcup\bigsqcup_{k\in N(i)}m_{k\to i}(t)$$

- 能量（x\* 是分量内的 join，即全局截面）：

$$\Phi(t)=\sum_i\sum_{c,z}\big[r(x^\star_{c,z})-r(b_{i,c,z}(t))\big]\ \ge 0,\qquad r(\bot)=0,\ r(\text{空})=1,\ r(\text{占据})=2$$

- 单调性：归纳得 m(t) ⊒ m(t−1)，所以 b(t+1) ⊒ b(t)，Φ 不增；t ≥ 树直径时 Φ = 0。这就是 Tarski Laplacian 调和流的不动点。
- 变长消息：只发 Δm(t)，即相对 m(t−1) 上移了的格。接收方保留旧消息，用 m(t−1) ⊔ Δm(t) 精确复原 m(t)，所以轨迹和 Φ(t) 与定长消息逐步相同。算术编码无损，没有量化。

**④ 架构。**

- 协议：两趟协议，或现有 8 轮同步加事件触发。
- 概率模型 p_θ(H_Δ | 接收方已有的 H, 位姿特征)：
  - 先粗级（2×2×2），再全分辨率；每级 8 组棋盘自回归；3D 卷积，1–2 M 参数；
  - 位姿只以"量程球 + 光线密度"特征图的形式输入；
  - 训练时随机旋转世界（针对表 6 的偏差）。
- 解码 = 逐组解码 + 重投射（numpy 约 0.5 s/位姿）。
- 链路有硬预算时先发粗级，这自然就是一个渐进码。

**⑤ 风险。**

- 学到的增益可能只有 1.2–1.4×（这是我对三维占据学习熵模型的经验量级）。那就是"精确 + ≈ 450 B"：质量上仍支配一切有损设计，但对 gzip/OctoMap 只有 12–15×。
- 熵模型可能记住生成器，导致 OOD 增益消失。
- 精确性有两个工程前提：解码端的光线行进必须与编码端逐位一致（建议改成整数 DDA，避免跨硬件浮点差异）；传感器必须无噪声。噪声下带噪图不满足重投射一致性，ELS 不再精确，只能传三态噪声图（贵，见表 5），或者走 D2。
- 最可能的失败方式：上下文稀释或过拟合，VAL 增益不到 10 %。

**⑥ 最小可证伪实验。**

- 单变量：熵模型（KT 9 邻域 → 学习模型）。解码器、融合、数据都不变。
- 对照：同一批 VAL-24 地图（192 张自己地图 + 全部 R8 并集）的 KT 码长，是确定性的。
- 种子：342101 / 342202，各训练约 40 分钟，一个租约内完成。
- 预注册判据：
  - 两种子都满足"自己地图中位 ≤ 0.70 × KT 且并集 ≤ 0.75 × KT" → **杠杆**，成为新基线；
  - 任一种子 ≥ 0.90 × KT → **不比对照好**；
  - 其他 → ambiguous。
- 断言：其中 24 张地图做真实的算术编码再解码，必须逐体素 0 误差；其余地图用 Σ−log₂p 计码长。
- 只报告：旋转 30° 的房子；12 位姿步行的累计增量。

### D2（任务定义改动；CPU 已部分证伪，模型需 2 个租约）：真值评分的噪声世界 + 先验去噪证据格层

**① 一句话。** 在模拟器里加入真实传感器误差，目标改成"干净传感器在真位姿下看到的东西"（仍只评观测区）；消息是"学习先验 MAP 去噪后的证据"的创新。无损传输噪声图既贵又达不到真值 F1，只有在这里，"相对无损十几到几十倍"才是诚实的。

**② 论证与量级。**

- 噪声不可压缩：无损编码器必须原样送过去，任务感知的编码器可以丢掉它。
- cam 条件下，无损送达的代价是自己地图 ctx 2,472 B（gzip 4,570），并集 6,624 B（gzip 12,024）。换来的只是 K0 .918 / .775、R8 .875 / .756。
- 如果去噪码能压到 D1 的水平（380 B / 约 1,000 B）：自己的地图对 ctx 6.5×、对 gzip 12×；并集 6.6× / 12×。
- 如果压到 D3 的图元级（约 160 B / 约 400 B）：自己的地图 15× / 29×，并集 17× / 30×。
- 预计（是要验证的目标，不是测量值）：K0 表面 ≥ .94，家具 ≥ .83（地板 + 5 pp）。R8 如果机间误差被 D3 消掉，能到 .955 / .915（cam 无机间误差时的地板）；否则约 .90 / .80。

**③ 底线。**

- stalk：每格量化 log-odds ℓ̂ ∈ {−15, …, 15}，向零取整（只会低估证据），|ℓ̂| 就是精度。
- 融合：通信图是 Kruskal 森林，所以在树上做整数求和。在独立噪声下这就是精确 BP（channel filter），不会重复计数；有环时退回 CI-max。
- 能量：S_i(t) 是 i 已计入的智能体证据集合，在树上它单调增大，每个因子恰好计入一次：

$$\Phi(t)=\sum_i\big|\mathcal V_{\mathrm{comp}(i)}\setminus S_i(t)\big|,\qquad b_i(t)=\sum_{u\in S_i(t)}\hat\ell_u$$

- Φ 不增，直径步内降到 0。整数求和没有舍入；变长消息只发子树和的增量，论证同 D1。
- 去噪只在编码端（发送前 MAP）和解码端（读取后 MAP）做，不进入融合迭代。

**④ 协议草图。**

- 光线层误差（照抄 p3 的 measure 和 integrate）：量程 σ0 + k·r、漏测、早返回离群、每位姿平移/偏航误差、每机坐标系误差。
- lidar、cam、harsh 三档的参数和种子固定。
- 必须报告：无损噪声图的码率和地板、经典去噪码、我们，全部按真值打分。

**⑤ 风险。**

- 目标从"传自己看到的"变成"传世界"，需要用户认可。它仍只评干净观测区，不奖励补全。
- 最可能的失败方式有两种：先验去不过地板（1 格级的表面抖动很难靠先验校正）；或者编码端的 MAP 把真家具当噪声抹掉。

**⑥ 最小可证伪实验。**

- (a) uk-linux CPU，≤ 15 min：把 p3 扩到 VAL-24，用真抖动位姿，跑两个噪声种子。
  - 预注册：cam 下自己地图 ctx 膨胀 ≥ 1.5×，且 R8 家具地板 ≤ .80。两种子都成立 → 噪声面板成为必报面板。
  - 现有 6 套房子已经给出 1.8× 和 .756。
- (b) GPU，2 个租约：
  - 先生成 1,600 套 cam 噪声缓存：约 14 核 × 1 h，超出探针规则，需要用户批准或排在 GPU 训练间隙。
  - 配方：3S-X 32×32，16k 次更新，两种子。
  - 单变量：训练目标（带噪自己地图 vs 干净自己地图）。输入都带噪。
  - 预注册：两种子都满足"干净目标臂 − 带噪目标臂 ≥ +5 pp K0 家具（按真值），且干净目标臂 ≥ 地板 + 3 pp" → 去噪码成立。

### D3（非常激进）：图元超先验 + 位姿 stalk 的配准感知层叠 sheaf

**① 一句话。** stalk 分三层：位姿（SE(2) + 高度）、结构与物体图元槽（墙段，带偏航的盒子和圆柱），以及 D1 的精确命中残差。限制映射是"按估计位姿把图元搬到公共坐标"。GBP 在森林上对位姿和图元做块坐标下降，并对残差做格 join。图元同时充当残差熵模型的超先验。

**② 论证与量级。**

- DL 是"知道生成器的编解码器"所需信息的上界：自己的地图 107 B，并集 306 B。
- 图元精确时残差为 0：
  - 对 ELS 5.4× / 5.2×，对 ctx 13× / 9×，对 gzip 25× / 20×，对 raw 1,225× / 428×；
  - 网络约 2.8 KB/次融合：对 ELS 4.6×，对 gzip/OctoMap 洪泛约 54×，对现系统 82×。
- 图元抽取不完美时，假设残差约为 ELS 的 10–20 %：自己的地图约 160 B，网络约 4 KB；对 ELS 3.2×，对 gzip 洪泛 38×。F1 仍恒为 1（由残差保证）。
- 更关键的是配准。机间误差 5 cm/1° 让并集家具从 .915 掉到 .756，10 cm/2° 掉 29 pp。墙平面让相对位姿可观测；目标是把并集拉回无机间误差时的地板（.955 / .915）。
- 这是 sheaf（非恒等限制映射）相对"无损体素传输"唯一的结构性优势：后者的码再好，拼起来的图也是糊的。

**③ 底线。**

- 索引集 = {每机位姿 T_i} ∪ {公共 1 m × 1 m 格内的 4 个图元槽（按位置规范排序以便对齐）} ∪ {D1 的竖柱}。
- 槽内容 θ_{i,k} = (类别, 中心, 尺寸, 偏航, z 区间)，精度为 Λ_{i,k}。
- 能量：

$$E(T,\theta)=\sum_{(i,j)\in E}\sum_{k\in K_{ij}}\rho\Big(\big\|A_k(T_i)\theta_{i,k}-A_k(T_j)\theta_{j,k}\big\|^2_{\Lambda_k}\Big)+\sum_i\big\|\mathrm{Log}(T_i^{-1}T_i^0)\big\|^2_{\Sigma_i^{-1}}+\lambda\,\Phi_{\mathrm{res}}$$

- 为什么不增：森林是二部图，两种颜色交替更新。一种颜色的智能体在固定的邻居消息下做一步阻尼 Gauss–Newton，也就是线性化问题的 GBP 消息；只有局部能量下降时才接受。这是块坐标下降，所以 E 不增。
- 量化：每个智能体先把自己的状态量化（1 mm / 0.01° / 1 cm），本地也只用量化后的状态，并且只在格点上接受下降步。所有人看到同一个状态，单调性照样成立。
- 残差层用 D1 的 join。位姿一变，残差层就无状态重算，不影响 E 的单调性。

**④ 架构。**

- 编码器：自己的地图 → 每格 4 槽的集合预测，加位姿协方差。
- 融合：上面的两色 GBP。
- 解码：渲染图元并重投射得到 H_prim，再用 p_θ(H | H_prim, 位姿) 解码残差。
- 编码端逐格选择"有图元"或"无图元"中更短的一种，所以 D3 永远不比 D1 差。

**⑤ 风险。**

- 最大的风险是生成器泄漏：换成真实家具后残差暴涨，比率退回 D1 的水平。
- 槽的集合预测和对齐工程量大。
- 对称房间、门洞会造成配准的局部极小。
- 最可能的失败方式：图元 + 残差 > 0.8 × ELS，超先验不划算。

**⑥ 最小可证伪实验（uk-linux CPU，≤ 15 min）。**

- 用 world_spec 的真值图元和真位姿渲染 H_prim，测 ctx(H | H_prim) + DL + 位姿。
- 三个扰动，各两个种子：坐标量化到 2 cm；随机漏掉 10 % 物体；世界整体转 20°。
- 预注册：三种扰动下中位都 ≤ 0.5 × ELS-KT → 值得建学习编码器；任一 > 0.8× → 放弃，回到 D1。
- 只报告：在 cam 面板上用真值墙段做一次 oracle 配准，作为上限。

## 4. 排序与对其他视角的挑战

**排序**

1. **D1。** 不训练今天就能得到 F1 = 1、12.9 KB/次融合（比现系统少 17.8×）。学习只决定再省多少，1 个租约可证伪。它也是之后任何有损设计必须打败的对照。
2. **D2。** 不改评估，任何"相对无损几十倍"都不诚实。它还暴露了现行 max 规则在噪声下家具 8–18 pp 的损失。
3. **D3。** 唯一能在无噪声世界对最强无损做到 3–5×、并在错配世界里做出 sheaf 独有优势的路线，风险也最大。

**其他视角最可能犯的错**

1. 拿 raw 128 KB 当分母（64×、1,200×）：分辨率换成 R2 就白涨 8 倍，内容并没有变。
2. 把 ctx 当最强无损：ELS 小 2.4× / 1.8×，而且它本身就是满足底线的 sheaf。
3. 只算一条消息：定长 GBP 一次融合发 112 条，总量比 ELS 贵 18×。"每条 2 KB"的说法会把结论方向搞反。
4. 用表面 F1 当主指标：只传墙、精确解码就有 K0 .915 / R8 .900。
5. 把 DL 当学习码的可达目标却不做泄漏审计：世界一转 45°，体素码就涨 44–76 %；而语义码面对的反向偏差更大。
6. 生成式解码（diffusion 或 mean flow 采样）在低码率下拿"像"换"准"：F1 会惩罚幻觉，所以必须报部件召回和幽灵（我们现在每机已有 0.4–1.1 个幽灵部件），并且解码要用后验均值或 MAP，不要用一次采样。
7. 用定长码和变长基线做等字节比较：K0 时约 79 % 的坐标没有证据；64×64 稀疏后仍要 925 B，比 ELS 的 574 B 还多。
8. 噪声缺席时宣称"相对无损几十倍"；或者加了噪声却仍把带噪的自己地图当目标，等于把噪声当信号奖励。
9. 继续用 max 规则融合带噪证据：树上 log-odds 求和的家具 F1 高 8–18 pp，而且在树上不会重复计数。
