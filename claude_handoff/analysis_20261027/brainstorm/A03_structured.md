视角：物体中心 / 结构化表示、analysis-by-synthesis、可微渲染与光线投射。2026-10-27 01:07 UTC 定稿（`date -u`）。独立思考：没有读其他成员的稿子，没有查文献。数字要么来自证据包（注"证据包"），要么来自我今天在本机 CPU 上的探针（P0–P10，脚本和输出在 `probes/A03/`，见文末）。探针用从 uk-linux 只读拷来的 36 个 VAL 房子的 HouseExpo json，在本机用同一个 v420 生成器（sha 与 uk-linux 一致）重建 24 个 VAL 房子，与演示数据逐位一致（6/6）。没有用 GPU，没有碰 uk-linux 上的进程、`runs/`、`scripts/`。

## 0. 一页结论

1. **可见性是白送的。** 192 张 own map 全部逐体素等于"它自己的击中集合 + 自己 3 个位姿"的首次命中光线投射；192 个 R8 目标全部逐体素等于"目标的击中集合"从所有已到达智能体位姿投射后的格并（P1，192/192、192/192）。证据包里占无损比特 69–77 % 的 known 掩码，信息量只是每个智能体几十 bit 的位姿。哪怕不懂任何结构，只把"击中集合 + 位姿"交给通用 3D 上下文编码器，own map 就从 ctx 1,259 B 降到 552 B（2.19×），R8 并集从 2,117 B 降到 1,287 B（1.65×）。
2. **这个合成世界在结构化语言里已经被"解完"了。** 一个不学习、不用家具库、不用真值标签的编解码器——平面图（墙 / 门楣列）+ 贪心实心盒子 + 位姿 + 层高，解码 = 画进体素再光线投射——每张 own map 中位 198 B（p10 74 / p90 331），用生成器的浮点位姿时 192 张里 190 张逐体素精确、另 2 张 F1 ≥ .9995（P8），用真值分割时 K0、R8 全部逐体素精确（P3）；把位姿按 44 bit 量化（已计入字节）后表面 F1 .998、家具 .994（P10）。对照：我们每条消息 2,048 B，家具区 F1 .58。
3. 所以现在的瓶颈不是信息论，也不是训练量，而是**表示**：把"可见性 + 几何"一起塞进一个让卷积解码器去读的定长竖柱码。坐标阶梯每级 +4–6 pp、字节 ×4，是在一条错误的轴上爬。
4. **反面同样重要：这个基准对结构化方法太容易**（轴对齐盒子、精确首次命中、精确位姿）。把同样的家具随机转 ±45°（P5），结构码从 245 B 涨到 394 B（盒子 62 → 109），对 ctx 的优势从 5.9× 降到 3.8×；加测距噪声（P6），σ = 2 cm 时 ctx 无损从 1,427 B 涨到 2,338 B（+64 %），而"无损的结构外壳"从 798 B 暴涨到 3,882 B——噪声下结构只能有损（去噪）地用，而且干净几何对噪声目标的精确表面 F1 只有 .37，评估目标本身也得换。任何"结构化 / 物体中心"的结论都必须在扰动世界和真实扫描上复核，否则就是对生成器的过拟合。
5. 我的推荐：**A（RAY-SHEAF）作为下一代表示**；B（RK-Δ）是现有学习线 1–2 个租约就能证伪的最小改动（注意 P4：不重训、只把 known 换成光线投射会略差）；C（学习的结构语言 = 骨架 ⊕ 残差）是走向真实数据的版本。

## 2. 设计 A（最激进）：RAY-SHEAF——消息是"可渲染的描述"，解码器是光线投射器

**A1 一句话。** stalk 仍是公共体素索引上的三态值（精度 0 或 ∞），融合仍是逐坐标最大精度 = 格 join；只换**线路语言**：每条消息是"发送侧并集"在"位姿 + 平面图 + 实心盒子"语言里的最短描述，接收方把它画进体素、从描述所带的位姿做首次命中光线投射，逐位还原；学习只用于这门语言的熵模型（先验）。

**A2 第一性原理与量级。**
- 地图 = 渲染(击中, 位姿)（P1），所以消息只需"击中了什么、从哪里看的"。known 掩码那 69–77 % 的无损比特，变成每个智能体 44–68 bit 的位姿（P10：44 bit 时表面 F1 .998、家具 .994；68 bit 时 .9998 / .9996；逐位精确要近乎无损的位姿）。
- 这个世界的击中是少数轴对齐实体的可见外壳：墙是平面图的竖直拉伸（P8：每张 own map 约 140 个墙列，平面图 32 B）；家具是盒子的并（P7：中位 47 个实心盒子，20.9 bit/盒）。一个 21 bit 的盒子替代了它平均约 34 个击中体素（P3），以及它在 known 掩码里投下的整片阴影——这就是比最强体素码少约 6 倍字节的来源。桌腿、桌面、层板都是体素精确的整数盒子，所以家具区 F1 = 1，而不是被 4 体素宽的码竖柱抹平。
- 每条消息的字节（熵编码后，含位姿、层高、计数、头部；24 个 VAL 房子的中位数，P9；盒子 token 的静态先验用其余 23 个房子的统计（留一法），部署时应换成 TRAIN 统计）：

|---|---|---|---|---|---|---|
| own map（K0 的内容） | **198 B**（p90 331） | 1,259 | 2,590 | 131,072 | 2,048 | **6.6× / 13.9× / 661× / 10.3×** |
| 有向边发送侧并集（一条收敛消息） | **317 B**（p90 618） | 1,658 | 3,485 | 131,072 | 2,048 | **5.0× / 10.3× / 414× / 6.5×** |

精度：用生成器的浮点位姿时 K0、R8 逐体素精确（P3：24 房，K0 192/192、R8 192/192；P8 无标签：190/192，余 2 张 ≥ .9995）；按表中计入的 44 bit 位姿，表面 F1 .998、家具 .994（P10）。也就是说预计 **K0 表面 .998（实测）、R8 表面 ≈ .998（同理推断）、家具区 ≈ .994**，而现在是 .929 / .908 / .58。

- 熵模型还能省多少：P7 的"相邻差分 + 联合表"已比逐字段先验省 19 %；学习的 AR 先验应落在它和生成器 DL（own 107 B）之间，预计 own 130–160 B。

**A3 底线（sheaf 向量 + GBP 式迭代 + 能量）。**
- stalk 索引集：(i) 体素 v ∈ 128×128×32，值 s_i(v) ∈ {⊥, 空, 占}，精度 0（⊥）或 ∞；(ii) 位姿 stalk 𝒫_a，a = 1…8，所有者精度 ∞；(iii) 全局 stalk (H_w, h_d)。盒子和平面图只是 (i) 在线路上的编码，不是新的状态变量。
- 融合：$s_i \leftarrow s_i \sqcup \bigsqcup_{j\sim i} \mathrm{Dec}(m_{j\to i})$，⊔ 为逐体素 max。两个已知值都来自真实观测，不会互相冲突。这就是现在的逐坐标最大精度选择，只是分辨率细到体素。
- 消息：$m_{i\to j} = \mathrm{Enc}\big(\mathrm{own}_i \sqcup \bigsqcup_{k\sim i,\,k\ne j}\mathrm{Dec}(m_{k\to i})\big)$——与现在完全同构的腔消息。中继先把已知的并集无损地重新拟合成一段描述再发（顺带去掉不同智能体对同一件家具的重复描述），只在内容变化时发，变长、算术编码。
- 能量：$E_A(t)=\sum_i\sum_v\big[\mathrm{rk}\,T^*(v)-\mathrm{rk}\,s_i^{(t)}(v)\big]$，rk(⊥) = 0、rk(空) = rk(占) = 1，T* 为连通分量的全局截面（= R8 目标）。每段描述都逐位还原某个"真实观测的并"，所以恒有 s_i ≤ T*；每步更新是 join，E_A 单调不增，树上 ≤ 7 轮归零，而且任一时刻 s_i 恰好等于当前 hop 的 stream target（K0、R1、R2、R4、R8 全部精确）。有环时 join 幂等，不会像 sum-GBP 那样重复计数（证据包：放大 875–1,582 倍）。这与 D8 的 Tarski Laplacian 调和流是同一个能量，只是格更细。
- 量化与变长：盒子坐标是体素格整数，Enc/Dec 无损，不存在"量化后能量上升"；能量只依赖内容，码长只影响字节。
- 为什么不需要跨智能体的数据关联：实心盒子会向"自己没看到"的空间多填，不同智能体的实心盒子直接并起来再统一渲染会互相挡光（P3：把各智能体的实心盒子直接并起来、从全部位姿统一渲染，R8 只有 17/192 逐位精确，但只损失表面 .13 pp、家具 .55 pp；按"每段描述只从自己的位姿渲染再 join"则 192/192 精确，代价是不去重时字节 ×2.6：中继各自的描述 1,607 B 对中心化 619 B——所以中继必须重新拟合）。解决办法不是在 GBP 里做物体关联（槽位置换、匈牙利匹配都非凸，不保证能量下降），而是**让 stalk 停在不可再分元素（体素 / 击中）上**：每段描述只从它自己的位姿集渲染，再在体素格上 join；结构只活在线路语言里，槽位的置换对称性被集合并天然商掉。这就是我对"限制映射 = 对齐 / 关联"的回答：限制映射取恒等，关联问题不出现。

**A4 架构草图。**
- 编码器（分析-综合，解析）：P3/P8 的贪心覆盖——种子 = 最低的未覆盖击中，逐层生长，新层不含已知空闲且含击中才接受；分割启发式：2.3–2.5 m 带有击中的列是结构，同列 2 m 以下看见空闲的是门楣；其余击中归盒子。CPU 0.2–0.3 s/图。渲染核对是确定的（不需要可微渲染）。
- 熵模型（唯一需要训练的部分）：AR Transformer，6 层、d = 256、~5 M 参数；token = (锚格, z0, dz, dx, dy)，按光栅序，条件于平面图；平面图用 2D 上下文模型。训练数据：TRAIN 缓存 4,708 套 × 8 个智能体的 own 描述 + 每条有向边的发送侧描述，约 10 万段（CPU，32 核约 15 分钟）。5090 上约 0.05 s/步，2 万步约 20 分钟。
- 解码器：GPU 首次命中光线投射（8 × 3 位姿 × 65,536 射线 × ≤ 160 步 ≈ 2.5 亿次查表，估计 ~10 ms；本机 numpy 3 s/智能体），无参数。
- 损失：熵模型的 NLL（bit）；有损版本 = 带 F1 约束的 MDL（贪心删 / 并盒子）。
- 分阶段：S0 解析编解码器（已在 CPU 上验证）→ S1 熵模型 → S2 有损 R–D 曲线。

**A5 最大风险。**
- 合成过拟合（最大）：旋转 45° 字节 ×1.6（P5）；测距噪声 σ = 2 cm 时无损外壳描述 ×4.9（798 → 3,882 B），必须改成有损的去噪拟合（P6）。真实扫描有斜墙、曲面家具、杂物，贪心盒子数会爆。
- 位姿：渲染解码对位姿精度敏感（P10：位姿量化到 1 cm 时 0.8 % 的已知体素改变；0.5 mm 时 0.05 %）；真实 SLAM 漂移会让 known 边界错位。
- 叙事：一个不学习的编解码器在合成基准上 F1 = 1，可能被读成"基准坏了"而不是"方法好"。我认为两者都对，必须先讲清楚。

**A6 最小可证伪实验。**
- A-0（已完成，CPU，确定性；判据为事后登记的探索性判据）：24 个 VAL 房子 K0 与 R8 逐体素精确（浮点位姿）、own ≤ 400 B、R8 收敛消息 ≤ 1,000 B → 通过（P3、P8、P9）。正式版：在 fresh 面板（VAL 索引 8–15）原样重跑，事前写下同样三条，任何一条不过即判 A 不成立。
- A-1（1 租约，两种子 342101 / 342202）：单变量 = 熵模型（AR Transformer vs P7 静态差分表）；判据：两种子 VAL own 中位字节都降 ≥ 25 % → 杠杆，< 10 % → 不值得；F1 不变（解码是确定的）。
- A-2（CPU，不训练）：扰动世界（±45° + σ = 2 cm）上结构码相对 ctx 仍 ≥ 2×，且有损版本在 ≤ 512 B 时家具 F1（对噪声目标）≥ .9；不满足就宣布 A 是"合成特供"，转向 C。

## 3. 设计 B（1–2 个租约可证伪）：RK-Δ——渲染出 known 的学习体素码 + 只发新息

**B1 一句话。** 保留学习的竖柱码和最大精度 join，删掉 known 头：解码器只出占据 o，三态图 = 从已到达智能体的位姿对 1[o ≥ τ] 做首次命中光线投射；训练加首次命中一致性损失；线路只发"有证据且变了"的坐标（4+4 bit 匹配码本 + 熵编码）。

**B2 论证与量级。**
- 现码把 8 bit 主要花在可见性上：分析者 B 测得 μ 与竖柱空闲比例的 Spearman .90，而 (μ, log q) 对家具占据的 R² 只有 .46。可见性由渲染白给（P1），删掉 known 头等于把这部分容量还给几何。
- 但 P4 说明"不重训、只换判决"略差（K0 / R8）：表面 −0.7 / −0.5 pp，家具 −1.5 / −2.1 pp；rk_free 漏光使 FPR +1.0 / +4.0 pp。现在的占据头从没被要求"水密、首次命中一致"。B 的收益只能来自训练。
- 字节（稀疏度取自分析者 B）：K0 有证据坐标约 21 %（~215 个）× 8 bit + 覆盖位图（上下文编码 ~20 B）+ 位姿 ≈ 245 B；R8 平均 33 %（p95 55 %）→ 收敛消息 ~360–600 B；只发新息 → 每条有向边整个协议 ≈ 一条收敛消息（现在 8 轮 × 2,048 B = 16 KB）。对 ctx：own 约 5×，消息内容 1,752 / ~450 ≈ 3.9×；对 gzip 约 8×；对原始约 290×。
- 预测 F1（不确定度大）：K0 表面 .929 → .94–.95（否决误差消失），R8 .91 → .92；家具 .58 → .62–.68（相当于半级到一级坐标阶梯）。

**B3 底线。** stalk = 32×32 公共竖柱的 (μ, q) + 位姿 stalk；融合逐坐标最大精度（不变）；能量 $E_B=\sum_i\sum_d[\ell(q^*_d)-\ell(q_{i,d})]+\kappa\sum_i|\mathcal P^*\setminus\mathcal P_i|$，ℓ = 精度码本序号。码本量化单调 ⇒ max∘Q = Q∘max ⇒ 量化后的选择仍是链上的 join，能量不增；只发新息时接收方保留旧值，内容逐位相同，轨迹相同；熵编码对量化符号无损。解码 $D=\bigsqcup_{b\in\mathcal P_i}\mathrm{render}(1[f_\theta(s_i)\ge\tau],\pi_b)$。

**B4 架构。** 可从 L1 / 3S-X 检查点热启动，单阶段 16k 次或两周期。编码器与融合不变（trunk + head ~0.6 M，Decoder3D W2 ~1.6 M）；解码器输出 2×8 → 1×8 通道；损失 = 现在的表面加权占据 BCE + λ·首次命中损失：每步每个位姿采 4,096 条目标射线，沿射线取 σ_k = σ(o_k)，透射率 $T_k=\prod_{u<k}(1-\sigma_u)$，最大化 $\log(T_{hit}\sigma_{hit})+\sum_{k<hit}\log(1-\sigma_k)$；GPU 上约 24 × 4,096 × 160 ≈ 1,600 万次三线性查表，步时 0.20 → ~0.22 s。熵模型：按覆盖条件的分解直方图（~10 k 参数）。

**B5 风险。** 首次命中损失与表面加权 BCE 打架；漏光（P4 的 FPR +4 pp）；家具上限仍受坐标数限制，B 很难把家具推过 .7——它不是代际突破，是给现有学习线的保险。

**B6 最小可证伪实验（3S-RK）。** L1 配方（32×32×1 @ 8+8，d3 W2，16k，4,708 套）；单变量 = "known 头 + 校准规则" → "只训占据 + 首次命中损失 + 光线投射判决"；对照 = L1 16k（校准规则重打分）；两种子；判据：两种子 Δ R8 表面 ≥ +1 pp 且 Δ R8 家具 ≥ +3 pp → 杠杆；都 ≤ −1 → 更差；保护：R8 FPR ≤ 对照 + 0.3 pp、楼板召回 ≥ 对照 − 2 pp、K0 可变 ≥ 对照 − 2 pp；机制读数：μ 与空闲比例的 Spearman 从 .90 降到 ≤ .6。预算：两次 16k 运行各约 3,500 s。零 GPU 前置：在 uk-linux CPU 上用 3S-X 的 logits（不是阈值平面）重做 P4，确认"免费版"不成立后再训。

## 4. 设计 C（走向真实世界）：学习的结构语言——骨架 ⊕ 残差，解码 = 可微渲染

**C1 一句话。** 把 A 的手写语言换成学习的语言：编码器输出一组可微基元（竖直平面段、带朝向的盒子 / 超二次体，各带存在概率）+ 只在骨架解释不了的竖柱上发的残差码；解码 = 软光线投射渲染骨架 ⊕ 残差占据；以 MDL（比特 + λ·重建）训练；融合仍是 A 的体素格 join。

**C2 论证。** 合成世界里精确描述存在且只要 ~200 B（P8），C 应收敛到 A。扰动世界里 A 的轴对齐盒子开始失效（P5：45° 时盒子 62 → 109），"每件一个朝向"的盒子应能把这部分收回（每件 +5 bit；估计，未测）；测距噪声下无损外壳描述失效（P6，σ = 2 cm 时 ×4.9），骨架必须是去噪拟合、噪声交给残差或直接舍弃。真实世界里墙仍是平面图的拉伸，大件家具仍近似盒子，杂物进残差。我的估计（没有数据，标为猜测）：真实扫描上 own 消息 300–600 B，对 ctx 3–5×、对 gzip 8–15×、对原始 220–440×；对去噪后的目标 K0 / R8 表面 .93–.97、家具区 .8–.9。

**C3 底线。** 同 A 的体素格 + 位姿格。真实噪声下把体素 stalk 换成 Belnap 双格（占据证据、空闲证据，各取 max；冲突在解码时按阈值判决），能量仍是格秩亏量。位姿有不确定度时，位姿 stalk 用高斯 GBP（树上精确，有环时用协方差交叉）——全系统里唯一合理使用 sum 型高斯 GBP 的地方，因为位姿是连续量、关联已知。积格上 $E_C=E_A+E_{\text{pose}}$（后者为高斯 sheaf Laplacian 能量），两部分各自单调不增：几何部分同 A（整数格、join 幂等，量化与变长不影响内容）；位姿部分在树上是精确的高斯 BP（二次能量的块坐标下降），有环时用协方差交叉换保守性，不会过度自信。

**C4 架构。** 稀疏 3D 卷积 / 点 Transformer 编码器（~3 M）；集合预测头（K = 128 个基元槽；S1 用合成真值的可见基元做匈牙利匹配监督——槽位只在编码器内部，线路上和融合里没有槽位）；软光线投射渲染器（无参数）；残差 trunk + head（~0.6 M）与 Decoder3D W2（~1.6 M）；A 的 AR 熵模型（~5 M）。5090 上估计 0.3–0.5 s/步。分阶段：S1 合成真值监督基元 → S2 端到端 R–D → S3 扰动世界 → S4 真实扫描（Replica / Gibson，已在 uk-linux）。

**C5 风险。** 集合预测的召回、MDL 非凸、软渲染梯度弱、工作量（≥ 4–6 个租约 + 3D 真实扫描管线）。

**C6 最小可证伪实验（不训练，CPU）。** 扰动世界（±45° + σ = 2 cm）上比较三种 ≤ 512 B 的码：(i) 2×2×1 降采样 + ctx（证据包的经典有损基线）；(ii) A 的轴对齐解析语言（有损：删小盒子）；(iii) A + 每件家具一个朝向的解析拟合。单变量 = 语言；判据：(iii) 在等字节下家具 F1 比 (i) 高 ≥ 10 pp 且比 (ii) 高 ≥ 3 pp → 值得做学习版本；否则停在 A。

## 5. 排序推荐（下一代模型，前 3）

1. **A：RAY-SHEAF + 学习熵模型。** 唯一一个今天就在两个目标上同时给出实测数字的设计（浮点位姿下 F1 = 1.000、44 bit 位姿下表面 .998；own 中位 198 B，R8 收敛消息中位 317 B，家具区 ≈ .994（44 bit 位姿）），底线原样保住（体素格 join，能量与 D8 同一个），实现几乎全是 CPU 代码。下一步：A-0 在 fresh 面板复核 + A-1（1 租约）+ A-2（CPU）。
2. **C：学习的结构语言（骨架 ⊕ 残差）。** A 的真实世界化，论文价值最大，代价也最大；在 A-2 确认"扰动后仍 ≥ 2×"之后投入。
3. **B：RK-Δ。** 现有学习线最便宜的升级，1–2 租约可证伪，把码率先降一个量级并去掉可见性误差；但家具很难过 .7。执行顺序上它可以最先跑（GPU 一空出来就能跑），A-1 的数据同时在 CPU 上准备。

关于"几十倍"的诚实口径：在这个世界里全保真时，A 相对 ctx 约 6.6×（own）/ 5.0×（每条收敛消息），相对 gzip 约 14× / 10×，相对原始栅格约 660× / 410×，相对我们的 2 KB 消息约 10× / 6.5×；整个协议对现在少 46 倍；要相对 ctx 到几十倍，只能是有损（P3 的 m 曲线）或在真实噪声下比较（P6：噪声让无损变贵、结构描述不变）。

## 6. 我认为别的视角最可能犯的错误

1. **让网络学 known 掩码 / 生成三态图**（diffusion、flow、AR 体素生成都一样）：它是几何 + 位姿的确定函数（192/192），占无损比特 69–77 %；学它就是浪费容量并制造否决误差。生成模型只该生成"击中"（几何），可见性交给光线投射。
2. **继续在坐标阶梯和每坐标比特上找突破**：P3/P8 说明对的语言用约 1/10 的字节就逐体素精确。
3. **用物体槽位 + 置换匹配，或高斯 sum-GBP，去融合物体**：前者关联非凸、能量不保证下降，后者在环上重复计数。选不可再分元素做 stalk、结构只放进线路语言，关联问题就消失。
4. **码率口径**：只报相对原始栅格（64×）或 gzip；不报 ctx；不算位姿、索引、头部；只看单条消息，不算 8 轮 × 每条有向边的协议总量（现在每栋房子 229 KB，比 ctx 无损泛洪的 24 KB 还多 9.6 倍）。
5. **把合成基准的增益外推到真实世界**：依赖 22 类家具码本、轴对齐、精确位姿的设计都要在 P5/P6 式扰动和真实扫描上复核；"补全 unknown"在这个评估里不得分，只会抬高 FPR。
6. 反过来，**因为"只是合成基准"而低估结构**：旋转 45° 后结构码仍是 ctx 的 3.8×；测距噪声让无损体素码变贵 1.6–2 倍（P6）而干净结构的描述不变，所以"相对无损几十倍"在真实数据上反而更可能——前提是评估目标换成去噪几何（干净几何对 2 cm 噪声目标的精确表面 F1 只有 .37，按现在的精确 F1，任何去噪的码都会被判差）。
7. **以为分析-综合已被否定**：D5-4 否定的是"在固定卷积解码器上做 50 步码精化"（R8 −1 pp，马赛克错配），不是"用精确渲染器做分析-综合"——后者在 P1/P3 里逐体素精确。
