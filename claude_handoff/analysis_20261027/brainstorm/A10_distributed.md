# A10 · 分布式信源编码与多智能体冗余：新一代 Sheaf-GBP 的三个设计

视角：Slepian–Wolf / Wyner–Ziv、新息编码、融合本身的码率优势。只用第一性原理和 CPU 探针，没有查文献。
探针脚本与输出都在 `claude_handoff/analysis_20261027/probes/A10/`（本地 6 套 VAL 演示房子，numpy）；精确重建的核验在 uk-linux CPU 上跑（nice 19、2 线程、5 分钟，只写 `.../claude-diag-20261021/analysis_20261027/A10/`，输出已拷回）。所有码长都是**可实现的**自适应算术码的精确长度（KT 估计器，含学习代价和头部），口径与证据包的 ctx 相同（`tern_bytes` 与 `ctx_bytes` 逐位相等，已断言）。

## 0. 结论先行

1. **按整个网络算，现在的协议比"各自把 gzip 过的地图洪泛"还贵**：每套房子 8 轮 × 14 条有向边 × 2,048 B = **229,376 B**；8 个智能体各自 gzip 后经树洪泛 166,410 B，F1 = 1。最强的**精确**分布式方案（可见面 + 位姿 + 光线投射 + 新息中继，KT 编码，不用学习）只要 **8,948 B/房**，少 26 倍，R8、K0、家具区 F1 全是 1。
2. **每条树边的条件熵（中位）**：发送侧并集 1,752 B；以接收者自己的地图为边信息 1,528 B（×.89）；只编接收者没有的新息 1,195 B（×.74）；只编接收侧整体没有的 1,135 B（×.71）。三态体素里冗余只省 11–29 %，因为 77 % 的比特是"哪里被看到"，对每个接收者都是新的。**可见性改由位姿光线投射算出**后同一新息 624 B（×.39）；墙柱、楼板、天花板也交给渲染后 **510 B（×.29）**；叶子发送只要 **223 B**。
3. **我们的码当边信息几乎没用**：已知我们的 K0 解码结果，精确地图仍要 1,242 B（只省 10 %）；家具区可见面已知预测时 249 B，不给底图反而 238 B——解码器错在哪里，信息就在哪里（表面边界）。
4. **坐标阶梯在码率上走不通**：64×64×1 的码改成新息、每 stalk 10 bit 熵编码，同步 8 轮仍要 29,778 B/房（精确码的 3.3 倍；收集—分发调度下也约 2 倍）。
5. 头号设计：把 stalk 换成**精确的可见表面原子**，GBP 换成**只传新息的并流**，学习全部放进**条件生成先验**（熵模型）。F1 由构造等于 1，码率由先验决定。

## 2. 设计 α（头号）：精确可见面格 sheaf（EVS-Sheaf）+ 新息中继 + 条件生成先验

**1. 一句话**：每个智能体只交换接收方还没有的"可见表面原子"（首次命中、确定是墙的竖柱、位姿），空闲与未知由解码端用公开位姿光线投射精确算出；融合是格值 sheaf 上的并流；学习全部放在两端共享的条件生成先验里，它只决定码长，不决定 F1。

**2. 第一性原理与量级**

- 精确性：首次命中传感器下，若 O 中每个体素都真被占据、每个真首次命中都在 O 里，则同位姿、同射线重投射得到的三态图逐体素相同（射线在真首次命中之前碰到 O 中体素，就意味着它在真实世界里会先停在那里）；并集同理。1.5 实测 0 不一致。所以 **R8 表面、K0、可变结构、家具区 F1 = 1.000**，一格错位、矮家具召回 .58、已知头否决都不再存在。
- 码率：楼板/天花板 = 两个层号；墙 = 2D 位图挤出；可见性边界（三态无损的 77 %）= 24 B 位姿；只剩家具命中逐体素编码。KT 实测：自己的地图 **360 B**（相对 ctx 3.8×、gzip 7.6×、原始 364×）；边新息 **510 B**（相对该边 ctx 3.4×、gzip 7.2×、原始 257×）；网络 **8,948 B/房**（相对我们 26×、gzip 洪泛 18.6×、原始栅格洪泛 7.34 MB 820×）。
- 加学习先验（主压家具命中，占结构化码的 80 % 以上；位姿 1.3 KB/房和头部不可压）：按 1.7 的代理与 DL 余量取保守的 1.6–2×，自己的地图约 **200–235 B**、边新息约 **290–345 B**、网络约 **5.2–6.1 KB/房**——单条相对 gzip 12–14×、原始 560–650×；网络相对 gzip 洪泛 27–32×、相对我们 37–44×。
- 家具 F1 为什么能"实用"：它从学习问题变成码率问题；家具区精确只需 238–259 B/张自己的地图，约为现在一条消息的 1/8。

**3. 底线**

- stalk 索引集 𝓘 = 公开竖柱 c ∈ [128]²（R1 的公开图）∪ 位姿槽 a ∈ 智能体 ∪ 房屋常数 κ（楼板层、天花板层、门楣层）。
- 内容（智能体 i）：x_i(c) = (ω_i(c), h_i(c))，ω ∈ {⊥, 墙}（平格），h ∈ {0,1}^{Z'}（Z' ≤ 30 个非楼板层的显式命中位，幂集格）；π_i(a) ∈ {⊥} ∪ (ℝ²)³（float32）；κ ∈ {⊥} ∪ 层号。写成"带精度的 sheaf 向量"：每个原子是一个变量，看到时精度 ∞、没看到时 0；**现有的最大精度选择 `select` 原封不动就是这里的并（OR）**，只换 stalk 基。
- 迭代：x_i(t+1) = o_i ∨ ⋁_{j∈N(i)} m_{j→i}(t)，m_{j→i}(t) = e_{j→i}(t) ∖ (sent_{j→i} ∪ heard_{i→j})，e 为外部信念。
- 能量：**E(x) = Σ_i Σ_{s∈𝓘} [ρ(⋁_j x_j(s)) − ρ(x_i(s))]**，ρ = 已知原子数。世界一致，⋁_j x_j(t) ≡ ⋁_j o_j 不随 t 变，每个 x_i 单调增，所以 E(t+1) ≤ E(t)，等号当且仅当不再变化，E = 0 当且仅当全局截面。它就是 D8 中"最大精度选择 = 协方差交叉 / Tarski Laplacian 调和流"在精度 ∈ {0, ∞} 时的特例：E = Σ_i Σ_原子 1[q_i < max_j q_j]。（边上分歧数 Σ\|x_i Δ x_j\| 在星形图上会先升后降，不能当 Lyapunov 函数。）
- 变长与新息：原子精确、熵编码无损；过滤只丢接收方可证明已有的原子，所以每轮信念与全量洪泛逐位相同（1.3 已断言），E(t) 轨迹不变。可选的率失真舍弃只让消息变成子集，信念仍单调，E 相对"被传输的全局截面"仍不增。
- K0 口径：K0 = 渲染(自己的码)，不读私有地图。R8 只读收到的码和自己发出过的码（反向消息两端都有，属于条件编码，不是 WZ）。

**4. 架构草图**

- 编码器：确定性分解（层号；"两段高度都占据"的竖柱判墙；其余为显式命中）+ **渲染自检**：编码端渲染自己的码与自己的地图比对，不一致的竖柱退回显式命中，精确性在编码端就有保证，启发式只影响码长（可换成小分类器，同样受自检约束）。
- 线路：头 4 B + 未发过的位姿 + 新墙柱（2D 算术码）+ 新显式命中（3D 算术码），概率来自 p_θ(原子 \| 接收方状态, 公开位姿, 已解码原子)。
- 融合：雷达森林上的并流 + 新息过滤；收集—分发调度（≤ 2 × 深度 ≤ 8 轮，去掉"盲"的第 1 轮，stalk 少 38 %），也兼容 HOPS = 0/1/2/4/8 的同步评估。
- 解码器：模拟器自己的首次命中投射，没有学习的解码器参与 F1。
- 先验 p_θ（即"生成模型"）：2 个尺度 × 4 组交错 = 8 遍的并行上下文模型，等价于 8 步解掩码的离散扩散——每步对一组原子给条件分布并算术编码，"先生成、再用比特纠正"。输入约 12 通道（已解码命中、组掩码、墙柱、层号、接收方 known/occ、可达场、到位姿距离、坐标、尺度 L）；space-to-depth 2 后 64×64×16、64 通道、8 个残差块，约 1.8 M 参数，每样本约 2.3e11 FLOPs。
- 损失：L = E[bits(自己的码)] + E[bits(边新息)]（接收侧取随机子树并集），即负对数似然；不需要 F1 损失。
- 训练：S0（CPU，已过）精确性 + KT 对照；S1（1 个租约）先验 NLL，batch 8 约 0.07 s/次，25k 次约 30 分钟/种子；S2（可选）率失真 λ 扫描；S3 叠加 γ 的物体层作超先验。解码：每条消息 8 遍前向约 20–40 ms，投射 CPU 1–2 s。

**5. 风险**

- 最大风险是口径：用户可能不认为"精度 ∈ {0, ∞} 的位向量"是 sheaf 向量。回应：融合规则、能量、迭代形式与现在逐字相同；真实传感器有噪声时原子自然变成有限精度的面元（伯努利对数几率或高斯位置），那时才需要求和型 GBP——这就是向真实数据推广的路径。
- 精确性依赖确定性世界和公开的传感器模型：位姿要 float32/float64（1 cm 量化每张图约 82 个占据体素不一致），射线集合与步进两端一致。真实噪声下无损码长会暴涨，要换"近无损 + 精度下限"。
- 学习先验可能达不到 1.6×——那时 α 仍以 KT 码率（8.9 KB/房、F1 = 1）支配现有系统，只是学习没有贡献。

**6. 最小可证伪实验（1 个租约）**

- 前置门（CPU，已通过，1.5）：逐体素精确，否则设计作废。
- 单变量：可见面原子的概率模型——学习的 8 遍上下文 CNN 对照 **KT-9 + 可达标志的自适应编码**（同一批 VAL-24、同一分解、同一接收侧状态，CPU 计算）。
- 数据：4,708 套 TRAIN 缓存（自己的地图 + 按缓存森林现场合成的边新息），VAL-24 评估，TEST 封存。种子 342101、342202。
- 预注册判据：两种子都满足"自己的码中位比值 ≤ .60 且边新息中位比值 ≤ .65"→ 杠杆；任一项 ≥ .85 → 先验不值得，α 退回 KT 版本（仍报告）；其余 ambiguous。保护：解码逐体素精确 100 %；单条解码 ≤ 1 s。机制读数：比特按楼板/墙/家具/细部件分摊，网络 B/房，对 ctx、gzip、原始和 DL 的倍数。我的预测：自己的码 .45–.60，边新息 .50–.70。

## 3. 设计 β（保守、零训练）：现有连续码 + 新息线路 + 闭环家具残差层

**1. 一句话**：不动 3S-X / 3S-Z2 的模型，线路改成"只发会改变接收方最大精度选择的 stalk"并熵编码，再加一层以解码器输出为两端共享边信息的家具区精确残差。

**2. 量级**：线路部分 F1 逐位不变（fresh：R8 .909、K0 .937、家具 .58），网络 229,376 → 8,882 B/房（同步 8 轮，10 bit/stalk）或约 5.7 KB（收集—分发），26–40 倍；K0 自身码 270 B。残差层：家具区精确 +249 B（K0）/ +705 B（R8 并集）→ K0 表面 .972、可变 .960、家具 1.000；R8 .965 / .944 / 1.000（演示 6 套实测）。单条 K0 约 520 B：相对 ctx 2.7×、gzip 5.3×、原始 250×。坦白：它的码率与 α 的 KT 版本相当、F1 略低，被 α 支配；价值在于**今天就能如实报告现有系统的网络码率**，以及用户坚持连续潜码时的退路。

**3. 底线**：层 1 = 现有 (μ, log q) stalk，最大精度选择；层 2 = 家具区竖柱的精确命中位（幂集格）。E = E₁ + E₂，E₁ = Σ_i Σ_k [log q̂*_k − log q̂_{i,k}]（q̂ 为线路量化精度；每个信念坐标是不断变大的集合上的最大值，故不增），E₂ 同 α。新息过滤下信念逐位不变，E₁ 轨迹不变，量化码本不变。

**4. 架构**：支撑集掩码（上下文：接收方报告过的证据、自己发过没有、左/上邻居；32×32 时全房 891 B）+ (μ, q) 符号的自适应算术码（上下文：接收方在该 stalk 最后报告的精度桶、已解码邻居）。残差层：树上收敛后发送方知道接收方的融合信念，能跑同一个解码器，用它的软占据概率作算术编码模型（闭环；两端都有边信息，不是 WZ）。可选：一个租约加 λ·R 训练。

**5. 风险**：(μ, q) 的实际熵可能 > 10 bit/stalk；软概率作模型可能仍省得很少（1.6 硬判决只省 0–10 %，错误集中在边界）；同步协议第 1 轮占 46 %。

**6. 最小可证伪实验（CPU ≤ 15 分钟，等 3S-Z2 结束、允许读 `runs/` 后）**：单变量 = 线路协议；对照 = 同一检查点的定长线路；两个种子 = `c2-s342101`、`c2-s342202`。判据：每个 hop 预测逐体素相同（断言）且两种子网络字节都 ≤ 定长的 1/15 → 采纳为报告口径；> 1/8 → 否。附带：软概率残差的家具区码长（预测 ≤ 300 B / K0）。

## 4. 设计 γ（最激进）：物体区间 sheaf + 渲染器 + 生成形状先验（叠在 α 上）

**1. 一句话**：家具按"物体槽位"传：每个槽是一个物体的类别和参数区间（看到的部分收紧区间），融合是区间的交，解码器把参数渲染成体素再交给 α 的光线投射，剩余不一致用 α 的显式命中补齐，所以仍然精确。

**2. 量级**：对凸部件有一个精确事实——**被看到的命中的包围盒，渲染出的首次命中与原部件完全相同**（包围盒在原部件内，打到原部件可见点的射线打到包围盒的同一体素，反之亦然），所以"最小一致物体"是精确码。按 DL：家具约 14 件 × 31 bit ≈ 54 B，加墙 21 B、位姿 24 B、头、残差（估 +20–40 %）→ 自己的地图约 **110–150 B**（相对 ctx 9–13×、gzip 18–25×、原始 870–1,200×）；边新息约 150–250 B（含发送侧位姿）；网络约 **2.5–3.5 KB/房**（相对 gzip 洪泛 48–67×），其中位姿占 1.3 KB——若协议规定传感器模型在量化位姿上运行，可再降 1 KB。F1：带残差仍为 1；只渲染不补残差时家具区约 .85–.95（参数量化到 R1 格）。

**3. 底线**：stalk 索引 = 公开 2D 锚格（物体最小角所在格）× K 个槽；内容 = (类别概率, 每个参数的区间 [lo, hi])；区间按反向包含成格，并 = 交；高斯读法：均值 = 中点、精度 ∝ 1/宽度²。能量 E = Σ_i Σ_槽 Σ_参数 [log w_i − log w*]（对数宽度亏损），交运算下不增。有噪声时换成高斯，E = ½Σ_{(i,j)}‖θ_i − θ_j‖²_Λ + ½Σ_i‖θ_i − ô_i‖²_Q，树上 GBP 在直径轮内精确收敛；块坐标调度每步不增，量化消息加"只接受能量下降"的保护。

**4. 架构**：槽编码器（3D CNN + 集合预测，K ≤ 64，约 10–15 M 参数）输出最小一致物体；渲染器 = 库的光栅化（真实世界换成学到的形状解码器，即生成形状先验）；残差 = α 的显式命中，渲染结果作超先验；跨智能体关联按公开坐标重叠。训练：软光栅化渲染损失 + 残差比特，约 0.2 s/次，2–3 个租约。

**5. 风险**：部分视角下的关联与拆分（两个智能体看到同一张桌子的不同腿）；库是这个世界专有的；检测错误会让残差暴涨（但仍精确）；训练最难。

**6. 最小可证伪实验（2 个租约）**：α 的墙、位姿、残差不变，单变量 = 家具表示（物体槽 + 残差 对照 α 的显式命中 + 学习先验）；两个种子；判据：家具部分字节中位 ≤ α 的 .5 且家具区 F1 = 1 → 杠杆；≥ .85 → 否。先做 CPU 预实验：用真值物体参数做最小一致物体渲染，量残差字节和参数量化对 F1 的曲线；若残差 > 显式命中的 .5，直接不训练。

## 5. 排序推荐与别的视角最可能犯的错误

**排序**：
1. **α**：F1 由构造为 1（家具问题直接消失），不学习时码率已支配现有系统 26 倍，最小实验一个租约，前置门已通过。它把"压缩再生成"改成"生成再纠正"：生成先验决定码长，比特只描述先验猜不到的东西。
2. **γ 叠在 α 上**：压缩上限最高（2.5–3.5 KB/房），精确性由 α 的残差兜底，风险集中在物体检测；看 α 的 S1 结果再定。
3. **β**：不是新一代模型，但应立刻在 CPU 上做，因为现有系统的网络码率必须如实报告；也是保留连续潜码的退路。

**目标怎么诚实地定**：这个确定性世界里，"几十倍"只在两种口径下诚实成立——对原始栅格（α 单条已 257–364×）和网络层面对 gzip 洪泛（α 18.6×、加先验约 30×、γ 约 50–65×）。单条消息对 gzip，精确码 7–14×，γ 才到 18–25×。报告必须同时给"相对最强精确分布式基线（α-KT，8.9 KB/房）"的倍数。

**别的视角最可能犯的错误**：
1. **只比单条消息、不算网络**：现在每套房子 229 KB，比 gzip 洪泛还多；任何"每条消息 X 倍"都要乘上 8 轮 × 14 条边，或改成新息线路后重算。
2. **拿 gzip 当无损基线**：一个不用学习的精确分布式码已经比 gzip 洪泛少 18.6 倍；对 gzip 声称几十倍而不报这个基线，会被一眼看穿。
3. **让模型去学"哪里被看到"**：三态无损的 77 % 是可见性边界，24 B 位姿 + 光线投射就能精确给出；known 头、否决、FPR 保护的麻烦大多来自这里。
4. **继续爬坐标阶梯**：64×64 的新息码已比精确码贵 2–3.3 倍，128×128 贵约 12 倍——阶梯在逼近一个更贵的无损码。
5. **为 Slepian–Wolf 分箱或"拉取"造机制**：网络层面上限只有 8–15 %，还会让 R8 解码读私有地图、破坏口径；树上的反向消息就是免费的"请求"。
6. **在体素级融合上用求和型高斯 GBP**：同一观测经不同路径重复计数（D8 测到环路上精度放大 875–1,582 倍）；精确原子用幂等的并，物体参数用区间交，只有独立的噪声测量才求和。
7. **用生成先验补全没看到的空间**：F1 只在目标已知处计分，补全只推高未知→已知 FPR；生成先验应当作熵模型，而不是幻觉器。
8. **以为更好的解码器能救回家具**：已知我们的解码输出，家具区精确码长 249 B，不给底图 238 B——瓶颈在比特不在解码器；家具 F1 要实用，就得把约 240–260 B/张的家具命中传过去（先验后约一半）。
