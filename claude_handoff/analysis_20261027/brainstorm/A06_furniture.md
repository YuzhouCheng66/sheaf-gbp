# A06 家具区 F1 专项：误差解剖、天花板、F1 最优判决，与三个下一代设计

A06（Claude），2026-10-27。只用本机 CPU，没查文献。数据：`demo_web3d/data` 的 6 个 VAL 房子 × 8 个智能体（3S-X + 校准规则），度量逐行照抄 `metrics3d`（逐智能体 `furn_f1` 平均，复算 K0 .524、R8 .540，与 `rate_baselines` 一致）。脚本和原始输出在 `probes/A06/`（第 9 节）。下文"K0 / R8"成对出现时，前者是自己地图，后者是 8 轮并集目标。

## 0. 结论

1. **家具区 F1 是"体素精确的薄壳 F1"。** 目标里家具的占据体素是首次命中的一层壳。把每件家具整体水平挪 1 格，F1 只剩 .52 / .57；水平加厚 1 格，.63 / .64；竖直加厚 1 格，.82 / .82；而把全部细部件（腿、层板、桌面、靠背）整个删掉，还有 .83 / .87。**我们的 .52 / .54 正好是"差一格"的水平**：码对家具只有竖柱级（4 格）的水平定位。
2. **误差以漏检为主，而且是全面的失败，不是某一类的失败。** 召回 .48 / .45，精度 .77 / .74，漏检 : 虚构 = 3.8 : 1 / 3.5 : 1。漏检里 71 % / 82 % 是 occ 头判"空"，known 头否决只占 29 % / 18 %。虚构里 69 % / 67 % 紧贴真家具（≤ 1 格），整件凭空虚构约 5 %。除了顶面（.71 / .67），各高度、各相位的召回都在 .29–.55；细腿细板只有 .08 / .07；占家具体素 73–75 % 的大块家具也只有 .51 / .48。
3. **家具 F1 到 .8 需要：大块家具的水平面精确到体素，竖直可容忍 1 格，细部件可以全丢。** 信息量很小：贪心程序里只留最大的 12 / 41 个家具盒子（44 / 135 B），家具 F1 就有 .81 / .85；留 34 / 106 个（116 / 322 B）有 .96 / .97。库内参数描述约 31 bit/件，即约 55 / 140 B，与之一致。
4. **一个被我们一直浪费的物理事实（本机逐体素验证）：** 首次命中地图**等于**"它自己的占据体素集合 O + 传感器位姿"再做同一套光线投射（48/48 张自己地图、48/48 张 R8 并集 0 个体素差）。而且任何满足 O ⊆ W、W ∩ F = ∅（F = 观测到的空闲）的世界 W 都给出同一张图。**未知空间（自己地图里 87 % 的体素）是 don't-care。**
5. **所以无损只需要传"一个与观测一致的最简世界"。** 一个几十行的贪心盒子覆盖 + 残差 + 精确位姿，不做任何学习：自己地图中位 259 B，一条收敛消息 517 B，R8 并集 821 B；**表面、可变、家具 F1 全部是 1.000**（无损）。按自己地图 / 收敛消息算，它比我们 2,048 B 的消息小 7.9 / 4.0 倍，比 ctx 无损小 5.4 / 3.4 倍，比 gzip 小 10.6 / 7.1 倍，比原始栅格小 507 / 254 倍。
6. **生成式采样伤害 F1。** 用同一个学到的条件模型，单次采样比确定性判决低 22 / 15 pp（家具）和 12 / 11 pp（表面）。F1 最优判决是"后验边缘 ≥ F1*/2"。生成模型该做熵模型（省比特）或边缘估计器，不该用来出计分的地图。
7. **排序：ProgSheaf（世界程序）> RaySheaf（占据面 + 光线投射）> RayField（保 join 的神经码 + 可微占据渲染）。** 三者都保留"带精度的 stalk 向量 + 逐坐标最大精度 join（格值 sheaf 上的 Tarski 流）+ 单调下降的能量"。

**读法（第一性原理）。**
- **表示量子。** 码的空间量子是 4 × 4 × 32 的竖柱，每柱一个 8 bit 均值；度量的容差是 0 格。80 % 的家具目标体素在竖直侧面上，而侧面的水平位置恰好是竖柱均值说不清的东西。所以面在竖柱边上（家具只占竖柱 1 格）时召回 .33，占 2 格时 .53；只要高度的顶面是 .71。
- **定长码率。** K0 时 80 % 的坐标没有观测；有观测的竖柱，不管是一块空地板还是"书桌 + 椅子 + 8 条腿"，都只给 16 bit。B 测到每个有证据的坐标需要约 45 bit，解码器只用到约 8 bit。
- **信息不够时解码器偏向"空"。** 漏检是虚构的 3.5–3.8 倍；虚构几乎全是贴边的一格错位，不是整件幻觉。
- **不是瓶颈的：** known 头（只占家具漏检的 18–29 %）、细部件（全删仍有 .83–.87）、离墙距离、判决阈值（C 的扫描：o 阈值从 0 到 1.5，家具 F1 从 .57 到 .56，是平的）。
- **对照：** 经典 4 × 4 × 1 降采样与码竖柱同一水平量子、竖直全分辨率，249 / 559 B 时家具 .47 / .49，与我们 2 KB 的 .52 / .54 几乎一样。2 × 2 × 1 降采样的 .76 / .77，误差几乎全是加厚：召回 .86 / .87，精度 .70 / .69，虚构 98 % 贴边。**家具 F1 由水平量子决定，不由字节数决定。**

## 3. 可以由物理推出的部分：光线投射、don't-care 与无损字节

**命题。** 记 F 为地图里观测到的空闲体素，O 为观测到的占据体素。对任何满足 O ⊆ W 且 W ∩ F = ∅ 的世界 W，用同一组位姿、同一组射线、同一个步进做首次命中投射，得到的就是原地图。证明只有一行：每条射线在真世界里的第一个占据体素在 O 里，因而在 W 里；它之前采样到的体素都在 F 里，因而不在 W 里。R8 并集同理：用并集的 (O, F) 和所有到达智能体的位姿。

本机验证（用生成器的 `observe()` 原样代码，在演示的智能体中心加自己的 ±0.1 m 抖动重新仿真；与演示的自己地图逐体素一致率 .996）：W = O 时，48/48 张自己地图、48/48 张 R8 并集**逐体素完全相同**；W = 贪心盒子程序（盒子伸进未知空间）时，48/48 张自己地图、48/48 张 R8 并集也逐体素相同。

| 每条消息要表达的内容（中位，B；演示地图） | 原始 2 bit | gzip-9 | ctx 三值 | **ctx(O) + 位姿**（RaySheaf） | **程序 + 残差 + 位姿**（ProgSheaf） | 库内参数 DL（world_dl，24 房） |
|---|---|---|---|---|---|---|
| 自己地图（K0） | 131,072 | 2,732 | 1,384 | 596 | **259**（p90 420） | 107 |
| R8 并集 | 131,072 | 6,060 | 2,813 | 1,756 | **821**（p90 1,341） | 306 |
| 一条收敛消息（树边发送侧并集，中位 4 个智能体） | 131,072 | 3,646 | 1,752 | 1,052（条件于反向消息约 −24 %） | **517**（p90 896；条件于反向消息估计约 307） | — |

- **位姿必须精确。** 本机实测：位姿按 1 cm 取整时，重建图与原图有 351–1,838 个体素不同（修正集 548 B）；1 mm 时 25–163 个（105 B）；0.1 mm 时 2–46 个（17 B）。所以表里按"0.1 mm 位姿 10 B + 修正集 17 B = 每个智能体 27 B"计入。world_dl 的 44 bit 低估了这一项；DL 一列仍是它的原值。
- 程序码 = 盒子字段（Δx0, y0, z0, 宽, 深, 高；用另外 5 个房子的静态直方图做算术编码，每盒约 25 bit）+ 残差（以渲染出的盒子为上下文的 ctx）+ 位姿 + 16 bit 头。"条件于反向消息"一项是估计：并集程序长度减去接收方一侧的程序长度，再加发送侧位姿，中位 307 B（p10–p90 为 32–707 B）。
- 贪心覆盖（m = 8）：自己地图中位 50 个盒子，残差 82 个体素（占据体素共 7,564 个）；R8 并集 140 个盒子，残差 221 个（共 27,699 个）。盒子可以穿过墙后、家具背后的未知区域一直长到栅格边界：一面墙、一块楼板、一张床各是一个盒子。
- 现在每轮每条有向边都重发 2,048 B，8 轮共 16 KB。只发新息时，一条边 8 轮的总流量约等于收敛消息一次的字节，总流量上再差一个 8 倍。
- **这条线上无损就是 F1 = 1。** 所以"F1"与"压缩"两个目标解耦：F1 由物理保证，学习只决定字节。

## 4. F1 最优判决与生成式采样

**F1 最优判决。** 设各体素后验边缘为 p_i，期望正例数 P = Σ p_i，对判占据集合 S 有 E[F1] ≈ 2 Σ_{i∈S} p_i / (|S| + P)。加入 j 有利当且仅当 p_j > F1(S)/2，所以最优集合是 {p_i > θ*}，**θ* = F1*/2**（不动点）。墙和楼板的 F1 约 .9，θ* ≈ .45，和校准规则（o ≥ 1.5 即校准概率 ≥ .47）一致；家具的 F1 约 .55，θ* ≈ .28。按区域分开的阈值在原理上是 F1 最优的。但现码的家具分数没有可分性（C 的扫描是平的），上限约 .59–.63，所以判决不是现码的杠杆；它是任何有损学习解码器（设计 3）的必选项。

**采样。** 若真值与样本都按后验独立抽取，单次样本的期望 F1 ≈ Σ p_i² / Σ p_i，永远不高于阈值化边缘；后验越模糊，差得越多。实测（`a06_sampling.py`）：码 = 2 × 2 × 1 τ .5 降采样；解码器 = 用另外 5 个房子数出来的 p(细 2×2 三值模式 | 本块及 6 个面邻块的粗值)，81 个模式 × 2,187 个上下文，相当于"带先验的生成式解码器"；留一房评估。

| 同一码、同一模型，不同判决（K0 / R8） | 家具 F1 | 表面 F1 |
|---|---|---|
| 不用先验：广播粗值 | .764 / .770 | .887 / .880 |
| 逐体素边缘 ≥ .3（≈ F1*/2） | .762 / .763 | .877 / .871 |
| 逐体素边缘 ≥ .5 | .671 / .699 | .760 / .801 |
| 联合众数（MAP 模式） | .656 / .674 | .766 / .801 |
| **单次采样**（4 次抽样平均） | **.546 / .617** | **.770 / .774** |
| 16 次采样平均后 ≥ .3 | .700 / .753 | .863 / .856 |

**判读。** 采样比确定性判决低 22 / 15 pp（家具）；联合众数也低 10 pp，因为 F1 要的是边缘。局部先验没有超过广播：块内细位置的信息不在邻块粗值里，只能在码里。生成式先验只有先变成更尖的后验才有用，正确用法有两个：(1) 做熵模型，无损码长 = −log p，先验越好比特越少、F1 不变；(2) 做边缘估计（x0 预测或多样本平均），再按 F1*/2 判决。mean flow / 一步生成的价值在可视化，不在 F1。

## 5. 设计 1：ProgSheaf——消息是"与观测一致的最简世界程序"（激进；CPU 原型已跑通）

**一句话。** 每条消息是一段与发送方观测一致、在未知空间里随意补全的最短世界程序（轴对齐盒子 + 残差体素 + 位姿）。接收方渲染后按位姿做光线投射，逐体素无损重建 known / free / occupied；学习只负责让程序更短。

**为什么同时提升家具 F1 和压缩率。** 第 3 节的命题意味着"无损"不必传 O，只需传区间 [O, ¬F] 里描述最短的 W。这个合成世界由轴对齐盒子构成，又有 87 % 的 don't-care，所以 W 极短。实测（贪心，未学习，精确位姿已计入）：自己地图 259 B、收敛消息 517 B、R8 并集 821 B，三种 F1 全是 1.000。倍数（相对 ctx / gzip / 原始）：自己地图 5.4 / 10.6 / 507×，收敛消息 3.4 / 7.1 / 254×（条件于反向消息估计约 307 B，即 5.7 / 11.9 / 427×），R8 并集 3.4 / 7.4 / 160×。学习的空间以库内参数下界为界（107 / 306 B，1 cm 位姿）。盒子字段现在每盒约 25 bit；用学到的程序先验（墙对齐、靠墙、标准尺寸、腿成组出现），预计盒子 + 残差再省 35–50 %，位姿用预测编码压到约 15 B/智能体。这样自己地图约 150–180 B（相对 gzip 15–18×），只发新息的收敛消息约 170–220 B（17–21×）。预计 R8 表面 = K0 = 家具 = 1.000（无损，可逐体素核对）。有损档也已实测：只传盒子、丢掉残差、照样投射解码，自己地图约 197 B 时表面 .994、家具 .961；R8 并集约 649 B 时表面 .995、家具 .972。

**底线：sheaf 向量、GBP、能量。**
- 索引集：公共砖块 b ∈ 𝓑（8 × 8 × 4 体素，16 × 16 × 8 = 2,048 块）∪ 位姿槽 a ∈ {1, …, 8}。
- stalk：砖块 b 上是逐体素的 (μ_v, π_v)，μ ∈ {0 空, 1 占}，π ∈ {0 未观测, 1 观测}，即退化的高斯 stalk；位姿槽是 3 个位姿和精度（未收到为 0）。线路上，整组 stalk 用它的规范程序做无损表示（盒子跨砖块无所谓，它只是一段码）。另一个等价视角：每个盒子面带精度 π_f ∈ {0, ∞}，面贴着观测到的空闲时为 ∞（钉住），落在 don't-care 里为 0。
- 融合（树上同步 8 轮，与现在相同）：m_{i→j} = x_i⁰ ∨ ⋁_{k∈N(i)∖j} m_{k→i}，x_i = x_i⁰ ∨ ⋁_{k∈N(i)} m_{k→i}。∨ 是逐坐标最大精度选择：两边都观测到的体素取值必然相同（同一个世界），所以这就是现在的 lattice join，即 CI 的 π ∈ {0, ∞} 极限。relay 解码后对并集证据做一次确定性的规范重拟合，再发出。
- 能量：E(x) = Σ_i Σ_b Σ_{v∈b} (π̄_v − π_{i,v})，π̄ = 连通分量内的证据并（全局截面）。每一轮 π_{i,v} 只增不减、不超过 π̄，所以 E 单调不增，树上 ≤ 直径轮归零。高斯视角：E_θ = ½ Σ_{(i,j)} Σ_f [π_{i,f} π_{j,f} / (π_{i,f} + π_{j,f})] (θ_{i,f} − θ_{j,f})²，只有两边都钉住的面计入，共识时为 0。
- 量化与变长：坐标本来就是整数体素，程序是证据的**无损**再表示，变长熵编码和"只发新息"都不改变迭代值，单调性不变。有损档若是删掉一个固定体素集 D（例如细部件），Q(x) = x ∖ D 满足 Q(x ∨ y) = Q(x) ∨ Q(y)，在 Q 的像格上同样单调；若是丢残差，只在源端作用一次，此后各轮都是无损 join，单调性也成立。

**架构草图。**
- 编码器：阶段 0 用贪心盒子覆盖（3D 前缀和，"新面片不碰 F"的判断是 O(1)；Python 每图约 2–5 s，C++ / GPU 约 10 ms），按"覆盖新占据体素 ≥ m"接收盒子。阶段 2 换成摊销提议网络（稀疏 3D 卷积 + 集合预测，约 2 M 参数），提议仍要经过 F 约束验证。
- 线路：盒子按 x0 排序，字段（Δx0, y0, z0, 宽, 深, 高）算术编码；残差用以渲染出的盒子为上下文的 ctx 编码；位姿按 0.1 mm 传并附修正集（约 27 B/智能体）。只发新息：发送方条件于反向消息，只发接收方那一侧还解释不了的盒子和残差。
- 融合：解码 → 证据并 → 规范重拟合（同一贪心，确定性）。
- 解码器：栅格化盒子和残差，再做光线投射。RTX 5090 上 8 × 3 × 65,536 条射线 × ≤ 100 步约 1.6 亿次查表，< 10 ms；本机 numpy 每个位姿约 0.45 s。
- 训练：阶段 0 不训练，已可用。阶段 1 训练程序先验：盒子 token 上的自回归 Transformer，6 层，d = 256，约 5 M 参数，序列 ≤ 128 盒 × 6 token，约 0.03 s/步，用 NLL。阶段 2 训练提议网络（集合损失 + 覆盖率），只为编码更快、程序更短。

**最大的风险。**
- R8 消息比自己地图大：并集的 F 约束多，盒子穿不过去；不同视角把同一张床拟成不同盒子，relay 必须去重。
- 非曼哈顿墙、圆柱（台灯、植物、圆桌）和细腿落进残差，个别房子里残差可能占大头。
- 只在确定性传感器下精确。真实噪声会让 O 与 F 冲突，需要概率版本，残差变大；但那是比特问题，不是 F1 问题。
- 学习的增益可能只有 20–30 %：静态直方图已抓住大部分规律。

**最小可证伪实验。**
- **E1-a（CPU，不占租约）**：在 uk-linux CPU 上用生成器的真位姿重建 24 个 VAL 房子（每进程 ≤ 15 min，分 4 批）。单变量是消息表示（程序 + 残差 + 位姿 对 ctx 三值栅格），对照是同一张图的 ctx。确定性，无种子。预注册判据：(i) 192 张自己地图和 192 张 R8 并集逐体素精确 100 %；(ii) 自己地图字节中位 ≤ 320 B，收敛消息和 R8 并集的中位 ≤ 0.40 × ctx 三值（本机 6 房：259 B、0.30 ×、0.29 ×）。任一不过，就否决"程序 + don't-care"的字节论断。
- **E1-b（1 个租约）**：单变量是盒子字段的概率模型（自回归 Transformer 对留一静态直方图），对照是静态直方图在同一批 TRAIN 程序上的码长，种子 342101、342202。判据：两种子的 VAL 码长都 ≤ 0.65 × 对照 → 杠杆；都 ≥ 0.85 × → 不是杠杆。

## 6. 设计 2：RaySheaf——只传"看到的占据面"和位姿（最稳）

**一句话。** 消息只传观测到的占据体素 O（稀疏、上下文熵编码、只发新息）和位姿，known / free 全由接收方光线投射推出：无损，家具 F1 = 1，字节约为 ctx 三值的 0.43（自己地图）到 0.62（并集）。

**为什么同时提升。** ctx 无损里 77 % 的比特花在可见性边界上（rate_split），而它是 "O + 位姿" 的确定函数（本机 0 体素差）。实测：自己地图 ctx(O) + 精确位姿 596 B（ctx 三值 1,384 B），收敛消息 1,052 B（1,752 B），R8 并集 1,756 B（2,813 B）；条件于反向消息再省约 24 %（发送侧占据体素里 63 % 是接收方没有的）。相对 gzip 4.6 / 3.5 / 3.5×，相对原始 220 / 125 / 75×。学到的八叉树上下文模型预计再省 20–35 %。预计 R8 表面 = K0 = 家具 = 1.000。

**底线。** 索引集、stalk、融合和能量都与设计 1 相同（逐体素 (μ, π) 证据加位姿槽；逐坐标最大精度 = OR；E 是证据缺口）。区别只在线路：这里直接对 O 做上下文编码，而不是写成程序；F 不上线，由接收方投射得到。有损档可以用砖块粗化 Q(O)（块内任一占据即全块占据）：它是 OR 池化，保 join；投射得到的 known 只会缩小，未知→已知 FPR 为 0。但实测有损档不可取：粗化后命中提前一格，家具只剩 .53 / .54（表面 .72 / .73）；删掉全部细部件只省约 14 % 字节，家具 .83 / .87，未知→已知 FPR 从 0 升到 .012 / .024。所以这条线应当无损。

**架构。** 编码器为恒等（O 直接取自自己地图）。熵模型是由粗到细的八叉树上下文 CNN：每个被占据的父格，用父层特征和接收方已知的边信息，预测 2×2×2 子格的 256 类字节，约 0.6 M 参数，5090 上一张图前向约 10 ms，0.05–0.1 s/步。融合是 OR。解码是光线投射。没有任何"学 F1"的部分。

**风险。** 学到的熵模型可能只比 KT-9 好 15–25 %；R8 消息随子树增大；对真实传感器噪声与设计 1 有同样的问题。

**最小可证伪实验。** E2-a（CPU）：与 E1-a 同一批 24 房，预注册判据为精确 100 %，且 ctx(O) + 精确位姿 ≤ 0.50 × ctx 三值（自己地图）、≤ 0.70 ×（收敛消息和 R8 并集）（本机 6 房：0.43 ×、0.60 ×、0.62 ×）。E2-b（1 个租约）：单变量是 O 的概率模型（八叉树 CNN 对 KT-9），两种子，两种子都 ≤ 0.70 × 判为杠杆。

## 7. 设计 3：RayField——保 join 的可变长神经码 + 可微占据渲染 + F1*/2 判决（学习型桥梁）

**一句话。** 保留神经编码器和解码器，但做三处改动：(i) 码是保 join 的可变长砖块码（块内 max 池化 + 单调量化），所以融合 = 逐坐标 max，恰好等于并集证据的码；(ii) 解码器输出"世界占据场"，未知空间不计损失，用已知位姿做可微的占据体渲染，得到 known / free / occupied 的边缘；(iii) 按 F1*/2 判决。

**为什么同时提升。**
- 去掉可见性边界（77 % 比特），码只需装面；可变长让比特流向家具竖柱。
- 保 join 让融合差（−2.5 pp）按构造为 0：并集上的 max 等于各自 max 的 max，单调量化与 max 可交换。
- 体渲染让 known 与 occ 自洽：消掉家具漏检里 18–29 % 的否决，以及 A 在 v420 规则下测到的 71 % 表面否决漏检。
- 有损时 F1*/2 是最优判决。

量级：16 × 16 × 8 个砖块（每块 8 × 8 × 4 体素），C = 8 通道，3 bit 单调量化。K0 有证据的砖块约 20–25 %（约 450 块），学到的先验约 1–1.5 bit/通道，所以 K0 约 450–700 B、R8 约 0.9–1.4 kB。预测（不确定性大）：K0 表面 .95、R8 表面 .94、家具 .80–.88。

**底线。**
- stalk：y_b ∈ {0, …, 7}^C，是链的积格；精度 = y 的单调函数。
- 融合：逐坐标 max，即最大精度选择。
- 能量：E(y) = Σ_i Σ_b Σ_c (ȳ_{b,c} − y_{i,b,c})，单调不增。
- 量化在 max 之前，且单调，所以 Q(max(a, b)) = max(Q(a), Q(b))；变长熵编码不改变值。

**架构。**
- 编码器 φ：逐体素 MLP（证据类别 one-hot + 块内偏移的正弦嵌入，3 层，64 宽）→ 块内 max 池化 → C = 8。
- 熵模型：砖块网格上的掩码 3D 卷积先验 + 超先验，约 0.5 M 参数。
- 解码器：砖块网格上的 3D U-Net → 128 × 128 × 32 的世界占据 logits，约 3 M 参数。
- 渲染：每智能体每步采 16k 条射线，每条 ≤ 100 个采样，透射率 T = Π(1 − p)，P(首次命中 v) = T_v p_v。
- 损失：渲染出的（首次命中，空闲，未知）三类边缘对目标的交叉熵（表面加权），+ λ·比特。
- 判决：P(首次命中) ≥ F1*/2 判占据，按预测的家具区分开 θ；P(到达) ≥ .5 判 known。
- 规模：约 4–5 M 参数，估计 0.25–0.35 s/步。

**风险。** max 池化码若装不下砖块内体素精确的面，就是又一次"竖柱量子"失败，家具会停在 .7 左右；漏掉的家具让射线穿过去，未知→已知 FPR 上升；λ 难选；从零训练两个租约可能不够。

**最小可证伪实验（1–2 个租约）。** 先测"解码路径"这一半。
- 单变量：解码路径。known / occ 两头 + 校准规则，换成世界占据场 + 可微体渲染 + F1*/2。码、编码器和融合全部沿用 3S-X：热启动，冻结编码器，只训解码器 10k 步。
- 对照：3S-X + 校准规则。种子 342101、342202。
- 预注册判据：两种子 ΔK0 表面 ≥ +1.5 pp 且 Δ家具区 ≥ +4 pp，并且 R8 FPR ≤ 对照 + 0.3 pp → 杠杆；Δ家具 < +1 pp → 否决"自洽可见性"这一半。
- 我的预测：K0 表面 +1–3 pp，家具 +2–6 pp。信息仍受 2 KB 码限制，所以不会是代际跳变。

## 8. 排序，与别的视角最可能犯的错误

**排序（前 3）。**
1. **ProgSheaf。** 唯一同时给出"F1 = 1（无损）"和"相对 gzip 十倍以上"的方案，CPU 原型已跑通。风险只在字节，学习只做熵模型。
2. **RaySheaf。** 最简单、最稳，是 ProgSheaf 的残差通道和后备；字节约为 ctx 三值的 0.43–0.62。
3. **RayField。** 唯一对真实噪声和极低码率有意义的学习方案；在这个合成世界里被前两个支配。

**别的视角最可能犯的错误。**
1. **继续加定长坐标**（64 × 64 × 1 → 128 × 128 × 1）。家具的量子仍 ≥ 2 格，而完美 2 × 2 × 1 只有 .77。我预测 3S-Z2 家具 [.62, .72] @ 8 KB。
2. **用生成式采样出计分地图。** 实测 −15 到 −22 pp。联合众数也是 −10 pp。
3. **只拿原始栅格当分母宣称几十、几百倍。** 一旦解码端可以光线投射，诚实的无损分母就是 ctx(O) + 位姿（自己地图约 596 B）。相对它，任何编解码器在全保真下最多再省约 4.5–5.5 倍（DL 107 B，精确位姿约 129 B）。"几十倍"只有相对 gzip 或原始栅格才诚实成立：ProgSheaf 现在相对 gzip 10.6× / 7.1×（自己地图 / 收敛消息），学到先验并只发新息后预计 15–18× / 17–21×；相对原始 507× / 254×。
4. **把家具问题归给细部件或 known 头。** 细部件全删仍有 .83–.87；known 头只占家具漏检的 18–29 %；大块家具召回只有 .48–.51。
5. **训练目标带容差**（tol-1、Chamfer、平滑占据）。家具 F1 零容差，一格错位就是 −45 pp。
6. **让解码器在未知空间"补全"家具。** 不计分，白花容量。正确的做法相反：把未知空间当 don't-care，用来缩短码。
7. **以为物体级、语义级码必须先解决跨智能体的数据关联。** 在证据格上做 join、再规范重拟合，就不需要关联。
