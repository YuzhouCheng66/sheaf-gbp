## 0. 一页结论

1. **物理事实已经证实。** 十个视角各自独立发现、协调者和我又分别复核过同一件事：在这个无噪声世界里，一个智能体的三态地图，等于用它自己的 3 个位姿和公共射线集，穿过任意一个"一致世界" W（O ⊆ W ⊆ ¬F）做首次命中投射的结果。所以可见性不用传也不用学，未知区可以随便补。
2. **不学习的精确码已经同时支配学习码。** 一个不学习的结构化精确码 S0（平面图 + 一致世界里的实心盒 + float32 位姿，解码 = 栅格化 + 光线投射）在 24 个 VAL 房子上实测：自己地图 219 B，收敛消息 401 B，R8 并集 723 B，一次 R8 融合全网 6.07 KB/房，四个 F1 全部 = 1.000。现模型是 2,048 B/条、229 KB/房，家具 .58。学习码在字节和 F1 两条轴上同时被支配。
3. **家具差的根源是表示，不是比特数。** 家具区 F1 是零容差的薄壳 F1，完美目标水平错 1 格就只剩 .52–.57。现码对家具的水平分辨率只有"4×4 竖柱 + 一个 8 bit 均值"。坐标阶梯到不了 .8：完美的 2×2×1 降采样也只有 .77。
4. **压缩：哪些倍数成立，哪些不可能。**
   - 今天就成立：相对原始栅格几百到上千倍；相对 gzip 洪泛 24 倍，其中 2.9 倍来自网内融合协议，8.5 倍来自编码。
   - 全保真下不可能（解码器不得预知场景，位姿按精确计价）：相对真正的最强无损（S0），按 DL 估只剩 1.4–1.7 倍；单是精确位姿这一项，就把上限压在 9–22 倍以内。相对 ctx 也只有 4–9 倍。所以"相对最强无损几十倍"在这个世界里不可能。
5. **学习的裁决。** 在干净世界里，学习对 F1 的贡献为 0，对码率按 DL 估最多 1.7 倍，"学习 + sheaf-GBP"在现基准上立不住。新一代的价值主张只能放在"测距噪声 + 位姿误差 + 机间配准误差、按干净真值评分"的世界里，评估必须改。
6. **主推与备选。**
   - 主推 M（ESR-Sheaf）：两层证据 sheaf。干净时是精确格层，有噪声时是整数 log-odds 在森林上求和，加 SE(2) 位姿 stalk。线路用结构语言，学习放在生成先验（熵模型、去噪器）和配准前端。
   - 备选 B（LF-Sheaf）：同态学习潜码场 + 首击渲染。
7. **先做两个纯 CPU 实验。** 第一个实验 E0 是精确码决赛，0 个租约。并行做 E1：噪声与配准面板的地板，同样 0 个租约，它决定学习还有没有空间。

### 1.3 辩论里已经了结的争议

- **对学习潜码做信息相加**（A09-B、A08-D3）：重叠观测是同一个确定性事实，求和会按 μ = 2.87 重复计数（A01、A02、A04、A10）。求和只适用于独立的传感器噪声。
- **A04"盒子槽位只有 .53"**：这是把包围盒画进了已观测空闲区。先裁掉 F 再渲染就是 1.000（A10 box_carve）；原语级贪心盒 192/192 精确（A03）。
- **A04"理想增量 254 B/边"**：不可实现，漏掉了"告诉接收方哪些它已经有"的代价。可实现的条件码中位约 1,131 B（A10）。
- **A04 ΔV-Sheaf 依据的".93 竖柱区间"神谕**：在它实际用的 2×2 竖柱分辨率上只有 .67 / .51（A05 p8）。
- **用 diffusion / MeanFlow 直接出计分地图**：被 F11 否定。
- **不重训把 known 头换成光线投射**：被 F12 否定。
- **"浮点运算不精确"的担心**：已撤回（F3）。
- **算力估计**：A02 的 0.1 s/步偏乐观，按项目实测吞吐应为 0.16–0.25 s/步（A07、A09）。

## 2. 对用户两个担心的直接回答

### 2.1 家具区 F1：为什么差，能做到多少

**为什么差：三层原因叠在一起。**

1. **度量。** 家具区 F1 是零容差的首次命中薄壳 F1。完美家具整体水平挪 1 格就只剩 .52–.57；把细部件全删掉反而还有 .83–.87（F10）。所以它首先考的是"水平面落在哪一格"。
2. **表示，这是主因。**
   - 码的空间量子是 4×4×32 竖柱，每柱一个 8 bit 均值；80 % 的家具目标体素在竖直侧面上，它们的水平位置正是竖柱均值说不清的东西。
   - 结果是召回只有 .48，漏检是虚构的 3.8 倍。面在竖柱边上时召回 .33，在竖柱正中 .53（F9）。
   - 同样水平量子的经典 4×4×1 降采样是 .47–.49，和我们几乎一样；2×2×1 是 .76–.77。**家具 F1 由水平量子决定，不由字节数决定。**
3. **比特放错了地方。**
   - K0 时 80 % 的坐标没有观测；均值与"竖柱空闲比例"的 Spearman 相关是 .90，对家具占据的 R² 只有 .46。码主要在编码可见性，而可见性由位姿免费给出（F1）。
   - 现码改成"只发有证据的坐标 + 熵编码"后约 270–330 B，与 S0 的 219 B 同量级（估计）。**字节差得不多，是信息放错了地方。**

**不是瓶颈的：** known 头（只占漏检的 18–29 %）、细部件、判决阈值（扫描是平的）、体素分辨率读出（+0.0）、数据量。

**坐标阶梯：** 每升一级字节 ×4，F1 +4–6 pp。64×64 对家具仍是 2 格的水平量子，天花板约为完美 2×2×1 的 .77。A06 预注册 3S-Z2 家具落在 [.62, .72]，结果约 04:30 UTC 出来，无论多少都不改变本结论。

**新一代能做到多少：**

| 世界 | 家具区 F1（R8 / K0） | 字节（自己地图） | 依据 |
|---|---|---|---|
| 干净，M 的精确层 | **1.000 / 1.000**（实测） | 219 B | F1、F2、F5 |
| 干净，只删不糊 | m = 16：.956 / .941；m = 32：— / .857（实测） | 146 / 108 B | F13 |
| 噪声 cam 档，M 的噪声层（**目标**，未测） | ≥ .88–.90 / ≥ .83–.85 | 250–400 B | 地板 .756 / .775；求和 + 配准做好时的参照：无机间误差 .915；无位姿误差 .977（F15） |

**"实用"建议这样定义（A07 提议）：** 家具区 F1（容差 1）≥ .95，部件召回 ≥ .95，幽灵 ≤ 0.1 个/机。经典 2×2×1 在干净世界已经达到 .96 / .96 / 0，我们现在是 .70 / .46 / 0.4–1.1。

**倍数拆成三个独立因子（C2 复核）：**

- **协议因子**（洪泛 → 中继，也就是 sheaf/GBP 网内融合的真实码率贡献）：体素码 2.87–2.91 倍，S0 只有 1.96 倍。S0 的位姿开销无法靠中继省掉，结构描述本身也已经吃掉了一部分冗余。
- **轮次因子**（定长同步 8 轮 → 每条边只发一次）：8 倍。这是现系统的浪费，不是任何方法的功劳。
- **编码因子**（同一协议下）：S0 对 gzip 8.5 倍，对 ctx 4.0 倍。

- 还有一个容易被忽略的事实：**现系统在压缩上的短板主要在线路，在精度上的短板在表示。** 现码换成诚实线路后，全网字节已经和 S0 同量级，但 F1 是 .91 / .93 / .58。

**"几十到几百倍"什么时候成立：**

- **今天就成立（不学习，实测）：**
  - 相对原始栅格：单条 181–600 倍，全网 1,210 倍；
  - 相对 gzip 洪泛：全网 24 倍，其中 2.9 倍来自融合协议。
- **估计能成立：**
  - 学习先验之后，相对 gzip 洪泛约 30–40 倍；
  - 噪声世界里，相对"gzip 洪泛噪声图"约 28–43 倍（A07 估计，要等 E1 / E3 实测）。
- **单条相对 gzip ≥ 20 倍：** 全保真时只有逼近 DL 的码才碰得到（DL 本身是 19.1 倍，而且含家具库知识）。不借生成器知识，就只能有损，例如 m = 32 时 24 倍，代价是家具 .857。
- **信息论上不可能**（解码器不得预知场景，全保真，位姿按精确计价）：
  - **相对 S0 几十倍：** 一条自己地图消息光位姿就要 10–24 B，S0 才 219 B。即使几何部分是 0 字节，上限也只有 9–22 倍；几何部分按 DL 约 100 B 计，上限约 1.7 倍；先验比 DL 再好 40 %，也不到 3 倍。

## 4. 新一代架构

### 4.1 主推 M：ESR-Sheaf（证据—结构—光线）

**一句话。** 融合状态停在不可再分的证据上（干净时是精度 0 / ∞ 的三态体素，有噪声时是整数 log-odds），位姿自成 stalk。线路把证据写成"一致世界的最短结构描述"。解码 = 栅格化 + 光线投射。学习只放在生成先验和配准前端。它取的是 A01–A10 十份合成提案的公共部分。

**stalk 索引集与内容**

| 索引 | 范围 | 干净（L1） | 噪声（L2） |
|---|---|---|---|
| I_vox | 128×128×32 公共体素，按 32×32 竖柱稀疏记账 | {⊥ < 空, ⊥ < 占}，精度 0 / ∞，等价于饱和 log-odds | 整数 log-odds ℓ̂ ∈ [−15, 15]，向零取整，\|ℓ̂\| 即精度 |
| I_pose | 每个智能体一个槽 | 3 个位姿：float32，或源端先量化再建图；拥有者精度 ∞ | (μ ∈ SE(2)×ℝ, Λ) 高斯 |
| I_glob | 全局 | 楼板层、墙高、门高（平坦格） | 同左 |
| 线路语言（不是状态） | — | 平面列 {⊥, 墙, 门楣} + [O, ¬F] 内的实心盒 + 光线序残差事件 | 同左，但盒和平面是去噪的 MAP 拟合，另附区域精度档 |

**GBP 迭代与能量。** 消息式和现在的 `rollout_max` 完全相同，只是基换细了，⊕ 在 L1 是 join，在 L2 是饱和整数和：

$$m^{t+1}_{i\to j}=a_i\oplus\bigoplus_{k\in N(i)\setminus j}m^{t}_{k\to i},\qquad b^{t}_i=a_i\oplus\bigoplus_{k\in N(i)}m^{t}_{k\to i}$$

L1 的能量是格秩亏量，也就是 D8 的 Tarski Laplacian 调和流：

$$E_1(t)=\sum_i\sum_{v\in I}\big[\rho(x^\ast_v)-\rho(b^t_i(v))\big]\ge 0,\qquad \rho(\bot)=0,\ \rho(\text{空})=\rho(\text{占})=\rho(\text{位姿})=1,\qquad x^\ast=\bigvee_{j\in\mathrm{comp}(i)}a_j$$

L2 的能量是尚未吸收的证据源数，加上位姿的高斯 sheaf Laplacian（限制映射 = SE(2) 变换）：

$$E_2(t)=\sum_i\big|\mathrm{comp}(i)\setminus S^t_i\big|+E_{\rm pose},\qquad E_{\rm pose}(T)=\sum_{(i,j)}\big\|\mathrm{Log}(\hat Z_{ij}^{-1}T_i^{-1}T_j)\big\|^2_{\Sigma_{ij}^{-1}}+\sum_i\big\|\mathrm{Log}((T^0_i)^{-1}T_i)\big\|^2_{\Sigma_i^{-1}}$$

**为什么下降：**
- **L1：** join 是外延的；从 m⁰ = ⊥ 归纳可得消息单调，所以 E₁ 不增，树直径（≤ 7）轮内归零。线路编码满足 Dec(Enc(m)) = m（F1、F2），所以编码前后的轨迹逐位相同。
- **L2：** 通信图是 Kruskal 森林，腔消息让每个源恰好进入每个信念一次，S_i^t 单调增大，所以 E₂ 不增。不动点在树上是精确后验（树上 Bethe = Gibbs）。
- **位姿：** 森林二着色，两色交替做阻尼 Gauss–Newton（线性化 GBP），只接受让 E_pose 下降的步。顺序是"位姿收敛 → 按新位姿重新分箱证据 → 证据融合"，两段各自单调。相对位姿观测 Ẑ_ij 来自对齐重叠区里收到的平面图和盒子地标。
- **量化、变长、增量**（A04 的 L-Q / L-S / L-Δ）：
  - 源端只量化一次，并且向下取整，不夸大证据；中继原样转发码本值。
  - 省略 ⊥、只发接收方下界之外的新息，都是精确的。
  - 熵编码是双射。
  - 有损只在源端做一次，或者用向下投影（A04 P10：逐跳有损重拟合在干净世界只差 ≤ 0.25 pp，但规则要写死）。

**用户可能的质疑，以及回答：**

1. **"sheaf 向量退化成了观测原子，GBP 退化成了集合并，这还算 sheaf-GBP 吗？"**
   - 算。A04 的角点命题：若每个坐标上的证据要么缺席、要么精确且一致，那么对 β ∈ [1, ∞]，$Q_\beta=(\sum_i q_i^\beta)^{1/\beta}$ 定义的融合（β = 1 是 sum-GBP，β = ∞ 是协方差交叉 / max）不动点完全相同，Tarski 秩亏量是整个 β 族共同的 Lyapunov 函数。L1 就是 GBP 在"精确证据角点"上的形态。
   - 到了 L2，精度变成有限值，融合就是货真价实的树上精确 BP。位姿 stalk 带非恒等的 SE(2) 限制映射，sheaf 结构第一次变得非平凡：重叠区必须先对齐。
2. **"学习在哪里？"**
   - 干净世界里只在熵模型（≤ 1.7 倍）和编码速度上；F1 不需要学习，这一点应当坦白。
   - 噪声世界里有四处：去噪的结构编码器（MAP 拟合）、生成先验（码长）、配准前端、给边缘概率做 F\*/2 判决。
   - 如果用户一定要一个"学习出来的 sheaf 向量在 GBP 里交流"，可以加可选组件 M+：A01-Ⅱ 的学习潜码 stalk，32×32 竖柱 × 4 个整数 + 精度，max-precision join，充当超先验。门槛是潜码 ≤ 60 B，且净省 ≥ 15 %。
3. **"这是在钻合成世界的空子吗？"**
   - L1 确实依赖确定性传感器，所以它只当基线和单元测试，价值主张放在 L2 和 v5 面板上。

**线路与熵编码：**
- 每条消息 = 4 B 头部 + 新位姿 + 新平面位（2D 上下文码）+ 新盒子 + 光线序残差事件。编码端渲染自检：盒子解释不了的地方退回残差，保证 100 % 精确，修掉无标签分割那 2/192 张的不精确。
- 编码端在不关心区里补全时，由先验挑选概率最大的那种（A02 的"遮挡区是免费画布"）。
- 以反向消息（腔）为条件，只编新息；整网用收集—分发调度。
- 中继先在证据格上 join，再规范重拟合；不转发各自的描述（转发各自描述字节 ×2.6）。

**解码器：**
- 栅格化 + 整数 DDA 光线投射，跨设备逐位一致；GPU 上约 10 ms。
- L2 读融合后的 log-odds，按区域取 F\*/2 阈值判决；对不确定体素用"停下但标未知"，在构造上不漏光。

### 4.2 备选 B：LF-Sheaf（同态学习潜码场 + 首击渲染）

**一句话。** 这是主推 M 在真实数据和非盒几何上的退路，也是"学习的 sheaf 向量"最完整的版本。家具 stalk 是稀疏 4³ 块上的学习潜码：逐体素特征先 max-pool，再单调量化，于是并集的码恰好等于码的逐元素 max。融合用 join。解码 = 局部隐式占据场 + 可微首击渲染 + F\*/2 判决。它由 A05-1、A06-3、A09-A、A04 E3 合流而来。

**stalk。**
- 索引集 I_furn = 32×32×8 个 4³ 块（稀疏），I_plan = 128²（OR 格），I_pose 同 M。
- 块 stalk 为 $x_i(b)=(\pi_i(b),z_i(b))$：π ∈ {0, 1, 2} 是证据级（无 / 只见空闲 / 有击中），即精度；潜码为

  $$z_b(M)=Q\Big(\max_{v\in b^+,\,M(v)\ne\bot}\phi_\theta(p_v,M(v))\Big)\in\{\bot,-K..K\}^8$$

- 对一致的观测有 $z(M_1\vee M_2)=z(M_1)\vee z(M_2)$。A05 p5 在它的特例 max-plus AABB 上验证过，A04 P6(d) 做过玩具检验。

**能量。**

$$E_B(t)=\sum_i\sum_b\Big[\sum_c(\bar z_{b,c}-z^t_{i,b,c})+(\bar\pi_b-\pi^t_{i,b})\Big]\ge 0$$

- join 是外延的；Q 单调，所以 Q(a ∨ b) = Q(a) ∨ Q(b)，量化后 E_B 照样不增。
- 融合差里"选源"那一半按构造归零。
- 噪声下潜码之间**不能求和**：重叠观测会重复计数。

**线路、解码与损失。**
- 线路：活跃块 + 16×16×4 超先验，以平面图为条件做熵编码，只发新息。
- 解码：潜码网格上跑 3 层上下文 U-Net，在查询点三线性插值，拼上 Fourier 特征后过 MLP，得到占据 logit；再从到达位姿做首击渲染。
- 损失：首击射线 NLL $-\log\sigma_s\prod_{j<s}(1-\sigma_j)$ + 家具加权 BCE + λ·bit；没有 known 头；空闲召回作保护。
- 规模：约 0.8–3 M 参数，A05 估 0.10–0.15 s/步。

**用户的质疑与回答。**
- **算不算 sheaf-GBP、学习在哪里？** 它和现模型同构：学习的向量 stalk + max-precision join + 秩亏能量。学习无处不在：编码器、潜码、解码场、超先验。
- **它在干净世界被 S0 支配，凭什么做？** 它不该在干净世界做，只在 v5 面板上与 B5 和 M 的 L2 比。它的价值在于盒子语言失效的地方：偏航、曲面、杂物、真实扫描。

**预计。**
- 干净世界（估计）：自己地图 150–300 B；家具 .65–.85（A05 自报 .85–.93，A06 预测 [.62, .80]）；表面 .95–.97。
- 噪声世界：没有可信预测，由门槛 E5 决定。
- 最大风险：噪声下 max 融合放弃了多观测的去噪收益（F15：max 的家具精度随观测重数降到 .39）；而要求和，就得给潜码加按源记账，字节随来源数增长。

### 4.3 "压缩再生成 / diffusion / MeanFlow"放在哪里

| 位置 | 做什么 | 为什么 |
|---|---|---|
| 熵模型（M 与 B 都有） | 码长 = −log₂ p_θ；算术解码就是"由比特驱动的生成采样"——先生成，再用比特纠正。M 用盒 token 上的 AR 模型 + 残差上的 next-scale / 掩码离散扩散；B 用超先验 | 这是"压缩再生成"在信息论上的精确形式；F1 不受影响 |
| 编码端补全（M） | 在不关心区里让先验挑最可能的补全 | 任何补全都精确（F2，C2 复核）；在体素码上实测省 35–43 %（A02 P7） |
| 去噪先验（L2） | MAP 结构拟合里用一步 consistency / MeanFlow 去噪器 | 一步即可，装得进 0.2 s/步的预算；不需要样本 |
| 可视化 | 在未知区采样补全，只用于展示 | 不计分，不进证据格 |
| **不放**：生成计分地图 | — | F1 最优判决是对边缘取 F\*/2 阈值；采样让家具掉 6–22 pp，联合众数也掉 10 pp（F11） |

## 7. 留给文献阶段的具体问题

1. **多机器人建图实际传什么、传多少？** 点云、关键帧 / 深度图 + 位姿、子图、OctoMap、TSDF 各是多少 KB/s，配准精度如何？"传深度图 + 位姿、接收端重投射"是不是标准做法（这正是我们的 F1 恒等式）？"融合后的并集中继"（2–2.9 倍协议因子）有没有先例？gzip / OctoMap 洪泛是不是合理的实践基线？

## 8. 少数意见（有分量，但没有进主推）

- **A08 / A05-2：** "家具是词"的 token 码是压缩路线的第二名，也是噪声下天然的配准地标；在噪声里它不随噪声变长，相对无损噪声图可达 16–22 倍。本文只把它列为"知道生成器的上界"。如果文献显示学习的部件词表在真实数据上召回够高，它应升为 M 的上层线路。
- **A07：** 若 E1 显示噪声面板也没有学习空间，就应停掉学习码线，直接把结构化精确格层作为系统工作发表。这是一条硬止损，本文采纳为 E1 的判据。
- **A04：** 主张保留一个学习潜码 stalk（A01-Ⅱ），让"学习的 sheaf 向量"留在融合路径里；并主张噪声下用按源位图让求和在任意图上幂等（split-CI）。本文作为 M+ 的可选组件，带门槛。
- **A06 / A08：** 纯测距噪声没有区分度，面板的主矛盾是位姿和配准；应把传感器噪声和配准拆成两条独立的轴。本文部分采纳（`_nf` 对照和单轴档），但 cam 档仍按 A07 合在一起报。
- **A09：** 不预生成噪声缓存，改为 GPU 在线传感器仿真。新结构一律先做函数保持的扩展，K0-only 筛选，12k 次之前不按 F1 掐。这些是执行纪律，应写进 E3–E5 的预注册。
- **A05：** 噪声里真正的主角是连续坐标——一块平面被 N 条射线命中，误差按 σ/√N 下降；带偏航的连续盒面能收回旋转带来的 ×1.6。这支持 B，也支持 M 的去噪编码器用连续参数。
- **A02：** next-scale / 掩码离散扩散熵模型就是"压缩再生成"的精确形式，遮挡区是免费画布。本文采纳，但 A02 原来估计的 ×0.6–0.8 增益已被它自己下调到 ×0.7–0.85。
- **A03：** 这个基准对结构化方法太容易。任何结构化结论都必须在扰动世界和真实扫描（Replica / Gibson）上复核，否则就是对生成器的过拟合。
- **A10：** Slepian–Wolf 分箱和显式拉取最多再省 8–15 %，不值得。树上的反向消息就是免费的边信息。
- **C2 自己的一点保留：** M 的 L2 用"去噪后的结构描述 + 区域精度"来近似各源的充分统计量。它与真正传 log-odds 相比损失多少，现在没有任何测量。这是 M 在噪声世界里最大的未知数，E3 必须把"无损传 log-odds 再求和"作为上限一并报告。
