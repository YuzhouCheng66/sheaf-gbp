## 1. 读出端学习先验与底线（E3-R）

### 1.1 对象（从冻结代码读出）[事实]

- **公共索引集**：V = 128 × 128 × 32 个体素。cam_nf 下所有机器共用坐标系；cam 下用各机位姿把地图搬到公共坐标系。
- **智能体 i 的 stalk**：x_i = (e_i, c_i) ∈ ℤ^V × ℤ^V。
  - e_i = c_s(L_i) ⊙ 1[τ_i]，c_s 是 E1c 的 111 项表；
  - c_i = 1[τ_i]，τ_i 是已知（触及）集；
  - 实现：`g4_e3r.stalk`。
- **消息与信念**（`G.relay`）：
  - m_{i→j} = x_i + Σ_{k∈N(i)∖j} m_{k→i}；
  - b_i = x_i + Σ_{k∈N(i)} m_{k→i} = (S, k)。
  - 每次合并都断言来源位图不相交，信念断言等于直接和（`relay_sums`）。
- **读出**：x̂ = 1[D_φ(S, k, z) ≥ t] 在 k > 0 处，k = 0 处为未知。
  - 已知掩码断言与 B4 逐位相同（`eval_job`）。
  - 网络特征里没有 ℓ0。网络的偏置 β 以 −θ·0.05 为初值，ℓ0 只以读出偏置的形式出现一次。
- **训练**（`sample_tensors`）：输入是连通分量中随机 1..n 台机器的子集和，损失只在"计分范围 ∧ k > 0"内计，只用 TRAIN 房、噪声种子 200–202。
  - 所以 D_φ 对任一中间信念（部分来源）都有定义。K0 就是它作用在第 0 遍的 b_i = x_i 上。

### 1.2 GBP、能量与单调量

**(a) 这就是信息形式的 GBP。** [推理]
- 把每台机器对体素 v 的观测看成一次单位精度的高斯测量，信息量为 e_i(v)。
- 那么体素 v 的 GaBP 消息就是 (η, Λ) = (Σ e, Σ 1)，正是 E3-R 的 (S, k) 两个通道。
- 在树上，GaBP 收集—分发两遍得到精确边缘。所以"两个和"是 GBP 在这个因子分解模型下的精确形式，不是近似。

**(b) 可测的能量。** 记分量的目标和为 k*，第 t 遍 i 的计数为 k_i^t。
- **计数亏缺** E_k^t = Σ_i Σ_v (k*_v − k^t_{i,v}) ≥ 0。
  - 来源只增不减、两两不相交（断言），所以 E_k^t 单调不增。
  - E_k^t = 0 当且仅当每个节点都持有完整的分量和。
  - E_k 就是线路上实际传输的向量，比抽象的 Bethe 自由能更可验证。建议每个批次把它写进日志。
- **来源亏缺** Φ^t = Σ_i |C(i) ∖ prov_i^t|，每遍严格下降，两遍归零。
- **不动点**：树上 Bethe = Gibbs，不动点是因子分解模型的精确后验自然参数。

**(c) 读出能量**：x̂ ≈ argmin_y [−log p_φ(y) − Σ_v y_v g_φ(S_v, k_v)]。
- 这是单次解码，不迭代，也不需要通信，因为 p_φ 是公共因子。g_φ 依赖 k，用来吸收"多机证据相关"的似然失配：B6 在 k ≥ 3 时校准斜率约 .6。
- 底线要求的"迭代交流下降能量"由 (b) 承担；(c) 是终端的一次性解码。

### 1.3 先验只计一次

- **论证。** [推理]
  - 后验为 p(y | Z) ∝ p_φ(y) · Π_i ℓ_i(y)。p_φ 是公开因子：φ 对所有节点公开，与 E1c 表、ℓ0 地位相同。
  - 在联结树语义下，公开因子只需挂在一个团上，等价于每个节点在本地乘一次。同一分量内各节点的 b 逐位相同，所以各节点的后验也相同。
  - 消息只带似然部分的充分统计量。任一节点后验中 p_φ 的重数 = 从数据到该节点输出的路径上 φ 被调用的次数 = 1。
- **代码核对。** [事实] `net_logits` 只在分量和与各机自己的 stalk 上调用，输出只进 `scored`，从不进 `G.relay`。
- **建议每个批次加的三条不变量测试**：
  1. **φ 无关性**：把 φ 换成随机权重，所有消息逐字节不变（∂m/∂φ = 0）；
  2. **拓扑无关性**：同一分量换一棵生成树或换一种调度，读出逐位相同；
  3. **一致性**：同一分量内各节点的读出逐位相同。

### 1.4 网络不是融合算子

- **判别标准**：融合算子 ⊕ 必须是 stalk 空间上的交换幺半群（结合、交换，单位元是"零观测机器"）。只有这样，任何树、任何调度给出的信念才相同。
- **D_φ 不满足。**
  - 它的定义域是 ℤ^V × ℤ^V × z，值域是 {−1, 0, 1}^V。值域不是 stalk 空间，所以它在类型上无法再进入消息。
  - D_φ(D_φ(a) ⊕ D_φ(b)) 一般不等于 D_φ(a ⊕ b)。它也不需要相等，因为它只在 ⊕ 收敛之后作用一次。
- **离开底线的写法**（今后审查要查）：
  1. 读出网络读各机分开的 stalk，再用学习聚合；
  2. 读出结果回传后与本机证据再融合；
  3. **新增第 7 条：下行只发读出结果（三态）。**
     - R-B 提出这一做法能再省 2–2.6 倍，并请 R-C 判。
     - 我的判断：**不作默认。**理由有三：
       - 它把 D_φ 的输出放进了消息，违反 C5；
       - 非根节点不再持有 sheaf 向量 b_i，E_k 在非根节点永远不归零，"中间 sheaf 向量"在下行上消失；
       - 节点之后若有新证据，就只能把自己的似然加到别人的后验上，造成先验重复计数。
     - 它可以作为"收集 GBP + 结果广播"的工程变体单独报告字节，但要明确标注它不在底线的严格形式内。
     - 合规的省法：下行发压缩后的腔和（q 级计数），让每个节点自己读出。

### 1.5 诚实的限定 [事实]

- 计数通道多花约 13 % 字节（88 KB 对 665 KB，D8-48）。
- clean 档 R8 家具 1.000 → .997–.998。
- 增益来自本生成器的形状先验，还没在留出类别上测过。
- cam 档：
  - NET 的 R8 家具 .806 / .813（342101），容差 1 下 .937 / .947；

## 2. 源端学习（E3-S）：怎样写才干净，怎样与压缩统一

### 2.1 第一性原理 [推理]

- **局部码保持条件独立。**
  - 若给定完整地图 y 时 z_i ⊥ z_j，那么任何只依赖本机数据的确定性函数 g_i = g(z_i) 也满足 g_i ⊥ g_j | y。
  - 所以 p(y | g_1..n) ∝ p(y) Π_i p(g_i | y)：先验恰好一个因子；信息只丢不增（数据处理不等式）。
  - "源端用了先验"本身不构成重复计数。
- **重复计数来自逐体素因子分解。**
  - 系统把 p(g_i | y) 近似成 Π_v exp(y_v ẽ_i(v))。
  - 当 g_i(v) 依赖 v 的邻域时，逐体素边缘似然会把邻域先验积分进去：p(g_i(v) | y_v) = Σ_{y_−v} p(g_i(v) | y) p(y_−v | y_v)。射线传感器的邻域是射线；源端去噪器的邻域是感受野。
  - k 台机器相加时，这一项被计 k 次。原始 V3 证据已有此问题（B6 在 k ≥ 3 时斜率约 .6）。
- **干净的补救只有一个**：读出端在它实际看到的统计量上用随机子集监督训练（或至少在该统计量上选阈值）。这样它学到 p(y | 统计量)，按构造是校准的；代价只是统计量可能不再充分。

| POSTSUM（源端去噪，软） | .7803（−2.5） | .7933（−2.0） | .919 / .936 |
| VOTE1（源端去噪，硬） | .7633（−4.2） | .7776（−3.6） | .919 / .942 |

- LIN 与 NETR 两行与 E3-R summary 的 cam 档逐位相同，可作自检。
- 读法 [推理]：在 cam 下，每台机器的去噪图在自己的（错位的）坐标系里是"清晰但偏了"的；把几张偏了的清晰图相加，比让读出端看见模糊的和再统一判断要差。
  - 所以**在主档上，学习先验必须看到融合后的证据**。这是"放在读出端"最强的理由，比 cam_nf 上的 0.1–1 pp 大一个量级。
  - 这也说明：任何源端去噪的压缩方案（QPOST4、VOTE1，以及 R-B 所说"几十 KB 必须源端去噪"的路线）在主档上要付 2–4 pp。
- k 分层（种子 1）：NETR k = 1 / 2 / 3–4 / ≥ 5 为 .810 / .850 / .872 / .882，POSTSUM 为 .786 / .821 / .847 / .873。差距在 k = 1–4 层最大。

### 2.4 统一的干净形式："虚拟传感器 + 求和 + 在其上训练的解码器"

- **源端**：g_i = Q_ψ(z_i) ∈ A^V，A 是小字母表（例如 q 级或票）。ψ 可以是固定量化器，也可以含去噪网络。
- **嵌入**：h(g)，即逐级的 one-hot，或标定级值。
- **消息**：m_{i→j} = h(g_i) + Σ_{k≠j} m_{k→i}。
- **信念**：b = Σ h(g)，是虚拟传感器模型在逐体素条件独立下的充分统计量。
- **线路**：W(g_i) 或 W(m)，无损编码（ctx 计数场；干净世界用 W3）。熵模型可以用公共先验，但不改变语义。
- **读出**：D_φ(b, z)，在 Σ_{i∈S} h(Q_ψ(z_i)) 上用随机子集训练；或者在 TRAIN 上对该统计量选阈值。

**五个条件**（满足即在底线内）：

| | 条件 | E3-R | R-B q4 + 冻结 NET | QPOST4 / VOTE1 | 下行发读出结果 |
|---|---|---|---|---|---|
| C1 | 局部：g_i 只依赖 z_i | ✓ | ✓ | ✓ | ✓ |
| C2 | 支撑在 τ_i 内，已知掩码与 B4 逐位相同 | ✓ 断言 | ✓ | ✓ | ✓ |
| C3 | 融合是固定的整数求和，来源断言 | ✓ | ✓ | ✓ | 上行 ✓，下行 ✗ |
| C4 | 读出在它实际看到的统计量上训练或选阈值 | ✓ | 近似：级值是标定 LLR，NET 不重训；q4 实测不掉 | 阈值须在 TRAIN 上对该统计量重选（探针用的是 K0 阈值） | — |
| C5 | 读出输出不进任何消息；每个节点持有 b_i | ✓ | ✓ | ✓ | **✗** |

- **完整的源端学习（真正的 E3-S）**是同一形式的率失真版本：min_{ψ,φ} E[BCE(y, D_φ(Σ_{i∈S} h(Q_ψ(z_i))))] + λ E[Σ_i |W(Q_ψ(z_i))|]。也就是以求和为瓶颈的分布式自编码器，而这个求和瓶颈本身就是精确 BP。
  - 它在底线内，但现在不做：cam_nf 余量约 3 pp；§2.3 显示在主档上源端承担先验反而更差；奥卡姆上多一个网络。
- **"只发量化似然、由读出端先验解码"**就是 Q_ψ 取固定量化器的特例，是奥卡姆最优的写法。R-B 实测 q4 不重训也不掉精度，所以它也是现在的默认候选。

### 2.5 与压缩的统一：两条路线

| 路线 | 先验位置 | cam_nf 家具 | cam 家具 | 线路（每房中位，ctx，严格收集—分发） | 网络数 |
|---|---|---|---|---|---|
| E3-R 原样 | 读出 | .966–.973 | .806–.813 | 753 KB | 1 |
| R-B q4 + 冻结 NET | 读出 | Δ 0.00 到 −0.12 pp（R-B 探针） | 未测 [估计：同 NETR ±0.5] | 304–352 KB（R-B 探针） | 1 |
| QPOST4（τ = 2） | 源端 | Δ −0.20 / −0.44 pp（342101）、−0.24 / −0.34 pp（342202） | [估计：−2 到 −4 pp] | 115–117 KB | 1 |
| VOTE1 | 源端 | Δ −0.68 到 −0.95 pp | −3.6 / −4.2 pp | 98–100 KB | 1 |

- **推荐的默认**：
  - 主档以精度为先，用"读出端先验 + R-B 的 q4 量化 stalk"（约 2.1–2.5 倍压缩，不掉精度）；
  - 源端去噪路线（约 6.5–7.7 倍）作为第二个帕累托点并列报告，并写明它在 cam 上付 2–4 pp。
- **"几十 KB"**：只有源端去噪才能到，而源端去噪在主档上掉精度。按用户的优先级（精度 > 压缩），不让它做默认。
- **W3 在噪声世界**：R-B 实测"光线投射重建"不成立，盒子数是干净图的 20 倍。我上一稿对"去噪图 + W3"的 35–60 KB 外推撤回；去噪图的字节以 R-B 的 25–40 KB 下限估计为准。

## 3. 剩下 2 个 GPU 租约

**事实约束**
- 每个租约 7,200 s，一次性，不续租。
- E3-R 两个种子各 40,787 步、每步 0.060 s，全租约用了 4,980 s。一个租约只容得下一个臂 × 两个种子。
- E4 / E4b 都判不够；配准受岛上限约束，不为配准排 GPU（D8-49）。

**候选**

| H-B：去掉若干家具类别后重训 | 安全 | — | 只在 H1 判"有害"或 ambiguous 时 | 第 3 个租约的条件候选（与 R-A 一致） |

**为什么 E3-C 值一个租约，而且不算"为配准排 GPU"** [推理]：

1. 主档剩下的约 16 pp 大多是岛间平移造成的约 1 体素错位，单机证据里没有信息，配准算法越不过（D8-45、D8-48 补充、D8-49）。剩下唯一合法的做法是**在读出端对不可观测的位姿边缘化**：给定融合后的模糊证据，输出期望 F1 最优的折中边界。这需要读出端见过 cam 档的模糊和。
2. §2.3 已经显示，没在 cam 上训练的 NETR 在 cam 档就比源端放置高 2–4 pp，比 LIN 高 7 pp。也就是说读出端确实有这个杠杆，只是还没被训练去用。
3. E3-C 不学配准器，不改位姿 stalk，也不改 GBP。它只换读出的训练分布，底线风险为零。
4. **风险**：它学到的是模拟器的机间误差分布（5 cm / 1°），又是一个合成世界专属的先验。所以要报告 lidar（3 cm / 0.5°）、harsh（10 cm / 2°）上的读数，并保护 cam_nf 与 clean。

**不在用户答复前用掉第 3 个租约。** 它的候选有：H-B（若 H1 有害）、E3-C 的后续（若 E3-C ambiguous），或用户选定的方向。

## 6. 下一批的预注册草案

### 草案 A：G4-H1 留出家具类别面板（CPU，0 个租约，只用现有 E3-R 检查点；与 R-A 的 H-A 合并，以 R-A 的生成器细节为准）

- **问题**：E3-R 的读出先验在生成器没见过的家具形状上，是否仍不劣于零学习的 B6？是否把新形状"盒子化"，即产生幻觉？
- **单变量**：测试世界的家具形状分布。其余照 E3-R：v420 网格、cam_nf、8 机、森林、B6 表、两个检查点与阈值。
- **生成器变体**：新文件，只 import v420、替换家具库，不改 v420。平面、占地比例和放置规则不变。三档：
  - H1-rot：原库，整体绕 z 轴旋转 15–40°（v420 只有轴对齐）；
  - H1-new：TRAIN 没有的原语，包括球或椭球、斜面、L 形转角沙发、细杆衣帽架（杆宽 2–3 cm）；
  - H1-ctrl：原库，新的世界种子。
  - 每档 24 房（r1 / r2 / r3 各 8），平面取 VAL，噪声种子 1、2，不碰 TEST。
- **对照**：同一地图上的 B6_A / B6_B 线性读出。
- **指标**：R8 与 K0 家具 F1（精确与容差 1）、空闲召回、表面 F1，按 k 与高度分层；已知区内 FP / FN 体素数；新原语附近 2 体素内的 FP（幻觉）单列。
- **判据**（2 个检查点 × 2 个噪声种子，4 格都要满足；H1-rot 与 H1-new 各判一次）：
  - **安全**：NET − B6 ≥ 0 pp；空闲召回 ≥ B6 − 0.5 pp；新原语附近的 FP ≤ B6 的 1.0 倍。
  - **有害**：任一格 NET − B6 < −1 pp，或新原语附近的 FP > B6 的 1.2 倍。
  - 其余 ambiguous。
  - H1-ctrl 必须复现 VAL 的 +6.8–7.1 pp（±1.5 pp），否则判 INCONCLUSIVE（变体生成器有 bug）。
- **预测** [估计]：H1-rot 为 +2 到 +5 pp；H1-new 为 0 到 +3 pp，细杆处 FN 可能上升。判"有害"的概率约 .15。
- **后果**：
  - 安全 → NET 读出成为默认，对外表述限定为"在两类形状分布下不劣于零学习"；E3-C 可以发射。
  - 有害 → 默认退回 B6 线性读出；E3-C 推迟；第 3 个租约优先给 H-B（带形状增广重训）。
  - ambiguous → 默认仍用 NET，但每个报告都并列 B6；E3-C 可以发射，但其预注册要把 H1 读数列为保护项。

### 草案 B：E3-C 读出端在主档 cam 上训练（5090，第 2 个租约；H1 出结果后、预注册加代码审查后才发射）

- **问题**：读出端学习先验见过带机间误差的融合证据之后，能否在主档收回一部分不可观测的错位损失？
- **底线**：与 E3-R 相同。stalk、求和、来源断言、已知掩码（= k > 0，与 B4 逐位相同）都不变；网络只读 (S, k, z)，用一次；三条不变量测试（§1.3）写进单测。
- **单变量**：训练数据的档位组成。
  - E3-R：clean 10 % + cam_nf 90 %；
  - E3-C：clean 10 % + cam_nf 45 % + cam 45 %。cam 用 L_pub（公共坐标系、无配准），与 VAL 判决时的输入相同。
  - 其余逐项照 E3-R：网络、步数 40,787、批量、学习率、TRAIN 186 + 19 留出、噪声种子 200–202（cam 档另取 203–205，与保留种子不相交）、两个训练种子、证据表 B6_A / B6_B。
  - 阈值规则：在留出房的 cam 与 cam_nf 合并分量和上选（家具 F1 最大，空闲召回不低于线性读出，同分取最小）。
- **为什么不带配准**：E4 的收回只有 .15 / .34，并且它与读出边缘化不可加。为保持单变量，判决用无配准输入，"E4 位姿 + E3-C"作只报告行。
- **对照**：NETR（E3-R 冻结检查点及其阈值），同一批 VAL 地图。
- **判据**（VAL，R8 家具，2 个训练种子 × 2 个噪声种子，4 格都要满足）：
  - **杠杆**：
    - cam 档 NETC − NETR ≥ +3 pp；
    - 保护项：cam_nf 档 NETC ≥ NETR − 0.5 pp；clean 档 ≥ .99；cam 档空闲召回 ≥ NETR − 0.5 pp；cam 档表面 F1 ≥ NETR − 0.5 pp；未知→已知 FPR 逐位相同（断言）；训练未截断；H1 面板上 NETC ≥ NETR − 1 pp。
  - **不够**：任一格 cam 档 NETC − NETR < +1 pp。
  - 其余 ambiguous。fresh 只报告，4 格均值的符号与 VAL 相反时降为 ambiguous。
- **只报告**：
  - 容差 1 的家具 F1（区分"折中边界"与"真对齐"）；
  - lidar、harsh 档（检验它是否只学到 5 cm / 1° 这一个误差分布）；
  - "E4 位姿 + NETC"；
  - 按 k 与"跨岛 / 单岛"体素分层；
  - 校准斜率。
- **出结果前的预测** [估计]：
  - cam NETC − NETR ∈ [+1, +4] pp，P(杠杆) ≈ .3；
  - 增益集中在 k ≥ 2 且来自不同岛的体素，单岛体素约 0；
  - 容差 1 的增益小于精确 F1 的增益；
  - cam_nf 变化在 [−0.5, +0.2] pp。
- **后果**：
  - 杠杆 → 读出先验默认用 E3-C 的配方；"四个一"不变，只改训练分布。
  - ambiguous → 默认仍用 NETR，E3-C 的读数写进主档报告；不追加租约。
  - 不够 → 主档的剩余损失定性为"观测设计问题"，交给用户（重叠或会合）；不再为它排 GPU。
