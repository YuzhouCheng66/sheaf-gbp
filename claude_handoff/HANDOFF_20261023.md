## 5. 已确立的结论（各有预注册判据，详见报告）
- 瓶颈 1：**码容量密度**——落在房子上的块数。贴合图幅带来 +10 pp。更多 bit 没有用（16 bit 时上限不变）。矩形图幅的增益不显著（安慰剂噪声与效应同量级），所以保留方形。
- 瓶颈 2：**解码器先验受数据限制**——600 → 7,200 套户型带来 +5 到 +10 pp；7,200 → 14,400 已基本饱和。
- 瓶颈 3：**训练不足**——4 轮比 3 轮 +1 到 +2.5 pp，第二周期再 +2.4 pp，**尚未饱和**。
- 最大精度融合**不丢信息**：理想同态（直接编码并集观测）与实际 R8 相差 ≤ 0.4 pp。
- 运行间噪声：同一配方不同训练运行约 ±1–2 pp；O 批的安慰剂组甚至达到 −5.9 到 +2.1 pp。判据一律要求两个种子都过。
