# 多机潜在世界模型：最小决定性实验设计（草稿，2026-10-28，未实现、未发射）

依据：`reports/多机潜在世界模型空白与基准.md`（深度调研，笔记在 `research_notes/多机潜在世界模型空白与基准/`）。本稿等用户认可后才定稿为预注册，再实现、独立审查、确认算力。

## 1. 要回答的问题

调研的结论是：没有人把"编码器给出 (z_i, 对角 Λ_i) + 二次 sheaf 能量 + 精确 GBP + 读融合后潜状态"放在一起。但每个部件单独都有先例，所以新意只能落在组合带来的可测性质上。本实验只回答一个问题：

> **在一个刻意构造、使"通信必不可少"的多机部分可观测动态世界里，每台机器一个 256 维学习潜向量、经 sheaf-GBP 达成共识后，能否在同字节下做到：**
> 1. 比不按精度融合好（精度有用）；
> 2. 比会重复计数的迭代融合好（GBP 的精确性有用）；
> 3. 接近集中式上界；
> 4. 不做丢包增广也比学习式通信更耐丢包（概率结构带来的鲁棒性）？

这四条正好对应方法区别于 MAMBA、DCWM、TarMAC、LatentToM 的地方。只在"F = I、单跳、无丢包"下赢了平均，不算成立（调研报告结论）。

## 2. 世界（自写的二维模拟器，约 200 行 PyTorch，CPU 生成数据）

选自写而不用 VMAS：四个必需条件要能逐个控制，代码 Occam，也没有许可问题。

| 条件 | 实现（写死） | 为什么需要 |
|---|---|---|
| 互补部分可观测 | 长廊 20 m × 4 m；N = 8 个固定观测者排成一行（x = 1.25 + 2.5 i），视野半径 1.6 m，相邻视野只略有重叠，每台机器只看到约 1/8 | 让"集中式 − 无通信"的差距足够大 |
| 记忆无法替代通信 | K = 6 个带身份的球，速度 0.5–2 m/s，与墙和彼此弹性碰撞，dt = 0.1 s；每步以 2 % 的概率瞬移到随机位置、换随机速度 | 排除"靠自己的历史就能推断"的捷径 |
| 精度有信息量 | 每台机器的传感器档位 σ_i ∈ {0.02, 0.1, 0.3} m，每局随机，并随距离增大：σ = σ_i(1 + d/r)；档位作为输入给编码器 | 让"按精度加权"可能优于平均 |
| 多跳 | 通信图是链（只和相邻机器通信），直径 7 | 单轮邻居聚合拿不到远处信息 |

- **观测**：视野内每个球给出（身份 one-hot、带噪位置）。没有像素，像素留到第二阶段。
- **一局**：40 步，前 10 步只作热身，不计分。
- **预测目标**：每台机器从自己融合后的 x_i,t 解码出全部 K 个球在 t、t+5、t+10 步的世界坐标位置。这就是"世界模型"的预测头。动作与规划留到第二阶段。
- **数据**：TRAIN 2 万局，VAL 1 千局（判决用），fresh 1 千局（降级检查），TEST 封存、不生成。

## 3. 模型（所有臂共享骨架，一次只改融合方式）

- **编码器（每台机器各自运行，只吃本机观测）**：每个检测过 MLP(64) → 求和池化（与顺序无关）→ GRU(256) → 两个头：z_i,t ∈ R^256，以及 log λ_i,t ∈ R^256（λ 夹在 [1e-3, 1e3]）。编码器输出的是证据（后验 ÷ 先验）。先验 N(0, λ0 I) 只计一次，在每个节点上以 λ0/N 的份额出现。
- **能量与融合（S1）**：
  - E = Σ_i ½(x_i − z_i)ᵀΛ_i(x_i − z_i) + Σ_(i,j)∈链 ½ w‖x_i − x_j‖²；F = I，w 可学。
  - 训练时直接解 (Λ + wL)x = Λz：在树上这与精确 GBP 等价，梯度也精确。
  - 评估时真的逐条发 GBP 消息（每条 256 均值 + 256 精度，fp16 共 1 KB），这样才能测丢包和时延。
- **时间维的规则**（调研报告的障碍 1）：融合结果 x 只交给解码器读，**不回灌**进本机 GRU。这样每个时刻都是一个独立的树上问题，精确性保留。
- **解码器**：MLP(256 → 256 → K × 3 个时刻 × 2 维)，所有机器共享。
- **训练**：MSE 对真值位置，对全部机器取平均。Adam 3e-4，3 万步，batch 128 局，种子 342101 / 342202。

## 4. 对照臂（6 个要训练，加 1 个不训练的核对）

| 臂 | 融合方式（唯一的变化） | 检验什么 |
|---|---|---|
| B0 无通信 | w = 0，每台机器只用自己的 z | 下界 |
| B1 等权共识 | 同 S1，但 Λ ≡ 1（去掉精度头） | 精度有没有用 |
| B2 迭代 PoE | 每轮每台机器把自己的证据乘上邻居的**当前信念**，共 R 轮；会重复计数；同样端到端训练 | GBP 不重复计数这一点有没有用 |
| B3 学习式通信 | R 轮注意力消息（TarMAC / GATv2 式），每条 512 个 fp16 数，与 S1 同字节；训练时随机丢 30 % 消息 | 与学习式通信的公平对照 |
| B4 集中式上界 | 全部机器的检测进同一个编码器 | 上界 |
| **S1 Sheaf-GBP** | 如上，F = I，学到的对角 Λ，w 可学 | 本方法 |
| C 同能量的集中式解 | 用 S1 的编码器直接解 Jx = Λz，不训练 | 代码核对：无丢包、R ≥ 直径时 S1 必须与 C 逐数一致（断言） |

- 所有臂同编码器、同解码器、同数据、同步数、同正则。
- R = 7（链的直径）。评估丢包时最多给 21 轮，每轮重发最新消息。

## 5. 指标

- **主指标**：解码位置误差 E（全部机器、全部球、h ∈ {0, 5, 10}，t ∈ [10, 40)）。用"恢复的差距比例"报告：R_X = (E_B0 − E_X) / (E_B0 − E_B4)。
- **只报告**：
  - 本机视野外的球的误差，这是"知道自己没看见的东西"的本质读数；
  - 各机器解码结果之间的离散度（一致性）；
  - 后验 NLL 与 1σ / 2σ 覆盖率；
  - 每局总字节；
  - 以下鲁棒性曲线**只在评估时扫描，不重训**：丢包 0–90 %；时延 0–5 步（比较"不降权"与"按动力学放宽精度"）；N = 4 / 16（训练在 N = 8）；
  - 边残差 ‖x_i − x_j‖。

## 6. 判据（草案；VAL，两个种子都要过）

**第 0 阶段：只训 B0 与 B4。**
- **P0（门槛）**：E_B0 − E_B4 ≥ 0.4 · E_B0，并且 ≥ 5 倍于两个种子之间的 |ΔE_B0|。不过就停止，先改世界再说，其余的臂一个都不训。

**第 1 阶段：其余臂。**

| 编号 | 主张 | 门槛 |
|---|---|---|
| P1 | 精度有用 | R_S1 − R_B1 ≥ 0.10 |
| P2 | 不重复计数有用 | R_S1 − R_B2 ≥ 0.05，且 S1 的 2σ 覆盖率在 [0.90, 0.99] |
| P3 | 接近集中式 | R_S1 ≥ 0.80 |
| P4 | 同字节下不输学习式通信 | 无丢包时 R_S1 ≥ R_B3 − 0.05 |
| P5 | 不增广也耐丢包 | 丢包 50 % 时，R_S1 的下降 ≤ 0.05，且 ≤ B3 下降的一半 |

- **判决**：P1–P5 全过 → **LEVER**，进入第二阶段。P1 或 P3 不过 → **NO**。其余 → AMBIGUOUS。缺任务、C 核对断言失败、sha 不符 → INCOMPLETE。
- **降级**：fresh 面板上 R_S1 比 VAL 低 0.05 以上 → 最多判 AMBIGUOUS。
