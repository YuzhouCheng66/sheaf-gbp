Sheaf-GBP multi-agent mapping

Eight agents, each limited to 64 Gaussian variables and 64 precisions. Agents random-walk inside their own rooms or corridor segments; neighbours within 5 m exchange their sheaf vectors every 6 steps; the decoder reads only the fused posterior.

Each run is a real simulation of the sealed v293 world family with the trained ldynft-s342202 model (H128): v293 first-hit sensor (256 beams, 5 m), hard-8 codes, profile-4 wire, max-precision join with per-agent CRDT memory. Runs were precomputed on the GPU host and exported as RLE maps; this page only plays them back.
